# DEC-014 项目记忆组件立项决策

本决策成立项目记忆组件的立项即组件名册第六席，承接 PRO-008 推导档与 2026-08-27 用户 A案裁定与 pk-017 出泊转正，契约面落 SPEC-007 即接口冻结与验收判据前置。本决策只裁立项与名册与措辞处置，实装归实装批另开待令。

## 概览 {#overview}

- 立项成立即项目记忆为直接治理动作组件第六席，定位五档已沉淀物的检索面激活，只报不判::[决策集](#decisions)
- 契约先行即 SPEC-007 冻结 recall 接口与验收判据八条，本批零代码::[决策集](#decisions)
- 向界措辞处置即 GOV-003 出 v1.1 承载组件六，GOV-002 冻结文本零字节改动::[向界措辞](#wording)
- 第六席与退出标准五条的关系未决停泊即 pk-024，里程碑结算时由用户裁::[向界措辞](#wording)

## 决策集 {#decisions}

### 立项成立 {#establishment}

项目记忆为组件名册第六席即直接治理动作组件。定位即五档已沉淀物在治理动作需要时的检索面激活，五档即事实档书简产、结论档结算产、经验档 ai-ex 产、悬置档泊界产、意图档三问产。职责边界四条即检索不产内容、只报不判、非全新存储即五档载体权威地位不动、底座只读调用。四判据承接 PRO-008 过堂即承接命题成立、明确接口随本决策升格为冻结、可插拔成立、最小原子经 A案裁定为组件承载。

### 契约先行 {#contract-first}

接口与验收判据以 SPEC-007 冻结。操作名 recall 随契约冻结即按主题或事件或时段取五档切面清单带出处，宿主命令名待实装批立名，宿主名落定不构成接口变更。验收判据八条前置为实装批 F 锚定来源。实装批承 DEC-013 第一步纪律即 SDD 规格先行落差钉死与 TDD 先红后绿，语言与家位承 DEC-007 归属判据落 src。消费侧三处即三问前向约束的检索加载、批次起草时的先例检索、段结算时的结论档回取，在 SPEC-007 声明为消费面，接线归后续批。

### 工作名 {#working-name}

项目记忆为工作名，承 pk-017 泊位条目与 PRO-008 推导与用户批令的一贯用词。正式立名与词条登记待人节点，本决策不默写。

## 向界措辞 {#wording}

GOV-003 追记 v1.1 三件即组件名册五改六、pk-015 句随出泊闭项改写、pk-024 停泊登记。GOV-002 冻结至里程碑结算即本批零字节改动，退出标准五条不改写，组件第六席不入退出标准清单。第六席与闭合判据的关系停泊 pk-024，出泊条件即主线里程碑结算时由用户裁第六席是否入闭合判据，不默写不预裁。

## 决策后果 {#consequences}

- pk-017 闭环完成即推导、审议、出泊、立项四段全走完
- pk-024 进泊即第六席与退出标准关系显式登记
- 实装批待令可开工即 SPEC-007 为其 SDD 输入

## 备选方案 {#alternatives}

B案视图先行实装与 C案消费侧约定经用户审议裁定弃，推导与裁定记录在 PRO-008，本决策不重开。

## 关系图谱 {#graph}

本决策上承 PRO-008 与 pk-017 出泊转正，侧承 DEC-007 层级归属判据与 DEC-013 契约先行纪律与 DEC-006 三问组件先例，下接 SPEC-007 契约与实装批与 GOV-003 v1.1。

## 认识论立场 {#epistemic-stance}

立项是名册治理动作不是功能承诺。组件对全态的贡献由两处分别承载即验收判据冻结于契约、闭合关系停泊于人节点，承诺不冒充完备承期票纪律。

## 版本与固定 {#version}

v1 即 2026-08-27 承用户立项批令成立，随立项批 mem-init-t6d 落盘。修订须走修订记录节逐条留痕。
