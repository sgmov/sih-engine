# DEC-011 锁本体立项与任务包匹配决策

本决策将两把锁立项为能力外切，裁定 worktree 与两把锁的任务包匹配机制，并承载 DEC-009 预告的终裁三对象与 DEC-010 预告的两项留裁。承用户 2026-08-25 开工令即开 worktree 和两把锁要和任务包匹配。2026-08-26 用户签署生效，五件建议原文转为裁定。立项与匹配与工具实装为已发生事实照实登记。

## 概览 {#overview}

- 锁本体立为能力外切即 sih-tools/locks 工作名 locks，四子命令，悲观链五验加乐观链基线验::[立项与形态](#decision-locks)
- 任务包匹配即写入范围第一源为任务包请求写入段，会话档机械承接，锁位范围验以此为准::[任务包匹配](#decision-matching)
- 终裁三对象即 commit 治理边界与 SETSP pre-commit 取舍与 lease 归属，2026-08-26 用户签署生效::[终裁一](#final-commit)

## 决策集 {#decisions}

### 锁本体立项与形态 {#decision-locks}

决策内容
: 两把锁立为能力外切，施工地 sih-tools/locks 即工作名锁本体／locks，命名次序问裁未答默认工作名先行承工地外壳先例。四子命令即 acquire 取锁、release 放锁、status 查锁、check 验基线。悲观链五验序固定即在册验加会话择定加范围验加身份验加绑定验，五验任一失败即拦退出码一，理由码入报告。乐观链吃级联边册与书简链，脏上游拦，unverified 不拦承有度，不在册过注记承误边方向拦多不拦漏。锁台账追加即唯一写点，零 LLM。

决策理由
: 承外切孵化环第一步判据四条即通用、纯确定性、可跨仓复用、可带退出码。正身留痕不签与锁位执行即拦的分工承 DEC-010 后果即锁语义随 worktree 加 2locks 批承载，本案即该承载。契约先于本体承孵化纪律即 sih-tools/locks/CONTRACT.md。

### 任务包匹配 {#decision-matching}

决策内容
: worktree 与两把锁以任务包为匹配源。写入范围第一源为任务包请求写入段即二级标题含请求写入字样下的列表项，工作区根相对路径，条目精确或目录前缀。工地外壳开工时机械读取该段为会话档 allow，台账记 scope_source 即 package 或 explicit。锁位范围验以会话档 allow 为准，范围外写入即拦。任务包模板与 README 增该段约定。

决策理由
: 承用户 2026-08-25 开工令原话即开 worktree 和两把锁要和任务包匹配。机械读取替代调用方自报即写入范围的可审计来源从声明降为件内事实，范围验的判据与任务包同源即人节点审批一次全链生效。

### 终裁一 commit 治理边界 {#final-commit}

决策内容
: commit 资格判据定为提交时持有效会话且提交路径全落会话范围。实现分两期，手动阶段维持内在自限即选择性暂存纪律与提交信息承载批次与事件哈希不变，锁台账为事后审计对表件不设 git 拦截面；引擎融回后 commit 闸门接锁即资格机械判定，锁态与管线绿态同为准入条件。

决策理由
: 围堰工具无权改 git 配置面，外加拦截面在引擎落地前是纸面锁承 DEC-009 当前阶段原则的精神延续。判据先行即判据入档后审计可对表，拦截面后置不损判据的约束力。

### 终裁二 SETSP pre-commit 取舍 {#final-precommit}

决策内容
: 取 SETSP WorktreeSession 生命周期语义即开工起工地、收工拆工地，弃其仓内 pre-commit hook 形态即围堰期不实装 git hook，接线位留引擎侧 commit 闸门承终裁一两期安排。

决策理由
: SETSP 为沉默参考不含设计继承，取舍判据即拦截面属于谁的职权。围堰期 hook 挂在仓库配置上即工具越权改仓，引擎期闸门挂在引擎写入位即职权对位。

### 终裁三 lease 归属 {#final-lease}

决策内容
: FileLease 语义归位悲观锁即 acquire 与 release 为租约的取放形态，TRAE 时代 acquire_lease 与 release_lease 两 Tool 不承接。trust_score_threshold 字段不随迁即置信度归度量服务线承 DEC-007，锁不耦合信任分阈值。

决策理由
: 承 DEC-009 lease 归属随终裁定。锁的对象是路径与范围，信任分是度量对象，字段耦合会使锁的判定依赖未落地组件即纸面耦合。SETSP 该字段为沉默参考不继承。

### 留裁一 稳定子集 {#stable-subset}

决策内容
: 本地壳语境绑定稳定子集定为三件即 hostname 加 user 加 boottime。pid 与 ppid 与 ancestry 限同瞬对表即不承载跨时绑定，mac 不入绑定，侧档载三件不入版控不进台账。

决策理由
: 承 DEC-010 适配点留裁。本地壳即每调用新建进程族，跨时可比件止于机器与登录会话层，进程级件跨时必变即绑定误伤。重启即 boottime 变即拦，属设备更替类漂移走人节点申诉重开工零惩罚。mac 属硬件标识不入持久件承隐私裁定。

### 留裁二 会话标识承载 {#session-bearer}

决策内容
: 会话标识承载定为会话档为主环境变量为辅即混合。工地外壳会话档为权威载体，锁位只认台账。正身 SIH_SESSION_ID 环境变量读取位保留为轻量通道，供同瞬对表与未来引擎注入。

决策理由
: 承 DEC-010 候选三选一。纯环境变量即声明式无台账可审计，纯会话档即每次调用须查册，混合即权威在档通道在变量，两极各取其长。

### 命名空间 {#pro-namespace}

决策内容
: 级联引用抽取的 PRO 族映射限引擎域内文件，哲学仓 PRO 引用一律入注记不建边。现状追认即首跑无主注记十八件中 PRO-008 与 PRO-010 属哲学命名空间。

决策理由
: 引擎 PRO 与哲学 PRO 同形异域，跨域建边会使引擎级联误拦于哲学仓变更即域外脏源。注记不建边即保守方向承误边失败方向拦多不拦漏。
