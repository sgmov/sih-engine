# 阶段 0 旧数据认识论判定加意图声明判定

## 概览 {#overview}

本决策包含两个独立子项判定,均为阶段 0 关键路径阻塞点。

子项一,旧 Phase 2 实验数据在偏离率新范式下的认识论地位,三选一:可复用或部分复用或不可复用。

子项二,参验语义层是否消费意图声明(intent_declaration),二选一:消费或不消费。若不消费,SPEC-003 第 25 与 26 与 31 与 39 行接口签名须修订;若消费,DES-009 第五层须补符号材料与意图声明对照层。

决策结构:决策内容含两子项各自判定与理由,决策理由提供支撑依据,关联规则列出上下游文档。

## 子项一 旧数据认识论 {#old-data-epistemology}

### 判定 {#old-data-verdict}

判定:部分复用。

旧 Phase 2 全量实验数据(263 文档,1052 sessions,7392 条判断记录)在偏离率新范式下,部分可复用,核心度量数据不可复用。

### 可复用部分 {#reusable-parts}

第一,263 份文档集与八大类型分层。DES-005 v2 §十一 v1 归档段已明确,文档集与类型分层从 v1 沿用至 v2,无需重新构建。

第二,失败标记文档清单十份。DES-005 v2 §四 分层与交叉段已明确,十份来自旧仓失败复盘的文档从 v1 沿用。

第三,采样协议的中立性要求与可复现性五要素。DES-005 v2 §十一 v1 归档段已明确,模型版本锁定与温度锁定与 prompt 版本化与记录格式锁定与文档集锁定从 v1 沿用至 v2。

### 不可复用部分 {#non-reusable-parts}

第一,N=4 隔离采样协议。DES-005 v2 §十一 v1 归档段已明确标注为废止,多族群隔离采样在本仓开源合规约束下不可行,被多次审阅偏离率机制取代。

第二,判断分布方差数据与 7392 条判断记录。Phase 2 数据的度量指标是判断分布方差与基础置信度,偏离率新范式的度量指标是 K/N 与波动系数与 Jaccard,两者数据模型不兼容,不可换算。

第三,置信度公式。Phase 2 用基础置信度等于判断为存在次数除以总采样次数,偏离率新范式用偏离率两态置信度,DES-005 v2 §五 置信度公式段已重写。

第四,审阅单元结构化数据。Phase 2 的 7392 条记录是 N=4 判断分布的聚合统计,不符合 DES-005 v2 §三 审阅单元段定义的 stable_id 与 target_id 与 kind 与 severity 与 reason 六字段结构,不能作为偏离率度量的直接输入。

### 不可复用根因 {#non-reusable-root-cause}

v1 与 v2 是实质性重写而非版本迭代。DES-005 v2 §概览段明确重写动因三条:合规约束下隔离采样不可行,LLM 度量违反工程基线第五条,偏离率度量取代判断分布方差。三条重写动因均属结构性,不修复。

### 阶段 8 依赖说明 {#phase-8-dependency}

阶段 8 即 SPEC-001 偏离率阈值实验,数据依赖仅复用可复用部分,即文档集与类型分层与失败标记清单与可复现性五要素。不可复用部分须重新实验收集,DES-005 v2 §十二 v2 标定数据空缺段列明波动系数阈值与 Jaccard 阈值与漏判率上限与审阅频次上下限与版本漂移差容忍度共五项参数待新实验填入。

## 子项二 意图声明判定 {#intent-declaration-verdict}

### 消费判定 {#intent-consumption-verdict}

判定:消费。

参验语义层消费意图声明,不消费时语义对应性检查无法成立,接口签名无需修订。

### 消费判定的事实依据 {#intent-consumption-basis}

第一,SPEC-003 §二 路径二入口段第 39 行明确,路径二入口接收 intent_declaration 参数,三处接口签名均含此参数,参验语义层在协议层接收意图声明。

第二,SPEC-003 §三 语义判断材料段第 71 行,判断值取值因检查项而异,承接语义对应性取对应或过度承接或不对应或不确定。语义对应性检查项的判断逻辑是符号材料是否与意图声明对齐,若不消费意图声明,语义对应性无法判定。

第三,DES-009 §五 第五层 Verifier 与偏离率段第 72 行,Verifier 判定节点内文本语义质量,判定结果切分为审阅单元指向产出物的语义单元节点。语义质量判断隐含地以意图声明为参照系,Verifier 若无意图声明,语义对应性检查失去参照。

第四,DES-005 v2 §一 核心问题段,偏离率新范式的语义对应性检查以材料与意图声明的偏差为度量对象,意图声明是偏差判定的必要参照。

### 不消费的降级风险 {#non-consumption-risk}

若语义层不消费意图声明,则只能检查材料自身的内部质量(论证自洽性),无法检查材料与意图的对齐度(语义对应性),路径二的校验能力降级为节点内质量检查,不符合 SPEC-003 与 DES-009 的设计承诺。

### 接口签名修订方案 {#interface-revision-scheme}

本判定结论为不修订。理由:SPEC-003 第 25 行主入口、第 31 行路径一入口、第 39 行路径二入口三处接口签名均已完整声明 intent_declaration 为输入参数,无需增加或修改参数签名。若判定为不消费,则三处接口签名须移除 intent_declaration 参数,本判定为消费,故不触发修订。

### DES-009 第五层表述确认 {#des-009-layer-confirmation}

DES-009 §82-94 路径二细分段未显式声明 Verifier 消费意图声明,只隐含于语义对应性检查项中。本 DEC 确认:语义对应性检查项依赖意图声明作为参照,DES-009 第五层的 Verifier 设计在语义上消费意图声明,表述上可通过本文档补强,不触发 SPEC-003 接口修订。

## 决策理由 {#decision-reasoning}

### 子项一理由 {#reason-sub1}

第一,设计继承关系已由 DES-005 v2 §十一 归档段明确划定。v1 的可继承部分与不可继承部分已在归档段清晰区分,本 DEC 不引入新的划分,只显式确认既有划分在偏离率新范式下的认识论地位。

第二,数据模型不兼容是实质性障碍。Phase 2 数据是判断分布统计,偏离率新范式需要审阅单元结构化数据,两者不可换算,硬复用等于伪造数据,违反工程基线第四条可验证性约束。

第三,阶段 8 实验复用可复用部分是效率最优路径。重新收集 263 份文档的偏离率数据成本极高,复用文档集与类型分层与失败标记清单可大幅降低阶段 8 实验的前置成本,同时不损失数据纯度。

### 子项二理由 {#reason-sub2}

第一,语义对应性检查项的定义要求参照系。若语义对应性判断值取对应或过度承接或不对应或不确定,则判断逻辑本身以意图声明为参照,语义层在功能层必然消费意图声明。

第二,若判定为不消费,路径二校验能力将降级为节点内质量检查,不符合 SPEC-003 与 DES-009 的设计承诺,且须触发 SPEC-003 三处接口签名修订,成本高于维持现状。

第三,SPEC-003 三处接口签名均已声明 intent_declaration 为输入参数,不存在接口签名缺失问题。DES-009 第五层描述不清晰可通过本文档补强确认,不必触发接口修订。

## 认识论立场 {#epistemic-stance}

本决策为设计推论( design-corollary )。两子项判定均属工程设计选择,非逻辑必然。

可证伪条件一:若阶段 8 实验数据显示旧数据直接可用(即可换算或可直接作偏离率数据),则部分复用判定被证伪。

可证伪条件二:若后续工程实践发现语义对应性检查不依赖意图声明即可成立,则消费判定被证伪,SPEC-003 接口须修订。
