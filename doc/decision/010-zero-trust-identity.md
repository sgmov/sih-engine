# DEC-010 零信任身份验证立项决策

本决策将零信任身份验证立项为能力外切，定型身份串规范与留痕不签边界，判定层级归属为基础设施层。承 2026-08-25 用户令即切一个 sih-tools 做零信任身份验证开发，与同日会话设计输入即盐哈希身份无令牌。实证先例承旧仓 2026-07-22 trail 身份哈希三事件与 PRO-036 身份三重验证提案，沉默参考不含设计继承。

## 概览 {#overview}

- 立项形态为能力外切即通用确定性能力切出围堰施工，施工地 sih-tools/identity 工作名待立名::[立项与形态](#decision-cutout)
- 身份串定型承旧仓实证即组件七件加盐 SHA-256，协议留痕不签::[身份串定型](#decision-identity)
- 层级归属判基础设施层即不承接哲学命题且提供运行前提，pk-014 出泊条件随之满足::[层级归属](#decision-layer)
- 适配点即本地壳语境稳定子集取法随锁批上裁，本案不预判::[决策后果](#consequences)
- 备选方案两条已拒即仓内实现与令牌凭证::[备选方案](#alternatives)

## 决策集 {#decisions}

### 立项与形态 {#decision-cutout}

决策内容
: 零信任身份验证立为能力外切，施工地 sih-tools/identity，工作名运行待立名签署。判据四条全中即通用、纯确定性、可跨仓复用、可带退出码。验证器即被调子进程，身份即其可亲自观察的父链与环境，pid 与 ppid 由内核分配用户态不可伪造。

决策理由
: 承外切孵化环第一步，2026-08-25 用户令直接裁定。验证器站在子进程视角即调用方对自己的子进程撒不了父链的谎，无被签发物即无被盗用面。名称待立名承孵化纪律，登记前以工作名运行。

### 身份串定型 {#decision-identity}

决策内容
: 身份串规范名 identity_string_v1，组件七件即 pid、ppid、hostname、user、sandbox_id、session_id、timestamp，键序固定，身份串前缀 v1 加竖线、键等值竖线连接、缺席即空串。哈希即 SHA-256，输入为盐串竖线身份串，盐为随机三十二字节十六进制。自报走确定性通道即声明文件，不走对话文本。声明键域限 timestamp 外六件。留痕不签边界即验证结果只进报告与 trail，不阻断治理动作，失败是观察材料不是裁决。

决策理由
: 承旧仓 2026-07-22 trail 三事件实证即 HASH-PID-2026-07-22 与 HASH-PID-DEMO 与 IDENTITY-HASH-2026-07-22，组件集与盐规格照录。留痕不签承旧仓 PRO-036 即验证只反映事实不预设身份真假，失败即阻断会使失败动作失去失败本身的证据。时间戳作新鲜度，盐作防重放即生产哈希逐次不同。

### 层级归属 {#decision-layer}

决策内容
: 融回落点判基础设施层。判据组合即不承接哲学命题且提供治理运行前提，身份验证为锁件与治理写入提供身份运行前提，不承接任何哲学命题的工程职能。

决策理由
: 承 DEC-007 四条判据组合。身份验证属 DEC-007 已登记五实例之外的新形态，本案即该新形态的归类 DEC。pk-014 出泊条件即基础设施待判定子项新形态出现时立 DEC 判定归类，本案成立即条件满足，出泊唯人节点待裁。

## 决策后果 {#consequences}

- pk-014 出泊条件满足，出泊待用户裁，裁即转正或废弃
- 适配点留裁：本地壳语境稳定子集取法，会话标识承载候选即环境变量声明式、worktree 开工落盘会话档、两者混合，随 worktree 加 2locks 批上裁
- 本案只产验证器，乐观锁悲观锁的强制位不在本案，锁语义随 worktree 加 2locks 批承载
- DEC-009 终裁不随本案触发，仍锚 worktree 与 2locks 立项时点

## 备选方案 {#alternatives}

仓内直接实现
: 已拒。围堰纪律即孵化期治理自治经手动调用验证后再融回，仓内实现跳过验证窗。

令牌凭证
: 已拒。签发即存在被复制面，需签发与吊销设施，且持有不等于环境事实。盐哈希身份无被签发物，验证器以子进程视角亲自观察，较令牌更彻底符合零信任。

## 认识论立场 {#epistemic-stance}

本决策为设计推论，非哲学承接，零信任为工程原则表述非哲学命题引用。

可证伪条件一
: 若组件采集在同类环境出现不可复现的观察偏差，即同进程同刻采得不同父链，观察前提失效，本案须重审。

可证伪条件二
: 若留痕不签边界被突破，即验证失败导致任何治理动作被阻断，边界失效，本案须重审。

可证伪条件三
: 若身份串规范形不稳定，即同组件同盐产不同哈希，哈希承载失效，本案须重审。
