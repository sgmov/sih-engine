# DEC-012 git commit 全面接管决策

本决策承接 GOV-004 git commit 司衡接管向界，承载七件裁决即接管域与通道唯一、信息机械生成、提交界与认证门同界、手动期升格、主线历史粒度、历史不可改起点、反绕行机制。承用户 2026-08-26 对接管建议方案的批准即六待裁点全按建议定案，承 DEC-009 终裁时点即 worktree 加两锁启动时一并定。本决策与 GOV-004 v1 于 2026-08-26 经用户同批签署生效，双签时点即治理域历史不可改起点。

## 概览 {#overview}

- 接管域即租约在册域现两仓，worktree 新建销毁唯一合法通道即 lease open 与 close，直改正本检出即违例::[裁决一](#decision-domain)
- 信息机械生成三形态即段内检查点、段结算、收约归并，偏离行唯一半自由位::[裁决二](#decision-message)
- 提交界与认证门同界即一段一结算，管线绿加认证落链为前置，禁 amend 与 rebase::[裁决三](#decision-rhythm)
- 手动期升格即提交执行权交 lease commit 与对表两子命令，显式修订 DEC-011 终裁一内在自限款::[裁决四](#decision-manual)
- 主线历史粒度即归并保留分支全史即现行为追认::[裁决五](#decision-granularity)
- 历史不可改起点即双签时点，签署前压缩为人类最后整理权::[裁决六](#decision-immutability)
- 反绕行即正身路径唯一加三方对表，绕行提交对表露形::[裁决七](#decision-bypass)

## 决策集 {#decisions}

### 裁决一 接管域与通道唯一 {#decision-domain}

决策内容
: 接管域为租约在册域即当前 sih-engine 与 sih-tools，未开租约的仓不在域内。域内 worktree 新建与销毁唯一合法通道为 lease open 与 close，open 起副本记基准分支，close 三检即锁清零、归并、拆本。治理域内直改正本检出即违例。编辑位迁移即治理文档编辑一律入副本，并入本裁决为其第一批真实用户。

决策理由
: 域以租约在册为判据即接管与租约同域同源，无租约处无会话无范围即资格判据无从谈起。通道唯一承 DEC-011 任务包匹配即写入范围第一源为任务包请求写入段，通道与范围同源即人节点审批一次全链生效。

### 裁决二 信息机械生成 {#decision-message}

决策内容
: 域内提交信息由确定性程序机械生成，LLM 零自由提交文本。三形态模板即段内检查点取 wip 冒头加任务包名加段号加会话号且零正文、段结算标题行机械取任务包段标题加尾行三件即会话号与认证事件哈希前八位与基准分支及基准提交号、收约归并承 lease close 现生成格式扩尾行。有偏离时附偏离行，偏离句为唯一半自由位且须与 trail 偏离披露一致。

决策理由
: 提交信息承载治理内容承 DEC-009 当前阶段原则，机械生成即该原则从内在自限升为工具执行。语义源全为机械可读件即任务包与台账与 trail，机械生成使信息可对表可审计。close 归并信息已由工具生成即现成先例，本裁决把先例推广到全节奏。

### 裁决三 提交界与认证门同界 {#decision-rhythm}

决策内容
: 域内一段一结算，段结算提交的前置为管线绿即化格核阅检词零违例加书简认证事件落链，上链前必须等绿由此在提交位落地。段内检查点自由即施工中可随时作检查点提交防长施工丢工，检查点用裁决二模板。禁 amend 与 rebase 于治理域分支与主线，修正即新提交前走。

决策理由
: 提交界与认证门分离即提交快照与 trail 真相可各自漂移，同界即一次穿透使两基准一致，哲学承接即映照一次穿透避免分开执行导致的基准不一致。真实性权威在 trail 承 DEC-009，同界使快照与真相的对应机械可查。禁改写已提交历史即裁决六的分支面落地。

### 裁决四 手动期升格 {#decision-manual}

决策内容
: 手动期提交执行权交工具即 lease 增 commit 与对表两子命令，子命令为机械动词不触发立名程序。commit 子命令四验即会话在册、暂存路径全落会话范围、该段认证事件已在链上、信息机械生成，四验过才执行提交。对表子命令即 git log 与锁台账与 trail 三方对表，不匹配出报告走视图。DEC-011 终裁一的手动期维持内在自限款由此升格为工具承载即其修订四，两期安排不变即引擎融回后闸门接锁。

决策理由
: 用户批准令即通过固定引擎实现接管，引擎落地前唯一的实物钉位即围堰工具。四验即 DEC-011 终裁一资格判据的执行形态，锁态与绿态同为准入在手动期即以在册验与认证在链验承载。升格显式修订不悄悄改即修订留痕纪律，DEC-011 修订四随本裁决签署联动生效。

### 裁决五 主线历史粒度 {#decision-granularity}

决策内容
: 收约归并保留分支全史即 close 现行为 merge 加 no-ff 追认为定则。检查点与段结算入分支史，主线经归并提交挂接即主线历史粒度为段结算与归并。人类视图靠 log 过滤与归并提交导航，不靠删史。

决策理由
: 分支全史是 trail 之外的第二现场即检查点为施工过程证据，删史违留痕构成性。人类注意力稀缺承工程基线第二条，主线粒度为结算级即视图负担可控，两取其全。

### 裁决六 历史不可改起点 {#decision-immutability}

决策内容
: 本决策与 GOV-004 v1 双签时点即治理域历史改写终点。签署前压缩与整理为人类最后整理权。签署后改写已归并主线即拒绝线，agent 拒绝执行，人类侧引擎无强制力即立对账可见性与双方承诺，任何改写在三方对表露形。

决策理由
: 历史不可改是操作历史不可篡改即工程基线第四条的 git 面落地。起点的显式钉位使整理权与不可改的分界可判，无起点即不可改无从起算。治理靠承诺加可见性不靠对人类的强制即司衡对人的关系是治理不是管制。

### 裁决七 反绕行机制 {#decision-bypass}

决策内容
: 无 hook 时代全面接管的执行力为正身路径唯一加机械对表抓偏。绕过 lease 直跑 git commit 的提交即信息无模板或无会话在册或无认证挂接，三方对表即 git log 与锁台账与 trail 比对全露形，出不一致事件走视图告警。拦多不拦漏的对偶即正身拦不住的对表全见。

决策理由
: 弃 hook 形态承 DEC-011 终裁二即拦截面属引擎职权位，围堰工具无权改 git 配置面。对表即事后审计对表件的推广，从锁台账单一对表扩为三方对表，判据先行拦截面后置的同一精神。

## 决策后果 {#consequences}

- 手动期提交纪律自此批起即段结算提交用机械模板，lease commit 实装前为过渡实践如实登记
- lease 1.1 实施批待开即 commit 与对表两子命令
- 编辑位迁移批随后同轨实施即首批全程受接管提交即验收场
- 对表首跑即存量绕行清点即可证伪条件一的度量时点
- DEC-011 修订四随本决策签署联动生效

## 备选方案 {#alternatives}

hook 形态拦截面
: 已拒。承 DEC-011 终裁二即围堰工具改 git 配置面越权，引擎期闸门已在两期安排内。

压平归并即主线只见结算
: 已拒。删分支史即删施工过程证据，违留痕构成性，视图负担靠过滤解决不靠删史。

LLM 自由信息加事后对表
: 已拒。即回内在自限即 DEC-009 当前阶段原则的延续，不构成接管，信息侧无机械源即对表无基准。

纯台账对表无正身路径
: 已拒。绕行无阻力即全面接管名不副实，正身路径是对表的因不是果。

## 认识论立场 {#epistemic-stance}

本决策为设计推论即 design-corollary，是工程设计承接哲学仓既有命题非逻辑必然。哲学锚为 PRO-07 鉴即映照一次穿透与鉴是建构的检验框架、PRO-08 应即留痕构成性。

可证伪条件一
: 若对表首跑与后续周期跑中绕行提交占比不可忽略即正身路径被系统性绕过，通道唯一须重审或拦截面提前。

可证伪条件二
: 若机械模板在长段施工中系统性不可用即检查点自由度不足或段标题语义源失真，模板与语义源须重校。

可证伪条件三
: 若三方对表在 facet 并行会话常态下误报频繁即多会话同仓对表语义不成立，对表域须按会话分割重推。
