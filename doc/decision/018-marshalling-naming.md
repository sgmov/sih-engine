## 命名对象与五件套 {#subject}

族名代理编组即英文对 marshalling、内部代号即后缀体系、展示名代理编组、历史曾用名即无正名时俗称 T6 范式。五形五件套即中文正式名、英文对、内部代号即后缀 token、展示名即中文名、历史曾用名即编号：

- 单线即 solo 即 -solo，曾用 T6-A。主线亲写零子代理，治理批默认形，名随三十三批实践活词走。
- 单发即 oneshot 即 -oneshot，曾用 T6-B。单子代理单文件单次响应。
- 反思即 reflect 即 -reflect，曾用 T6-C。单子代理单文件多轮反思，价值钉义即抓结构性违规非润色。
- 并联即 parallel 即 -parallel，曾用 T6-D。多子代理并行独立簇主线收敛验收，边界硬钉即编排者是主线，司衡协议编排者属借脑预留位。
- 串行即 serial 即 -serial，曾用 T5。单子代理全量上下文连续产强耦合多文件。

族名推导即直陈本体，谱系所治为代理如何被编组投用，铁路编组站与 CS marshalling 双重同向，化合物判别度高。英文对 reflection 带 Java 反射域距披露即域距远上下文可救，串行带工具级泛用轻占用披露，两处披露随词条存档。

## 编号退场 {#code-retirement}

编号出身即 2026-07-21 实验代号，字母为子模式序标非语义。退场范围七枚编号加 t6d 后缀 token 共八枚入检词死档 name_only 即历史行保留不得作新名。三十三份历史任务包档名、结果档、台账行、历史分支名零改写即血统保留。租约分支前缀 t6d 改 msh 即活代码连带，本批分支骑旧前缀即过渡如实。

## 名实复审 {#review}

T6-D 曾有三个指称并存即谱系单子代理多文件读、README 双子并行读、实践三十三批单线读。复审裁定：本名随双子形立即并联，谱系旧读即单子代理多文件就近归并串行形经用户归并照准，实践读即单线为独立一等形。2026-08-17 README 的 Twin-agent 双子代理加 Mainline 加 Dependent 助记扩写经复审系助记非词源，随批撤除，skill 与 README 改写归位。

## 反推审查 {#stress}

三轮反推逐轮处治。第一轮古典册即运筹、亲笔、传书、炼句、合击、接力，抓两处错向即亲笔撞人节点签署义改主笔、接力交棒隐喻错指多代理改长卷，后全册因偏工程裁定弃。第二轮工程通用册即编排、单线、单发、迭代、并行、串行，抓三处结构撞即编排与并行撞 AGENTS 准名级占用、迭代占用重于推敲同尺同死，处治即反思替迭代。第三轮修正册即编队、单线、单发、反思、并联、串行，抓两处噪声级即编队军味邻接复诉向量、reflection 撞 Java 反射域距，处治即族名三四字放宽后取化合物代理编组。终册四过两披露。反推得出一般规则登记即偏工程立名取术语位不取通用位。

## 病史收口 {#illness}

编号时代三十三批全部单线实跑而挂集群名，以任务包偏离声明糊住形名不符，聚合形态即范式空载与名实漂移，2026-08-28 经用户点破收口。处治即选形制替代偏离制，单线为一等队形即选形声明非偏离，空载处治承用户甲乙裁即并联形首跑归句读实现批与空载事实旧仓数据未复验标注随批落档。经济性数据即 2026-07-21 旧仓上下文实测，标注未复验。

## 范畴排除 {#scope-exclusion}

T6 管线之称谓即化格核阅检词书简链的 T6 标签非谱系义，本批不动待另裁。借脑与顺序链两预留位不预立即随启用批立名。task-packages 模板档在未跟踪区不动，随去留裁另行归位。

## 认识论立场 {#epistemic-stance}
