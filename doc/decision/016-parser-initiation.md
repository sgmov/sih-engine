# DEC-016 自研解析工具立项决策

本决策成立自研检索解析工具的立项与路线裁定，承接 2026-08-27 用户四令即开工、不动 Python 版本、崩溃语料新工具成后重接测试、不再依赖 tree-sitter。本决策只立项与钉契约面，不写引擎代码，工具本体归后续实现批。

## 概览 {#overview}

- 立项对象即自研解析工具，物理名 parser，治理名未签即 pk-025 在泊::[立项对象](#subject)
- 依赖裁定三条即不动 Python 版本、零第三方解析依赖替代 tree-sitter、崩溃语料转验收材料::[依赖裁定](#dependency-ruling)
- 算法钉死 PEG 族序选择即同树恒定，配错误节点包裹与自动恢复::[算法选型](#algorithm)
- 空腹形态即语言包三件纯数据无代码，新语言零引擎改动::[空腹形态](#fasting-form)
- 路线即外切自研围堰，远期融回按 DEC-013 开发非移植::[路线](#route)

## 立项动因与对象 {#subject}

寻址工具的 code 载体解析依赖 tree-sitter 原生绑定，在 cpython 3.14.6 下确定性段错误，四文件实锤即引擎 memory 模块与事件查询等，对分皆过全文独崩即整文件组合效应，崩溃帧在载体元信息节。缺陷位于原生绑定层，本仓不可治。SETSP 先例曾拒自研即成本考量，新证据即确定性崩溃与不可复现面使重估成立。立项对象为空腹解析引擎加声明式语言包，物理名 parser，治理名未签即候选句读随汇报呈人节点，pk-025 在泊承载，物理名与治理名解耦承锁改称向界物理文件名维持不改先例。

## 依赖裁定 {#dependency-ruling}

三条用户裁定显式承接。一即不动 Python 版本，寻址锁 3.13 的止血案撤销，运行时环境维持现态。二即不再依赖 tree-sitter，目标零第三方解析依赖即 code 载体由自研解析承接，标准库自足。三即崩溃语料不在本批重接测试，转新工具验收材料，新工具成后重接即重接测试是验收判据之一不是前置。寻址现行运行不动即窄域包继续服役，切流在新工具验收过后。

## 算法选型 {#algorithm}

钉死 PEG 族。判据是确定性：有序选择从构造上消除歧义即同一输入恒得同一树，双跑逐字节一致是司衡机械可判定的构成性要求，项目记忆 F-7 先例即输出恒定判据。歧义接受算法被拒即 LR 族与 GLR 类，解析森林须配正典树选择即多一重机制且 Lark 教训先例已证双跑多树。容错两层即树级错误节点包裹承 ANTLR ErrorNode 模型即错误处包节点永远产树，语法级自动恢复承 2025 路线即 arXiv 2507.03629。砍编辑器增量能力，保留索引级容错即截断与残缺输入仍产树不崩。

## 空腹形态 {#fasting-form}

引擎零语言知识即同构于核阅规则包与检词术语包先例。语言包三件即词法表、产生式、条目映射，纯数据无代码，新语言零引擎改动即纯数据包接入。ctags optlib 为空腹先例。蓝本 Lezer 即纯托管语言与声明式文法与内置容错。文法包按深度分级出版即 v1 声明层全保真、表达式内部作配平节点，深阶语法随需升级不阻塞首版。产出对齐寻址条目十字段即消费侧零改。

## 路线 {#route}

外切自研于 sih-tools 围堰即孵化期治理自治，随立项批登记契约与验收判据承孵化环第二三步。远期融回按 DEC-013 开发非移植即契约过去、实现以 Rust 重落、金向量对拍。融回门承孵化环第四步即验收判据全过、接口契约未变、回迁债已评估，两重门槛与贡献度主判据，外切贡献度从留痕取数承 DEC-015。

## 范畴排除 {#scope-exclusion}

本工具不入 GOV-002 冻结清单的信息洪流工具群即该群限 facet 与路择两席，本件是检索基础设施为寻址的解析依赖替代，非洪流治理工具，不触该群新增测量条款。本批零引擎代码、零寻址运行变更、零哲学升格即工程路线决策不自证命题。

## 决策后果 {#consequences}

- 解析依赖有替代路线在档，段错误缺陷以替代消解不修于旧件
- 契约面冻结即后续落差规格批与实现批以本决策与契约为范围源
- 命名悬置有界即 pk-025 在泊，出泊唯人节点
- GOV-002 概览行版本残留即 v1.3 对 v1.4 失配随本批修正归一

## 备选方案 {#alternatives}

维持 tree-sitter 并锁 Python 3.13
: 已拒。用户裁定不动 Python 版本，且止血不消缺陷只避让，环境改动代价转嫁给全部工具。

仓内直建不外切
: 已拒。解析能力通用、纯确定性、可跨仓复用、可带退出码，承孵化环外切判据四条，且非治理核心职能本体。

维持现状不立项
: 已拒。段错误缺陷使 code 载体索引不可用即寻址退化，缺陷登记无消解路径则检索链路长期带伤。

## 认识论立场 {#epistemic-stance}

本决策为工程路线决策，哲学锚定标待锚。可证伪条件一即若 PEG 序选择在目标语料上无法达到索引级容错即残缺输入不能稳定产树，算法选型须重开。可证伪条件二即若语言包三件不足以承载 Rust 声明层解析即须引入第四件或代码钩子，空腹形态须重审。
