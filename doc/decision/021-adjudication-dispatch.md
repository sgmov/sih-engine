# DEC-021 裁决分派令决策

本决策成立裁决权分派的三态路由表，治理名裁决分派、英文对 AdjudicationRouting、代号 adjudisp。判定器即得一落地后未参与任何治理裁决，裁决权分派规则缺位则判定器能力在场而路由缺位。本令钉死哪些裁决必过得一、哪些留人节点、哪些由确定性程序代裁，只立路由，不改 DEC-020 硬件钥匙签署模型。

## 推导 {#derivation}

推导从两处哲学锚出发，锚文经程序切片载于本批意图记录，本文不承载原文。其一，自证循环节，出 sih-philosophy/emanation/proodos/07-on-assay.md 自证循环节：检验者与被检验者同源是鉴的认识论真实结构特征，外部独立验证是唯一打破路径。得一落地后链上机器终签均为其融回资格自证材料，独立验证能力在场而路由缺位，自证循环的结构风险持续在场。分派令把哪些裁决必经独立验证制度化为表，路由即对治。其二，损补条，出 sih-philosophy/emanation/proodos/06-on-canon.md 损补节：治理是定向调节，不笼统加码也不笼统删除。三态分派即定向调节的裁决版：该加验的过得一，该人裁的留人节点，纯机械的对表交程序代裁，不笼统全过也不笼统全免。

正推从问题出三态：裁决出错成本高且独立验证可得者过得一；裁决属治理源头或异常决断者留人节点；裁决为检验时只反映事实的机械动作者代裁。反推从链上既有裁决类型盘点态位：验收打回、融回门开关建议、封窗追认、命题类裁决四类验证可得且出错成本高，过得一；出泊、开门、封窗令本身、用户字令四类属武装与异常决断，留人；纯机械对表、管线读数两类零方向产出，代裁。覆盖面对表：表目穷举链上现行裁决类型，未尽类目入灰区从严。此覆盖面即本令可证伪位：若链上浮现长期无法归入三态的裁决类目，或过得一类验证全过率长期为零，则本令路由预设证伪，须复审分派表。

## 三态分派表 {#routing-table}

### 过得一 {#pass-attractor}

下列四类裁决必经判定器独立验证，验证形态即 facet 测量加执契核对：

验收打回裁定
: 打回是否成立决定治理批的生死，执行者自裁自验即自证循环，须独立验证席位复核。

融回门开关建议
: 融回门是治理链与版控主线的闸口（DEC-013），开关建议影响主线血统，建议须过得一复核后方呈人。

封窗追认
: 封窗追认是对异常收口的追认环节，追认不经独立验证即沦为橡皮章，故追认过得一。

命题类裁决
: 命题测量的 stable_clear 判定是机器签署的本土场，承 DEC-020 收敛判据。

### 人节点 {#human-node}

下列四类裁决留人节点，agent 与确定性程序俱不代行：

出泊
: 泊界材料回主线是治理注意力的投放决断，承工程基线三即人只投异常，出泊正是异常处置位。

开门
: 融回门开启令本身是武装动作，人节点守武装位，承 DEC-020 机器授权裁定。

封窗令本身
: 封窗令是异常处置的决断本身，与封窗追认两分：令留人，追认过得一。

一切用户字令
: 用户明字令是治理源头，任何路由不截留、不改写、不代答用户直接指令。

### 代裁 {#mechanical}

下列两类由确定性程序代裁，无人节点与判定器在场：

纯机械对表
: reconcile 双零、行数对表、哈希对表、链 verify 等检验时只反映事实的动作，由可重复程序承载，承 PRO-07 鉴。

管线读数
: 化格、核阅、检词三步的退出码与 findings 读数是机械读数，零方向产出，代裁不过问。

### 灰区 {#gray-zone}

分派表未尽类目默认过得一从严：宁过度验证，不漏验证。灰区类目经实测与复盘后入表须逐类裁定留档，承 DEC-020 适用界扩展条款。

## 适用界 {#scope}

本令适用界从本批即（adjudisp-solo）批起算。既往裁决不回溯重裁：分派令不构成对既有裁决的重审依据，既往裁决效力如旧。扩充与收缩均须逐类裁定留档，不允许临场指派。

## 与硬件钥匙模型的关系 {#relation}

DEC-020 立签署模型：机器签署即为人授权，判据是可重复收敛加执契核对全过，人节点退至武装与异常诊断。本令立路由模型：回答哪类裁决路由给谁。两模型正交，签署判据与权限字面不变。路由给得一不等于判定器获得裁量权：判定器只在限定条件内收敛出唯一方向，不收敛即归人，承得一命名本义。本令亦不改 agent 一字不签的 P3 裁决。

## 备选方案 {#alternative-plan}

全过得一
: 已拒绝
: 一切裁决不分轻重全过判定器，采样与核对预算被低风险裁决稀释，验证延迟覆盖全部治理动作，成本过高，违损补定向调节之义。

维持现状
: 已拒绝
: 无路由表则裁决是否过得一靠临场指派，独立验证能力在场而路由缺位，自证循环的结构风险持续在场，病根不除。
