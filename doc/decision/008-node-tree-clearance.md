# DEC-008 节点树补正两案决策

本决策对 DEC-001 节点树做两案补正：其一治理语义节点命名清账，其二 knowledge 节点拓扑正式化。承 OPEN-QUESTIONS 原 OQ-06 与 OQ-07 的既有推导、OQ-07 专档逐节点评估、pk-007 与 pk-011 出泊清算令与意图流 round 11 事件 1c170454。用户 2026-08-25 裁定为纲即 view 归一、前缀简称、定义与用拆开。

## 概览 {#overview}

- 命名清账覆盖十八治理语义节点，即已立名件归档清点、前缀简称声明、空节点首内容触发立名、feedback 先例登记::[决策集](#decisions)
- knowledge 拓扑以本宅、临时围堰、界外经桥三分登记，定义与用拆开，物理位置留操作空间::[决策集](#decisions)
- 节点树为逻辑位不预设物理实现，本决策不改该原则只补正名分与拓扑定性::[决策后果](#consequences)

## 决策集 {#decisions}

### 案一 治理语义节点命名清账 {#case-naming}

已立名件归档清点：trail 经 DEC-004 书简与载体二层划分立名；plan 与 calibration 经 DEC-001 修订立名；event 与 state 的本体二分由 DEC-001 正文自证；参验、书简、三问、判定器、视图五组件经 DEC-007 组件名册立名，其中状态层 view 节点与组件层视图为同一物之两层描述，经用户 2026-08-25 裁定归一，DEC-007 即其立名礼。

前缀简称声明：七大文档类型前缀为 DEC-001 简称方案，职能是人类输入的快捷地址与引擎管线的定位索引，非待立礼的治理术语，经用户 2026-08-25 裁定销账。

空节点首内容触发立名：registry、graph、challenge、report 四节点空置未实装，名字参与构成实体，空节点无物可构，不预立礼，各自首件真实内容到场时触发立名程序。

feedback 定性：正式管线零使用，非正式反哺有一轮先例即哲学仓格式修复轮，粗体禁用与 markdownlint 配置与审计表述同步经哲学仓 git 史在案，立名礼等反哺通道开启时随通道一并立。

OQ-07 专档既有逐节点评估随本案收口，其优先级与批次问题由上述四款覆盖。

### 案二 knowledge 节点拓扑正式化 {#case-knowledge}

定义与用拆开：定义层回答什么内容够格归 knowledge 类型，现役证据即检索路径、术语映射、经验参考类；用层回答各处内容怎么消费，用法跟着物理形态走；物理层即存储位置刻意不定，承 DEC-001 节点不预设物理实现原文，操作空间是设计目的。

三处物理形态定性：本宅即 doc/knowledge，KNOW 类型加 WRITING-KNOW-003 术语映射规范，KNOW-001 为首件产物；临时围堰即 ai-ex，为未来融回 knowledge 而设的临时物理空间，融回为远端指针挂账；界外经桥即哲学仓与数学仓独立成仓，根据是体量即避免喧宾夺主与权威源地位，经 KNOW 检索路径间接消费不并入。

OQ-06 边界闭案：knowledge 与 view 之分即内容资格与状态投影之分，非物理位置之分，边界以逻辑类型边界正式化。

## 决策后果 {#consequences}

- pk-007 与 pk-011 出泊，命名清账与拓扑正式化经裁落档俱成
- ai-ex 融回 knowledge 成为远端指针，与工具线融回同族候触发
- 空节点立名触发条件登记在案，首内容到场即起礼，agent 不得以补正名义预立
- 本决策不改 DEC-001 节点树结构，不改任何物理路径

## 备选方案 {#alternatives}

逐节点全礼：十八节点逐一走立名程序，成本过高且空节点无物可构，弃。物理归一：把 ai-ex 与知识包并入 sih-engine 统一存放，违背体量与权威源分仓根据，弃。

## 认识论立场 {#epistemic-stance}

本决策是结构补正不是新哲学。名字是本体性的，故立名跟物走，物未到名不至；节点位是逻辑承诺，故物理形态的自由是承诺的一部分而非承诺的违反。
