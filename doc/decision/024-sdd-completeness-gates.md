# DEC-024 SDD/TDD 完备度判据与确定性执法定约

本定约把 SDD 与 TDD 完备度从原则落为可机械校验的判据族与四层消费面。令源即用户 2026-09-12 三令：「sdd是司衡引擎事前优化 ai 即 agent 与 llm 代码生成的重要功能之一，应该作为上线前的重要指标」、「AB走完不走CD了？另外所有的 sdd 、tdd的文档标准都是要走司衡确定性程序落，而不是交给llm自由发挥！」、「多子代理并行跑。」判词：SDD 的本体位次是 AI 代码生成的事前约束位，不是事后文档义务：规约与实现的间隙不会消失只会位移，规格先行把间隙前移到规格层由人节点裁掉，规格缺位时间隙后移到实现层由 AI 临场裁掉且无人看见。本定约承文规线孵化登记件（sih-tools/incubation/regula-line-tools-2026-09-06.md）与 sdd-v1 五件格式包族消费而不另造，承 DEC-022 判定命令形先例：每条判据载判定命令，禁印象语。

## 概览 {#overview}

- 四判据全部判定命令形，校验机械可重放，零 LLM 判词位::[四判据](#criteria)
- 四层消费面即上线门槛、逐批执法、扫描召回、长程度量，单源四表::[四层消费面](#layers)
- 确定性纪律四条即判据判定命令形、文档走 T6、校验可重放、检查器先红后绿::[确定性纪律](#determinism)
- 适用界自两道门落地时点起算不溯往，绕行走显式登记通道::[适用界](#scope)
- 备选三案即 LLM 审卷形与仅原则不入闸与另造标准包俱拒绝::[备选方案](#alternative)

## 四判据 {#criteria}

SDDG-1 典在码前
: 判定命令：取会话台账会话号，链面取意图笔时戳 t0 与首个实装落笔时戳 t1，查 t0 至 t1 区间内或首个实装提交本身存在规格物变更：规格物即 DEC 与 DES 与 SPEC 路径文件或任务包规格节；或意图记录显式申报规格消费面即消费既修正典清单。三者有一即过，俱无即拒。
: 反例：实装提交先于任何规格物落笔且意图零申报，DEC-023 后补于段1 即本判据的实况反例，判据若在会拒出先立典或补申报两通道。

SDDG-2 规格束齐备
: 判定命令：settle 差分文件清单交源码面，逐新增源码文件取头注前二十行，匹配正典指针词形即 SPEC 与 DES 与 DEC 与正典 至少一处；零命中清单非空即拒。
: 反例：新模块头注无任何正典指针：生成时规格束缺位的实况残留。

SDDG-3 偏差有承载
: 判定命令：结果档偏差申报逐条扫描，每条须命中承载词形即 pk 编号或 DEC 或 DES 或 SPEC 或 候批 至少一处；偏差节缺席且差分非空且无零偏差显式申报即拒。
: 反例：设计级偏差只落在会话散文与子代理报告：sihmcp-solo 段3 三条 HTTP 偏差即本判据的实况反例。

SDDG-4 测试同批
: 判定命令：settle 差分文件清单匹配测试词形即 tests 路径或 test_ 前缀或 _test 后缀至少一件，且验收材料或对表判词档在档；俱无即拒。
: 反例：实装笔落而测试件与对表材料俱缺。

## 四层消费面 {#layers}

A 层
: 上线门槛。DEC-022 晋升判据族增第四判据引用本定约，1.0.0 晋升判定时重放。

B 层
: 逐批执法。lease close 轴两道门：close 链闸增 SDDG 四判据机械检查，拒即教学载荷载判定命令与反例，显式绕行走 close 增旗标落 bypass 台账留痕；两道门即文规线登记件延后项，租约修复线收口后延后理由消失。

C 层
: 扫描召回。critsweep 增 GOV2-C6 完备度在档判据，扫描面即两道门执法记录与 bypass 台账，降级即视图告警候人节点。

D 层
: 长程度量。gauge 增完备度趋势读数，数据源即链面与台账，零新写点。

## 确定性纪律 {#determinism}

判据判定命令形即每条判据载判定命令或材料指针，禁趋稳与成熟与质量良好类印象语作答。文档标准走确定性程序即本定约与 GOV-002 修订走 T6 三闸，SDD 文档形校验归检查器工作名承载件机械承载：检查器空腹吃 sdd-v1 五件格式包对文档族逐条谓词判定，三值退出码，三态失败定位，验证时刻零人裁零模型裁。校验可重放即判定命令在主树重放同数同判词。先红后绿即检查器与两道门的测试先于或同笔于实装，golden 夹具绿加畸形体红的判词在档。

## 适用界 {#scope}

两道门自落地时点起算不溯往：落地 commit 之前开立的会话收约不受试，落地后新开批受试；本批 sddgate-solo 自身为门的反身受试批，门缺陷即批内修复。显式绕行通道对任何判据在案：绕行落 bypass 台账留痕，绕行露形只报不拦承 reconcile 既有语义。判据定义单源在本定约，四层引用不复制；判据修订走本定约修订不走各层私改。

## 备选方案 {#alternative}

LLM 审卷形
: 已拒绝
: 以模型读批叙事判完备度，判定不可重放不可复算，违确定性纪律本定约的立约根基。

仅原则不入闸
: 已拒绝
: 完备度停留在散文判词，闸面零牙，AI 生成的事前约束位落空。

另造标准包
: 已拒绝
: 文规线五件格式包与检查器契约已在档，另造即双源分叉，违单源四表。
