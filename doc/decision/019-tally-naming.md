# DEC-019 执契立名决策

本决策成立 DES-011 桥接件的正式命名，执契为中文正式名、tally 为英文对，承接 2026-08-29 用户逐名签署。同批连带四件即机器终签裁定、死因档补行六件、覆盖面审计结论、DES-011 暂名改指。

## 概览 {#overview}

- 命名集五件即执契、tally、代号不设、展示名不设、历史曾用名基线核对器::[命名集](#naming-set)
- 推导链即本质两版加正推加反推约束交集加覆盖面审计，反推唯一解::[推导链](#derivation)
- 机器终签裁定即收敛成唯一方向由确定性脚本落据、人节点收缩到非收敛异常诊断、agent 仍一字不签::[机器终签](#machine-signing)
- 血统档死因补行即定谳与鉴裁与衡鉴与验算四件同因入档::[血统档](#lineage)
- 覆盖面审计即执契名到终签留底重放新半条命，合契与稽算各缺其半::[覆盖面](#coverage)

## 命名集 {#naming-set}

中文正式名
: 执契。典源道德经七十九章「是以圣人执左契，而不责于人」。执的是条件绑定与哈希链这半边契据，重算相符即合契结案落据，不契（不收敛）才归人。执契落据即机器终签，左契留底即重放锚。用户 2026-08-29 逐名签署，前置三名死因否决在案见血统档。

英文对
: tally。有据之意与核账语义，与中文名平行表达非翻译。仓内 `_strict_seat_tally` 席位计数同向不错向，词条钉义「执契据以核结，非执行」。用户 2026-08-29 签署。

内部代号
: 不设，工具目录即 tally，trail 报告名前缀 tally。

展示名
: 不设。

历史曾用名
: 基线核对器，DES-011 暂名，不构成命名承诺，本决策签署后退役为描述语不复用作名。

## 推导链 {#derivation}

推导四段。第一段本质两版：初版即确定性基线核对程序，对话钉实后升级为核对与机器终签与条件绑定留底与重放锚四职一体。第二段正推：从动作根出候选，禁根判谳裁验，得稽算与勘验系，勘验旋即死于验根死档。第三段反推：把名的落位写成七条硬约束即可署名单名词、留据可重放成句、核对主体替换、分工句成句、体例禁根、口语指令、裸名无错向，约束交集过三名唯执契全过。第四段覆盖面审计：七语义面即复算核对、三态落处置、机器终签、留底、重放锚、异常归人、零语义判断，执契六面半、合契四面半、稽算四面，执契为唯一名到终签留底重放新半条命的候选。用户 2026-08-29 逐名签署执契。

## 机器终签 {#machine-signing}

用户 2026-08-29 裁定：facet 的最终目的是限定条件内的唯一方向选择；收敛成一条固定方向时由确定性脚本终签落据，人节点收缩到唯一异常即不收敛时诊断遗漏条件或命题错误；机器落据带全条件绑定，即为条件改变时的重制点，重放即可不必重审，异向则翻案留痕。agent 一字不签承 P3 原裁决不变，P3 与 rg-P3 留痕不抹，facet-measure skill 修订六显式接替常设人签核位。换人换模型不崩承工程基线二三四：审查由当事人依赖改为重放依赖，当事人可换，重放不会。

## 血统档 {#lineage}

死因补行四件。定谳、鉴裁、衡鉴三名同因入档即名实错位钉席位不钉动作，把治理结构中的裁决席位误当作工具动作，而工具不产方向只做核对与处置。验算入档即验字根与参验共享承勘验先例。另有落选非死档者即 arbiter 屋内死语义承 counter 的 LLM arbiter 反例、collator 标准库占用、witness 承哲学仓 convergence 层活词、勾稽英文对与租约 reconcile 撞车、稽核与核阅双核待分工、assessor 职权弱化名实不符。

## 覆盖面 {#coverage}

覆盖面审计结论入档供复审：复算核对三候选俱名；终签与留底与重放三面唯执契全名，合契有契无执、稽算算无所留；异常归人一面执契承不责于人原文。此审计即本决策可证伪位：若实装后执契的核对全过率长期为零，则两层自动终签预设证伪，本名随实装复核。
