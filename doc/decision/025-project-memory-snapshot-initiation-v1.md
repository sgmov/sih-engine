- 病灶即日志层与快照层失衡，快照层手写行使最高事实权而零版控零闸零过期检测，项目记忆连续失真承载于三轮考古实录::[病灶](#lesion)
- 机制即派生快照层，以链与正典档为唯一权威源、收约即再生、启动即加载的机械投影器，零 LLM 同参双跑逐字节一致::[决策内容](#content)
- 分工即温故检索面与快照常驻投影两消费形划界，视图纪律构成性承 view 先例::[决策内容](#content)
- 实施路线即设计批加实装批加切换批三步，立项不含实施，组件命名候裁另走立名::[复用](#reuse)

## 病灶 {#lesion}

- 日志层机械完备：链 trail 全事件留痕、温故五档召回、判据扫机械沉底召回，在役。
- 快照层必烂：AGENTS.md 等工作区文档手写维护，零版控零闸零过期检测而行使最高事实权；节点压缩致全痕链条注意力稀释，检索靠 LLM 语义撞见。
- 三轮考古失真实例：facet 归属误判即已融回引擎而误报为工具侧独立件；MiniMax 退役误判即照抄代码错误注释当事实；T6 与租约 merge 两起同名异义撞车即编组旧名撞管线现义、并库撞融回。逐例皆 AGENTS.md 与会话摘要残片失真所致，链与正典档皆对。
- 本立项令源：用户 2026-09-13 令「项目记忆，就是我们这几轮考古要正式立项」与「多子代理并行加速」。

## 决策内容 {#content}

机制
: 派生快照层即工作区文档投影器：以链 trail 与正典档为唯一权威源，机械再生工作区可派生文档节，收约即再生挂租约 close 收约流，启动即加载挂会话启动例行读数；零 LLM、同参双跑逐字节一致、投影与源不符时以源为准，三纪律构成性承 view 视图先例与 PARKING-v1 及 BASELINE-v1 投影惯例原话形「投影与链不符时以链为准」。

投影源与投影对象
: 投影源五路即链 trail 事件流、双线 PARKING-v1 名录、各组件 CONTRACT 与 README 头部、DEC 与 SPEC 档登记面、组件注册面；投影对象首件即 AGENTS.md 可派生节：文件索引表逐行、项目阶段行、工具清单与版本面、在泊计数面。宪法性手写节即项目身份与 Agent 身份与哲学仓地位与产出前自检保留手写位，本机制零触碰。

分工划界
: 温故（retriever）是检索面即按需 recall 按轴激活；快照层是常驻投影即启动即全量在场零查询；两者同一数据源两种消费形，SPEC 面显式划界不重复实现。view 族提供同参双跑逐字节一致纪律与告警装配先例，再生器作 view 纪律的姊妹承载非 snapline 扩张，snapline 仅 glob 谓词可复用。

过期检测
: 源变更而投影未再生即 stale 告警，哈希对表机械判定，承 pk-055「级联边册投影更新机制缺位即无陈旧检测无告警」直接对口；pk-055 出泊并入本机制实施批作首个消费案例。

## 三查 {#checks}

验收判据全过
: 立项批验收即本决策档管线三步全过加认证上链加收约过闸，实施批验收逐件另钉。

接口契约未变
: 温故与 view 与回锚既有契约零改动，快照层为新增消费面不触碰既有接口。

回迁债已评估
: 零回迁债即新增机制非搬迁；pk-055 与 pk-103 候泊内容并入实施批显式承接，不默写。

## 复用 {#reuse}

实施路线三步即设计批落 DES 钉待建面与验收判据、实装批 TDD 先红后绿、切换批换旗手写节改投影，每批独立开立。组件命名走司衡立名程序另会终裁，本档工作名「派生快照」只作指称，批名 memsnap 认领已入回执，承 stem 闸甲表形即认领即声明非终裁。

## 决策理由 {#reason}

项目记忆失真烧的是治理信任本身，日志层全对而快照层必烂的失衡不可靠人手纪律修复；再生器把快照层降格为投影即消灭手写漂移的根源而非修补单次失真。承知止纪律先问现有席位：view 与温故与回锚皆无再生位与常驻位，新建最小组件为缺口所迫非扩张。
