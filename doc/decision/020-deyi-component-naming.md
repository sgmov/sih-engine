# DEC-020 得一组件立名与机器授权决策

本决策成立二层裁决结构组件的正式命名，得一为中文正式名、attractor 为英文对，并承载用户 2026-08-30 机器授权裁定即机器签署即为人授权的硬件钥匙模型。组件由 facet 上层与执契下层按材料契约构成，承 DES-011 二层裁决结构。

## 概览 {#overview}

- 命名集五件即得一、attractor、代号不设、展示名不设、历史曾用名无::[命名集](#naming-set)

- 推导三证会师即正推、反推署名位交集、覆盖面审计同向得名::[推导](#derivation)
- 血统即道德经三十九章文本根直引、英文对动力系统行业根::[血统](#lineage)
- 签名时序即终签 2657ac9b 先于裁定文、裁定追认其为授权记录::[时序](#sequence)

## 命名集 {#naming-set}

中文正式名
: 得一。典源道德经三十九章「昔之得一者：天得一以清，地得一以宁……万物得一以生」。义即限定条件内收敛出唯一方向，不得一（不收敛）即归人诊断。用户 2026-08-30 签署，前置三名死因否决在案即归一词场淹没、衡准偏干预腿、鉴裁死档待翻案另议。

英文对
: attractor。动力系统吸引子即系统演化所趋向的唯一终态，行业用例 Hopfield 吸引子网络，词源拉丁 attrahere 引向。与中文名双典源平行非翻译，承温故 retriever 先例。用户 2026-08-30 签署。

内部代号
: 不设。

展示名
: 不设。

历史曾用名
: 无。组件曾以「二层裁决结构」描述语指称，描述语不复用作名。

## 机器授权 {#machine-auth}

用户 2026-08-30 裁定原文：「得一／attractor 的裁定的人节点也要退，机器签署即为人授权，这个东西可以类比为机器狗密码硬件，点一下就授权。」裁定内容：授权的判据是可重复收敛即 stable_clear 加执契核对全过，机器签署即为人授权；人节点退至两处即武装（规则、基线、验收标准的供给）与异常诊断（不收敛、核对败）；适用界以组件名采纳与已收敛裁定为界，向外扩展须逐类裁定。P3 自反裁决字面不变且加强即 agent 一字不签，终签主体是确定性脚本；facet-measure 修订七显式接替，P3 与 rg-P3 留痕不抹。

## 推导 {#derivation}

推导三证会师。正推从本质七语义面出发；反推从署名位七约束交集得语义核唯一即收敛而得唯一，纯核对名与纯观察名与判官意象俱出列；覆盖面审计七面矩阵即得一在定义面、例外面、重放面满格且对工具辖区面正确让渡。三证独立同向，评审稿全载于 proposition/topics/2026-08-30-component-naming-review.md。
