# 参验职能边界判定

本决策确立验证类组件内部鉴与应的职能边界判定。DEC-002 在命名问题诊断中推出，参验组件的职能横跨 PRO-07 鉴的反映与 PRO-08 应辨的处置，以单一组件承载两类哲学归属不同的职能，须判定职能边界以指导下游协议设计。

本决策只判定边界，不定具体实施。判定的哲学依据是 PRO-07 与 PRO-08 的原文职能分工。实施层的组件拆分与否、协议字段如何承载，归 DES-003 修订承载。

## 概览 {#overview}

- 参验组件的职能按哲学归属切分为反映层与处置层两层::[决策集](#decision-set)
- 反映层承接鉴，职能是如实呈现材料与意图的差异，不判断好坏::[反映层判定](#reflection-layer)
- 处置层承接应辨，职能是对已抵达的偏差做分类量度与纠正方向判定::[处置层判定](#disposition-layer)
- 两层的哲学依据是 PRO-07 鉴不判断与 PRO-08 应辨处理已抵达挑战的原文分工::[边界依据](#boundary-basis)
- 组件拆分与否留待 DES-003 修订判定，本决策不定组件物理形态::[决策后果](#decision-consequence)
- 备选方案含单层不分与三层细分，均因不同原因被拒绝::[备选方案](#alternative-plan)

## 决策集 {#decision-set}

### 子决策一参验职能按鉴与应辨分两层 {#decision-two-layer}

决策内容
: 参验组件的职能切分为两层。反映层承接 PRO-07 鉴，如实呈现符号材料与意图声明的差异事实。处置层承接 PRO-08 应辨，对已抵达的偏差做分类量度与纠正方向判定。两层哲学归属不同，反映层属鉴的认识动作，处置层属应辨的处置动作。

决策理由
: 哲学依据是 PRO-07 原文与 PRO-08 原文的职能分工。PRO-07 原文明确鉴只反映事实不判断好坏，判断是法与术的范畴不是鉴的范畴，验证报告只列事实不列应该怎样的建议。PRO-08 原文明确应辨处理已抵达的挑战，覆盖 bug 修复、规约违反纠正、错误决策调整。DES-003 参验组件现有三项产出，偏差类型即不一致或过度实现或低度实现属判断，偏差度量值属评判性量度，建议纠正方向即修代码或修意图属应该怎样的建议。按哲学分工，三项产出中反映差异事实归鉴，分类量度与纠正方向归应辨。不分层则单一组件的职能横跨两个哲学命题的边界，违反 PRO-07 原文的判断归属声明。

关联规则
: 本判定约束 DES-003 参验组件协议修订，修订时须按两层分别定义职能与字段。本判定不约束组件的物理形态，即是否拆分为两个独立组件，留待 DES-003 修订时按治理环节点实施判据决定。

### 子决策二反映层不承担判断职能 {#decision-reflection-no-judge}

决策内容
: 反映层的职能严格限定为如实呈现符号材料与意图声明的差异事实，不承担判断好坏、不承担量度偏离、不承担给出纠正方向。反映层的产出是事实陈述，即材料做了什么与意图要求什么的对照呈现，不含好坏判定。

决策理由
: 承接 PRO-07 原文鉴的核心约束。原文明确镜不区分好与坏平等映照，判断是治理动作不是认识动作，验证报告只列事实不列应该怎样的建议。若反映层承担判断职能，则违反鉴的反映而不投射原则，回到映照名实不符的结构性冲突。

关联规则
: 本判定约束反映层的产出格式，产出只含差异事实不含判断结论。具体字段定义归 DES-003 修订承载。

### 子决策三处置层承接应辨职能 {#decision-disposition-settle}

决策内容
: 处置层的职能是对反映层呈现的已抵达偏差，做分类量度与纠正方向判定。处置层承接 PRO-08 应辨，偏差即已抵达的挑战，分类量度即辨明识别，纠正方向即处理已发生挑战的处置动作。

决策理由
: 哲学依据是 PRO-08 原文应辨的定义。原文明确应辨处理已抵达的挑战，辨即辨明识别，覆盖 bug 修复与规约违反纠正与错误决策调整。偏差三维即不一致或过度实现或低度实现对应应辨的辨明识别，偏差度量值对应应辨的量度，建议纠正方向对应应辨的处理动作。三项产出归应辨符合原文职能分工。

关联规则
: 本判定约束处置层的产出格式，产出含偏差分类、偏差度量、纠正方向。具体字段定义归 DES-003 修订承载。

### 子决策四组件拆分判定延后至 DES-003 修订 {#decision-split-deferred}

决策内容
: 反映层与处置层是否拆分为两个独立组件，不在本决策判定，留待 DES-003 修订时按治理环节点实施判据决定。本决策确立的是职能边界判定，不是组件物理形态判定。

决策理由
: 组件拆分涉及治理环节点的物理形态，属实施层判定。参照 DEC-001 先例，DEC-001 把事件与状态二分的哲学判定放决策文档，把四节点清单与子节点物理形态放 DES-003。本决策照此分工，边界判定归决策，物理形态归设计。拆分判据须结合治理环的因果流向、数据流闭合性、事件流集成等实施约束综合决定，这些约束归 DES-003 承载。

关联规则
: 本判定委托 DES-003 修订承载组件拆分判定，委托边界是本决策确立的两层职能划分不可被 DES-003 混淆合并。

## 边界依据 {#boundary-basis}

本决策的边界判定依据 PRO-07 与 PRO-08 两份哲学原文的职能分工。

PRO-07 鉴的职能边界。原文确立鉴三义，去蔽即去除验证偏见，客观即不预设立场，映照即反映而不投射。原文明确鉴的核心约束有三条。第一条，鉴只反映事实不判断好坏，原文表述为镜不区分好与坏平等映照。第二条，判断是治理动作即法与术的范畴，不是认识动作即鉴的范畴。第三条，验证报告只列事实，不列应该怎样的建议，建议是法的范畴不是鉴的范畴。三条核心约束共同划定鉴的职能边界，鉴的认识动作止于反映事实，判断与建议归法与术。

PRO-08 应辨的职能边界。原文确立应变二相，应辨处理已抵达的挑战，应几预防未形成的微兆。原文明确应辨的定义，辨即辨明识别，处理已发生的挑战，覆盖 bug 修复与规约违反纠正与错误决策调整。应辨的处置动作含分类、量度、纠正，对应已抵达挑战的立即处理。

两层的边界线。反映层止于如实呈现差异事实，越过此线进入判断即归处置层。判据是产出是否含好坏判定。不含判定的差异呈现归反映层，含判定的分类量度与纠正方向归处置层。

## 决策后果 {#decision-consequence}

### 决策正面后果 {#consequence-positive}

- 参验组件的职能边界有明确的哲学分工依据，反映层归鉴处置层归应辨，两层不混淆
- 反映层不判断的约束承接 PRO-07 原文，化解映照名实不符诊断揭示的结构性冲突，判断职能不再伪装成鉴
- 处置层承接 PRO-08 应辨，偏差分类量度与纠正方向有了明确的哲学归属
- 组件拆分判定延后至 DES-003，边界判定与物理形态判定分离，各自归位

### 决策负面后果 {#consequence-negative}

- 参验组件内部出现两层划分，协议设计复杂度上升，DES-003 修订须按两层分别定义字段
- 两层之间的数据传递须明确接口，反映层产出供处置层消费，接口设计归 DES-003 承载
- 若 DES-003 修订判定拆分为两个独立组件，治理环节点数变化，事件流集成与数据流须相应调整

## 备选方案 {#alternative-plan}

单层不分
: 已拒绝
: 参验组件不按鉴与应辨分层，维持单一职能块。拒绝理由是单一职能块横跨两个哲学命题的边界，违反 PRO-07 鉴不判断的原文约束，回到映照名实不符的结构性冲突。分层是为化解冲突，不分则冲突仍在。

三层细分
: 已拒绝
: 在反映层与处置层之外增设第三层，如独立的量度层或独立的纠正建议层。拒绝理由是过度细分增加协议复杂度而无哲学依据支撑。PRO-07 与 PRO-08 的原文职能分工只支持两层划分，鉴反映与应辨处置，量度与纠正同属应辨的处置动作不宜再拆。

按 convergence 层 P1.2.2 划分
: 已拒绝
: 按偏差三维即不一致或过度实现或低度实现划分职能层。拒绝理由是偏差三维是处置层内部的分类细项，不是职能层的划分依据。偏差三维承接 convergence 层 P1.2.2 是有效的工程约束来源，但它的归属是处置层的分类逻辑，不构成独立的职能层。

## 认识论立场 {#epistemic-stance}

本决策为外部锚定（external-anchor），承接哲学命题。

核心判定即鉴与应辨的职能边界划分承接 PRO-07 与 PRO-08 两份哲学原文的职能分工。原文的判断归属声明与应辨职能定义是本判定的直接哲学依据。

可证伪条件一
: 若哲学仓后续修订 PRO-07 或 PRO-08 改变了鉴与应辨的职能分工，例如鉴被重新定义为可承担判断职能，则本决策的边界判定须重新审视。

可证伪条件二
: 若 DES-003 修订实践中发现两层划分导致协议设计无法闭合，例如反映层与处置层的数据传递无法定义有效接口，则两层划分须重新审视，可能须合并或重选划分轴。

### 自反性结论 {#reflexive-conclusion}

本决策确立参验组件内部鉴与应辨的职能边界判定，以 PRO-07 与 PRO-08 原文职能分工为哲学依据。本决策本身经过自我审视，未发现违反自身边界判定的形态。本决策的边界是职能判定，组件物理形态与协议实施归下游设计文档承载。
