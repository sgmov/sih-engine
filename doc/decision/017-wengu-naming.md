# DEC-017 温故立名决策

本决策成立组件第六席的正式命名，温故为中文正式名、retriever 为英文对，承接 2026-08-28 用户签令。连带三件同批清偿即三问立名补全、gate 宿主名登记、命名术语裁定。

## 概览 {#overview}

- 命名集五件即温故、retriever、代号不设、展示名不设、项目记忆反向锚点::[命名集](#naming-set)
- 术语裁定即英文对为仓内正名，工程代码标识符说法弃用::[术语裁定](#terminology)
- 三问补全即英文对归位 Ask3Repeater 承旧仓 DEC-035，宿主名随批改 ask3repeatergate 即家族公式统一::[三问补全](#ask3-supplement)
- gate 宿主家族惯例登记三件即 ask3gate、scribegate、retrievergate::[宿主家族](#gate-family)
- 血统档死因收录即司忆与英文四件与 memgate::[血统档](#lineage)

## 命名集 {#naming-set}

中文正式名
: 温故。典源温故而知新即论语为政篇。组件职温故即报出已沉淀物，消费侧职知新即新治理动作受益，名实切分线与只报不判边界同构。用户 2026-08-28 签署，前置死因否决在案见血统档。

英文对
: retriever。平行表达非翻译，温故典源在论语，retriever 典源在行业即信息检索与 RAG 生态中检索层的角色名。与寻址分工钉义即寻址管在哪里、retriever 管取什么。用户 2026-08-28 签署。

内部代号
: 不设，无 trail 专用字段需求。

展示名
: 不设。

历史曾用名
: 项目记忆，反向锚点，不得复用为别名。

## 术语裁定 {#terminology}

英文对的槽位名即英文对，承立名本体论英文对取名理据节用词即司衡对与道法术几诸名皆称英文对。旧仓 DEC-035 自造的工程代码标识符说法弃用，不继承该词。用户 2026-08-28 裁定。

## 三问补全 {#ask3-supplement}

DEC-006 承接旧仓 DEC-035 五件套时沿用其槽位说法，本批归位：三问英文对为 Ask3Repeater，承旧仓 2026-07-25 用户签收的完整推导即三问报时表机芯典源；ASK3 维持内部代号即仅用于 trail 与日志字段；宿主二进制名随批由 ask3gate 改为 ask3repeatergate，词根由代号小写形态归英文对，承用户 2026-08-28 改名令。ask3gate 出生于三问首落 src 批即既成事实，本批不以既成事实豁免处治，处治形态即改名归公式而非补册特例，旧名入死档。

## 宿主家族 {#gate-family}

gate 后缀宿主名惯例登记三件：ask3repeatergate 即三问宿主、scribegate 即书简宿主、retrievergate 即温故宿主。公式即组件英文对加 gate，统一无特例，宿主名属工程命名不入治理名册，新宿主随组件落位循此公式。

## 血统档 {#lineage}

死因入档如次。司忆死因二即撞司衡字头与谐音失忆方向反。英文对候选四案全拒即复盘义、摘要义、保管义、希腊教义名各承其拒因，词形与死因全录死档，档外不复述防死词回流入文。memgate 与 ask3gate 随新名落位入死档即禁复用，类均 name_only 即禁作名不禁史述。谐音核验自本批起为立名显式检查项。

## 决策后果 {#consequences}

- 组件第六席名分落定即名册、退出标准、规格、代码语域同名同源
- 英文对落代码面即模块与宿主与测试随批改名，旧名入死档管住复用
- 三问命名集在新仓术语下归位闭环，宿主名公式统一后无特例

## 认识论立场 {#epistemic-stance}

本决策为命名决策，哲学锚定承立名本体论。可证伪条件一即若温故在实践中被期待知新即生成新知，词条钉义受压须复审。可证伪条件二即若 retriever 与寻址的取什么与在哪里分工在实践中出现计量死角，分工钉义须重审。
