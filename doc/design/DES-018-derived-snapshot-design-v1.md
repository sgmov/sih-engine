- 组件家位即 sih-tools/projsnap/，工作名候立名另裁，与 attnanchor 同形即工作区级工具：读各仓与链，写工作区根文档，孵化环外切位候融回评估另走。

## 验收判据 {#acceptance}

### A1 同参双跑逐字节一致 {#a1}

- build 与 check 与 diff 三子命令同输入双跑输出逐字节一致，无时间戳无随机，排序键与缩进与尾换行冻结。

### A2 手写节零触碰 {#a2}

- 投影写面仅限登记的可派生节，手写节哈希批前批后一致，零越节写即源码扫描断言承载。

### A3 stale 零漏报 {#a3}

- 源变更而投影未再生时 check 必报 stale，fixture 面源变三形即链新笔加名录变更加 CONTRACT 版本变更逐形零漏报。

### A4 再生幂等 {#a4}

- 连续两次 build 第二次零 diff 即重跑落零，承 ORD-023 幂等语义。

### A5 失效裁决条款 {#a5}

- 投影与源不符时以源为准条款在档在码，check 报告载投影哈希与源哈希双面即裁决材料面。
