# DES-015 MCP HTTP 面多项目识别与分项目写授权安全模型

## 概览 {#overview}

- 本设计承 mcpline 线 HTTP 写面设计批定位，令源用户 2026-09-09 令「http要分项目的如何做，也要做写入权限」加同日基底改令「每项目一域，工具中央账本随项目」加同日简化裁定「我觉得没有那么复杂，我们的机制是为了防止善意的误操作，锁工作区，而不是做安全防护」；机制定位即防善意误操作不做安全防护，对抗面(泄露与劫持与枚举与重放)不在本设计防域，威胁模型缩为防呆清单四条::[边界申明](#boundary)
- 项目识别判词取一项目一治理域形：链与锁册与台账与泊界全住各项目自己的 sih 目录，目录布局规约定稿，司衡仓即第一域历史布局登记映射不迁移::[项目域识别形](#domain-identity)
- 令牌判词取项目标识牌形：明文短标识即可，台账即明文登记册，标识牌职责是绑域与分档与可停行，砍哈希落册与明文一次性交付与轮换双活窗口三件::[项目域识别形](#domain-identity)
- 签发判词取签发台进视图形：mcpline.web 加令牌管理台承载签发列表撤销三动作，无管理钥，签发带一步确认防手滑，签发即台账追加行::[项目域识别形](#domain-identity)
- 鉴权判词取识别语义形：连接头带项目标识即可，Bearer 头形留守为标识携带位，错误直给教学语不设反枚举形::[令牌与会话映射](#token-session-mapping)
- 授权判词取域隔离为主加域内薄层形：scope 三档即 readonly 与域写档与 custom，域绑定承载分项目写授权主防线，租约五验与锁队列原位零新执法位零 LLM 裁决位::[授权矩阵](#authorization)
- 中央工具判词取本体一份全域共用形：scribe 与 lease 与 critsweep 与 gauge 与 mcpline 中央一份全机共用如 git 一装仓库遍地，执法语义全域同源，版本兼容约束与中央单点可用性边界逐条载::[中央工具版本对全域的约束](#central-tools)
- 写面判词取零新增执法形：标识牌只识别与锚定域根，scribe 三闸与租约五验与 closeguard 与 git hooks 原位生效::[写路径复用](#enforcement-reuse)
- 审计判词承既有哈希链形：信封记项目标识非哈希，撤销即台账停行，链验与判据扫与秤星在每域内自足闭合::[审计与撤销](#audit-revocation)
- 威胁模型缩为防呆清单四条：防错域、防误写、防并发踩踏、防不可追溯；本机制防善意误操作不做安全防护::[防呆清单](#foolproof-list)
- 失败语义判词取直给教学语形：错误载荷直说原因与修复动作，砍反枚举统一形与五因不区分申报::[失败语义](#failure-semantics)
- 多人多agent预留：四缝即凭证槽位不变律与归因槽位与传输缝与签发台即人节点入口，只声明缝不预装机制，四缝留齐加人即换牌加行::[多人多agent预留](#multi-agent-reserve)
- 边界申明：司衡仓即第一域历史布局不迁移，SiInfer 彩排即首个新城的第一实例但不预占，DES-014 stdio 面安全模型不废两面对表同一执法层::[边界申明](#boundary)

## 项目域识别形 {#domain-identity}

判词：一项目一治理域形加项目标识牌形。项目的治理身份承载是该域自己的 sih 目录树，链与台账与泊界全住域内；HTTP 面多项目识别问题在域隔离下消解为标识牌与域的一对一映射问题，标识牌是防呆锚点不是安全凭据。

域目录布局规约定稿：新域自举按正典布局落地，即域根下 sih 目录树承载全部治理状态：sih/event/trail/ 住逐日哈希链、sih/ledger/ 住台账册族即 sessions.ndjson 会话册与 locks.ndjson 锁册与 tokens.ndjson 标识登记册与 bypass 与 bills 等既有账册同规约、sih/state/ 住治理状态即 plan 任务包区与 parking 泊界与 skills 与校准面、泊界材料住 sih/state/parking/materials/。域内数据一律 ndjson append-only 形，写点纪律承 pk057fix 批台账写点纪律即 flock 串行加 O_APPEND 原子整行禁整文件重写，全域适用。

第一域历史布局映射：司衡工作区本身即第一域，现存引擎仓加工具仓两处历史布局登记映射不迁移，即链与治理状态住引擎仓 sih-engine/sih/ 下、租约台账住工具仓 sih-tools/lease/ledger/ 下、调用留痕住 sih-tools/calllog/ 下、标识登记册住 sih-tools/mcpline/ledger/tokens.ndjson 与工具仓工具面自治位规约同形；第一域布局是映射表数据不是代码，中央工具按映射表寻径，后继新城一律正典单根布局，两形并存以登记面为准。

标识牌判词：明文短标识即可。标识牌是项目在 HTTP 面的名字牌，形即可读短串(形如项目名或其缩写)，人可读可辨认可手输，台账明文登记明文可查；防呆语境下标识牌职责三件即绑定项目域与承载 scope 分档与可停行可换，砍哈希落册(明文登记册即账，台账失窃无凭据意义因标识牌本就无保密设计)、砍明文一次性交付程序(管理台即明文可见即取即用)、砍轮换双活窗口申报(轮换即发新加行与停旧撤销两个普通操作，无双活问题待申报)。

登记册形判词：tokens.ndjson 明文登记册，落位第一域 sih-tools/mcpline/ledger/tokens.ndjson，新城即域根下 sih/ledger/tokens.ndjson，管理归 mcpline 面不混入 lease 会话台账。台账行字段固定：token_id 即明文短标识、domain_root 即所绑域根、scope 即三档之一、status 即 active 或 stopped、issued_at、issued_by 即签发来源。停行即追加新行同 token_id 载 status stopped，读数取每 token_id 末行，append-only 精神与链同构。

签发台进视图判词：mcpline.web 加令牌管理台，三动作即签发与列表与撤销，视图页面承载零命令行门槛；无管理钥，本机回环面零防与管理台即人节点操作位同义，不做管理鉴权；签发带一步确认防手滑，即签发页提交后出确认步显示标识与所绑域与 scope 待操作者复核再落笔，确认后签发即台账追加行；撤销同理带确认步。管理台是视图面的普通页面，与面板静态页同栈。

传输形判词：留 Authorization Bearer 头形。识别语义下连接头带项目标识即可，Bearer 头是 HTTP 惯例的连接头标准承载位：不进 URL 不落访问日志、streamable HTTP 客户端原生支持头注入、与 mcpweb 单端口统一形态相容；标识牌既无保密设计，头形选择只看工程惯性与可辨认性，路径段与每项目端口两形照旧不合(进 URL 落日志与破单端口形)，防呆形下维持同一取舍判词。

域自举程序形：新城立域四步，即按正典布局落地 sih 目录树、经中央 scribe 落首笔域登记链事件、管理台签发首标识牌入域册、域映射登记入中央工具寻径面；自举的实装细节归实装批，本设计只定形零预写。

## 令牌与会话映射 {#token-session-mapping}

判词：标识牌会话一对一形。一条经识别的 HTTP 连接绑定恰好一个 lease 会话，同时刻一标识牌至多一个活跃 lease 会话，重复 open 即同包活跃闸既有拒定，禁一标识牌多会话并行禁会话池；会话住所绑域，即 lease open 以所绑域为 --root 立会话，会话行落所绑域会话册，零跨域会话。

绑定形：MCP streamable HTTP 连接经 Bearer 头带项目标识后，server 查登记册得所绑域与 scope，以本进程正身件加标识牌派生值调用 lease open 立会话，会话号经工具结果透出给客户端记录；此后该连接上一切写操作携带该会话号，server 对一切写调用的 root 与 trail 与台账参数一律锚定所绑域，调用方参数中的域指向面不透传即结构上不存在写落他域的通路。断开收约形承 DES-014：零写连接轻收约，有在途写走完整 close 链闸与 closeguard 三检照走，收约失败转挂起候人节点 takeover。孤儿会话处置承既有 PID 探针三态与心跳停滞判据与 takeover 通道，零新增清理机制，全部在所绑域台账与锁册内闭合。

身份锚判词：从进程正身形变体为 server 进程正身件加项目标识注入复合形。HTTP 形下 server 是常驻进程，客户端无独立进程身份可采，身份可分性迁移到标识牌粒度：lease open 时 server 以项目标识为连接派生值注入正身可选件即 session_id 位，信封记项目标识非哈希，链笔归因零回查即到域；正身件答谁在写、登记册答写到哪域。五验在 HTTP 下各验什么逐条：在册验即标识牌在所绑域登记册 status 末行 active 且会话在所绑域会话册活跃；会话择定验即操作须落本连接自立的会话；范围验即 scope 分档覆盖检查；身份验即 server 进程侧 hostname 与 user 与 boottime 漂移照验加标识牌与登记册对表；绑定验即请求携带标识与会话在册标识逐笔对表加操作目标路径前缀属于所绑域根。

## 授权矩阵 {#authorization}

判词：域隔离为主加域内薄层形。分项目写授权的主防线是域绑定即结构性隔离，一标识牌只写所绑域，他域对其结构性不可寻址；scope 三档为域内防呆分档，防的是拿错档不是防敌。矩阵与分档俱是静态映射表随批评审，零 LLM 裁决位。

scope 三档语义逐条：readonly 档即只读五工具可调与写工具一律拒透传，防误写主档；域写档即所绑域内全部写工具可调，域内不再设第二层项目面裁剪；custom 档即域内细粒度白名单，逐工具逐旗标显式登记于登记册行，可含域内路径前缀收紧，登记面即授权面，零缺省放行。域写档是缺省授出形，custom 是收紧形，readonly 是只读形，三档皆以所绑域为边界前提。

与既有理由码原位衔接逐条：scope_violation 即域内分档出界或会话登记面出界的既有执法拒，原样透出；locked_elsewhere 即所绑域锁冲突既有拒，原样透出不吞不译；wait_turn 即排队受理既有返位次形，经独立工具透出，零 LLM 轮询零 token 消耗语义承 DES-014 不变。零新理由码零新执法位。

## 中央工具版本对全域的约束 {#central-tools}

判词：本体一份全域共用形。工具本体即 scribe 与 lease 与 critsweep 与 gauge 与 mcpline 与核阅与检词与正身与计数的中央安装一份全机共用，如同 git 一份安装仓库遍地，域只住状态与数据不住工具代码。

域内零工具副本判词：每域 sih 目录树只承载链与台账与状态，零工具代码零二进制副本；若工具随域复制，执法语义即随副本分叉，同一操作在不同域得出不同判定的风险结构性出现，故域内工具副本禁入是执法语义全域同源的构造性保障，非部署优化。

中央工具清单与现位登记：引擎件即 sih-engine/target/debug 下的 scribe 与 attractor 与 scrutinator，工具面即 sih-tools 下 lease 与 critsweep 与 gauge 与 mcpline 与 identity 与 meter 与 nomenclator 与 formatter；中央位登记随第一域历史布局映射面承载，新城不另设工具位。

版本兼容约束逐条：其一读兼容硬约束，即工具新版本必须可读全部既有域的链与台账与泊界材料，ndjson append-only 格式加版本字段是读兼容的载体，读兼容破坏的版本不得发布；其二升级程序唯一，即工具版本变更走各工具既立换版程序与引擎重编程序，全域同批切换，禁按域分批升级形成版本混跑窗；其三链格式演进走版本字段加既立程序，旧域链在新版本工具下 verify 语义不变；其四台账写点纪律跨域同形，即 flock 加 O_APPEND 原子整行全域适用不因域而异。

中央单点可用性边界如实申报：中央二进制不可用即全域写面不可用，这是本体一份形的代价；域内数据是朴素 ndjson 文件，中央不可用期各域仍可读可审计可对表，写面恢复随中央恢复，本设计不为可用性引入域级工具副本，那会买回执法分叉风险；此边界申报归档不隐藏。

## 写路径复用 {#enforcement-reuse}

判词：零新增执法。HTTP 写面是既有 CLI 的薄投影加标识牌识别与域锚定层，参数透传、结果透传、退出码透传，全部既有执法原位生效，标识牌只做识别与锚定不做第二套判定。

执法复用逐件：scribe 三护栏即工地链副本禁追加与闸二重意图拒与闸三会话在册验对 HTTP 写面逐笔生效，链路径按所绑域解析后护栏照验，server 禁以任何方式代填或绕过；lease open 六位闸序与 lock 悲观五验与 unlock 加持锁验与 closeguard 收约三检与 close 链闸与 claims 领取账本俱在所绑域台账与锁册内原位；git hooks 直提守卫在每域各仓 commit 位照拦，HTTP 发起的 commit 须经 lease commit 正典通道；域级泊界与判据扫与秤星承接 CLI 照旧以域根为参，零新增承接面。

record append 无幂等闸的误操作风险如实申报：HTTP 形下客户端超时重试即同 report 重复认证笔，闸二只拒 intent 重放不拒 append 重放。防呆缓解即锁纪律强制形：写面调用必须携带在册会话且所绑域链路径锁面持有约束承既有锁面语义，跨客户端重试撞锁即 locked_elsewhere 拒；重复笔由事件信封审计与 meter 交叉核对检出，处置归人节点；客户端重试纪律入工具描述教学面。

禁令三条承 DES-014 照录并扩域维：server 禁内嵌任何 allow 或 deny 判定逻辑替代执法，禁缓存执法结果跨调用复用，禁绕过 CLI 直写任何域的台账链文件或 git 对象。

## 审计与撤销 {#audit-revocation}

判词：承既有链加标识归因加域内自足。每笔写已上链是既有事实，本设计零新审计面，只定标识归因与停行形与域内治理自足性。

信封归因形：链事件信封既有位生效即每笔链事件载 session_id 与 identity_hash；lease open 时 server 以项目标识注入正身可选件即 session_id 位，信封记项目标识非哈希，同 server 不同项目的信封 session_id 位直接可辨，归因零回查即闭合；信封与登记册行的对应表载签发留痕，链面审计按信封回查域册行即归项目。

撤销即停行判词：停行即向所绑域登记册追加新行同 token_id 载 status stopped，末行为准；停行动作经管理台一步确认或治理通道落所绑域链留痕。停行后该标识牌的下笔写操作被路由层拒透传，与 takeover 与 bypass 拒透传同形，零新理由码零新执法位；已立会话不被 server 强拆，客户端换标识牌重连重立会话，旧会话由既有孤儿清理通道兜底。

域内治理自足性判词：每域链 verify 全文验独立可跑可判 valid、critsweep 以域根为参回算域内五判据与泊界与在飞、gauge 域内读数、租约 status 与 reconcile 域内对表，四件俱在域内自足闭合，域间零依赖；一域治理健康度的审计不要求读他域任何数据。

## 防呆清单 {#foolproof-list}

判词：本机制防善意误操作不做安全防护，威胁模型章按简化裁定缩为防呆清单四条，每条指认误操作形态与既有防位；对抗面(泄露与劫持与枚举与重放)不在本设计防域，概览一句带过不在章内展开。

防错域：误操作形态即拿错标识牌写错项目；防位即域绑定结构性隔离，写通路只锚定所绑域根，选错标识即写落错域结构性不存在，登记册 domain_root 列即人可查的对照面。

防误写：误操作形态即只想读却调了写、只想动 A 文件却扫到 B；防位即 readonly 档拒透传写工具、租约五验与 --allow 登记面既有拦截、scope_violation 理由码原样透出指认出界面。

防并发踩踏：误操作形态即两批同时写同面互相盖；防位即锁队列既有保序，locked_elsewhere 即拒与 wait_turn 即排队透出位次，撞锁不盖写不静默覆盖，脏位与 closeguard 三检既有兜底。

防不可追溯：误操作形态即出错后查不到谁写的写了什么；防位即一笔一链一信封，信封记项目标识与会话，链 verify 全文验可重放，登记册末行可查标识现行态，操作归因到域与会话零回查闭合。

## 失败语义 {#failure-semantics}

判词：直给教学语形。错误即教学，载荷直说原因与修复动作，砍反枚举统一形与五因不区分申报，防呆语境下侦察面不是设计关切，教学面即全部面。

传输层映射逐条：401 未识别即缺头或标识未登记或已停行，载荷教学语直说哪一因(缺 Authorization 头、标识不在册请查管理台列表、标识已停行请换牌重连)与修复动作，不再统一遮蔽；403 分档拒即识别过但 readonly 调写工具或 custom 白名单外，载荷直说现行档位与越界面与换牌指引；405 与 400 即传输形错照 HTTP 标准语义。429 限流即映射语义在档而限流器不在本设计，本设计零实装零预设。

载荷层映射：MCP streamable POST 常态 200 包 JSON-RPC error 或 isError 载荷；执法理由码即 scope_violation 与 locked_elsewhere 与 SessionNotActive 与 IntentRecordUsedRejected 与 PackageAlreadyClaimed 原样透出不吞不译；教学四字段承 SPEC 023 号契约件即 error 与 what_this_tool_does 与 valid_params 与 canonical_pointers，写工具载荷加 retry_discipline 一字段载重试纪律即撞锁改 wait-turn 与重试前查会话在册。

报错即教学边界：教参数名与退出码三值与闸位名称与理由码与修复动作与管理台指引；错误转述一律域根相对形不泄绝对路径面；零动态拼接不可信数据进错误文本承 DES-014 照录。

## 多人多agent预留 {#multi-agent-reserve}

判词：四缝只声明缝不预装机制(令源用户 2026-09-09 问未来多项目多人多agent引入司衡引擎治理如何预留鉴权入口)，本节零机制零实装承诺，只把今天的形立为可换的牌面。

凭证槽位不变律：身份解析单点是设计律，即连接头带标识、服务端查册单点解析，全链只认登记册末行一个解析位；未来把名字牌升级为签名牌(令牌绑人、可过期、可签名)只换牌不拆墙，解析位与五验与域锚定的调用面不变。

归因槽位：链信封主体预留人级粒度扩展，即谁的人、哪个 agent、经谁签发三问在信封位可加行承载；台账 append-only 加行即扩不改历史，现有行与读数语义零变。

传输缝：127.0.0.1 缺省绑定与远程不防表述为部署缝而非永久约束，多人版扩展路径即绑址放开加 TLS 反代加通道认证，三层俱在本设计防域外按需加装，加装不改登记册与解析位形。

签发台即人节点入口：视图签发台三动作即签发撤销列表即未来 RBAC 动作集，多人版先认操作者人级身份再签人绑令牌，归因闭环到人；一步确认形即未来审批流的最小胚形。

总纲：四缝留齐，加人即换牌加行。

## 边界申明 {#boundary}

本机制定位即防善意误操作不做安全防护(用户 2026-09-09 简化裁定)，对抗面不在本设计防域；注入面通用化与自有对话循环归 pk-079 分相承载，本设计只涉 MCP server 进程边界内的标识识别与域锚定与路由分档层。GOV-002 与 v3 换版不触碰：写面投影以现行各工具版本为界即 lease 1.39.0 与 scribe 引擎件现行与 identity 0.5.0 与 meter 0.2.0，版本升级走既立程序与中央工具版本约束节，本设计不预设不预占。判定语义正典留确定性程序：本设计零 LLM 裁决位，scope 三档矩阵与域锚定映射与错误教学映射俱是静态数据，任何判定语义变更走既立程序即得一裁加执契终签。

司衡仓即第一域：现存引擎仓加工具仓历史布局登记映射不迁移不重写。SiInfer 彩排写授权即首个新城的第一实例但不预占，实装批的域自举与登记册初册归实装批按本设计落，本批零预写零预占。alpha 相读数面归 SPEC 023 号契约件已立契约，本设计不重复不修改不冲突。DES-014 stdio 面安全模型不废：stdio 形下单机单工作区无标识牌位，本设计标识牌层与域锚定层对 stdio 形不适用；HTTP 形下两设计对表同一执法层，重叠面以先立 DES-014 为准从其判词。本设计属 des-001 域，产出经化格核阅检词认证序。
