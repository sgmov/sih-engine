# DES-013 三问组件设计

## 概览 {#overview}

- 本设计承 DEC-006 七项决策，承载三问组件的机制设计与接线设计，接口与格式细则归 SPEC-005::[协议](#protocol)
- 三层诘察维持 intent-refine skill 已验证形态，本设计做正式化表述不发明新机制::[协议](#protocol)
- 责权边界即三问产出锚点与意图契约、书简持有唯一写入、参验时序在后::[关系](#relations)
- 说话口接线手动期以 skill 为正式载体，facet 回流方向登记不实装::[接线](#wiring)
- 调用总量度量给会话级对比口径，机械源三落点即手动期估计、工具调用机械计数、引擎侧完整计数::[度量](#metrics)

## 协议 {#protocol}

三层诘察是三问的核心认知协议，认知主体为 LLM，向内诘察严禁向用户发问。

一问析出显层。对到达的自然语言意图析出显层诉求即用户明说的任务、对象、约束。二问挖掘隐含。挖掘隐含前提、逻辑裂隙、歧义分支，即用户未说但影响生成方向的部分。三问递归细化。对仍含歧义的分支持续细化逼近原子命题，止于认知域契约的深度限制。

触发时机承 skill 已验证四项：请求含糊、请求含提示诱导、请求携带任务特异精度而原话未显、生成契约在实质产出前须收窄。产出为意图契约即收窄后的精确生成契约，格式归 SPEC-005。

失败模式承 skill 已验证四类：过度细化即三问不止、误读诱导即把诱导当意图、契约漂移即产出偏移原意、外问违规即向用户发问。外问违规为红线，出现即记违规事件。

## 锚点 {#anchors}

每个推演节点必须产出推理锚点并移交，禁止熔断即低置信节点必留。锚点格式归 SPEC-005，血统三件套必须保留即哲学引文、理据、证据行号，承旧仓推理锚点子系统的模式重推导。锚点经书简写入事件流，三问不持有持久化格式。

## 认知域契约 {#cognitive-domain}

目标域为本次诘察的最终意图，支撑域为辅助推理的旁支命题。支撑域深度不得超过目标域深度，从根源限制无限递归规避算力黑洞，承道四间隙增长约束。深度计数口径归 SPEC-005 字段定义。

## 关系 {#relations}

与参验：时序分离，三问在生成前即意图到规约的第一次有形化阶段，参验在生成后即相容性核验。两组件不合并，接口互不内嵌，衔接经事件流。

与书简：承接关系，三问的产出经书简 append 写入事件流，三问本身不持有写入权限，哈希链由书简承载。

与判定器与路择：三问调用筛的谓词件即路择的单件判定族，级联调用图合法跨过治理边界；路择按轮判定的族将来融三问，融回件边界以本设计的协议节与锚点节为对表位。

## 接线 {#wiring}

说话口调用位。说话口即用户意图进入系统的位置，三问在此承接应几即在生成前预判微兆。手动期正式载体为 intent-refine skill 升格，sih 触发协议与其协同即治理触发到达时先过三问载体再入实质生成。引擎组件落地 src 后 skill 降回辅助，降回时点另行裁决。

facet 会话模式信号回流方向登记：facet 测量的会话信号经书简回流三问，供诘察的触发时机校准，方向登记不实装，实装随引擎组件批。

降级复现关系。skill 是三层诘察的手工降级复现，本设计正式化后 skill 措辞与本设计协议节对齐，机制语义零变更。

## 度量 {#metrics}

调用总量度量给会话级对比口径：以引入三问前后的会话级 LLM 调用计数为对比基线，基线参照 sih-engine/sih/state/calibration/agents-revision-effect 的既有实验数据。记录字段即 calls_in 与 calls_out 归 SPEC-005，会话级汇总是度量执行形态。判据：三问在役期间会话级调用计数不高于基线上浮一成，超限触发 DEC-006 可证伪条件二。

机械源现状与三落点。现状即会话级 LLM 调用计数无机械源，calls_in 与 calls_out 暂为操作者最优估计，知情登记于说话口载体。三落点分层：第一落点说话口手动期即操作者估计，载体为 intent-refine skill；第二落点工具调用机械计数即 meter 的包裹式计数器，meter 为工程简易工具临时调用不走立名程序即 2026-08-25 用户裁定，同日经 facet 测量与确定性核裁定甲路线即外部包裹不动五工具本体，计的是确定性外壳的工具调用，非 LLM 调用，其对本节判据的作用是工具侧机械数据源与漏计交叉核对，不直接充当会话级 LLM 调用计数，裁定出处即 sih-tools/proposition/DES/m-meter-variant/disposition.md；第三落点引擎侧即组件落地后调用经引擎，LLM 调用计数随引擎实装完整化，本节判据的执行时点随此落点。

## 边界 {#boundary}

三问不裁决即意图契约是收窄不是决策，生成与否判在别处。不外问即严禁向用户发问。无写入权即一切持久化经书简。不消除间隙即道四间隙不可消除，三问只识别与记录意图歧义。本设计不含实现排期，确定性外壳工具是否外切孵化另走孵化环裁定。
