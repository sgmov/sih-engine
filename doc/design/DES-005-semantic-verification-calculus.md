## 核心问题 {#core-problem}

v1 的核心问题是验证 LLM 语义判断经多次采样积分后是否收敛。v2 替换为验证 NPC 专家团多次审阅后偏离率是否稳定可度量。

替换依据三条。第一条,工程基线第五 LLM 是材料生成器不是度量权威,v1 的 N 次采样方差统计违反此基线。v2 把 LLM 输出限定为审阅单元材料,度量交给确定性程序。第二条,PRO-004 已登记路径二细分二 a 文本质量、二 b 语义结构、二 c 偏离率度量,二 c 偏离率度量是 v2 的核心。第三条,工程基线第一确定性程序是治理操作的唯一执行者,偏离率 K/N 由确定性程序计算,可复现。

新问题的实验可证伪条件。若偏离率收敛双指标在实际审阅中无法稳定判定,即方差与 Jaccard 无法区分真收敛与假性收敛,则偏离率度量机制须重新审视。这是 v2 的可证伪条件一,文末认识论立场段详述。

## 实验问题 {#experiment-questions}

实验回答三个问题。三个问题的答案决定偏离率度量机制是否成立以及参数取值。

### 问题一 偏离率稳定性 {#question-stability}

同一份文档,同一 NPC 专家团,多次审阅的偏离率 K/N 是否稳定可度量。稳定定义:从第 K 次审阅起,后续审阅的偏离率波动系数低于阈值,且审阅单元集合 Jaccard 相似度高于阈值。两个指标都过才算稳定。K 即审阅频次下限的候选值。

稳定性判据。波动系数是标准差除以均值,刻画 K/N 数值稳定性。Jaccard 相似度刻画审阅单元集合重合度,排除「稳定地漏判」的假性收敛情形。两者联合判定避开单指标盲区。

### 问题二 版本漂移差 {#question-version-drift}

模型版本漂移对审阅结果的影响量化。实验设计:同一份文档,同一检查项,在不同模型版本下各审阅 N 次。比较不同版本的 K/N 差异与审阅单元集合差异。差异量化为版本漂移差,纳入偏离率补偿。

版本漂移差的预期形态。某些检查项对版本漂移不敏感如结构层,某些检查项对版本漂移敏感如范畴排除检查。实验须按检查项分别量化版本漂移差。

### 问题三 审阅频次边际收益 {#question-marginal}

审阅 1 次、3 次、5 次分别达到多高的稳定性。每增加一次审阅的边际收益是否递减。递减到哪个点后继续增加审阅是费用黑洞。

实验设计。对同一份文档同一检查项,从 1 次审阅逐步增加到 N 次审阅,记录每次增加后的 K/N 波动系数与 Jaccard 相似度。绘制审阅频次与稳定性的权衡曲线。曲线的拐点即边际收益递减点,是审阅频次上限的候选值。

费用黑洞判据。拐点之后,每增加一次审阅的稳定性提升低于某阈值,继续审阅的费用不带来有意义的稳定性提升。阈值是治理参数,待实验数据支撑后定参。

## 审阅单元 {#audit-units}

审阅单元是路径二材料的基本结构,承接 T6-PARADIGMS.md 集群范式的子代理输出。审阅单元由 NPC 专家团产出,确定性程序消费。

单元结构。每条审阅单元含六字段。单元标识 stable_id 由确定性程序派生,文件路径加节点类型加节点序号加内容 hash。产出物定位 target_id 指向产出物语义单元节点的 stable_id。偏差类型 kind 含偏差发现、纠正建议、范畴标记三子类。严重度 severity 含 error、warning、info 三级。理由 reason 是一句话事实陈述,不引导判定。审次序号 attempt_id 标识本次审阅是第几次,跨次配对用于 Jaccard 计算。

字段来源。stable_id 与 attempt_id 由确定性程序派生,kind、severity、reason 由 NPC 专家团产出。target_id 由 NPC 专家团判定(指向哪个产出物节点)。

不变量。每条审阅单元必须是结构化输出,可机械解析。reason 字段不引导判定,中立陈述。kind 与 severity 跨次稳定(不因 attempt_id 变化而变化字段语义)。

## 偏离率 {#divergence}

偏离率是路径二的核心可复现度量,承接 SPEC-003 L190 原则 LLM 是材料生成器不是度量权威。

计算公式。K 等于 NPC 专家团命中偏差的单元数,N 等于产出物总单元数。偏离率等于 K 由 N 除。计算由确定性程序执行,可复现。

可复现边界。不可复现的是 LLM 单次审阅的具体 K 值,可复现的是 K/N 的计算与阈值判定。承接工程基线第四可验证性约束,可复现性在度量层不在判定层。

单向有效性。偏离率低不代表文档真没问题,可能是 NPC 集体漏判。偏离率高且跨次稳定则问题大概率真实。这是单向有效,高偏离可信,低偏离存疑。漏判风险由路径一确定性规则兜底。

## 收敛判定 {#convergence}

收敛双指标。指标一,K/N 波动系数低于阈值,刻画数值稳定性。指标二,审阅单元集合 Jaccard 相似度高于阈值,刻画集合稳定性。两个指标都过才算收敛,任何一项不过都不算收敛。

假性收敛识别。方差低但集合不重合是「稳定地漏判」的假性收敛,这是双指标设计的对治目标。双指标联合避免单指标盲区。

判定时机。每次审阅完成后立即计算 K/N 与审阅单元集合,跨次聚合计算波动系数与 Jaccard。聚合由确定性程序执行,触发时机由审阅流水线决定。

参数留空。波动系数阈值与 Jaccard 阈值是治理参数,待实验数据支撑后定参。本设计结构已定,参数留空。

## 分层与交叉 {#stratified}

分层统计沿用 v1 思路,按八大类型分别计算,decision、design、governance、proposal、spec、knowledge、research、draft。不同类型对语义判断的敏感度不同,混算会掩盖类型差异。

每类型的统计产出:该类型所有文档在四个检查项上的偏离率分布、收敛曲线、版本漂移差、审阅频次边际收益。跨类型汇总仅在实验结论阶段进行。

失败标记文档清单沿用 v1,十份文档来自旧仓失败复盘。design 类型四份含 DES-018 应层实施、DES-020 MCP 契约等,draft 类型两份,decision 类型三份,proposal 类型一份。

交叉验证判据。失败标记文档若在偏离率度量中不收敛,优先假设是文档自身不一致而非机制问题,因为这些文档已被失败复盘确认承载真实治理矛盾。若失败标记文档反而收敛良好,则须检查检查项是否足够敏感。

## 置信度公式 {#confidence-formula}

v2 的置信度公式反映偏离率两态,低偏离率与高偏离率。

低偏离率态。K/N 接近零且跨次稳定,文档在该检查项上判定为「未发现偏差」。置信度表述为「未发现偏差的概率」,具体数值由 K/N 决定,K=0 等于 1 减 NPC 漏判率上限。漏判率上限由双指标与版本漂移差共同推算。

高偏离率态。K/N 显著大于零且跨次稳定,文档在该检查项上判定为「发现偏差」。置信度表述为「偏差存在的概率」,具体数值由 K/N 与 Jaccard 共同决定。

公式暂定形态。文档在某检查项的置信度等于 1 减 K/N 再加上 Jaccard 相似度权重,具体公式留空,待三个实验问题数据全部到位后定参。

阈值是治理参数。低偏离率态的漏判率上限、高偏离率态的最小 K/N、跨态的 Jaccard 阈值,都是治理参数,待实验数据支撑后定参,不在本方法学拍脑袋决定。

## 费用估算 {#cost-estimation}

费用估算基于规模数据。估算的目的是评估实验本身的费用是否在可接受范围内,以及为后续常态化运行的预算提供基线。

单次全量审阅的 input token 粗估。全量 263 份文档,总行数 45115,中文约每行 8 个 token。每次审阅检查 4 个检查项含承接关系有效性、可证伪条件存在性、认识论标签合法性、术语一致性。单次全量审阅 input token 粗估等于 45115 乘以 8 乘以 4,约 144 万 token,未含 prompt 模板开销与 output token。

多次全量审阅的 token 粗估。审阅 3 次约 433 万 input token。审阅 5 次约 722 万 input token。审阅 7 次约 1011 万 input token。

output token 粗估。每次审阅产出结构化审阅单元加一句话理由,约 100 至 200 token。263 份文档 4 个检查项每次审阅约 10 万至 21 万 output token。审阅 5 次约 52 万至 105 万 output token。

费用换算。实际费用取决于模型定价,本方法学不锁定模型定价。实验执行时须记录实际模型定价与实际 token 消耗,作为费用基线。

费用黑洞判据。若实验问题三的数据显示,拐点之后每增加一次审阅的稳定性提升低于阈值,则继续审阅是费用黑洞。阈值留空待数据定参。

## 实验可复现性 {#reproducibility}

实验协议锁定以下要素,确保可复现。

模型版本锁定。实验执行时记录模型名称与版本号。版本号是记录项不是控制项,模型版本不在司衡控制范畴内。后续重跑若版本不同,版本差异纳入版本漂移差分析。

审阅 prompt 模板版本化。模板每次变更记录版本号与变更内容。后续重跑须使用同一版本模板。承接工程基线第五 LLM 是材料生成器,prompt 模板约束生成方向,模板版本化是材料生成的元层治理。

审阅单元记录格式锁定。记录格式须可机械解析,供统计聚合程序消费。沿用本设计「审阅单元」段定义的结构。

审阅温度锁定。实验执行时记录审阅温度取值。后续重跑须使用同一取值。

文档集锁定。实验对象是旧仓全量 263 份文档,文档集固定。后续重跑须使用同一文档集。

## 实验产出 {#experiment-output}

实验产出三类材料。

第一类是原始审阅单元记录。263 份文档乘以 4 个检查项乘以 N 次审阅,全部审阅单元结构化存储,含 stable_id、target_id、kind、severity、reason、attempt_id 六字段。这是实验的原始数据。

第二类是统计聚合结果。按类型分层统计的偏离率分布、收敛双指标、版本漂移差、审阅频次边际收益。这是实验的分析产出。

第三类是参数定参建议。基于统计聚合结果,给出波动系数阈值、Jaccard 阈值、漏判率上限、审阅频次上下限的定参建议。参数定参建议不是最终决策,最终决策须人类确认。

## 实验失败判据 {#failure-criteria}

实验可能失败。失败判据须显式声明,不掩盖失败。

判据一。若问题一的偏离率稳定性实验显示,同一文档同一 NPC 专家团多次审阅的 K/N 不稳定即双指标无法同时过阈值,则偏离率度量机制的假设不成立,本方法学作废。语义验证回退到无承担者的诚实空白状态。

判据二。若问题三的权衡曲线显示,稳定性在合理审阅频次内无法达到可用水平即审阅 10 次以内双指标仍不收敛,则偏离率度量机制虽理论成立但工程不可行,本方法学搁置。

判据三。若版本漂移差过大即不同 NPC 专家团版本的 K/N 差异使双指标无法稳定判定,则偏离率度量机制的稳定性不足以支撑治理决策,本方法学须引入版本锁定或降级为辅助参考而非权威验证。

## 认识论立场 {#epistemic-stance}

本设计为 empirical-hypothesis 加 design-corollary 双重标签。empirical-hypothesis 是实验方法学,偏离率收敛的稳定性假设尚未经实验验证。design-corollary 是工程范式承载,承接 T6-PARADIGMS.md 集群范式与 PRO-004 路径二细分。

可证伪条件一。若实验问题一显示同一文档同一 NPC 专家团多次审阅的 K/N 不稳定,则偏离率度量机制的假设被证伪,本方法学作废。

可证伪条件二。若实验问题三显示合理审阅频次内双指标不可用,则偏离率度量机制虽理论成立但工程不可行,本方法学搁置待算力成本下降后重评估。

可证伪条件三。若版本漂移差使 K/N 波动超过治理可接受范围,则偏离率度量机制稳定性不足,须降级为辅助参考。

可证伪条件四。若工程实施发现审阅单元结构字段不足以承载 NPC 专家团实际产出,本设计需补字段并升 v3。

## 十一 v1 归档 {#v1-archive}

v1 基于 N=4 隔离采样的旧设计已废,保留作历史。v1 的核心假设是 N 次采样后判断分布方差随 N 增大而趋稳,实验方法学是 N 次采样的统计聚合。v1 的失败原因三条。第一,N=4 多族群隔离采样在本仓开源合规约束下不可行,推导链见 OQ-13,司衡代用户调用第三方 key 有封停风险且不能通过免责声明转移合规责任。第二,工程基线第五 LLM 是材料生成器不是度量权威,v1 的判断分布方差统计违反此基线。第三,PRO-004 已登记路径二细分,偏离率度量是路径二 c 的核心,取代 v1 的判断分布方差。

v1 内容摘要在 §一至 §十。实验对象旧工程仓全量 263 份文档,八个检查项含承接关系有效性、可证伪条件存在性、认识论标签合法性、术语一致性,采样协议锁定 N 初始值 10,温度与 prompt 留空,失败标记文档清单十份,置信度公式由基础置信度减去版本漂移补偿因子按类型敏感度加权,失败判据三条。

v1 的可继承部分。第一,实验对象旧仓全量 263 份文档沿用,分层统计八大类型沿用,失败标记文档清单十份沿用。第二,采样协议的中立性要求与温度锁定与 prompt 版本化沿用为 v2 的审阅协议中立性与温度锁定与 prompt 版本化。第三,实验可复现性的五要素模型版本锁定、温度锁定、prompt 版本化、记录格式锁定、文档集锁定沿用为 v2 的审阅可复现性五要素。

v1 的不可继承部分。第一,N=4 隔离采样,已废,被多次审阅偏离率取代。第二,采样次数 N 等于 10 的初值,已废,被审阅频次权衡曲线取代。第三,基础置信度等于判断为存在次数除以总采样次数,已废,被偏离率 K/N 取代。

## 十二 v2 标定数据空缺 {#v2-calibration-gap}

v2 偏离率度量机制有以下参数待实验数据填入。第一,波动系数阈值,留空。第二,Jaccard 阈值,留空。第三,漏判率上限,留空。第四,审阅频次下限与上限,留空。第五,版本漂移差容忍度,留空。

参数定参依赖 SPEC-001 偏离率阈值实验的产出。SPEC-001 实验设计不归本设计承载,归下游 SPEC 决策。
