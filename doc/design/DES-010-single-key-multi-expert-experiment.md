# 单 KEY 多专家范式实验设计

## 概览 {#overview}

本设计承接 PRO-004 路径二 NPC 专家团(单 KEY 多专家协作模式)与 DES-005 v2 偏离率收敛实验方法学,设计单 KEY 多专家范式对比实验。司衡引擎默认用户单 KEY 单模型部署,本实验在此约束下验证 T6-D 集群范式的引导式专家团机制。

驳回两项对比实验的边界声明。无引导对比实验驳回,无引导是 LLM 不可复现的根因属业界共识,无需实验验证。多 KEY 隔离对比实验驳回,司衡不显式支持多 KEY,用户 LLM 部署不是司衡权责,司衡引擎默认单 KEY 单模型。

## 核心问题 {#core-problem}

T6-D 集群范式 = 单 KEY 引导式专家团共同协作(用户语境明确)。本实验验证此范式在偏离率度量机制下是否成立。

核心问题拆为三子问题。第一,专家数从 1 增加到 5,偏离率 K/N 是降低还是升高。第二,多专家审阅的审阅单元集合 Jaccard 相似度是否随专家数提升。第三,多专家范式的边际收益(每增加一个专家的稳定性提升)是否递减。

承接 DES-005 v2 实验问题一偏离率稳定性与问题三审阅频次边际收益。本实验将 DES-005 v2 的「单专家多次审阅」维度扩展为「多专家单次审阅」,与 DES-005 v2 互补。

## 实验对象 {#experiment-subject}

实验对象沿用 DES-005 v2 实验对象,旧工程仓全量 263 份文档,八大类型分层含 decision 36 份、design 58 份、governance 2 份、proposal 50 份、spec 35 份、knowledge 46 份、research 8 份、draft 28 份。

失败标记文档清单沿用 DES-005 v2,十份文档来自旧仓失败复盘,design 类型四份含 DES-018 应层实施、DES-020 MCP 契约等,draft 类型两份,decision 类型三份,proposal 类型一份。

## 实验设计 {#experiment-design}

### 实验因子 {#factor}

因子一,专家数 N 含三档。N 等于 1 单专家对照,N 等于 3 三专家协作,N 等于 5 五专家协作。专家指同一模型实例下的多个独立 sub-agent,各自生成审阅单元。

因子二,引导强度固定。所有专家接收同一任务包模板,模板基于 ai-ex/SUBAGENT-TASK-TEMPLATES.md 模板二,五段结构含任务目标、项目背景、任务构成规则、参考文件、交付要求。

因子三,文档集固定。263 份全量旧仓文档,每份文档每个专家审一次。

因子四,模型固定。司衡默认单 KEY 单模型,所有专家共享同一模型实例。模型版本记录在实验日志。

### 关键变量 {#key-vars}

单 KEY 共享。专家数 N 等于 5 时五个 sub-agent 共享同一模型实例,不是五个独立 API key。这是司衡引擎默认部署模式。

引导式任务包。所有专家接收同一五段任务包,任务包含 self-check 六项核心、通用格式规范、类型特异化约束五条、哲学检索四项。这是 T6-D 范式的引导式体现。

审阅单元输出。每个专家产审阅单元,审阅单元六字段含 stable_id、target_id、kind、severity、reason、attempt_id。attempt_id 在本实验中替换为 expert_id(标识来自哪个专家)。

### 不变量 {#invariants}

每份文档每个专家只审一次,审阅单元 attempt_id 等于 expert_id。N 等于 5 时每份文档有 5 个独立审阅单元。N 等于 1 时每份文档有 1 个审阅单元,attempt_id 等于 solo。

## 实验方法 {#method}

承接 DES-005 v2 偏离率度量机制,本实验扩展为多专家版本。

### K/N 偏离率 {#divergence}

产出物总单元数 N 等于 263 份文档乘以每份文档语义单元数,语义单元数由第一层分词工具 pulldown-cmark 加 comrak 派生。

N 等于 1 时,偏差单元数 K 等于该单专家审阅命中的偏差单元数。N 等于 5 时,偏差单元数 K 等于五专家审阅并集命中的偏差单元数,即只要任一专家命中偏差,该单元计入 K。

偏离率 K/N 由确定性程序算,可复现。

### Jaccard 相似度 {#jaccard}

N 等于 1 时,Jaccard 不适用(单集合无自比)。

N 等于 3 时,审阅单元集合有 3 个,两两配对计算 Jaccard 相似度,聚合用平均 Jaccard 反映三专家集合重合度。

N 等于 5 时,审阅单元集合有 5 个,两两配对 10 对,聚合用平均 Jaccard 反映五专家集合重合度。

Jaccard 高意味专家间一致,Jaccard 低意味专家间分歧大。

### 收敛双指标 {#convergence}

本实验的「收敛」不是 DES-005 v2 意义上的「多次审阅稳定性」(因为本实验每专家只审一次)。本实验的「收敛」改为「跨专家一致性」。

指标一,跨专家 K/N 集合的方差低。五专家的 K/N 数列(每份文档 1 个值)方差低于阈值,意味专家对偏离率判定稳定。

指标二,跨专家审阅单元 Jaccard 高于阈值,意味专家对哪些是偏差的判定一致。

两指标都过意味单 KEY 多专家范式收敛,任一不过意味不收敛。

### 边际收益 {#marginal}

每增加 1 个专家(N 等于 1 增至 2 增至 3 直至 5)的稳定性提升,绘制专家数与稳定性的权衡曲线。曲线拐点即边际收益递减点,是专家数上限的候选值。

按 DES-005 v2 实验问题三的范式,本实验将「审阅频次」维度改为「专家数」维度,两实验互补验证路径二稳定性。

## 实验可复现性 {#reproducibility}

模型版本锁定。实验执行时记录模型名称与版本号。版本号是记录项不是控制项。

任务包版本化。任务包模板每次变更记录版本号与变更内容。后续重跑须使用同一版本模板。

审阅单元记录格式锁定。沿用 DES-005 v2 审阅单元结构,attempt_id 字段在多专家实验中替换为 expert_id,其他字段不变。

温度锁定。实验执行时记录 temperature 取值。后续重跑须使用同一取值。

文档集锁定。实验对象是旧仓全量 263 份文档,文档集固定。

## 实验失败判据 {#failure-criteria}

判据一,多专家反直觉漏判。若 N 等于 5 的 K/N 高于 N 等于 1 的 K/N,意味多专家机制反而漏判更多,与设计预期相反,本实验机制不成立,单 KEY 多专家范式作废。

判据二,跨专家一致性不收敛。若五专家 Jaccard 相似度低于阈值且跨专家 K/N 集合方差高于阈值,意味专家间判定不一致,引导式任务包未起到约束作用,本实验机制不成立。

判据三,边际收益不递减。若 N 等于 5 比 N 等于 3 的稳定性提升大于 N 等于 3 比 N 等于 1 的稳定性提升,意味多专家无收敛迹象,边际收益假说不成立。

判据四,版本漂移差过大。若不同模型版本的实验结果差异使双指标无法稳定判定,本实验须引入版本锁定或降级为辅助参考。

## 认识论立场 {#epistemic-stance}

本设计为 design-corollary 加 empirical-hypothesis 双重标签。design-corollary 是工程范式设计,empirical-hypothesis 是实验方法学。

可证伪条件一。若实验判据一触发,多专家反直觉漏判,单 KEY 多专家范式作废,路径二 NPC 专家团设计须重新审视。

可证伪条件二。若实验判据二触发,跨专家一致性不收敛,引导式任务包机制作废,任务包模板须重新设计。

可证伪条件三。若实验判据三触发,边际收益不递减,专家数上限的工程经济性不成立,推荐值须下调。

可证伪条件四。若版本漂移差过大,实验须引入版本锁定,司衡引擎部署模式须重新评估。

### 自反性结论 {#reflexive-conclusion}

本设计经过自我审视,未发现违反 DES-001 格式规范的形态。本设计承接 PRO-004 路径二 NPC 专家团与 DES-005 v2 偏离率度量,设计单 KEY 多专家范式实验,显式驳回无引导与多 KEY 隔离对比实验的边界。本实验验证 T6-D 集群范式的工程价值,承接工程基线第五条 LLM 是材料生成器不显式多 KEY 部署。
