# SPEC-007 温故组件契约

本规格承接 DEC-014 立项决策与 PRO-008 推导档，定义温故组件的接口契约与验收判据。本规格为契约先行落盘即接口冻结与验收判据前置，本批零代码，实装批以本规格为 SDD 输入承 DEC-013 第一步纪律。温故是五档已沉淀物的检索面激活组件，只报不判，非全新存储，五档载体权威地位不动。

## 概览 {#overview}

- 组件定位即五档已沉淀物的检索面激活，承接四链同构缺口即已沉淀物在需要时不可得::[定位](#positioning)
- 接口面单操作 recall 即按主题或事件或时段取五档切面清单带出处::[接口签名](#interface-signature)
- 输入三轴即主题轴与事件轴与时间轴加档过滤与参照时间，输出切面记录 ndjson 逐行::[数据契约](#data-contract)
- 底座两件即寻址 locator 承五载体检索与引擎 scribe query 承 trail 事件查询，组件缺席则体系不失效::[底座与退化](#base)
- 确定性细则即排序机械、无评分、无建议字段、同参双跑逐字节一致::[确定性](#determinism)
- 退出码三值即零成功一拦二异常::[退出码](#exit-codes)
- 消费侧三处即三问前向约束检索加载、批次起草先例检索、段结算结论档回取，接线归后续批::[消费侧](#consumers)
- 边界排除五条即不做向量召回与不产内容与不替判断与不建存储与不动载体权威::[边界与排除](#boundaries)
- 验收判据八条前置冻结即实装批 F 锚定来源::[验收判据](#acceptance-criteria)

## 定位 {#positioning}

温故让五档已沉淀物在治理动作需要时被机械地找到并加载进注意力。五档即事实档书简产即 trail 事件流、结论档结算产即 sih/event/plan/ 下结果档、经验档 ai-ex 产、悬置档泊界产即两册投影与停泊事件、意图档三问产即 ask3 记录件与链上意图事件。承接命题四链同构即注意力加载、跨域检索、留痕读侧、判据错位，四链不立新命题只承接，推导与逐字引文在 PRO-008。

组件分层即与寻址 locator 即底座、与判定器即消费侧不同层，检索不产内容不替判断。与视图的分工即视图是人读聚合面，温故是机器检索面。

## 接口签名 {#interface-signature}

接口面单操作 recall，调用形态为命令行子命令，宿主命令名待实装批立名，操作名 recall 随本规格冻结，宿主名落定不构成接口变更。recall 接收查询参数组，返回切面清单即 ndjson 逐行，输出到标准输出或 --out 指定文件。

参数七件。--topic 即短语，可重复，主题轴。--event 即事件类型或标识，可重复，事件轴。--since 与 --until 即日期，时间轴边界，边界日含即含。--archive 即档名，可重复，五档过滤即 fact 与 conclusion 与 experience 与 parked 与 intent 五值枚举。--at 即日期，参照时间显式给参，不读系统钟。--out 即路径，输出文件，缺省标准输出。

轴至少给一即 topic 或 event 或时间轴至少一件在场，轴全缺即拦。

v1.3 增 --root 即路径，显式数据根，给定即不上溯且须为布局两形根即 first_domain 中央双仓目录或 canonical 新城正典 sih/ledger，两形标记俱缺即拒退出码二教学报文；缺省自当前目录上溯现形不变，上溯判别同步认 canonical 形。布局两形即静态目录标记判别零读钟零 LLM。canonical 形两根分离即检索数据取本域 root 而 locator 码根自最近祖先供给，城零 sih-tools 亦可检。

## 数据契约 {#data-contract}

主题轴匹配为机械匹配承寻址词查询语义，逐载体取条目级命中，无语义召回无向量。事件轴作用域限事件在档的记录即链上事件与停泊事件，按事件类型或 entry_id 或 session_id 匹配。时间轴作用域限时间戳在档的记录即链上事件与停泊事件，文件载体不猜时间。

五档映射即事实档经 scribe query 直查 trail 事件流，ndjson 载体不经寻址。结论档经寻址检索 md 载体。经验档经寻址检索 md 载体。悬置档两路即两册 PARKING 投影 md 经寻址与停泊记录 json 经寻址，停泊事件经 query。意图档两路即 ask3 记录 json 经寻址与链上意图事件经 query。

v1.3 增 canonical 城档映射即结论档 sih/event/plan 下 -results.md 后缀件、意图档 sih/state/plan 下任务包 md、悬置档 sih/state/parking/materials 下 json 加 sih/state/parking/PARKING-v1、事实档与停泊与意图事件档属分类表现表两形共用；经验档城无对应载体零命中如实。canonical 形链目录即本域 sih/event/trail。canonical 形索引用内嵌记忆包建至系统临时文件，零城侧配置零工作区落盘；first_domain 形映射与链目录与记忆包逐字节零变。

切面记录字段七件逐一必填。archive 即档名五值枚举。carrier 即载体记号即 md 或 json 或 event。ref 即出处，文件载体为相对工作区根路径加行区间，事件载体为 event_id 加 event_hash 前缀八位。axis 即命中轴即 topic 或 event 或 time，多轴命中各出一行。excerpt 即逐字摘录，上限二百五十六字符，超长截断附三句点省略标记。matched 即命中词或事件记号原文。at 即调用给参的参照时间逐字回显。

## 底座与退化 {#base}

底座两件即寻址 locator 承 md 与 json 与 yaml 与 toml 与 code 五载体条目检索、引擎 scribe query 承 trail 事件流查询。底座调用一律只读。退化性质即组件缺席则五档载体原样在，检索退化为裸 grep 与裸 query，功能降级而体系不失效。寻址两张期票即精确解析与向量召回若日后进场，底座可换轨，接口不变。

## 确定性 {#determinism}

同参双跑输出逐字节一致，即输出不含随机量、不读系统钟、不含未给参时间。排序机械即档序固定 fact 加 conclusion 加 experience 加 parked 加 intent，档内文件载体按路径字典序加行序，事件载体按链上顺序。输出无 score 字段、无 suggestion 字段、无 ranking 字段，即只报不判的字段级落点。截断规则唯一即 excerpt 超限截断附三句点。

## 退出码 {#exit-codes}

零即成功，有命中与零命中皆零。一即拦，轴全缺或参数互斥违例或档名非枚举值。二即异常，底座件缺席或目标不可读或输出不可写，报缺席件名不静默。

## 消费侧 {#consumers}

消费侧三处为声明面非接线承诺。一即三问前向约束的检索加载，意图锚定时命题与先例经 recall 机械在场，调用记录可验，机械在场不以自觉作保。二即批次起草时的先例检索，任务包起草前按主题取结论档与经验档切面。三即段结算时的结论档回取，结算单起草时按事件或时段取事实档与结论档切面。接线批另开，本规格只冻接口不接线。

## 边界与排除 {#boundaries}

不做语义向量召回即承寻址期票同源约束，进场在人节点。不替代 ai-ex 的经验沉淀职责即检索不产内容。不替任何工具做治理裁定即只报不判。不建全新存储即五档载体是权威源温故是查询面。不动五档载体的权威地位与写入路径。

## 验收判据 {#acceptance-criteria}

八条前置冻结即实装批 F 锚定来源，逐条机械判定。

- F-1 五档覆盖即五档各至少一条真实材料命中且出处可回验
- F-2 出处可机械回验即每条切面的 ref 可机械解析回源即文件行区间或事件哈希在链
- F-3 主题轴跨档即同一主题词跨至少三档返回切面
- F-4 事件轴正确即按事件类型过滤事实档与意图档，返回集与 query 位直查一致
- F-5 时间轴边界即 since 与 until 对链上事件时间戳过滤正确，边界日含即含
- F-6 只报不判字段级落点即输出无 score 无 suggestion 无 ranking 字段
- F-7 确定性即同参双跑逐字节一致
- F-8 退化不崩即底座件缺席时退出码二并报缺席件名，五档载体原样无损

## 实装与调度 {#implementation}

实装批另开待令。SDD 即以本规格为输入钉落差规格，TDD 即逐判据先红后绿留痕。语言与家位承 DEC-007 归属判据即引擎组件落 src。排序随统一裁决标准即哪一步让级联更早闭合哪一步先做。

## 版本与固定 {#version}

v1.2 于 2026-08-28 即底座引擎件名随 DEC-017 修订二回滚连带改写三处，接口零改。v1.1 于 2026-08-28 即组件名随 DEC-017 温故立名连带改写，接口零改即参数与退出码与输出形态不动。v1 于 2026-08-27 随立项批 mem-init-t6d 落盘。接口冻结即修订须走修订记录留痕，破冻显式可见。v1.3 于 2026-09-11 随 wengumcp-parallel 批增 --root 旗标与布局两形判别与 canonical 城档映射与内嵌记忆包，接口增量见接口签名与数据契约两节 v1.3 段，MCP 面投影归 SPEC-023 修订二承载。
