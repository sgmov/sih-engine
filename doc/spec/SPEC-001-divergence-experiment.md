# 偏离率阈值实验协议 v2

## 概览 {#overview}

本协议承接 DES-005 v2 偏离率收敛方法学与 DES-010 单 KEY 多专家范式实验设计，定义 SPEC-001 v2 偏离率阈值实验的接口契约与验收依据。

SPEC-001 v1 基于 N 等于 4 隔离采样加多数投票，已随 OQ-13 废止。本协议 v2 改基于偏离率 K 由 N 除加 Jaccard 相似度加收敛双指标，由确定性程序执行偏离率计算与收敛判定。

- 偏离率实验协议锁定接口签名与数据契约::[接口签名](#interface-signature)
- 语义判断材料结构与偏离率数值结构与 Jaccard 集合结构::[数据契约](#data-contract)
- 波动系数阈值与 Jaccard 阈值与偏离率阈值参数留空待实验数据填入::[验收依据](#acceptance-criteria)
- LLM 是材料生成器不是度量权威::[度量权威约束](#measurement-authority)
- 偏离率稳定性与版本漂移差与审阅频次边际收益三问题::[实验问题](#experiment-questions)
- 单 KEY 多专家范式收敛性验证::[专家数维度](#expert-dimension)

## 接口签名 {#interface-signature}

### 主入口 {#main-entry}

主入口接收实验材料，执行偏离率计算与收敛判定。

主入口的输入。document_id 即待审阅文档的唯一标识。check_items 即语义检查清单，含检查项名称与对应检查对象列表。expert_count 即本轮审阅的专家数，取值 1 或 3 或 5。attempt_id 即审次序号，标识本轮是第几次审阅。model_version 即模型名称与版本号。

主入口的输出。成功时返回 DivergenceExperimentOutput，含偏离率 K 由 N 除、数值结构、审阅单元集合、收敛双指标。失败时返回 DivergenceExperimentError，覆盖文档不存在、检查项为空、专家数不合法三类错误。

### 路径二入口 {#path-semantic-entry}

路径二入口在 SPEC-001 v2 中专指多专家审阅路径，与 SPEC-003 路径二含义不同。SPEC-003 路径二的 N 等于 4 隔离采样已废，本协议路径二指同一 KEY 下的多专家单次审阅。

路径二入口的输入。与主入口相同，expert_count 取 3 或 5。

路径二入口的输出。与主入口相同，额外返回跨专家 Jaccard 相似度与跨专家偏离率方差。

## 数据契约 {#data-contract}

### 语义判断材料 {#semantic-judgment-material}

语义判断材料是 NPC 专家团的产出，是偏离率计算的输入材料，不是最终度量。

语义判断材料的必须字段。stable_id 即审阅单元唯一标识，由确定性程序派生，取值文件路径加节点类型加节点序号加内容哈希。target_id 即检查对象，指向产出物语义单元节点的 stable_id。kind 即偏差类型，取值偏差发现、纠正建议、范畴标记三子类。severity 即严重度，取值 error、warning、info 三级。reason 即理由，一句话事实陈述，不引导判定。expert_id 即专家标识，取值 solo 或 expert-1 或 expert-2 或 expert-3 或 expert-4 或 expert-5。attempt_id 即审次序号。

kind 与 severity 跨专家稳定，不因 expert_id 变化而变化字段语义。reason 字段中立陈述，不含引导判定词汇。

### 偏离率数值结构 {#divergence-rate-numeric}

偏离率数值结构承载 K 由 N 除计算结果，由确定性程序派生。

偏离率数值结构的必须字段。k 即命中偏差的审阅单元数。n 即产出物总单元数，由确定性程序统计语义单元数得出。rate 即偏离率，等于 k 除以 n，保留四位小数。attempt_id 即本计算对应的审次序号。expert_count 即本计算对应的专家数。

N 大于 0 由上游入口校验保证。rate 为零时不代表无偏差，可能是 NPC 集体漏判。

### Jaccard 集合结构 {#jaccard-set}

Jaccard 集合结构承载审阅单元集合的相似度计算结果，由确定性程序派生。

Jaccard 集合结构的必须字段。set_a 即集合 A 的 stable_id 列表，对应 expert-1 或第一次审阅。set_b 即集合 B 的 stable_id 列表，对应 expert-2 或第二次审阅。jaccard_index 即 Jaccard 相似度，等于集合 A 与集合 B 交集除以并集，保留四位小数。pair_label 即配对标识，取值 expert-pair-1-2 或 attempt-pair-1-2。

expert_count 等于 1 时 Jaccard 不适用。expert_count 等于 3 时两两配对得 3 对，聚合取平均 Jaccard。expert_count 等于 5 时两两配对得 10 对，聚合取平均 Jaccard。

### 收敛双指标结构 {#convergence-dual-indicator}

收敛双指标结构承载波动系数与 Jaccard 阈值联合判定结果。

收敛双指标结构的必须字段。volatility_coefficient 即波动系数，等于标准差除以均值，保留四位小数。jaccard_mean 即平均 Jaccard 相似度。volatility_pass 即波动系数是否低于阈值。jaccard_pass 即平均 Jaccard 是否高于阈值。converged 即是否收敛，取值 true 当且仅当 volatility_pass 为 true 且 jaccard_pass 为 true。threshold_volatility 即本轮使用的波动系数阈值。threshold_jaccard 即本轮使用的 Jaccard 阈值。

参数阈值留空，待 DES-005 v2 的三个实验问题数据到位后填入。

### 偏离率实验输出结构 {#output-structure}

偏离率实验输出结构是主入口的成功返回类型。

偏离率实验输出结构的必须字段。document_id 即文档标识。check_items 即检查项清单。divergence_rate 即偏离率数值结构。jaccard_sets 即 Jaccard 集合列表，expert_count 等于 1 时为空列表。convergence_indicators 即收敛双指标结构。timestamp 即实验执行时间戳。model_version 即模型版本号。

## 验收依据 {#acceptance-criteria}

### 波动系数阈值 {#volatility-threshold}

波动系数阈值是收敛双指标之一，用于判定 K 由 N 除序列是否稳定。

波动系数定义。波动系数等于标准差除以均值，刻画偏离率数值的跨次稳定性。

波动系数的样本集等于同一文档同一检查项在指定维度(跨次审阅或跨专家审阅)下的 K 由 N 除序列。

阈值留空。波动系数阈值由 DES-005 v2 实验问题一审阅频次稳定性数据支撑后填入。

验收判据。同一文档同一检查项的审阅结果，若波动系数低于阈值则 volatility_pass 为 true。

### Jaccard 阈值 {#jaccard-threshold}

Jaccard 阈值是收敛双指标之二，用于判定审阅单元集合是否收敛。

Jaccard 定义。Jaccard 相似度等于两集合交集除以并集，刻画跨专家或跨次审阅的单元重合度。

阈值留空。Jaccard 阈值由 DES-005 v2 实验问题一审阅频次稳定性数据支撑后填入。

验收判据。跨专家审阅单元集合的平均 Jaccard 高于阈值则 jaccard_pass 为 true。

### 偏离率阈值 {#divergence-rate-threshold}

偏离率阈值是单次审阅结果的可接受上限，与收敛双指标独立判定。
独立判定意味着两套指标不互为否决;偏离率高加收敛态等于稳定告警(高偏离告警态),偏离率低加收敛态等于可能漏判(单向有效性)。

阈值留空。偏离率阈值由 DES-005 v2 三个实验问题综合数据支撑后填入。

验收判据。若单次审阅的偏离率高于阈值，触发高偏离告警，由确定性程序写入偏差记录。

### 收敛双指标联合判定 {#dual-indicator-joint}

波动系数阈值与 Jaccard 阈值须同时满足才算收敛。

判据。volatility_pass 为 true 且 jaccard_pass 为 true 时 converged 为 true，任一不过则 converged 为 false。

假性收敛识别。波动系数低但 Jaccard 低是「稳定地漏判」的假性收敛，双指标联合设计对此情形有效。

## 度量权威约束 {#measurement-authority}

度量权威约束是本协议的核心约束，不可绕过。

LLM 是材料生成器。NPC 专家团产出语义判断材料，含 kind、severity、reason 字段。LLM 的输出是审阅单元，不是度量值。

确定性程序是度量权威。K 与 N 由确定性程序统计，偏离率 K 由 N 除由确定性程序计算，Jaccard 相似度由确定性程序计算，波动系数由确定性程序计算。收敛双指标的阈值判定由确定性程序执行。

此约束承接工程基线第一条与第五条，承接 SPEC-003 L190 度量权威约束。

## 实验问题 {#experiment-questions}

本协议设计回答三个实验问题，参数阈值由实验数据填入。

### 问题一 偏离率稳定性 {#question-stability}

同一份文档，同一 NPC 专家团，多次审阅的偏离率 K 由 N 除是否稳定可度量。

稳定性判据。波动系数低于阈值，且审阅单元集合 Jaccard 高于阈值。两个指标都过才算稳定。

稳定性实验的操作规程。对同一文档同一检查项，执行 1 次、3 次、5 次审阅，记录每次的偏离率与审阅单元集合。跨次聚合计算波动系数与平均 Jaccard。K 由 N 除 次数不小于 2 时方可计算波动系数。

### 问题二 版本漂移差 {#question-version-drift}

模型版本漂移对审阅结果的影响量化。

版本漂移差的操作规程。同一份文档同一检查项，在不同模型版本下各审阅 1 次，比较偏离率差异与审阅单元集合差异。差异量化为版本漂移差，纳入偏离率补偿因子。

版本漂移差用于 DES-005 v2 的版本漂移差分析，不在本协议中设定容忍度阈值。

### 问题三 审阅频次边际收益 {#question-marginal}

审阅 1 次、3 次、5 次分别达到多高的稳定性，每增加一次审阅的边际收益是否递减。

边际收益的操作规程。对同一文档同一检查项，从 1 次审阅逐步增加到 5 次审阅，记录每次的波动系数与 Jaccard，绘制审阅频次与稳定性的权衡曲线。拐点即边际收益递减点，是审阅频次上限的候选值。

费用黑洞判据。拐点之后每增加一次审阅的稳定性提升低于阈值，继续审阅是费用黑洞。阈值留空。

## 专家数维度 {#expert-dimension}

专家数维度承接 DES-010 单 KEY 多专家范式实验设计，将 DES-005 v2 的「多次审阅」扩展为「多专家审阅」。

### 专家数三档 {#expert-count}

专家数含三档。N 等于 1 为单专家对照基准。N 等于 3 为三专家协作。N 等于 5 为五专家协作。

专家指同一模型实例下的多个独立 sub-agent，各自生成审阅单元，共享同一 KEY。

### 跨专家偏离率 {#cross-expert-divergence}

N 等于 1 时，偏差单元数 K 等于该单专家审阅命中的偏差单元数。N 大于 1 时，偏差单元数 K 等于多专家审阅并集命中的偏差单元数，即只要任一专家命中偏差，该单元计入 K。

### 跨专家一致性 {#cross-expert-consistency}

跨专家一致性的指标与单专家多次审阅相同，均为波动系数与 Jaccard 相似度。

指标一，跨专家 K 由 N 除 的方差低于阈值，刻画专家对偏离率数值的一致性。

指标二，跨专家审阅单元集合的平均 Jaccard 高于阈值，刻画专家对哪些是偏差的判定一致。

两指标都过意味单 KEY 多专家范式收敛。

### 边际收益递减 {#expert-marginal-utility}

每增加 1 个专家的稳定性提升，绘制专家数与稳定性的权衡曲线。曲线拐点即边际收益递减点，是专家数的推荐上限。

## 实验可复现性 {#reproducibility}

实验协议锁定以下要素，确保可复现。

模型版本锁定。实验执行时记录模型名称与版本号，版本号是记录项。

审阅 prompt 模板版本化。模板每次变更记录版本号与变更内容。

语义判断材料记录格式锁定。记录格式须可机械解析，供统计聚合程序消费。

审阅温度锁定。实验执行时记录 temperature 取值。

文档集锁定。实验对象是旧仓全量 263 份文档，文档集固定。

## 实验失败判据 {#failure-criteria}

判据一。同一文档同一 NPC 专家团多次审阅的偏离率不稳定，即波动系数与 Jaccard 双指标无法同时过阈值，则偏离率度量机制的假设不成立，本协议作废。

判据二。审阅 10 次以内双指标仍不收敛，则偏离率度量机制理论成立但工程不可行，本协议搁置。

判据三。版本漂移差使双指标无法稳定判定，则偏离率度量机制的稳定性不足，须引入版本锁定或降级为辅助参考。

判据四。五专家的 K 由 N 除 高于单专家的 K 由 N 除，即多专家反而漏判更多，与设计预期相反，单 KEY 多专家范式作废。

## 认识论立场 {#epistemic-stance}

本协议为 design-corollary 加 empirical-hypothesis 双重标签。design-corollary 是工程范式设计，empirical-hypothesis 是实验假设，偏离率收敛的稳定性尚未经实验验证。

可证伪条件一。若实验问题一显示偏离率不稳定，则偏离率度量机制假设被证伪，本协议作废。

可证伪条件二。若实验问题三显示合理审阅频次内双指标不可用，则偏离率度量机制工程不可行，本协议搁置。

可证伪条件三。若版本漂移差使 K 由 N 除 波动超过治理可接受范围，则偏离率度量机制稳定性不足，须降级为辅助参考。

可证伪条件四。若五专家 K 由 N 除 高于单专家，则单 KEY 多专家范式作废。
