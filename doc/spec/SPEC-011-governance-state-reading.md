## 定位 {#positioning}

治理态读数回答三问：引擎内组件离全治理态多远、agent 是否真经引擎做治理、工具轮孵化件距融回多远。三问今日靠人答，本组件把答案变成机械读数。组件是投影不是存储、是读数不是裁决：P5.1 信任锚点在人不在机，机械给不了信任只能给事实汇总，PRO-07 映照即工具只反映事实不投射判断。

三层正好盖住治理态全域：引擎自己对应收敛度、引擎的用户对应调用置信度、引擎的边界对应融回度。治理态评价即三层各一读数，一具三表盘。

## 三维定义 {#dimensions}

维度名随用户共识冻结，轴值三枚举即 convergence 与 adoption 与 mergeback。

收敛度 convergence 维、主体为引擎组件。语义即组件离全治理态的距离。证据类五件：契约面即组件在 doc 位的契约文档在席、检验面即核阅与检词对组件域内文档的通过记录、测试面即测试绿记录、锚定面即三问意图与认证事件对组件的覆盖、洁净面即级联上游洁净不变式记录。聚合语义即各类齐全为全治理态，收敛度是已具类占比的时间序列，收敛判据承 LIM-007 即序列最终距全治理态入 epsilon。

调用置信度 adoption 维、主体为会话或 actor。语义即该走引擎的治理动作中实际经引擎且验身者的窗口占比，零信任即不预存任何信任每笔都验。证据类四件：正身核验记录即三态与异常点、链上事件 actor 归属覆盖、计量对表记录、守卫拒写记录即拒写是绕行尝试信号。聚合语义为窗口占比，占比序列承 PROB-001 大数定律依概率收敛到真实采用率。

融回度 mergeback 维、主体为工具轮孵化工具。语义即工具距融回引擎侧的就绪度。证据类四件：契约完整度即契约在位与版本、验收判据状态、采用量即调用日志行量、融回门条件状态承外切孵化融回环登记。聚合语义即就绪类单调累积承 ORD-002 完全格序结构，越阈建议只报不判，出泊裁决归人节点。

## 接口签名 {#interface-signature}

接口面两动作，命令行子命令形态，宿主命令名待实装批立名，操作名 read 与 record 随本契约冻结。

read 即只算不落。参数五件：--dimension 即维度，可重复，缺省三维全出；--subject 即主体，可重复；--window 即窗口，批数或日期区间；--at 即参照时间显式给参不读系统钟；--out 即输出文件缺省标准输出。输出即读数清单逐行，含三表盘各主体的当前值与序列摘要。

record 即算并落链。接收与 read 同参，先算后经书简写路径落链为 reading_recorded 事件，走锁位守卫，落链后回显事件哈希。record 与 read 同参所得读数值逐字节一致。

## 数据契约 {#data-contract}

reading_recorded 事件字段七件逐一必填。dimension 即维度三值枚举。subject 即主体标识，收敛维为组件标识、采用维为会话或 actor 标识、融回维为工具标识。value 即零到一读数值，序列不足时为 insufficient 标记不虚构数值。window 即窗口描记。formula_version 即公式版本号，公式增改走版本管理。computed_at 即参照时间逐字回显。inputs_digest 即证据输入摘要，可机械解析回链上事件哈希集。

事件经引擎件书简写入主链，verify 链 valid。读数历史序列即链上同 dimension 与 subject 的 reading_recorded 事件按链序即得，无别处存储。

## 持久化 {#persistence}

证据输入零新写入即三维证据类全部读既有链上事件与既在档记录，组件不为取证据而新写任何档。读数输出落链即 record 动作经书简写路径追加 reading_recorded 事件，走锁位守卫，留痕不可篡改。链即库即不建独立存储，投影可弃可重算，投影与链不符以链为准。

持久化是收敛维的构成性条件而非可选项：收敛是序列性质，无持久化序列即只能出快照不能出收敛，单点无序列时收敛维出 insufficient 标记。此条承用户 2026-08-28 持久化裁定与 PRO-08 留痕构成性条件。

## 确定性 {#determinism}

同参双跑输出逐字节一致，即输出不含随机量、不读系统钟、不含未给参时间。排序机械即维度序固定 convergence 加 adoption 加 mergeback，维内主体按标识字典序。零 LLM 即全链路确定性程序。公式带 formula_version，公式增改走版本管理即旧读数不回改。

## 退出码 {#exit-codes}

零即成功，有读数与零主体皆零。一即拦，维度名非枚举值或参数互斥违例或窗口非法。二即异常，底座件缺席或链不可读或输出不可写，报缺席件名不静默。

## 消费侧 {#consumers}

消费侧三处为声明面非接线承诺。一即租约入口，open 报告附三维读数摘要，校准信号主动到场承 P5.2 校准去人类化。二即结算报告，段结算附本批相关主体读数。三即例行读数，周期触发点出全量三维快照。接线批另开，本契约只冻接口不接线。

## 边界与排除 {#boundaries}

不建独立存储即链即库。不读内容只读事件即零语义评估零 LLM。只报不判即输出无 suggestion 无 ranking 无 auto_action 字段，不替任何工具与人类做治理裁定。组件零拦截权限即读数不拦任何操作，硬闸归既有理由码位，阈值数值归人节点另令。不做向量召回。不动五档载体与链的权威地位。

## 验收判据 {#acceptance-criteria}

八条前置冻结即实装批 F 锚定来源，逐条机械判定。

- F-1 三维覆盖即三维各至少一真实主体证据命中且出处可回验
- F-2 出处回验即每读数 inputs_digest 可机械解析回链上事件哈希集
- F-3 持久化即 record 落链事件 verify 链 valid 且后续 read 可取自身历史序列
- F-4 确定性即同参双跑逐字节一致
- F-5 只报不判即输出无 suggestion 无 ranking 无 auto_action 字段
- F-6 零拦截即组件无拒写权限，退出码语义仅指自身异常与参数违例
- F-7 序列语义即单点无序列时收敛维出 insufficient 标记不虚构趋势
- F-8 退化不崩即底座件缺席时退出码二并报缺席件名，证据载体原样无损
