## 适用面 {#scope}

- 本规范约束引擎向界层命题起草位：facet_task_packages 命题档与进得一采样合同与执契裁决流的命题文形。
- 本规范是写法规范即文形约束：命题怎么写使裁决依据族可收敛、命题质量可机械核；命题选题的实质成立性与规范内容的具体修订不在本规范的裁断域。
- 每份依本规范起草的命题可经规范逐条机械核：结构在场可查、依据族归属可查、披露文形可查，判定不依赖审查者口味。

## 五条款 {#clauses}

- 条款一，一命题一裁决依据族：每份命题锚定单一裁决依据族，命题文中承载的规约诉求收敛到一族；实测底稿为 predmerge-guard-1 前裁跨主题捆绑命题致三族并立即 boundary 打回，与 predmerge-refine-b1 单基线锚重投收敛成对。
- 条款二，禁跨主题捆绑：一份命题不得并述多个互不隶属的主题对象；实测底稿为前裁三事并述命题的依据族散布，与 predsplit-a1/a2/a3 各单主题命题的逐发单值收敛成对；散的支配变量是命题对象跨主题。
- 条款三，双述不罚：命题文并述两条基线不构成违本规范，判散的支配变量是主题跨不跨而非述了几条；实测底稿为 predsplit-a1 双基线并述仍逐发收敛单族。
- 条款四，frontmatter 必载项：命题档 frontmatter 必载 gid 与 ng 与 n 与 authored 与 anchors 五项，自本规范起增列 seat 为第六必载项；五项是合同装配与 R5 基线配对与血统追溯的机械输入且在 predsplit 系命题档齐备，seat 项承 pk-035 身份强携带即计分与配对的既有强制面，predspec2-guard-1 命题档为增列前最后一档。
- 条款五，对己不利声明模板：涉自身利益的命题须载结构化对己不利声明，文形见下节模板；实测底稿为 adisp-guard-1 与 predsplitAB 系命题档的两重声明文形。

## 对己不利声明模板 {#adverse}

- 第一重利益面声明：判命题成立即规范或机制将约束起草席位自身后续动作的，须写明约束内容与判不立时席位保留的自由，两向并述。
- 第二重元层自指声明：命题自身应按其主张的规范被评，须逐条款写明本命题的自评落点，五条款逐项自指不缺项。
- 收尾要素四件：两重不利指向方向如实写明、如实陈述不为收敛而修饰、判定入飞轮留痕不抹、基线材料为既成事实非本批新造。
