# 语义验证微积分实验执行规格

本规格是 DES-005 语义验证微积分实验方法学的执行协议。DES-005 定义方法学即为什么这么设计，本规格定义执行协议即具体怎么跑。本规格承接 DES-005 的三个实验问题与采样协议，定义实验工具接口、判断记录数据契约、实验阶段状态转换、验收判据。

本规格的参数留空由实验数据填入，与 DES-005 一致。

## 概览 {#overview}

- 实验分两阶段：阶段零 prompt 校准与阶段一全量三轮::[实验阶段](#experiment-phases)
- 接口签名定义实验工具的输入输出契约::[接口签名](#interface-signature)
- 数据契约定义判断记录与统计产出的结构::[数据契约](#data-contract)
- 阶段零用锚定小集验证 prompt 区分力，不收敛则终止::[阶段零](#phase-zero)
- 阶段一三轮串行：收敛性、版本漂移、预算权衡::[阶段一](#phase-one)
- 验收依据含三轮的判定阈值::[验收依据](#acceptance)

## 实验阶段 {#experiment-phases}

实验分两阶段五步。阶段零一步即 prompt 校准，阶段一三轮即收敛性、版本漂移、预算权衡。两阶段串行，阶段零不通过则阶段一不启动。

实验阶段状态转换如下。初始态为待校准。阶段零通过后转为已校准。轮一通过后转为已收敛。轮二通过后转为已定量。轮三通过后转为已完成。任一步失败转为已终止，记录失败判据。

## 接口签名 {#interface-signature}

实验工具的接口签名。实验工具不是治理组件，是实验用的特殊程序。它消费文档集与检查协议，产出判断记录。

采样接口的输入。文档集路径，指向旧仓 sihankor/doc/ 全量 263 份文档。检查项清单，含承接关系有效性、可证伪条件存在性、认识论标签合法性、术语一致性四项。模型配置，含模型名称、版本号、temperature。采样次数 N。prompt 模板版本号。

采样接口的输出。判断记录列表，每条含文档 ID、检查项、采样序号、模型版本、temperature、判断结果、理由、时间戳。判断记录须可机械解析。

统计接口的输入。判断记录列表。分层维度即八大文档类型。交叉验证标记即失败标记文档清单。

统计接口的输出。按类型分层的判断分布、收敛曲线、版本漂移效应、预算置信度权衡曲线。

## 数据契约 {#data-contract}

判断记录的数据结构。每条判断记录是一个 JSON 对象，单行存储。

判断记录必须字段。doc_id 即文档相对路径。check_item 即检查项名称，取值承接关系有效性或可证伪条件存在性或认识论标签合法性或术语一致性。sample_seq 即采样序号，从 1 起整数。model_version 即模型名称与版本号。temperature 即采样温度。judgment 即判断结果，取值因检查项而异。reason 即一句话理由。timestamp 即采样时间戳。

判断结果的取值域。承接关系有效性取存在或不存在或不确定。可证伪条件存在性取存在或不存在或不确定。认识论标签合法性取合法或不合法。术语一致性取一致或不一致或不确定。

统计产出的数据结构。按类型分层的聚合结果，每类型每检查项含采样次数、各判断结果计数、基础置信度、方差、收敛标记。

基础置信度计算。基础置信度等于确认存在或合法或一致的次数除以总采样次数。方差计算采用二项分布方差公式即 p 乘以 1 减 p 除以 N，p 为基础置信度。

## 阶段零 {#phase-zero}

阶段零的目标是验证 prompt 模板的区分力。prompt 模板是实验的核心，如果模板本身无法区分好文档与坏文档，后续全量实验无意义。

### 锚定小集 {#anchor-set}

锚定小集 6 份文档，由 3 对对照组成。每对含一份失败标记文档与一份对照文档。

第一对。失败标记文档 design/DES-058-multi-agent-collaboration-framework.md，555 行，标记 FM-01 至 FM-06，失败类型为范畴归属层即多 Agent 错位为治理执行框架。对照文档选 design 目录中行数相近且未被标记的设计文档，候选为 design/DES-039-index-rebuild-design.md。

第二对。失败标记文档 decision/DEC-008-know-sediment.md，55 行，标记 FM-12，失败类型为结构性盲区即点状否决被整体层绕过。对照文档选 decision 目录中行数相近且未被标记的决策文档。

第三对。失败标记文档 draft/sprint-plan-setsp-reuse-2026-07-21.md，141 行，标记 FM-11，失败类型为范畴归属层即误诊注意力瓶颈为产出速度问题。对照文档选 draft 或 research 目录中行数相近且未被标记的文档。

对照文档的选择判据。同类型，行数差异不超过 30%，内容主题不同，未被失败复盘标记。

### 阶段零执行 {#phase-zero-execution}

锚定小集 6 份文档，4 个检查项，每项采样 10 次。总调用 240 次。

阶段零的判定。对每对对照，失败标记文档与对照文档在四个检查项上的判断分布须有统计差异。差异的判据：失败标记文档的方差或不确定比例显著高于对照文档，或失败标记文档的判断分布与对照文档的判断分布的卡方检验 p 值低于待定阈值。

阶段零的三种结果。结果一全部三对均有统计差异，prompt 模板区分力验证通过，进入阶段一。结果二部分对照对有差异部分无差异，须分析无差异对的检查项，调整对应 prompt 模板后重跑阶段零。结果三全部三对均无统计差异，prompt 模板区分力不足，须重新设计检查项或 prompt 模板。

### prompt 模板设计要求 {#prompt-design}

prompt 模板须满足三条要求。

要求一不引导判断。模板不得暗示应发现问题或应确认合规。模板以中立方式呈现检查问题。

要求二判断格式约束。模板须要求 LLM 按判断记录的取值域输出，不自由发挥。

要求三可复现。模板内容须版本化，每次变更记录版本号与变更内容。阶段零用模板版本 v0，调整后用 v1 以此类推。

prompt 模板的初稿留待阶段零执行前起草，不在本规格中定义具体内容。模板初稿须承接上述三条要求。

## 阶段一 {#phase-one}

阶段一在全量 263 份文档上执行三个实验问题。三轮串行，后轮依赖前轮结果。

### 轮一收敛性实验 {#round-one}

轮一在全量 263 份文档上，每份每个检查项采样 10 次。总调用 263 份乘以 4 检查项乘以 10 次等于 10520 次。

模型版本固定。temperature 固定。prompt 模板版本固定为阶段零通过的版本。

轮一产出。按类型分层的判断分布。每个文档每个检查项的收敛曲线，即从 1 次到 10 次采样的基础置信度与方差变化。

轮一判定。全量文档中超过 70% 在每个检查项上收敛，则机制成立。低于 50% 则机制不成立，实验终止，DES-005 作废。50% 至 70% 则机制部分成立，按检查项分别评估。

收敛的判据。从第 K 次采样起，后续采样的加入不改变基础置信度超出待定宽度的次数低于待定比例。K 即采样预算下限。

轮一不通过则实验终止，不进入轮二。

### 轮二版本漂移实验 {#round-two}

轮二在轮一的子集上执行。子集每类型选 3 份共 24 份。选择判据：每类型中选收敛性最好、收敛性最差、收敛性居中各 1 份。

轮二在 2 至 3 个模型版本下各采样 K 次。K 是轮一确定的收敛采样次数。总调用 24 份乘以 4 检查项乘以 K 次乘以 2 至 3 版本。

轮二产出。版本间判断分布差异。差异量化为版本漂移效应值。

轮二判定。版本间差异低于 10% 则补偿因子可忽略。差异 10% 至 30% 则补偿因子纳入置信度公式。差异高于 30% 则机制稳定性不足，降级为辅助参考。

用子集而非全量的理由。版本漂移实验的目的是量化效应大小，子集足以估计。费用控制。

### 轮三预算权衡实验 {#round-three}

轮三不产生新的 LLM 调用。轮三从轮一的 10 次采样数据中截取前 3 次、前 5 次、前 7 次的子序列，计算各自的基础置信度与方差。

轮三产出。采样次数与置信度稳定性的权衡曲线。曲线的拐点即边际收益递减点。

轮三判定。拐点之后每增加一次采样的置信度稳定性提升低于待定阈值，则拐点即费用黑洞边界。实际采样预算取轮一的下限 K 与轮三的上限 M 的权衡。

轮三复用轮一数据的理由。10 次采样的子序列分析等价于分别跑 3 次、5 次、7 次，但不需要新的 LLM 调用。这是费用优化，不影响统计有效性。

## 验收依据 {#acceptance}

实验的可独立验收工程单元是三个实验问题的统计结论。验收依据如下。

机制成立性验收。轮一的全量收敛数据，按类型分层报告。验收判据：超过 70% 文档收敛则通过，低于 50% 则不通过，50% 至 70% 则部分通过。

采样预算验收。轮一的收敛曲线确定下限 K，轮三的权衡曲线确定上限 M。验收产出：预算区间 K 至 M。

版本漂移补偿验收。轮二的版本间差异分布。验收产出：补偿因子计算方法或忽略声明。

prompt 模板验收。阶段零的区分力验证。验收判据：三对对照全部有统计差异则通过。

交叉验证验收。失败标记文档在轮一的收敛情况。验收判据：失败标记文档的不收敛优先归因于文档自身不一致，不归因于机制。若失败标记文档反而收敛良好，须检查检查项敏感度。

费用验收。实际总 token 消耗与预估的差异。验收产出：实际费用基线，供后续常态化运行参考。

## 费用估算 {#cost-estimate}

阶段零费用。6 份乘以 4 检查项乘以 10 次等于 240 次调用。按平均 200 行每份估算，input token 约 38 万。output token 按每次 100 至 200 估算约 2 万至 5 万。

轮一费用。263 份乘以 4 检查项乘以 10 次等于 10520 次调用。input token 约 1440 万。output token 约 105 万至 210 万。

轮二费用。24 份乘以 4 检查项乘以 K 次乘以 2 至 3 版本。K 待轮一定参。若 K 等于 5，调用 960 至 1440 次。input token 约 80 万至 120 万。

轮三费用。无新调用，复用轮一数据。

总费用。约 1500 万至 1700 万 input token，加约 110 万至 240 万 output token。实际费用取决于模型定价，本规格不锁定定价。

费用黑洞判据承接 DES-005。轮三的拐点之后继续采样是费用黑洞。

## 实验产出归属 {#output-placement}

实验产出分协议与数据两层，分属文档区与治理区。

协议层即 DES-005 方法学与本规格 SPEC-001，归文档区 doc/design/ 与 doc/spec/。协议的消费模式是被持续引用，任何人重跑实验或修订验证机制都须查阅协议。协议不随实验结束而归档。

数据层即标定的原始判断记录、统计聚合结果、参数定参建议，归治理区状态层 sih/state/calibration/。数据的本体是参验机制的标定基准集，不是发生过的事件。标定基准是当前已标定的度量值，可查询可被设计文档引用，随机制演进而更新，归状态层。

数据层的目录结构。按标定批次分目录，每批次一个子目录，目录名格式为标定代号加日期。每批次目录内含三类文件。第一类原始判断记录，即每次采样的结构化输出，JSON 单行格式，文件名格式为文档 ID 加检查项加批次。第二类统计聚合结果，即按类型分层的判断分布、收敛曲线、版本漂移效应、预算置信度权衡曲线。第三类参数定参建议，即基于统计聚合结果的参数取值建议。

sih/state/calibration/ 是 DEC-001 状态层的子节点。calibration 承载标定数据的结构即原始记录加聚合结果加定参建议。calibration 的实验设计受微积分与概率论与数理统计启发，用 N 次隔离采样标定语义判断的收敛基准。calibration 是已标定的基准值，不是探索性实验。

## 前置条件 {#prerequisites}

实验执行前须满足三个前置条件。

前置一执行环境。需要一个能批量调用 LLM API 的程序，支持记录每次调用的完整输入输出、控制 temperature 与模型版本、按判断记录格式结构化存储。这是实验工具不是治理组件。

前置二 prompt 模板。四个检查项各需一个 prompt 模板初稿，满足不引导判断与判断格式约束与可复现三条要求。模板初稿留待阶段零执行前起草。

前置三模型与定价。实验执行需要一个具体的模型与定价。DES-005 声明模型版本是记录项不是控制项，但执行须选定一个起始模型。模型选择与定价不在本规格范畴。

本规格为 design-corollary，是工程设计选择。实验阶段划分与执行协议是工程约定，承接 DES-005 方法学。参数留空由实验数据填入。

- 阶段一三轮串行依赖关系清晰，轮一不通过则终止

- 费用估算基于规模数据，分阶段估算
- 前置条件三项显式声明
