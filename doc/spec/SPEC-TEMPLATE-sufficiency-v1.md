# SPEC-TEMPLATE-sufficiency-v1: SDD 规格模板内容充分性必填项

## 概览 {#overview}

- 本模板为 docmath 程序收尾批交付件：SDD 规格模板增内容充分性必填项，承 2026-09-04 人节点裁定新旧都管，新批起草即用本模板，存量旧文档由同批补齐
- 必填三件即判据清单附红证、判定性常数挂锚、约束算子显式化，三件缺一即收尾闸门红
- 本模板自身按本模板评：三必填逐件自指见下

## 三必填 {#three-required}

- 判据清单附红证：每条验收判据须附能令其失败的可构造输入即红证；判据无红证即零信息判据，如实申报并留清账路径，不硬凑。承 ORD-010 与 PROB-008 与证伪覆盖度载体 sih-math/docs/docmath-carriers-derivation-2026-09-04.md
- 判定性常数挂锚：文中声明的判定性常数逐件携数学载体引用加推导档指引：同线双指针或同文档邻近在场，无声明的判定性常数则如实申报无声明的常数。des-001 C007 与 C008 与 C009 在役机械核验
- 约束算子显式化：规格若定义约束系统，约束算子 T_C 须显式书写并指明解唯一性判据，承规格充分性载体 ORD-002 与 ORD-003；无约束算子面则如实申报

## 节文形 {#section-shape}

新 SDD 文末置内容充分性节，锚 sufficiency，节内三行对表即判据红证对表、判定性常数挂锚对表、约束算子对表，逐行如实填写。文形样张见本模板自身文末节。

## 内容充分性 {#sufficiency}

- 判据红证对表：本模板三必填的红证为构造性自指：任一必填件缺席的规格样张即令闸门红，红证由收尾闸门缺节红证构造承载；判据红证对表行自身即必填件一的文形
- 判定性常数挂锚对表：本文档无声明的判定性常数；des-001 C007 与 C008 与 C009 行级与邻近级闸在役核验
- 约束算子对表：本文无约束算子面，如实申报
