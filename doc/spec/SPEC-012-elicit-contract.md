# SPEC-012 叩问组件契约

本规格承接用户 2026-08-29 叩问 Elicit 签核、三问意图链事件 9cc72514、askloop 批 skill 修订七所钉本质，定义叩问组件的接口契约与验收判据。本规格为契约先行落盘即接口冻结与验收判据前置，本批零代码，实装批以本规格为契约输入承 DEC-013 第一步纪律。叩问为机械缺口信号驱动的人工介入升级位：三问自审为正位，叩问只在信号响处发问，答案落人类输入日志，关键裁定在链。

## 定位 {#positioning}

叩问是三问的升级位不是替代位：三问自审先行，叩问在机械缺口信号响处接入人工。组件是符号数学件：信号计算、闸校验、日志写入全部确定性程序，语义判断留给人与 agent、被召回面支配、受外壳 schema 约束。哲学锚即应几，其未兆易谋，预防未来之未形，信号先于失败。

## 接口签名 {#interface-signature}

三操作，命令行子命令形态，宿主命令名实装批已定 elicit 原形，操作名 check 与 digest 与 suspend 承 v1.1 修订入冻结面。

check 即产缺口信号件。参数：--words 即显式词表可重复承接契约草稿新词、原 --input 文本件收紧淘汰即分词不做；--topics 即主题词可重复；--conflict-words 即冲突查词可重复；--packs 即检词包路径；--recall-face 即温故召回面 ndjson；--history-face 即历史裁定清单件；--out 即输出 ndjson 缺省标准输出；--at 即参照时间显式给参。输出即信号件 ndjson 逐行，字段五件：signal_type 即 unregistered 或 recall_miss 或 recall_conflict 或 ruling_conflict、subject 即命中词或主题、weight 即轻或重、source_ref 即出处可回验、at 即参照时间回显。

digest 即消化闸。参数：--signals 即信号件；--contract 即契约件。机械校验契约件含逐信号处置记录即每信号行有对应消解声明或升级声明，缺一即拦。

suspend 即挂起记录：--signals 落 state suspended 于 --log，升级后无应答时调用，无代答路径。

## 三扳机 {#triggers}

两半机械承两类数学分账。符号层工具算：未登记词即检词登记面查无、召回零命中即归档面按主题零行，两者全机械可复算。语义层 agent 判：召回面命中与请求相抵为 recall_conflict 候选、与历史裁定相抵为 ruling_conflict 候选，工具只出候选面不出判定，判定由 agent 作并受信号件支配，外壳只验处置记录在否。

## 消化闸 {#digest}

契约件必须逐信号携带处置记录：消解声明即解释信号为何不构成缺口，或升级声明即列明将问问题交人作答。缺任一处置即 digest 退出码一，契约不得过闸。处置记录落契约问答位，问答正文落人类输入日志。

## 嫁妆 {#dowry}

量级相称即叩之小大应小大：信号 weight 分轻与重，轻信号短问即一词一线，重信号长问即一组一线，问粒度与信号量级相称写入升级声明格式。无应答挂起即钟不在场不代鸣：升级后无应答时升级记录落日志挂起态，组件不代答不自选不复炼契约。

## 确定性 {#determinism}

同参双跑输出逐字节一致：信号件排序即 signal_type 字典序加 subject 字典序、无随机量、不读系统钟、--at 显式。零 LLM 即组件全链路确定性程序，语义判断在组件外。日志与信号件只增不改。

## 退出码 {#exit-codes}

零即 check 无信号或 digest 全处置。一即 check 有信号或 digest 有未处置信号。二即异常，检词包或召回面或历史面缺席或不可读，报缺席件名不静默。

## 边界与排除 {#boundaries}

不做语义向量召回。不代答不裁决即答案与判定归人。不在三问向内诘察期间发问即本组件是升级位非前置位。主链零日常对话即问答正文归人类输入日志。不动检词与温故本体。

## 验收判据 {#acceptance-criteria}

- F-1 未登记词信号即检词查无词机械检出双跑一致
- F-2 召回零命中信号即归档面零行机械检出双跑一致
- F-3 消化闸即缺处置记录契约被拦退出码一、全处置过闸退出码零
- F-4 量级相称即信号 weight 字段与升级声明格式在案
- F-5 无应答挂起即挂起态可落日志且组件无代答路径
- F-6 确定性即同参双跑逐字节一致
- F-7 退化不崩即底座件缺席退出码二报缺席件名
- F-8 外切形制即家位 sih-tools、契约先行、融回门承 DEC-013 两重门槛
