# SPEC-019: 判定性常数邻近级闸门规约

## 概览 {#overview}

本规约钉死 gatemath-solo 批新增核阅违规类的规则语义与机械边界，承载 mathpipe-full-program-v1 收尾批节「闸门自维持」的第二级收紧。gatecap-solo 批 2026-09-04 已落行级闸即 des-001 包 C007 与 C008，声明形行须行内双指针；本批在其上加文档级邻近地板即 C009，触发面扩到水平与窗口与预算类，合规形降为载体引用与推导档指针同文档邻近在场。本规约同时承载 F-3 checkcite 书单对表规则化的择路申报与推导档复核语义钉死，与判变申报。批性质为行为变更批：SDD 先行，TDD 先红后绿，判变只向前生效不溯往。

## 背景与定位 {#context}

### 上游在位 {#upstream}

- gatecap-solo 批落 C007 与 C008 行级闸：声明形行全行无 @ 指针即违规，仅携单指针即违规，包版本 0.2.0 在役，双实现双跑一致，存量对表 135 面零命中。
- gatecap 批包头注记如实声明机械边界：全文档级条件与邻近登记面核查超出六类 text 谓词能力，由 tally R8 推导档机械复核与人工抽检承载。
- constclear-solo 批三态清账落定：推导 8 件与改判 3 件与冻结 23 件入泊 pk-053，rev3 账本为判定性常数判定源。
- checkcite 引用闭包核对自 2026-09-02 起脚本化在役，sih-tools/wikirecall/checkcite.py，各批实战调用。

### 语义缺口 {#gap}

行级闸留两处缺口。其一，触发面缺口：C007 词面为阈值与判据与裁决规则三类，常数以水平与窗口与预算词形声明时行级闸不可见。其二，合规形缺口：行级闸要求指针与声明同线，而 M-1 语义只要求载体引用加推导指引邻近在场，同文档在场即为合规，行级闸把邻近合规形误作违规。本批以文档级谓词补这两处缺口，既有 C007 与 C008 判定位零触碰。

## 规则语义 {#sdd}

### 判定性常数触发面 {#trigger}

判定性常数声明形行定义：行内出现触发词后经至多一个桥接符与空白邻接数字的形态。触发词七类：阈值、判据、裁决规则、水平、窗口、预算，前三类承 C007 既有词面，后三类为本批扩展。桥接符集为半角冒号与半角等号与全角冒号与全角等号与汉字为。词面正则即触发词接空白接桥接符计量零或一接空白接数字。围栏代码块内行豁免声明形判定，行内代码跨内文本剥离后判定，承既有行级谓词约定。

### 载体引用与推导指引 {#carrier}

载体引用词面：数学条目 ID 族九前缀即 TOP 与 PROB 与 ORD 与 ALG 与 CALC 与 LIM 与 DIFF 与 INT 与 APP 接连字符接数字，前后词边界。前八前缀承 des-001-mathe 包 M008 合法前缀族，APP 承 AGENTS.md 数学仓承接面读数即附录族 APP-009 与 APP-011 为数学载体。路径内嵌 ID 计为在场，即 @ sih-math 路径中含概念 ID 与裸写概念 ID 同判。词面族与 checkcite 引用件 ID 提取词面同构承 F-3 复核语义一贯。

推导指引词面：sih-math/docs/ 路径且路径含 derivation 段，即推导档命名族。裸写推导档路径与 @ 指针内路径同判。

### 邻近在场 {#nearby}

邻近在场的 v1 机械定义：同文档在场。文档全文含围栏内行存在至少一处女体词面命中且存在至少一处推导档词面命中，则本文档内全部声明形行合规。子文档节级邻近即同节或邻近数行的机械判定超出本批谓词能力，如实声明为边界，归后继谓词批或人检抽核。

### 违规判定 {#verdict}

文档存在声明形行而邻近在场不成立，即载体与推导档至少其一全文缺席，则每一条声明形行各出一笔违规，码位 C009，违规单元是常数引入行本身。合规判据是全文双在场，声明行自身是否携指针不作要求，即邻近合规形与同线合规形都合规，同线合规形由既有 C007 与 C008 继续独立约束不因本批放松。

### 谓词形态择路申报 {#predicate-choice}

实查结论：六类 text 谓词即 charset_forbid 与 charset_allow 与 forbid_pattern 与 header_structure 与 line_flag 与 nav_format 皆为行级或标题级无文档级条件求值能力，des-001-mathe 包头 M001 至 M009 必含语义未能实现注记与 des-001 包 C007 注记双证在案，纯数据组合不可表。择路：引擎谓词类扩展，新增文档级 kind 双实现入引擎 Rust 侧与工具侧 Python，包侧纯数据传参零域知识内嵌，承包文件「零规则知识」头部约束。Rust 与 Python 变更各走 TDD 先红后绿。

### 机械边界如实声明 {#boundary}

三边界如实声明。其一，散文后置形不可及：常数以「累计采样发数不超过九」类散文形声明而无触发词邻数形态时 C009 不可见，此形归 tally R8 与人工抽检承载，承 gatecap 批已声明边界。其二，节级邻近不可及：同文档即邻近，节级收紧归后继批。其三，载体词面为词面判非盘面判：词面命中不核实所指条目盘面实存，盘面实存复核归 F-3 书单对表即 checkcite 闭包核对承载，两层合成完整闸。

## 书单对表规则化 {#checkcite}

F-3 实查结论：checkcite 已脚本化，判据为被引概念 ID 全落召回书单条目集与一跳图闭包与骨架文件清单的并集，退出码零即过一即拦。择路申报：升格为管线必跑步，BATCH-FACE 全链序定位节加书单对表一行，不并入 tally。依据三条：其一 tally R8 已在裁决时点核对推导档指针所指文件存在性，引用闭包语义并入 tally 与 R8 存在性核对叠床且把生产时点闸后移到裁决时点削弱闸力；其二管线必跑步是零代码变更升格，承工程基线第五条减少机制；其三 checkcite 各批实战在役调用形已稳定即 BATCH-FACE 书单对表守卫节在案。

推导档复核语义钉死：盘面实存即推导档被引概念 ID 经 checkcite 闭包核对全落书单并集为机械闸，退出码一拦收口；引文一致性即推导档内引文须为被引源文件逐字节子串，承 ask3 三锚程序切片纪律由生成端切片承载，复核端抽核，禁手打引文为生成纪律红线。两层语义自本批起为推导档机械复核的钉死语义。
