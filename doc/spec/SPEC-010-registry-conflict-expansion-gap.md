# SPEC-010 路择登记冲突谓词扩域落差规格

本规格承接路择契约修订二即按轮判定族登记与 SPEC-008 与 SPEC-009 落差规格先例，钉死路择登记冲突告警扩域批的工具侧待建面。本规格是 SDD 产物即先于实现，实现按 TDD 执行即逐判据 F-1 至 F-6 先红后绿，红转绿留痕于实现批结果档。谓词参数名随本规格钉死，实现批不得改名，表达力不足走本规格修订留痕。工具侧现状权威即 sih-tools/selector/CONTRACT.md。

## 概览 {#overview}

- 现面即按轮回执自包含式冲突检测一处，四处落差即告警无归件、结论面单值硬编码、匹配唯全串相等、回执参与面无界::[现面盘点](#baseline)
- 扩域四件即告警归件、匹配面参数、结论面参数、回执面参数，全数据驱动缺省形即现行为::[扩域四件](#expansion)
- 三边界不破即空腹、回执自包含、告警不拦路，范畴排除三条显式声明::[边界与排除](#boundaries)
- 测试计划六组即缺省零漂移与归件与匹配面与结论面与回执面与确定性面::[测试计划](#tdd)
- 缺陷登记即停泊材料时刻串支线两日复现属材料侧如实登记不归本规格::[缺陷登记](#defects)

## 现面盘点 {#baseline}

登记冲突告警是路择按轮判定族第四件，告警位非路由位即谓词恒过不参与定路，产出通道是批级告警。现行为钉死即：仅轮记录材料参查即 round 键为对象；逐结论查其 kind 恰为 establishes_term；该结论 term 恰出现于任一回执的 flagged_terms 即全串相等；命中即产告警，告警形态三键即 kind、term、conclusion。实现单点即 predicates 的 registry_conflicts 一函数，冲突检测全路径只此一处。

四处落差逐条：一告警不带材料 id 与路径，批内多材料冲突不可归件，回溯断链，对照同族在泊超期告警携 id 先例；二结论种类 establishes_term 硬编码于谓词源，新承诺种类须改引擎即违空腹；三 term 比对唯全串相等，死档词作子串嵌于新名一类包含形态漏检，检词死档禁用实质是包含关系；四 flagged_terms 取自任意工具回执无界，回执面无法按工具收窄。

## 扩域四件 {#expansion}

扩域全落告警位即判定算法、路由定路、退出码语义零改，改的只是冲突告警的检测面与形态。

告警归件
: 冲突告警形态由三键扩五键，增 id 与 path 两键取自材料顶层同名字段。批级汇聚次序不变。

匹配面参数 match
: 谓词新增可选参数，取值枚举 exact 与 contains，缺省 exact。exact 即现行为全串相等。contains 即结论 term 包含任一参查 flagged_terms 项为子串即判撞，子串方向恒为 term 含 flagged。

结论面参数 establish_kinds
: 谓词新增可选参数，字符串表，缺省 establishes_term 单值表。结论 kind 命中表内任一值即参查，未命中跳过。

回执面参数 receipt_tools
: 谓词新增可选参数，字符串表，缺省空表即全回执。非空时仅 tool 字段命中表内值的回执的 flagged_terms 参查，其余回执忽略。

缺省形零漂移
: 四参数全缺省且材料无冲突告警时，报告与 0.4.0 基线逐字节相等。有冲突告警时告警形态变更即五键，此形态变更以路择工具版本升 0.5.0 显式承载，契约修订记录留痕，旧测相应修订不静默。参数非法即 match 非枚举值或 establish_kinds 与 receipt_tools 非字符串表，包装载拒即包非法退出码二。

## 边界与排除 {#boundaries}

三边界不破。空腹即四件全为包参数，引擎零登记册知识零词表知识，新语义零引擎改动。回执自包含即不读检词登记册不解析外部报告，flagged_terms 的产出与写入仍归轮记录作者，路择零跨包耦合。告警位恒不参与定路即扩域只反映事实不投射判断，告警是事实不是动作，判在别处。

范畴排除三条：不扩时间维度族即到期判定与在泊告警零改；不改轮记录 schema 即 conclusions 与 receipts 字段形零改；不动 parking 谓词包。

## 测试计划 {#tdd}

红态即现役 0.4.0 面，绿态即全判据过。六组如下。

F-1 缺省形零漂移
: 无冲突批输出与 0.4.0 基线逐字节相等；既有冲突标本在缺省参数下判定结果与 0.4.0 一致即告警仅增 id 与 path 两键。

F-2 归件
: 批内两材料各携一冲突，两告警各带本材料 id 与 path，互不串件。

F-3 匹配面
: contains 下新名含 flagged 子串判撞，exact 同料不撞；contains 对全串相等形态亦判撞即包含关系含相等。

F-4 结论面
: establish_kinds 扩值后新结论种类命中出告警，缺省单值对新种类不撞。

F-5 回执面
: receipt_tools 收窄后未列工具回执的 flagged_terms 不入查，列内工具照常出告警。

F-6 确定性面
: 同输入同包双跑逐字节一致；源文件零写即对表前后内容哈希不变；参数非法三形各证包非法退出码二。

## 缺陷登记 {#defects}

停泊材料 pk-023 的 entered_at 载时刻时区串不合 ISO 日期 schema，到期判定 fail-closed 判败走支线，2026-08-27 与 08-28 两日心跳复现。属材料侧格式与时间谓词域，不归本规格处置，如实登记。

## 验收判据 {#acceptance-criteria}

- A1 本规格在实现代码落盘前在档即落差先钉后实现
- A2 F-1 至 F-6 全绿且红态输出在实现批结果档留痕
- A3 三边界逐条对表无违即空腹与自包含与不拦路各机械可判
- A4 缺省形零漂移机械可判即无冲突批输出与 0.4.0 基线逐字节相等
