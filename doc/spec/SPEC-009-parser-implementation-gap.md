# SPEC-009 句读落差规格

本规格承接句读契约与 DEC-016 立项决策与 SPEC-008 SDD 先例，钉死句读实现批的工具侧待建面。本规格是 SDD 产物即先于实现，实现按 TDD 执行即逐判据 F-1 至 F-8 先红后绿，红转绿留痕于实现批结果档。参数旗标名随实现批冻结，本规格钉行为面与输出形态。工具侧现状权威即 sih-tools/parser/CONTRACT.md。

## 概览 {#overview}

- 现面即 parser 目录契约单件零代码，落差为语言包三件加解析引擎加四子命令加文法包四件::[现面盘点](#baseline)
- 语言包三件即词法表与产生式与条目映射，JSON schema 逐字段钉死，纯数据零代码::[语言包三件](#langpack)
- 引擎即先词法后产生式两段，PEG 组合子五类数据形，零语言知识零第三方解析依赖::[引擎形态](#engine)
- 四子命令行为面即 parse 产树不落盘、entries 产十字段条目、lint 三查、vectors 金向量::[子命令面](#cli)
- 文法分级 v1 即 Rust 声明层全保真与表达式配平节点，产出对齐寻址 code 九 kind::[分级与对齐](#staging)
- 容错两层即树级错误节点包裹与语法级数据驱动再入，残缺输入永远产树::[容错两层](#tolerance)
- 测试计划八组承契约验收六判据加补充两组，红态即入口建桩未实现::[测试计划](#tdd)
- 缺陷登记即对表基准用窄域包绕开寻址 core 包段错误::[缺陷登记](#defects)

## 现面盘点 {#baseline}

parser 目录现状即 CONTRACT.md 单件，立项批判据三锚定之一即目录无实现代码，本规格落盘后维持零代码即落差全件归实现批。寻址在役面即 code 载体走 tree-sitter 原生绑定，崩溃语料四文件经逐文件隔离子进程机械重推定档即 sih-engine/src/ask3repeater/validate.rs 与 src/event_stream/append.rs 与 src/event_stream/query.rs 与 src/retriever/mod.rs 各退出码 139，重接测试在验收位即用户 2026-08-27 裁定。条目对齐目标即寻址条目十字段 id、path、carrier、kind、name、seq、line_start、line_end、content_hash、text，id 派生承 DES-009 即料串 path、carrier 冒号 kind、seq 十进制、content_hash 四段以 U+0000 连接取 sha256 六十四位十六进制。code 载体 kind 九值即 function 与 struct 与 enum 与 trait 与 impl 与 const 与 static 与 type 与 module。

## 语言包三件 {#langpack}

语言包即一目录三文件，纯数据零代码，JSON 即 UTF-8 无注释，三件齐备由 lint 判。

词法表 tokens.json
: 顶层两字段即 version 恒一、tokens 有序表。表元三字段即 name 词法名、pattern 即 Python 标准库 re 语法字符串、skip 布尔省假。有序即先声明先试即序即优先级，匹配锚定于剩余输入之首。skip 真即记号不入流不入树。全表不中即产 error 记号吞一字符继续，词法层不拒输入。

产生式 grammar.json
: 顶层三字段即 version 恒一、start 起始规则名、rules 映射即规则名到组合子树。组合子五类数据形即 seq 子列表、choice 子列表、repeat 带 min 与 max、opt 单子、ahead 带 neg。叶两类即 token 引词法名、rule 引规则名。有序选择即先中先取后位不回溯即 PEG 语义。规则引用闭合由 lint 判即未定义规则与不可达规则与直接及间接左递归皆违例。

条目映射 mapping.json
: 顶层两字段即 version 恒一、entries 表。表元四字段即 rule 规则名、kind 即寻址 kind 值、name_from 即取名词法名可缺、text_form 即原文或紧凑两枚举省原文。规则命中即产一条条目，name 取该节点下首个 name_from 词法记号之原文，缺即置 null 承寻址无名单元例。text 即节点区间原文，数据标量用紧凑即 json 紧凑序列化。seq 投影时按文件按载体按 kind 文档序起一即与寻址同式。行位即节点起止行。

## 引擎形态 {#engine}

解析两段即先词法后产生式。词法按词法表有序扫描产记号流，记号带行位与原文。产生式即组合子解释器按数据树运行于记号流，选择不中即败于当位即无回溯重试前位。树即节点三形即规则节点带名带子女、词法叶、错误节点。产出树进程内即弃永不落盘即契约语义。

空腹可证即引擎源零语言名与语言特判，判据即引擎源检索语言名零命中，rust 语全部在语言包数据。新语言即新包目录三件零引擎改动即 git 对表引擎面零改动。确定性即同输入同包同引擎版本双跑逐字节一致，序列化无系统钟无随机无路径外量。零第三方解析依赖即标准库自足，依赖清单机械可证即 uv tree 零分布。

## 子命令面 {#cli}

四子命令行为钉死，旗标名随实现批冻结：

parse 即单文件解析产树至标准输出，退出码承三值，用途即语料观察与调试非管线件。

entries 即语言包与输入与输出三参即契约已钉形态，产出 ndjson 十字段条目流，与寻址索引件条目同形可对表。

lint 即语言包三查即三件齐备与引用闭合与条目映射可达，包作者第一动作。三件齐备即三文件在且 schema 合。引用闭合即 token 与 rule 引用皆有定义、无不可达规则、无直接及间接左递归。条目映射可达即映射件所引规则自 start 可导。

vectors 即金向量冻结与回归，模式承寻址与书简先例即冻期望输出逐字节复算，全过才许发布，包版本变更须重冻。

退出码三值承契约即零解析产树或抽取完成、一包校验违例或输入不可读、二工具异常。

## 分级与对齐 {#staging}

文法包按深度分级出版即契约钉死。v1 即 Rust 声明层全保真：fn 即 function、struct、enum、trait、impl、const、static、type 别名、mod 即 module，九 kind 与寻址 code kind 集一一对应。use 即树节点不入条目映射。声明层全保真即声明头与署名与可见性与属性全解析，函数体内嵌项亦入树。表达式内部作配平节点即括号与引号配平吞区间产单节点不析内部，配平节点不入条目映射。深阶语法随需升级即 v2 表达式层出版走契约修订记录，不破 v1 条目流。

对表语言包即 md 与 json 两语随实现批出版，供窄域包语料对表用即验收判据二载体面，非 v1 分级承诺面。md 语 kind 承寻址即 heading 与 para 与 list_item 与 fence，json 语即 key 与 idx，无名单元 name 置 null，json 无行位即 null 同形。

## 容错两层 {#tolerance}

树级错误节点包裹承 ANTLR ErrorNode 模型即期望不中处包错误节点记期望与实得与区间，永远产树不弃不拒。语法级自动恢复承 2025 路线即 arXiv 2507.03629，恢复点数据驱动即产生式可声明同步集即词法名表，缺省即规则界恢复。恢复后继续产树，错误节点计入树即错误可见不静默。词法层兜底即全表不中产 error 记号吞一字符。任何残缺与截断与空输入产树带错误节点零异常退出码零即契约语义。

## 测试计划 {#tdd}

红态即入口建桩未实现承 SPEC-008 先例，绿态即全判据过。八组如下，F-1 至 F-6 承契约验收判据六条，F-7 与 F-8 为补充。

F-1 崩溃语料重接零崩
: 语料即现面盘点所钉四文件按内容取件，现役运行时逐件 parse 产树退出码零，错误节点有无如实计不计失败。

F-2 窄域包条目对表
: 寻址窄域包语料即 packs/memory 百九十四文件，entries 对表基准即寻址 build 索引件，判据即同文件同条目十字段逐字段一致含 json 无行位 null 同形与 id 同式复算。

F-3 双跑逐字节一致
: 同输入同包两跑 parse 与 entries 输出逐字节相等，含残缺输入两形。

F-4 零第三方依赖可证
: 依赖清单即 uv tree 零分布，引擎源零 tree-sitter 引用，机械对表留输出。

F-5 新语言纯数据接入零引擎改动
: 以最小玩具语言包三件接入，git 对表引擎面零改动即 diff 空。

F-6 残缺输入产树带错误节点
: 截断与乱码与空文件各形 parse 产树退出码零树含错误节点零异常。

F-7 lint 三查
: 三件齐备与引用闭合含左递归拒与不可达拒、条目映射可达，违例各形退出码一。

F-8 退出码三值与只读面
: 三值映射各证一形即成功零、包违例或输入不可读一、工具异常二，源文件零写即对表前后内容哈希不变。

## 缺陷登记 {#defects}

对表基准即寻址窄域包，绕开 core 包全仓构建段错误即 SPEC-008 缺陷登记，窄域包不含 code 载体即基准安全。对表跑于寻址 build 现役面零改即只读调用。
