## 全态定义 {#full-state}

承接 PRO-005 全态段，决策落位即 DEC-007 子决策七。全态是司衡引擎开发完毕且 sih-engine 与其所有组件正常展开级联工作的运行形态，级联涵盖工具调用链，全态即引擎组件级联加工具调用链。全态是领域的运行态补全，信息洪流治理是全态的运行效果本身，不是全态里的一个功能。全态非封存态，到达全态后损补节律仍在运转，判据再校准、席位基线重测、规则退出与替换照常进行。全态给建造侧提供知止锚点，回答什么叫做完了。级联未闭合前不宣称到达全态，排序统一裁决标准即哪一步让级联更早闭合哪一步先做。

## 展开清单 {#expansion}

组件六即三问、参验、书简、判定器、视图、温故。前四为直接治理动作组件，三问承接应几的前向约束，参验承接鉴的反映，书简承接应的留痕，判定器承接结构性裁定；视图为聚合输出组件，承接人类只在视图告警时介入；温故为已沉淀物的检索面激活组件，承接注意力加载与跨域检索与留痕读侧即已沉淀物在需要时机械在场，2026-08-27 经 PRO-008 A案与 DEC-014 入列。层级归属与四条判据见 DEC-007 与 PRO-008。

基础设施五即 worktree 加 2locks、度量服务、hash 与时间戳、持久化、索引。本层不承接哲学命题，提供组件运行前提，层内待判定子项形态的归类停全态泊界。

融回件集即路择谓词经可插拔机制融回判定器模块、按轮判定的谓词族融回三问模块、facet 转模块接口且单独发布能力保留即双模并存、书简融回接引擎既有 event_stream 非重建。核阅与化格与检词与计数随组件实装同期归位。

闭合判据即 GOV-002 退出标准五条：任务包 007 至 013 执行完毕并关闭且六组件落地 src；路择的谓词件融回判定器模块；按轮判定的截流谓词族融回三问模块；facet 转模块接口调用双模并存；引擎 task-packages 内 facet 过程件归零。五条全部可机械判定，全部达成即级联闭合，即主线 v1 结算。组件第六席即项目记忆经 pk-024 于 2026-08-27 用户裁入退出标准清单即 GOV-002 v1.4 承载，首条组件列扩为六席。

## 编排 {#sequence}

第 0 段，已结算沉淀。文档链毕即 DEC-006 与 DEC-007 与 DES-013 与 SPEC-005 落盘，三问端到端贯通即核阅验收位、书简 intent 写入位、首条真实意图记录入链。工具线八件外切孵化中即核阅、化格、书简、检词、路择、计数、LaTeX 书写辅助、正身即身份验证，工具线第一次段结算已执行，结算单 SETTLEMENT-001 待人节点签署。

第 1 段，当前段，唯一详列段。worktree 加 2locks 外切孵化，2026-08-25 用户裁定基础设施先行，即并发隔离与文件锁经围堰施工。立项 DEC 承 DEC-009 终裁即 git commit 治理边界随案定案，终裁对象含 SETSP 既有 pre-commit 设计取舍与 lease 即文件租约归属。接口契约先于工具本体，验收判据前置，融回落点即引擎基础设施层承 DEC-007 归属判据。

第 2 段，仅方向。三问 src 实装与确定性外壳，承 SETTLEMENT-001 遗留与指针节，另批承载。

远端，仅指针。组件 src 实装序按排序统一裁决标准随任务包推进。六工具融回门评估由用户届时裁量，体量与时间两重门槛齐备且贡献度成立才开，贡献度记账已裁沿用融回机制既证形态即证据全部从留痕取数即 pk-015 于 2026-08-27 出泊闭项。GOV-002 冻结清单首项里程碑修订窗观察停全态泊界。

## 泊界 {#parking}

全态线未来事项一律停全态泊界即 sih-engine/doc/governance/PARKING-v1.md，不入本向界。账本走书简 trail 停泊事件，到期判定与在泊告警走路择 parking 谓词包，心跳报数归视图族远端，出泊唯人节点。停泊名册与工具线泊界共单一名册续号不重号。

## 增长纪律 {#discipline}

每段结算后追加本向界，向界是轨迹的沉淀不是计划的预写。新想法一律泊界，前瞻深度恒为一。一页为限，超限即拆结算记录另存。
