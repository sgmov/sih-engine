# git commit 司衡接管向界 v1

本向界是 git commit 司衡接管线的方向页，承接 DEC-009 终裁时点即 worktree 加两锁启动时一并定与 DEC-011 终裁一二，承用户 2026-08-26 对接管建议方案的批准。本页承载接管的向界定义、五钉位与分期，终裁细节归 DEC-012，冲突时以 DEC-012 为准。

## 概览 {#overview}

- 接管域即租约在册域现 sih-engine 与 sih-tools，域内提交资格与信息与节奏与 worktree 生命周期与历史不可改五面收归司衡机械判定::[向界定义](#takeover-scope)
- 五钉位即通道唯一、信息机械生成、提交界与认证门同界、历史不可改起点、反绕行对表::[五钉位](#pins)
- 分期三段即期零签署立起点、期一 lease 1.1 工具承载、期二引擎闸门::[分期](#phases)
- 接管线未来事项一律停治理泊界，出泊唯人节点::[泊界](#parking)
- 版本 v1 于 2026-08-26 起草待签，签署即历史不可改起点::[版本与固定](#version)

## 向界定义 {#takeover-scope}

git commit 司衡接管即治理域内提交行为从 LLM 自由裁量收归司衡机械判定。LLM 仍是符号材料的生成器即代码与文档内容，提交的资格判定、信息生成、时点判定归确定性程序，承工程基线第一条即确定性程序是治理操作的唯一执行者与第五条即治理延伸是减少 LLM 参与。接管生效判据为租约在册即开租约的仓入域，未开租约的仓不在域内。哲学承接即鉴层的没有鉴道与法是封闭的，提交面留在 LLM 自由裁量即该面对鉴封闭。

## 五钉位 {#pins}

通道唯一。域内 worktree 新建与销毁唯一合法通道为 lease open 与 close，open 起副本记基准分支，close 三检即锁清零、归并、拆本。治理域内直改正本检出即违例，编辑位迁移即治理文档编辑一律入副本，并入此钉位为其第一批真实用户。

信息机械生成。提交信息三形态模板即段内检查点、段结算、收约归并，语义源为任务包与台账与 trail 机械件，LLM 零自由提交文本，有偏离时偏离行唯一半自由位且须与 trail 偏离披露一致。

提交界与认证门同界。一段一结算，段结算前置为管线绿即化格核阅检词零违例加书简认证落链，上链前必须等绿由此在提交位落地，段内检查点自由，禁 amend 与 rebase。

历史不可改起点。本向界与 DEC-012 双签时点即治理域历史改写终点，签署前压缩为人类最后整理权，签署后改写已归并主线即拒绝线。

反绕行对表。正身路径唯一加 git log 与锁台账与 trail 三方对表，绕行提交对表露形出不一致事件走视图告警，正身拦不住的对表全见。

## 分期 {#phases}

期零即本案双签，历史不可改起点成立。期一即 lease 1.1 增 commit 与对表两子命令即手动期工具承载，编辑位迁移批随后同轨实施即首批全程受接管提交即验收场。期二即引擎期，融回后 commit 闸门接锁即锁态与管线绿态同为准入，对表转引擎内置周期跑。

## 泊界 {#parking}

接管线未来事项一律停治理泊界即 sih-engine/doc/governance/PARKING-v1.md，不入本向界。账本走书简 trail 停泊事件，到期判定与在泊告警走路择 parking 谓词包，出泊唯人节点。

## 版本与固定 {#version}

v1 于 2026-08-26 AI 起草随 gov004-commit-takeover-t6d 立界批，同日用户签署生效，与 DEC-012 同批联动。双签时点即治理域历史改写终点即历史不可改起点，签署前整理权窗口随签署关闭即两仓历史以现状冻结。三层固定即本文件、git 版本化 commit 挂批次与认证哈希、内容哈希入 trail 链。
