## 地图 {#repos}

- sih-philosophy 即哲学仓：唯一权威源，构成性约束全部生成与推理。工程问题先查 `llm-friendly-build/mapping.md` 定位命题。工程层不越俎代庖改哲学。
- sih-math 即数学仓：哲学到工程的数学化桥梁。工程生成层的合法语义消费面是数学仓映射表与条目，工程产出不得以哲学散文为直接规范输入。
- sih-engine 即引擎仓：本体。组件六席在 `src/`，治理链在 `sih/event/trail/`，治理文档在 `doc/`。
- sih-tools 即工具仓：孵化器。新工具先在围堰里按契约孵化，成熟后融回引擎。融回后工具件转兼容只读。
- sih-visual 即视觉仓：视觉身份探索，不受引擎治理约束。

工作区根的 AGENTS.md 是 agent 指令层与总索引，五仓关系与全部纪律的当前正典以各仓治理文档与链为准。

## 组件 {#components}

引擎六席全在 src 即三问 ask3repeater 承前向约束、参验 scrutinator 承文档规则核验、书简 event_stream 承留痕上链即二进制名 scribe、判定器 attractor 承结构性裁定与谓词路由即名词得一、视图 view 承聚合输出即二进制名 viewer、温故 retriever 承检索面激活。

工具侧孵化件与职能：核阅规则包 scrutinator、化格 formatter 承格式归一即笔在核前、检词 nomenclator 承术语三态登记与核查、正身 identity 承身份串加盐哈希、级联 cascade 承文档图洁净检查、句读 parser 承空腹解析、路择 selector 承三路路由谓词、寻址 locator 承稳定标识派生、租约 lease 承写入治理八子命令、执契 tally 承裁决材料核对与机器终签、判据扫 critsweep 承主线判据每日回算、回锚 attnanchor 承五行锚注入、交叉审阅 facet 承异质审阅聚合。

每个工具的权威契约在其目录 CONTRACT.md，修订走修订条目只增不减。

## 纪律 {#discipline}

第一条，空腹引擎。引擎不含业务规则，规则以包数据形态外置，加规则零引擎改动。判定语义与规则内容分离是红线。

第二条，契约先行。新工具先登记接口契约与验收判据再写本体，CONTRACT.md 修订条目制即每笔修订带编号与事由，只增不减。

第三条，TDD 双种。规约测试从场景导出先于实现，金向量承基线冻结即同输入同输出逐字节断言。先红后绿是常态，红证留档不清洗。

第四条，退出码即法律。零合规、一违规、二工具异常。管道掩退出码是禁手，每命令即捕返回码。

## 机械链 {#chain}

每个批固定全序，命令正典是 sih-tools 仓 `BATCH-FACE.md` 即逐命令可复制形加坑位注记，以它为准。节拍如下：

全序十三节拍：一三问双门即意图结构化与核阅闸；二叩问即新词信号登记；三正身即会话身份核验；四租约 open 与 claim 与 lock 即写入面锁定；五书简 intent 上链；六工地施工即 worktree 隔离副本；七化格核阅检词三步文档管线序固定；八 checkcite 即引用对表；九认证即内容哈希绑定上链；十 settle 归并主树；十一 unlock 放锁；十二 close 收约吊销会话；十三 reconcile 对账对表。

两个闸位常识：close 的无主闸拦未声明文件，CALL-LOG 闸拦跨批留痕面，对非本批活面用双旗标 bypass 显式留痕通过，不代收他批活面。

## 路径 {#howto}

从想法到上链五步。

第一步，成形。想法先过三岔路由即属当下吸收、或成形入队泊界、或未成形缓议。未决事项一律泊界停靠，不抢占注意力。

第二步，立任务包。在 `sih/engine 仓 sih/state/plan/` 落包文件即目标、范围、红线、产出四要素。包是批的唯一权威范围。

第三步，过闸。凡裁决点即真两难，过得一测量拿 stable_clear 终签，刀锋即打回转人诊断，不硬凑重采。无两难的设计取舍在设计件内据实定。

第四步，执行。单线 solo 或委外多窗并行，租约仲裁一切路径冲突。执行侧红线是主树零直写、链文件只经书简写位、误差红证如实记档。

第五步，验收。独立会话对链复算关键笔与判据与对账，不凭执行者自报。结果档落 `sih/event/plan/` 带大白话节与机器可读投影。

## 泊界 {#parking}

泊界是未决事项唯一合法停靠地。进泊即记账，材料零修饰只列事实。每件带出泊条件与存活时限，到期未决由路择心跳告警。出泊唯人节点，机器不代裁。名册投影在 `doc/governance/PARKING-v1.md`，与链不符以链为准。

## 族谱 {#docs}

治理文档九类各有专职：GOV 即向界与泊界名册承方向边界、DEC 即决策档承已定案、DES 即设计档承组件设计、SPEC 即规格档承接口规格、SETTLEMENT 即结算单承里程碑闭账、PRO 即提案、results 即批结果档、CONTRACT 即工具契约、knowledge 即沉淀知识。文档产出走化格核阅检词管线，认证后任何改写使认证作废。

## 首周 {#week}

建议路径：

1. 读本件与使用者入门，跑通验算三命令
2. 通读 `BATCH-FACE.md` 与一个近期结果档如 `sih/event/plan/` 下任意 `*-solo-results.md`，对照链文件看笔形
3. 挑一个小修复立包走完整机械链，体验三问与租约与管线
4. 第一次裁决点到来时走一遍得一测量，看闸门怎么工作
5. 遇到词拿不准，检词查登记面；遇到坑位，先查 BATCH-FACE 坑位注记

社区提问与贡献入口以仓内治理文档为准，新词与新建仓先过命名与泊界纪律。
