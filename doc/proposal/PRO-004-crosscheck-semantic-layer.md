# 参验语义层设计方向提案

本提案登记一个待审议的治理方案：在本仓建立参验语义层，把治理文档审阅从格式层扩展到语义层，含文档分词、语义单元树、静态语义分析判定器、声明式规则定义、NPC 专家团偏离率度量五层。本提案同时登记 DES-005 语义验证微积分方法学的重写方向，从采样收敛转为偏离率收敛。本提案不立即实施，登记以待审议。

本提案承接本轮外部采样与设计推导的全部输入。外部采样覆盖八类业界范式，见 sih-engine/sih/state/calibration/markdown-tokenization-toolchain-survey.md 与本轮对话留痕。本提案分阶段产出，不一次性产出完整 DES，承接 OQ-12 信息洪流内建防护。八类范式即编译原理静态语义分析、形式化方法、IETF xml2rfc 工具链、RFC 语义提取、法律合规 NLP、Markdown AST 生态、多 agent 验证、Architecture as Code。

## 核心问题 {#core-problem}

参验当前只有路径一确定性规则校验，工具即 sih-doclint，查字符集与结构层。语义层是真空区，含候选方案拒绝理由是否搪塞、哲学检索引用是否真实、范畴排除是否显式、命题承接是否成立这些问题。

SPEC-003 路径二原定义 N 等于 4 隔离采样加多数投票为语义校验方法。经多轮推导，多族群隔离采样在本仓开源合规约束下不可行，推导链见 OQ-13。单 key 单模型是默认部署前提，同模型多次是假隔离不消解偏差，司衡代用户调用第三方 key 有封停风险且不能通过免责声明转移合规责任。

语义层校验的替代路径须在本仓约束内重新设计。本提案登记这个重新设计的方向。

## 候选方案 {#candidates}

候选方案一 维持现状不建语义层
: 待审议
: 参验只保留路径一确定性规则，语义层永久靠人类审阅。拒绝理由：人类逐篇审阅违反基线二注意力稀缺与基线三人类只看异常信号。规模化场景下语义层问题无人发现，治理文档质量无机械保障。

候选方案二 纯确定性规则扩展
: 待审议
: 把所有语义层问题都形式化为确定性规则，不引入 NPC 专家团。拒绝理由：节点内文本的语义质量即论证是否搪塞与范畴是否混淆，无法完全形式化。强形式化会把 LLM 应做的判定硬塞进声明式规则，违反基线第五条 LLM 是符号材料生成器不是规则执行者。

候选方案三 NPC 专家团单路径
: 待审议
: 语义层全部由 NPC 专家团判定，不建确定性语义规则。拒绝理由：NPC 判定不可复现，违反基线第四条可验证性。且节点存在性与引用合法性这类可机械判定的问题交给 LLM 是算力浪费。

候选方案四 混合分层
: 待审议
: 结构层归确定性判定器，含节点存在性、必填性、引用合法性、跨文档一致性。文本层归 NPC 专家团，含节点内文本语义质量与语义结构对齐。偏离率作为 NPC 判定的可复现度量。拒绝理由：混合分层须建五层基建，工程量大于前三候选。此代价被评估为可接受，因前三候选各自违反不同基线，混合分层是基线约束下的唯一可行形态。

## 推荐方案 {#recommended}

推荐候选方案四即混合分层。

设计前提。治理文档是混合结构，不是纯结构化标注。文档含结构化语义单元与大段叙事文本。结构化语义单元含候选方案、拒绝理由、哲学检索条目、命题编号引用、范畴排除声明。大段叙事文本含哲学阐发、决策论证、辩论记录。正确的模型是结构化标注加自由文本容器。语义单元是节点，节点内可以是自由文本。规则检查分两种，节点结构层归确定性判定，节点内文本语义层归 NPC 判定。

路径二细分。承接混合结构前提，路径二分为三细分。二a 文本质量判定，判节点内文本写得是否成立，含论证是否搪塞与范畴是否混淆。二b 语义结构判定，判节点自称类型与内容类型是否对齐，如节点自称候选方案但内容是拒绝理由。二c 偏离率度量，确定性聚合程序对二a与二b的审阅单元做度量，可复现。二a与二b产审阅单元材料，二c做度量，承接 SPEC-003 第 190 行原则 LLM 是材料生成器不是度量权威。

偏离率消解可复现性。NPC 专家团单次判定不可复现，偏离率可复现。产出物分词得 N 个语义单元，NPC 审阅命中偏差的单元 K 个，偏离率 K 由 N 除。K 的内容是 LLM 材料，K 由 N 除是确定性度量。不可复现的是单次判定的具体内容，可复现的是偏离率度量与阈值判定。承接基线第四条，可复现性在度量层不在判定层。

单向有效性。偏离率低不代表文档真没问题，可能是 NPC 集体漏判。偏离率高且跨次稳定则问题大概率真实。这是单向有效，高偏离可信，低偏离存疑。漏判风险由路径一确定性规则兜底。NPC 专家团职能是捞确定性规则查不到的语义问题，捞到即净增益。

## 五层骨架 {#architecture}

### 第一层 分词 {#layer-tokenization}

把治理文档从纯文本切分为语义单元。每个单元带类型标记与 stable id。

stable id 派生规则。由文件路径加节点类型加节点序号加内容 hash 派生，碰撞由内容 hash 兜底。stable id 变更进 trail，承接决策等于治理对象。

工具栈。选 Rust 栈 pulldown-cmark 加 comrak，不引入 Node 工具链。理由见 markdown-tokenization-toolchain-survey.md。tree-sitter-markdown 不选，因 ikatyang 版自述不追求正确性主目标是语法高亮。

业界对应。IETF xml2rfc 的 XML 元素标签、法律 NLP 的语义元数据提取，GDPR 合规检查论文原文 semantic metadata is a prerequisite。

### 第二层 语义树 {#layer-semantic-tree}

把语义单元组织成树结构，表达单元间的包含与顺序关系。候选方案节点下挂拒绝理由子节点，哲学检索节点下挂命题编号子节点。

业界对应。tree-sitter 的具体语法树、remark 的 mdast、IETF 的 XML DOM 树。本仓用 pulldown-cmark 与 comrak 产的 AST 树。

### 第三层 判定器 {#layer-judge}

在语义单元树上跑静态语义分析，查跨节点语义约束。这是路径一确定性规则校验的语义层扩展。

判定范围。节点存在性即候选方案节点必须存在。必填性即候选方案必须含拒绝理由子节点且非空。引用合法性即命题编号引用必须能在哲学仓索引定位、哲学检索单元必须含原文路径且文件存在。跨文档一致性即同一语义单元被多文档引用时一致性校验。

判定器不查节点内文本语义质量，那归路径二 NPC 专家团。判定器是 NPC 专家团 Verifier 角色的外部确定性证据之一，不替代 NPC 的语义判定。

业界对应。Schematron 跨元素语义规则校验、remark-lint 自定义规则、编译器属性文法即 AST 节点挂属性且节点间属性传递构成规则检查。

违规进 trail。承接 PRO-08 应而不藏，sih-doclint 当前只输出 exit code 是已存在工程断点，违规本身须进 trail。

### 第四层 规则定义 {#layer-rule-definition}

第三层规则用声明式语言定义，不硬编码。规则本身是治理对象，承接 PRO-09 元层。

元约束一，规则可证伪。每条规则必须配至少一个反例，即违反该规则的文档样例，反例本身进治理。承接 convergence 层 P3.1 退化机制，规则也会退化，反例是规则退化检测器。

元约束二，冲突检测。规则间可能矛盾。声明式规则格式天然支持冲突检测，靠类型系统与约束求解。规则数少于 10 不强制显式跑冲突检测，多于 10 进 CI。冲突检测结果进 trail。

业界对应。Z notation 形式化规格语言、Alloy 关系约束声明、Schematron 的 rule 加 assert 加 report 声明式语法。

### 第五层 Verifier 与偏离率 {#layer-verifier}

NPC 专家团承接路径二，判定节点内文本语义质量。判定结果切分为审阅单元，每个审阅单元指向产出物的某个语义单元节点，靠 stable id 主定位加位置备查。

偏离率度量。产出物 N 个语义单元，NPC 命中偏差 K 个，偏离率 K 由 N 除。度量由确定性程序算，可复现。

收敛双指标。同一文档多次审阅，偏离率是否收敛由两指标判定。指标一，K 由 N 除的波动系数低于阈值。指标二，审阅单元集合的 Jaccard 相似度高于阈值。两者都过才算收敛。方差低但集合不重合是稳定地漏判，假性收敛。

业界对应。Mavis 的 Verifier 对抗关系即靠外部确定性证据做判定、CodeBuddy NPC 的 CI 验证门禁、LLM-RUBRIC 的多维准则评估。

## DES-005 重写 {#des005-rewrite}

DES-005 语义验证微积分方法学原定义三个实验问题，基于 N 等于 4 隔离采样。N 等于 4 已废，但微积分方法学本身不废，从采样收敛转为偏离率收敛。

问题一重写。从 N 次采样判断分布是否收敛，转为多次审阅偏离率是否收敛。收敛判据是双指标，K 由 N 除波动系数加审阅单元 Jaccard。

问题二重写。从版本漂移效应，转为不同模型版本的 NPC 专家团偏离率差异。同一文档同一检查项，不同模型版本的偏离率与审阅单元集合差异。

问题三重写。从预算置信度权衡曲线，转为审阅频次与偏离率稳定性的权衡。每增加一次审阅的边际收益是否递减。

DES-005 修订依赖本提案审议通过，不立即改。

## 待定问题 {#open-questions}

待定问题一。规则集初始规模与优先级。本提案登记五层骨架，初始规则集应先覆盖哪些语义约束。倾向先覆盖 PRO 与 DEC 两类文档的结构层规则，含候选必含拒绝、哲学检索必含路径、命题引用必可定位，再逐步扩展。

待定问题二。偏离率阈值与 Jaccard 阈值的具体取值。双指标阈值须实验数据支撑，归 SPEC-001 对照补登实验。

待定问题三。二b 语义结构判定的触发条件。节点自称类型与内容类型对齐判定是每次审阅都跑还是按类型触发。倾向高风险文档类型强制触发，低风险按概率触发。

待定问题四。规则反例的治理形态。反例进治理的具体形态，是独立文档类型还是附在规则定义内。倾向附在规则定义内，反例是规则的构成性部分。

待定问题五。跨文档语义一致性的实现机制。同一语义单元被多文档引用时一致性校验，须建跨文档索引。索引的存储与更新机制归下游 DES。

待定问题六。sih-doclint 迁移路径。OQ-09 登记的 doclint 迁移，须把语义层判定器与格式层判定器合并。迁移路径是先迁移格式层再扩展语义层，还是合并重建。倾向先迁移格式层保 continuity，再扩展语义层。

## 认识论立场 {#epistemic-stance}

本提案为设计推论即 design-corollary，是工程设计方向的登记，非已验证的机制。

五层骨架与偏离率度量机制为外部锚定即 external-anchor，承接哲学仓已立命题与业界八类范式的外部采样。规则可证伪性元约束为设计推论，承接 convergence 层 P3.1 的对照基础。

可证伪条件一
: 若偏离率收敛双指标在实际审阅中无法稳定判定，即方差与 Jaccard 无法区分真收敛与假性收敛，则偏离率度量机制须重新审视。

可证伪条件二
: 若 NPC 专家团在节点内文本语义质量判定上的命中率系统性低于随机基线，即判定不如随机猜，则路径二三细分须重新审视，可能须回退到候选方案一即维持现状靠人类审阅。

可证伪条件三
: 若混合分层导致确定性判定器与 NPC 专家团的边界频繁模糊，即同一问题难以判定归路径一还是路径二，则分层判据须重新审视。
