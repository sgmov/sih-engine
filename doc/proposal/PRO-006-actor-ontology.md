# 行动者本体论提案

本提案登记一个待审议的治理命题：司衡体系的行动者分类，含异质来源同类、确定性执行者非来源、权限附着三部分。本提案是对话副产物的登记，AI 起草，谱系披露即依据 2026-08-18 两次独立会话对同一提示词的采样对比与本对话的行动者讨论。主线是信息洪流一体双面的工程落地开发，本提案不占用主线排期，审议通过后按需再由后续 DEC 承载命名与实施决策。2026-08-21 签署会用户签署，候选方案一通过即登记为工程层行动者本体论，待定问题三条留后续 DEC。

## 概览 {#overview}

- 人类席位与 LLM 席位是同一类异质来源，共享全部认知病理，LLM 全谱系承接人类特点是经验断言::[来源对称](#source-symmetry)
- 确定性程序不是来源，是无认识论属性的执行者，承接工程基线第一条::[执行者](#executor)
- 仅有的两个不对称是权限不是能力，即意图源与兜底，多人协作收窄为负责人::[权限结构](#permission-structure)
- 失败表型不对称，人类显性弃审有信号，LLM 静默稀释无信号，检测按表型配置::[表型区分](#phenotype)
- 哲学层已锚定于鉴层，本提案是已锚定命题的工程实例化，非待锚定，反哺条件登记在案::[锚定状态](#anchor-status)

## 来源对称 {#source-symmetry}

核心经验断言：LLM 在人工智能领域全谱系承接人类的认知特点。来源是用户即司衡哲学唯一创作者经过长时间与多 LLM 协作的工程实证，非单次观察。

病理对称清单如下。

- 注意力稀释：convergence 层 P3.1 整章以人类注意力研究为原型论证 LLM 的注意力预算结构性稀释，witness-archive/00-ai-coding-governance-principles.md 第 233 行登记软退化三表现即全局一致性丧失、历史记忆模糊、决策锚定漂移，对两类席位同样成立。
- 偏导：同文件第 67 行登记人类选择性偏差即易验、确认、可见性三层偏好，P5.3 的分层抽样设计正以此为对象。模型侧偏差由席位体温基线校准承载。两侧对称建模。
- 合理编造：P3.1.3 论证编造内容与真相在风格上无法区分，此断言不区分作用对象，人类记忆与模型生成同样适用。
- 稀疏长程记忆：人类靠长期稀疏记忆加直觉，模型靠冻结权重加上下文窗口，形态不同，长程稀疏性同构。

工程形态。facet 的席位登记表即 reg-llm.yaml 与闸不问席位出身的判据设计，已是本本体论的部分实现。人类在验证职能上是又一个跨家族席位。

## 执行者 {#executor}

确定性程序不是来源。它无认识论属性，不产语义判断，不持立场，对信息洪流三条产生路径全部免疫。理由是人类独有的弃审失败模式即索性不看在程序上不存在，程序对每条记录执行同一谓词。

执行者承接工程基线第一条即确定性程序是治理操作的唯一执行者。写入权限归确定性程序或人，是权限结构的一翼，见下节。

## 权限结构 {#permission-structure}

两个不对称是权限不是能力。

意图源。建议能力两侧都有，agent 持续产出方向、命名、分类的提案，但建议不经签署不成意图。承接道二即意图先于代码，03-on-second-tao.md 第 15 行与第 19 行，因果方向意图到代码不可逆，此处意图指被批准的意图。意图锚定的写入权限不向 LLM 开放，见工程禁止条款第一条。

兜底权限。Layer 2 终审签核位，agent 代签即 violate，facet 判据 v3 已实测此红线的机械形态即 P3 代签清晰违。

多人协作收窄。意图源与兜底在多人协作中收窄为负责人，对应 Layer 2 单一签核位。此收窄规则由用户预埋于治理制度。

人类不是不受治理的治理者。哲学仓 11-on-recursion-termination.md 第 29 行明确人类本身也需要元约束，人类也会出错、自利、腐败。人类席位被文本权威即哲学仓唯一权威源、trail 留痕、锚定验证回路共同治理，其特殊性在权限不在认识论豁免。

## 表型区分 {#phenotype}

同一失败在两侧现象学不同。

人类侧。审阅超载表现为显性弃审即索性不看，有信号，队列深度上升与滞留时长增加可直接机械检测。

LLM 侧。同一失败表现为静默稀释即看而不见，输出仍然流畅，无自发信号，须仪器化检测。facet 变卦率即静默稀释的读数，同题多答未决数是先兆。

反向不对称一条。窗内逐字召回是 LLM 席位独有能力，锚定核查交机器承载部分依赖此能力。对称断言限于病理层，不延展至能力层。

## 锚定状态 {#anchor-status}

本提案的锚定状态区别于待锚定形态。基线二即信息洪流标注哲学相邻但未精确覆盖，属待锚定。本提案的抽象内容哲学仓已承载，属已锚定的工程实例化。

鉴层承载点三处。07-on-assay.md 第 44 行验证者主动承认自己的偏见并以盲审、多人独立审查、对抗性测试减偏，偏见归属于验证者本身，不豁免人类。第 119 行多模型交叉验证即多 LLM 独立参与列为方法论支撑。第 122 行至第 134 行自证循环论证检验者与被检验者无差别同属司衡内部，外部独立验证是唯一打破路径。

不反哺的判据。哲学仓吸纳工程命题的时机是抽象层出现缺口即工程实践回原文找不到答案，本提案逐点核验无缺口。全谱系承接是绑定当前模型代际的易变经验断言，哲学不收易变前提。向哲学仓添加抽象层已有的内容违反损补与知止两法。

反哺观察条件。鉴层外部独立验证空位被工程填时，什么算外部的判定可能把行动者分类问题顶回哲学层。LLM 全谱系承接若成为某条哲学论证的必要前提时触发重估。

## 认识论立场 {#epistemic-stance}

本提案为工程实证登记即 empirical-registration，核心断言来自长时间多 LLM 协作观察，非已验证机制。

来源对称是经验概括，权限结构是治理设计，表型区分是检测工程设计，三者认识论地位不同，不合并标注。

可证伪条件一
: 若实践中出现人类席位独有且 LLM 席位无法承接、同时影响治理设计的认知特性，则来源对称断言收窄，须补不对称清单并重估权限结构。

可证伪条件二
: 若权限结构在多人协作中出现意图源冲突即双负责人并行签署矛盾意图，则意图源收窄规则须重新设计。

时效性声明
: 全谱系承接断言绑定当前代际模型，模型代际更替时须重估病理对称清单。
