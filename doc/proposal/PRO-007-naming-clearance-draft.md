## 附录：facet 立名原始推导转录 {#appendix-facet}

格式按 DES-001 转录，原文措辞未动。

候选一，Facet 即切面。中文名切面，英文名 facet，CLI 命令 fct。职能依据：工具接收一个对象，让多个审阅者各自产出发现，每个审阅者就是对象的一个切面。切面之间重叠的是共识，独有的是异质。工具的核心产出是切面集合及其差异关系，而非单一视图。facet 直接锚定多个独立视角这一输入结构，异质性是切面间的自然差集。角色名衍生 facetor 即切面者，替代 banor 与 pickor。字段名衍生 facets 即切面项发现列表，替代 attacks 与 defenses。对齐度：与 analyze_heterogeneity 完全对齐，facets 天然包含共识与异质的区分，coverage 是切面对对象的覆盖程度，Jaccard 是切面间的重叠度。

候选二，Collate 即汇校。中文名汇校，CLI 命令 clt。职能依据：collate 在文献学中指收集多个版本、比对异同、整理成校勘记，恰好匹配步骤二至五的全流程。比 compare 更强调整理后产出，比 merge 更强调保留差异。角色名 collator，字段名 collations。

候选三，Surface 即呈面。CLI 命令 surf。职能依据：工具不做判断，只把异质性发现浮现出来。surface 作动词意为使浮出水面，强调差异本来藏在各审阅者内部，工具将其表面化。对齐度与 coverage 与 Jaccard 偏间接需额外解释。

候选四，Probe 即探察。CLI 命令 prb。职能依据：核心动作是探测异质性。偏单次探查而非多视角比对，对齐度中等。

候选五，Assemble 即汇整。CLI 命令 asm。职能依据：把多个审阅者的发现汇集整理成整体。缺少异质性专属指向，职能贴合偏泛。asm 与汇编语言歧义。

候选六，Audit 即核审。CLI 命令 aud。职能依据：审阅审查的工程实现。惯用语义为合规检查或单方审计，天然不具多视角异质内涵，贴合度最低。aud 与 audio 混淆。

原始综合建议：首选 Facet 即切面，理由三条：核心价值异质性发现直接来自多个切面这一输入结构，切面间差异即异质重叠即共识无需额外比喻；与现有概念体系无缝对齐，命名即解释；CLI 极短无歧义。次选 Collate 即汇校，若需强调流程化整理而非多视角结构。
