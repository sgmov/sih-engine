## 承接命题推导 {#propositions}

推导从知识包映射表出发，四链命题与失效实录同源即已沉淀物在需要时不可得。

链一注意力加载
: 映射表注意力与加载机制类即规范加载在场但执行缺位，命题 PRO-09-overcome 与 PRO-07，必收。失效实录 ai-ex/HAS-REGISTRY-BUT-NOT-READ.md 记载 AGENTS.md 被提及七十三次却零次触发自检、SETSP 路径在册多轮未读、沉默参考标注被违反三案。命题原文即 sih-philosophy/emanation/proodos/09-on-arche.md 第三步元层三治：治理者最大的敌人不是外部的恶意，而是自身的"偷懒"与"捷径思维"：自胜者强（道德经 33）。绕过鉴直接批准，不是"效率"，而是治理者输给了自己的懈怠。项目记忆承接在册不等于在注意力这一缺口，检索面是规则进入注意力的机械入口。

链二跨域检索
: 映射表跨域检索类即跨域检索的失败模式与治理设计的跨域指导优先，命题 PRO-09-overcome 与 PRO-07 与 CNV-00，必收。失效实录 ai-ex/CROSS-DOMAIN-RETRIEVAL-METHODOLOGY.md 记载自主设计冲动、SETSP 当权威、检索走过场、检索后仍自主设计四类失效，ai-ex/SETSP-PRECEDENT-REDISCOVERY.md 记载独立推导完成后才发现先例已有同构设计。项目记忆承接先找已有指导从自觉变机械可执行，检索缺位时自主设计就是懈怠绕行的工程形态。

链三留痕义务
: 映射表应对留痕类即治理动作的留痕义务，命题 PRO-08，必收。原文即 08-on-settle.md：留痕不是治理的附属品，是应-鉴循环的构成性条件。留痕的构成性一半在写一半在读，沉没不可取回的留痕在效果上等效于藏。项目记忆承接留痕的检索面，是应而不藏的读侧完成形态。

链四判据错位
: 映射表元层治理类即判据承载层错位的识别，命题 PRO-09 与 CNV-02，必收。失效实录即八轮漂移后才发现 convergence 分工早已规定。项目记忆承接已立判据在决策点的自动在场，防同层反复造方案。

四链同构结论：四链不指向四条新命题，指向同一缺口的四个侧面，即已沉淀物在需要时不可得。命题承接若成立必是共用承载，这本身是最小原子判据的正面证据，也是不另立命题的原则依据即工程层不创造命题只承接。

方案A独立组件即组件名册第六席
