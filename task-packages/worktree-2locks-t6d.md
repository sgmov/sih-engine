## 二、关键设计 {#design}

### 2.1 身份与登记 {#identity}

登记档两因子即出生证加活体检查：agent 登记档一次性签发载出生身份哈希与授权人，会话档每批活一份载范围与到期，收工即吊销。文件时刻防拷贝即登记档出生时刻与链上签发事件对表，晚于即异常，绊线级。治理哲学三条：名活账真即身份绑定随时重绑而归因记录不可造假；漂移重绑即设备更替软件升级走申诉通道零惩罚；合取告警即身份失配单独不进视图，失配且治理漂移才报警人介入。硬件锚定已泊 pk-016 归另一引擎版本，本案锚定取轻方案即确定性外壳加 git 与链源真身锚。

### 2.2 级联三层定形 {#cascade}

路径即 id：仓内相对路径天生唯一即身份，零新增字段。不改名规则：文件身份不可变，改名即删除加新建，旧件 git 历史留全尸，孤儿边检查机械兜底。引用即边：正文引用扫描全自动建边，无人核，误边失败方向全是拦多不拦漏。边账四计数器：上游变更次数、下游被拦次数、咨询次数、咨询后出事次数。健康循环三档：数据侦查只降级不删边，LLM 复核读原文拿得准才删边，LLM 拿不准升人断疑难。强弱边战绩升档：v1 全边生而弱边即顺序语义，上游变更后下游复验真实发生攒强边证据，基线向量版语义上线时强边触有效性复验弱边只触顺序等待。上游洁净不变式：文件洁净当且仅当当前内容哈希等于链上最近认证哈希，链即账本零新增记账。

### 2.3 SETSP 遗产摘要 {#setsp}

SETSP 05-infra-deploy 载 WorktreeSession 生命周期即 agent 启动创建会话、git worktree add、工作中、提交、git worktree remove、会话结束。FileLease 结构体含 lease_id、doc_id、status、trust_score_threshold、worktree_path 字段，信任分阈值耦合在租约内。全局锁服务单列。取舍随 DEC-009 终裁：lease 归属即悲观锁位、pre-commit 设计取舍、commit 资格控制即锁管不管 commit。信任分阈值字段与本批置信度两轴设计同源，终裁时对表。

## 三、工作清单 {#work}

### Cluster 1：cascade 工具外切（本批执行）

sih-tools/cascade 即级联／cascade，能力外切承正身先例。三子命令：build 扫引用建边册、check 验上游洁净、orphans 查孤儿边。空腹零内置知识、json 报告退出码三值、双版本戳、复演确定性。

### Cluster 2：边册采种与真仓 build（本批执行）

对 sih-engine/doc 真仓跑 build 生成 CASCADE 边册入仓为派生投影，索引与正文不符以正文为准，随批认证生成动作。

### Cluster 3：worktree 乘 T6-D 捆绑实装（下段）

按任务包名起 worktree 的确定性外壳，会话档签发挂开工，收工即吊销。

### Cluster 4：锁本体与 DEC-009 终裁（跑三）

悲观锁挂 identity 验人，乐观锁挂 cascade 验基线，DEC-009 终裁三对象一并载入 DEC-011。
