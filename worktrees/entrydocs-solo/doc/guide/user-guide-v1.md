# 使用者入门 v1：三十分钟看懂并信任司衡引擎

写给只想使用司衡引擎治理自己工程的人。不要求读哲学仓，不要求会 Rust。读完你知道它给你什么、你怎么用、你怎么亲自验证它没有骗你。

## 承诺 {#promise}

第一条，注意力只投异常。系统设计假设是人类注意力是稀缺资源，确定性程序处理绝大多数操作，你只在告警或裁决点出现。

第二条，一切可复算。每个治理动作落哈希链，链文件每日一件，任何人任何时候可以一条命令验证整条链完整且未篡改。

第三条，材料同权。人的直觉与 LLM 的建议在裁决前是同等地位的参考材料，谁都不能直接当裁决用，必须过测量闸门拿到机器签名才生效。这条同时约束人和机器。

## 词汇 {#glossary}

九个词覆盖日常九成场景。

- 批：一次有边界的治理施工，有名字、有任务包、有开始和收约。引擎世界的基本工作单位。
- 机械链：每个批固定要走完全序即三问、叩问、正身、租约、意图上链、工地施工、文档管线、认证、归并、对账。顺序固定，跳步会被闸拦。
- 意图：批开工前把目标、排除项、红线写成结构化记录上链。事后争议看链上的意图，不看谁的记忆。
- 租约与锁：批要写哪些路径就先锁哪些路径，两个批撞路径时锁说了算。无锁写入会被拦。
- 工地：批在隔离副本里施工，收约时归并回主树。主树不直接改。
- 泊界：未决事项的有界停靠地。有进泊记录、有出泊条件、有存活时限。出泊唯人节点，机器不代裁。
- 判据：主线目标被写成可机械判定的检查项，每天判据扫自动读链判定达成、在飞或沉底，不靠人记。
- 得一：判断类产出的测量闸门。一个命题经九发采样与统计闸检验，稳定清晰才给执契终签，两难态即刀锋会打回转人诊断，不硬凑。
- 链：sih/event/trail 下的每日哈希链文件，一切治理动作的最终账本。

## 走读 {#walkthrough}

以下是真实发生的一个批族，拿来当教材。背景：源码里有 34 个来历不明的常数，行话叫魔法数字即写死在代码里没人说得清为什么是这个值的数字。

第一步，人节点下了一句话令：34 个魔法数字的账全部清掉，并给出口径即不能留任何拍脑袋的，要么是数学模型优先，要么是工程实践但必须登记回归数学模型的义务。一句话就是令源，会被照录上链。

第二步，立包。这句话被展开成任务包即目标、范围、红线、产出的清单文件，批有了名字和边界。

第三步，分类清账。确定性脚本把 34 件逐一盘点，8 件找到数学推导在档，3 件改判环境参数候裁，其余逐件按口径路由。账面落数学仓文档，每行带证据指针。

第四步，裁决过闸。改判怎么裁、后继怎么拆，这些判断点没有直接拍板，而是命题化后过得一测量，机器给了稳定清晰的终签才执行。

第五步，落码与收口。54 处注记贴回源码即每 个数字旁边注明出处与登记行号，数值一个都没改，机器逐行核过。判据扫里数学归因这条主线判据由机器判定达成。

第六步，验收。另一个独立会话对链复算全部关键笔，不信任执行者的自报。

全程人节点只说了三句话即开工令、口径令、拆分批准。其余是确定性程序与受约束的执行代理在做，每一步留痕可查。

## 动作面 {#actions}

你作为人节点日常只做四类事。

1. 下令。一句话即可，会被照录成令源。说不清楚时执行侧会先做意图对齐再开工。
2. 裁决。出泊唯人节点、形态裁定、结算批准。裁决前你会拿到带机器签名的材料或大白话呈报，多数裁决是一句话的事。
3. 看回显。每个批完工有五行锚回显即当前任务、在飞面、泊界面、链面、纪律令，三十秒读完备态。
4. 异常介入。告警出现时处理，没有告警就不用看。

## 验算 {#verify}

三条命令，任何时候可以自己跑，不需要信任任何人的转述。

其一验链完整性，输出 valid 即整条链自首笔起未篡改，日期取当日实日：

`cd sih-engine && target/debug/scribe verify --trail sih/event/trail/$(date +%F).ndjson`

其二判据现态，achieved 即达成、in_flight 即在飞、sunk 即沉底需关注：

`python3 ../sih-tools/critsweep/sweep.py --at $(date +%F) --root ..`

其在飞与持锁，当前有多少会话与锁在册：

`cd ../sih-tools/lease && uv run --project . lease status`

判据扫的沉底项是给你看的异常信号：某条主线目标超过三天没有任何程序活动痕迹即沉底，这是唯一需要你主动过问的常态告警。

## 问答 {#faq}

问：LLM 会不会骗我。答：它的产出只是材料，写入要过租约闸，裁决要过测量闸，验收有独立复算。它骗不了链。

问：执行中出错了怎么办。答：红证文化即错误与对己不利的读数逐件留档不清洗。你会看到如实申报节，这不是缺陷多，是透明度高。

问：我的数据在哪。答：三个 git 仓即引擎、工具、数学，加每日链文件。链是账本，仓是材料，两者不符以链为准。

问：我不懂哲学能用吗。答：能。哲学约束的是引擎的构造与执行代理的生成，已经沉淀在机制里。想懂再读 sih-philosophy。

问：多个窗口并行会乱吗。答：租约与锁仲裁一切路径冲突，今天常见的形态是多个委外窗口并行施工、主窗独立验收，全程无绕锁。

问：怎么开始第一个批。答：给执行代理一句话令即可，它会走意图对齐、立包、过闸、执行、收约全序。你也可以先读贡献者入门了解内部。
