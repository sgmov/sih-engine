# docmath-b4-solo：文档数学化程序收尾批（模板与闸门合并扩容）

> task-packages 治理任务，承 docmath 程序（docmath-full-program-v1.md 与 docmath-task-package-2026-09-04.md）
> 队形：单线形 solo，确定性脚本与主线亲写零子代理
> 日期：2026-09-04

## 概览 {#overview}

- 批性质：收尾批，模板与闸门。人节点裁定：模板必填项新旧都管；收尾闸门与 mathpipe 收尾批合并扩容为同一处闸门且错误信息清晰人可读；裸奔违规类在役
- 模板件：sih-engine/doc/spec/SPEC-TEMPLATE-sufficiency-v1.md，内容充分性三必填即判据清单附红证、判定性常数挂锚、约束算子显式化
- 存量补齐：sih-engine/doc/spec/ 二十一件存量 SPEC 逐件补「内容充分性」节，红证缺席如实申报零信息不硬凑
- 合并闸门：docmath_gate_script.py 一处闸覆盖 mathpipe 判定性常数裸奔复核与 docmath 裸奔数与充分性节在位三面，违规报文含文件与节与补法三要素人可读，双跑逐字节一致
- 裸奔违规类在役：des-001 C007 与 C008 与 C009 继续在役核验（零触碰），闸门脚本为合并复核位不替代规则包

## 一、问题陈述 {#problem}

文档规则数学化收口：规格模板把内容充分性升为必填项，存量旧文档按裁定补齐，全部批产出由一处闸门机械维持，人只看清晰报文不看原始日志。

## 二、关键设计 {#design}

- 必填三件：判据红证对表（判据逐件携红证或如实申报零信息）、判定性常数挂锚对表（声明的常数携载体与推导档或如实申报无声明的常数）、约束算子对表（约束系统显式书写或如实申报无约束算子面）
- 闸门不新建引擎谓词类（任务包禁区），以确定性脚本闸承载合并复核，des-001 裸奔违规类继续在役
- 闸门报文形：文件、缺件、补法三要素逐笔人可读
- 存量补齐纪律：逐件亲读判据条目再写红证，判据无红证者如实申报零信息并留清账路径，不代改其判据实质
