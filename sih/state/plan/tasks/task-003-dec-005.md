# 任务包 003 DEC-005 阶段 0 旧数据认识论判定加意图声明判定

## 任务目标

起草 `sih-engine/doc/decision/005-phase-0-data-and-intent.md` 新文件,显式判定两件事。第一,旧 Phase 2 实验数据(263 文档加 1052 sessions 加 7392 条判断记录)在偏离率新范式下的认识论地位,三选一,可复用或部分复用或不可复用。第二,参验语义层是否消费意图声明(intent_declaration),若不消费,SPEC-003 第 25 与 26 与 31 与 39 行接口签名须修订,若消费,DES-009 第五层须补符号材料与意图声明对照层。

## 项目背景

阶段 0 是 8 阶段路径的关键路径起点,文档契约先行,无代码。本任务包承担阶段 0 拆 0b(旧数据认识论判定)与 0c(意图声明判定)两子项,阻塞阶段 8 标定实验与可能触发的 SPEC-003 接口签名修订。

## 任务构成规则

### self-check(六项核心)

1. 主动判断产出性质 — 这是 DEC 判定,不是 DES 设计
2. 服务原始意图 — 显式判定,不让判定隐式默认
3. 范畴排除显式 — 不引入新的实现路径,只判定边界
4. 不逃避当下责任 — 旧数据若不可复用要明示,不能模糊
5. 每行去掉会犯错吗 — 判定结果直接喂阶段 8 实验设计
6. 与哲学仓相容 — 承接 PRO-09 元层治理,判定本身是治理对象

### 通用格式规范

DEC 范式承接 DEC-001 至 DEC-004 既有结构。决策内容加决策理由加关联规则三段。

### 类型特异化约束(五条)

1. 结构特异非字符集 — DEC 是决策类文档
2. 特异化需支撑 — 两项判定各自有事实依据。旧数据认识论从 SPEC-003 第 115 至 127 行核实数字,从 DES-005 v2 §十一 沿用部分,从 ai-ex/EXPERIMENT-T1-T5-SEDIMENT.md 找 T5 实验数据。意图声明从 SPEC-003 第 25 与 26 与 31 与 39 行核实接口签名,从 DES-009 第 82 至 94 行核实路径二是否消费
3. 不照抄通用 — DEC 与 DES 与 SPEC 文档结构不同
4. 不重复定义 — 不重述 SPEC-003 与 DES-009 已定义内容
5. 最小化原则 — 只判定两个具体问题,不展开 DEC 体系

### 哲学检索

任何决策前查哲学仓 PRO-08 应而不藏与 PRO-09 元层治理。判定本身是治理对象,需 trail 留痕。
