## 一、问题陈述 {#problem}

- 立项批已落契约与词条，sih-tools/locator 下仅 CONTRACT.md 零实现代码，索引槽位仍无本体。
- 治理 agent 定位材料仍靠裸 grep 与 find，四载体统一寻址与稳定标识无承载。
- 本批实现工具本体即 SDD 规格先行加 TDD 红先绿后加金向量冻结。

## 二、关键设计 {#design}

### 2.1 SDD 规格先行

实现细节落 sih-tools/locator/SPEC.md，契约约束接口与判据，规格约束实现细则即模块布局、条目模式、id 派生公式、索引头部模式、域包模式、六操作签名、确定性细则、退出码表。文体承书简 SPEC 先例。

### 2.2 四载体与稳定标识

载体矩阵四类即 markdown 加 json 与 yaml 与 toml 加代码 Rust 先行。稳定标识承 DES-009 即文件路径加节点类型加节点序号加内容哈希派生，条目流 ndjson 为真契约，头部记工具版本与语法版本与域包版本，语法版本一变即全量重建标志。解析主干 tree-sitter 树进程内即弃永不落盘，出现层无状态扫描。

### 2.3 存储 trait 与文件后端

trait 六操作从查询侧设计即按标识取、按名查、按词反查、批量写、按域遍历、陈旧验。v1 仅实装文件后端即 ndjson 流，余四槽位进场皆人节点裁定，接口不泄漏图查询语义。

### 2.4 金向量冻结

金向量随契约冻结即冻结语料加冻结期望件，每后端实现须过同一套一致性向量，模式承引擎件 vectors 先例。冻结后实现变更须重走冻结程序。
