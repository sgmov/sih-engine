## 范式：代理编组 {#paradigm}

**代理编组是工作流队形谱系**，族内五形即单线 solo、单发 oneshot、反思 reflect、并联 parallel、串行 serial，不是任务编号。经用户 2026-08-28 全签批立名即 DEC-018。旧编号 T5、T6-A 至 T6-D、T7、T8-S 与后缀 token t6d 已退场入检词死档 name_only 即历史行保留不得作新名。2026-08-17 版曾将 T6-D 助记扩写为 Twin-agent 双子代理等语，经复审系助记非词源即编号本义为实验代号，随批撤除。

来源：用户 2026-08-28 全签批 + ai-ex/T6-PARADIGMS.md（实证谱系与选择判据）。

### 队形表 {#forms}

| 队形 | 英文对 | 后缀 | 形义 |
|---|---|---|---|
| 单线 | solo | -solo | 主线亲写零子代理，治理批默认形 |
| 单发 | oneshot | -oneshot | 单子代理单文件单次响应 |
| 反思 | reflect | -reflect | 单子代理单文件多轮反思抓结构违规 |
| 并联 | parallel | -parallel | 多子代理并行独立簇主线收敛验收 |
| 串行 | serial | -serial | 单子代理全量上下文连续产强耦合多文件 |

预留位：借脑即原 T7 即司衡 MCP 协议编排多代理认领，随启用批立名；顺序链即原 T8-S 即依赖链串派，同。

### 流程即以并联形为典 {#flow}

```
1. 主线选形立任务包（含 F 锚定 + 约束 + 请求写入）
2. 主线拆三类簇：并行簇、主线簇、依赖簇
3. 双子代理后台并行各领一并行簇（提示词自包含）
4. 主线亲写主线簇即最复杂件
5. 主线验收：F 锚定实跑，文档产出走 T6 工具链
6. 依赖簇待验收后串行
7. 主线 commit 全部
```

## 命名约定 {#naming}

格式：`<主题>-<形英文对>.md`

主题命名：主题在前即具体做什么，形在后即怎么编排，全部小写加中划线分隔。历史 `*-t6d.md` 档名不改即血统保留。

## 请求写入段 {#writes}

任务包可带「请求写入」段即二级标题含请求写入字样，下列表项为工作区根相对路径或目录，条目精确或目录前缀即会话写入范围。工地外壳开工时机械读取该段为会话档 allow 第一源，两把锁的范围验以此为准，2026-08-25 用户裁定即 worktree 和两把锁要和任务包匹配。无该段即范围空由调用方显式补充。
