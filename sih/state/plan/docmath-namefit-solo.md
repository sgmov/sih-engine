## 一、问题陈述 {#problem}

## 二、关键设计 {#design}

- 命题为材料性断言（m-namefit 先例同形）：候选名文规对实体职能名实相副加 en 对 Regula 平行表达非误译加 en 与 code 同形，不含采纳裁断形

- 签署后随批登记：检词五件套（zh 文规 en Regula code regula）、血统档死因（文衡对冲上位名、衡文词场淹没、书矩双沉、文鉴撞鉴层）、连带改写清单（向前件称谓替换，历史件不改）
