## 一、问题陈述 {#problem}

收敛公式的干预项零推导：治理结构里的提示词分量对模型判定分布的移动量从未被测过。本批在单一席位（MiniMax-M3 关思考，注册文件现成）上跑首圈剂量-响应：规矩内容注入四档（none 与 NG 级联 L1、L2、L3，经确定性装配器产出）乘四命题（边界两道 e1-01b 与 p-06，守门两道 c1-09 与 p-12）乘六十发，加末位漂移哨兵一格，共一千零二十发，产出干预项第一组坐标。

## 二、关键设计 {#design}

剂量轴只取规矩内容注入即 NG 级联档位，框架层戏法经本体论实证排除。装配走 ng_assembler 即 L1 条目标题、L2 条目核心句、L3 AGENTS 原文段落带源哈希牌照，none 为空档；装配显式传工作区根 AGENTS.md 绝对路径绕开围堰相对根缺陷。守门锚向检查是安全读数：共识命题任何档位翻向即干预过冲旗。末位哨兵复跑 none 档 e1-01b 测日内端点自漂。统计四件：逐格分布与 Wilson 与熵、相邻档位二比例置换检验、邻档 Hellinger 散度、basis_regulation 引用计数。现有四百二十发 medium 通用档作异族参照点免费并入曲线图不作主曲线点。
