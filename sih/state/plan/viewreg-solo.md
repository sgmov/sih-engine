## 二、关键设计 {#design}

立名三段落档如下。

段一本质段四件。一句话定义即聚合输出组件，把仅可消费类事件与泊界心跳与结算计数聚合为人类介入接口的只读呈报面。职责不变即三视图面 alarms 过滤仅可消费事件、heartbeat 泊界名册三态配对、settle 按日结算计数，加零写零 LLM、同参双跑逐字节一致、缺席字段如实标不虚构；职责可变即质量基线三度量衡聚合面承 DEC-015 占位、log 过滤与归并导航承 DEC-012、告警视图族远端承 GOV-003。边界即不判即裁决归判定器与检词族、不写即零落笔、不进仅记录类事件、不载原始日志全量即聚合面不是日志浏览器。适用域即引擎聚合输出组件席。认识论状态即已裁席位定位与 view 节点归一与零写纪律、待裁质量基线聚合面实装形态、可证伪点即若出现视图必须写台账或必须载原始日志全量的需求即证伪当前边界。

段二推导段记录。查档四件即 terms 八十六与 dead 二百五十二与 candidates 二十一与 lazy 七，view 与 viewer 与视图三串零命中，零命中方进候选。候选三即 Viewer 采纳、View 反候选、造词族反候选。Viewer 即施动名词与 code viewer 及二进制署名位同根，体例承六席先例即 Scribe 与 Retriever 与 Parser 与 Ask3Repeater 与 Attractor 全部 code 与 en 同根，借词原形豁免。View 反候选死因即撞 DEC-001 状态层 view 节点与 src/view 模块路径即符号负载撞车、违六席施动名词体例、裸名在命令行误向为动作。造词族反候选死因即反推署名位不过与代码标识符脱钩。反推署名位交集即命令行 target/debug/viewer 三子命令已冻结、trail 行历史认证指针含 viewer 字样、报告名、commit 机械信息、席位行 zh 为主 en 不进、重放句同，交集唯一幸存 Viewer。覆盖面矩阵即五语义面 alarms 与 heartbeat 与 settle 与质量聚合远期与 log 导航，Viewer 逐面覆盖，不判不写边界由 viewer 行业例证只读观察器背书，判责让渡给得一与检词是正确空缺。裸名测试即 viewer 在 CLI 与 commit 不带词条零错向。词场淹没即仓内 view 活词为节点与路径义，Viewer 施动形不同形不淹没。

段三裁决登记。用户令在案即查问后开工令，裁决归人已满足，机器签署路线适用界未扩到本类承 deyireg 误差申报二。登记经 nomenclator register 落笔即词条 state established 加 zh 视图加 en Viewer 加 code viewer 加 definition 加 source 视图立名批 已签项 承 DEC-007 名册即立名礼加 signed 2026-08-31，manifest 升 0.4.0。
