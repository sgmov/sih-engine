# Skill: sihankor-marshalling（代理编组）

代理编组是长程任务的执行队形谱系，规定主 agent 与子代理如何分工、产出如何进租约治理包络。族内五形即单线、单发、反思、并联、串行，经用户 2026-08-28 全签批立名，旧编号 T5、T6-A、T6-B、T6-C、T6-D、T7、T8-S 退场入检词死档 name_only 即历史行保留不得作新名。主 agent 是主会话界面与首席编排者，子代理放大上下文窗口可利用率并保持界面清晰，只领符号材料生成簇。权威源为 sih-engine/sih/state/plan/README.md 即队形与命名约定、ai-ex/T6-PARADIGMS.md 即实证谱系与选择判据。本 skill 是调用契约，与权威源冲突时以权威源为准。

## 五形 {#forms}

- 单线 solo：主线亲写零子代理。需全局上下文与裁决连续性的批即此形，治理批默认形。
- 单发 oneshot：单子代理单文件单次响应。模板化独立任务。
- 反思 reflect：单子代理单文件多轮反思。价值在抓结构性违规非润色。
- 并联 parallel：多子代理并行各领独立簇，主线写最复杂件，收敛验收归主线。编排者是主线即此形；编排者是司衡 MCP 协议即借脑预留位，启用时随批立名。
- 串行 serial：单子代理持全量上下文连续产强耦合多文件。

## 触发时机 {#trigger}

- 用户点名代理编组或任一队形名或长程任务模式
- 用户要求大型批一次性完成且任务可分解
- 用户要求按任务包跑子代理

不触发：单点小改、纯问答、明确指定其他方式的任务。

## 硬性工作流 {#workflow}

选形即声明即非偏离，六步顺序固定。

一，选形。按 README 队形表与 ai-ex 选择判据定形，任务包文件名与范式行声明形，命名即主题前缀加形英文对后缀。

二，先写任务包再动手。落 sih/state/plan/ 即主题加形后缀.md，F 锚定跑前立文。

三，按形执行。单线即主线直写。单发与反思即派单子代理，提示词自包含即只凭包内容跑。并联即主线拆三类簇：并行簇双子代理后台各领、主线簇亲写最复杂件、依赖簇待验收后串行。

四，主线串行验收。F 锚定逐条实跑，文档类产出走 T6 工具链即化格、核阅、检词、书简认证。

五，写结果档含完成度表、F 验证表、队形验证一行。

六，主线 commit 全部。
