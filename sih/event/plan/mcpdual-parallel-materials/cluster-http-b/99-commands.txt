# mcpdual-parallel 子代理乙（MCP HTTP 路径簇）curl 命令 verbatim 记档
# 全部退出码 0，各调用 HTTP 状态码见对应落档文件尾行 HTTP_STATUS=。
# 端点 http://127.0.0.1:8765/mcp，全程无 Mcp-Session-Id（stateless 形），无牌调用零 Authorization 头。

## T0 initialize → 00-init.txt（HTTP 200）
curl -sS -X POST 'http://127.0.0.1:8765/mcp' \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -D - \
  --data-binary '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-03-26","capabilities":{},"clientInfo":{"name":"mcpdual-cluster-b","version":"1.0.0"}}}' \
  -w '\nHTTP_STATUS=%{http_code}' > "$OUT/00-init.txt" 2>&1
EXIT_CODE=0
