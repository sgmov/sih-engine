# defectwave 批结果档

## 验收判词 {#verdict}

- 五件全先红后绿，红证俱在批材料：open 输入闸（缺席件 exit 2 零残留）、罚金取样前移（merge-then-close 形红转绿即病灶签名同形件）、scrutinator w/ 形归一（两红一回归钉）、cascadeclose 测试真可达 skip 形（生产码零改验证力不降）、attnanchor last-row-wins（真台账验证撤牌域告警灭）。
- 全量回归零新红：lease 系九套与 usedpaths 七件与 cascadeclose 六件与集成约五十套全绿；lib 全量唯一红系 event_stream 工地环境假红族（任务书预告未触碰，基点同红）。
- 主会抽测复跑三套俱绿；settle 与 close 以本批新二进制 dogfood，缓存写读全链在案。

## 偏差申报 {#deviations}

- 闸序裁量候裁：open 输入件校验先于 stem 闸，正身缺席与未立名并存时先报输入位，两俱 exit 2 清晰报文（子代理申报一）。
- 缺陷二残余边界照录：末次 settle 后 closeguard 预收提交扫入的新脏面不在缓存取样内，settle-then-close 纪律内不可达，窄缝残余罚点候裁（子代理申报二）。
- last-row-wins 键位取 domain_root 而非 token_id，真台账两键判全同，同根多令牌以文件序末行为准（子代理申报四）。
- t5 与 t7 harness 适配系缺陷一闸前置的有意后果，原验证力保住（子代理申报一）。
