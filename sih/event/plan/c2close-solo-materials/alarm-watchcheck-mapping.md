# c2close-solo 腿三读数：告警语义对 watchcheck 五类残留映射表

> 对表双面：异常台红黄灯语义（违例批、在飞未收、超期泊件、域外壳）对五类残留（幻影会话、僵尸锁、停滞检验件、散位收据、无主工地）。
> 语义出处如实标注：五类残留判定语义正典在 lease 扫残留子命令（sih-tools/lease/CONTRACT.md 修订四十六，sweepimpl-solo 批立；sha256 dbb27f48207505db723539dc9bf957c1470278f61bdc616633414cf8978a272c 即 sweepcore.py），watchcheck 本面即无主清单与锁面超宽哨兵（sih-tools/watchcheck/CONTRACT.md；core.py sha256 c6e9549ab9c604c836573eae558542781e63e0399208a8342312b92e61f49c92）。任务包称「watchcheck 五类残留」系哨检族统称，语义以各判定正典为准。
> 视图数据面即 projector.py 三源（trail 与 sessions 与双线泊材料，见腿二行级指针件）；本表逐行列数据面与判定面。

## 四、三态结论

**部分对齐**。计数读数：语义向即四语义中一语义（S2 在飞未收）与残留类（幻影会话）症状级对齐，三语义（S1 与 S3 与 S4）与五类残留正交即分属不同信号族各有哨检承载位；残留向即五类残留中一类（R1 幻影会话）有症状级呈面，一类（R3 停滞检验件）有间接关联不可分辨，三类（R2 僵尸锁与 R4 散位收据与 R5 无主工地）零呈面；watchcheck 本面两行（W1 与 W2）零呈面。判定语义面与视图呈面存在结构性差距：视图数据面三源（trail 与 sessions 与泊材料）不含锁台账与检验文件位与收据位与工地面。

按任务包三态规则即部分对齐：差距申报与补齐候选呈人裁，追记挂起（GOV-002 v2.8 达成追记本批不落，腿四条件性停摆如实申报）。

## 五、差距申报

1. 差距一：锁台账（locks.ndjson）不在视图数据面，僵尸锁（R2）与超宽哨兵（W2）零呈面。
2. 差距二：检验文件位（lease/ledger/checks 与 state/plan 散位）不在视图数据面，停滞检验件（R3）零直接呈面。
3. 差距三：散位收据位（LEGACY_RECEIPT_DIRS 冻结位）不在视图数据面，散位收据（R4）零呈面。
4. 差距四：工地面（worktrees 目录与 msh 分支）不在视图数据面，无主工地（R5）零呈面。
5. 差距五：无主清单（W1）即 git 活写面不在视图数据面，watch 对表检出的无主修改零呈面。
6. 差距六：幻影会话症状级对齐缺判定级分辨（S2），视图将持续在飞呈黄但不能区分真在飞与幻影。
