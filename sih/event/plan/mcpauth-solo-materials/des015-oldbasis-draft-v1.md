# DES-015 MCP HTTP 面多项目识别与分项目写授权安全模型

## 概览 {#overview}

- 本设计承 mcpline 线 HTTP 写面设计批定位，令源用户 2026-09-09 令「http要分项目的如何做，也要做写入权限」，是 mcpweb HTTP 只读面在役与 DES-014 stdio 安全模型在档之后的传输变体与多项目扩展，为 HTTP 写面实装批的硬前置，未过本设计不一裁实装批不开工::[边界申明](#boundary)
- 项目识别判词取令牌正身形：签发通道归主窗签发位承人节点令源，台账形即 tokens.ndjson 哈希落册明文一次性，传输形三形取舍判词取 Authorization Bearer 头形拒路径段形拒每项目端口形::[项目识别形](#token-identity)
- 识别与会话映射判词取令牌会话一对一形：一令牌同时刻至多一个活跃 lease 会话，身份锚从 DES-014 进程正身形变体为 server 进程正身件加令牌哈希注入复合形，五验逐项在 HTTP 下各验什么逐条载::[令牌与会话映射](#token-session-mapping)
- 授权判词取路由层矩阵加命名空间裁剪形：scope 三档即 readonly 与命名空间写档与 custom，写操作包命名空间前缀裁剪，与既有 scope_violation 与 locked_elsewhere 与 wait_turn 理由码原位衔接零新执法位零 LLM 裁决位::[授权矩阵](#authorization)
- 写面判词取零新增执法形：令牌只裁剪透传，scribe 三闸与租约五验与 closeguard 与 git hooks 原位生效；record append 无幂等闸的 HTTP 重试风险如实申报，缓解取锁纪律强制形加重放明示不防两件::[写路径复用](#enforcement-reuse)
- 审计判词承既有哈希链形：信封既有位生效令牌身份经正身注入直接归因，撤销即台账追加行末行为准，在飞会话拒绝归路由层拒透传，轮换双活窗口如实申报::[审计与撤销](#audit-revocation)
- 威胁模型六向各给缓解或明示不防：令牌泄露与跨项目越权与重放与枚举与台账膨胀与单令牌滥调，缺省绑定 127.0.0.1，远程与 HTTPS 暴露明示不防入边界::[威胁模型](#threat-model)
- 失败语义判词取双层映射形：传输层状态码与 MCP 载荷层教学四字段分离，未认证统一 401 零区分，执法理由码走载荷层原样透出不吞不译，不泄露他项目存在性::[失败语义](#failure-semantics)
- 边界申明：自有运行时归 pk-079 与 GOV-002 v3 换版不触碰，SiInfer 彩排写授权即本设计第一实例但不预占，stdio 面安全模型 DES-014 不废两面对表同一执法层::[边界申明](#boundary)

## 项目识别形 {#token-identity}

判词：令牌正身形。HTTP 面多项目的项目身份唯一承载是签发位签发的访问令牌，令牌台账哈希落册，明文一次性交付不经台账不经链。

签发通道判词：主窗签发位承人节点令源。签发动作不在 MCP 工具面对任何 HTTP 客户端开放，参照 DES-014 takeover 与 bypass 拒透传先例，server 对签发类调用一律拒透传；签发机械执行归主窗代理，令源归人节点，即人节点裁决面收缩到令源与机械执行归代理，承工程基线五治理延伸是减少人参与。签发程序四步固定：其一高熵随机源出令牌明文，其二算 sha256 得令牌哈希，其三追加台账行，其四明文经签发会话回执一次性交付认领项目，明文不落台账不落链不落任何仓内文件。

台账形判词：tokens.ndjson 哈希落册，落位 sih-tools/mcpline/ledger/tokens.ndjson，管理归 mcpline 面不混入 lease 会话台账，职责单一即 lease 台账管会话与令牌台账管凭据。台账行字段固定：token_id 即哈希前十六位、token_hash 即全 sha256、ns 即项目命名空间、scope 即三档之一、status 即 active 或 revoked、issued_at、issued_by 即令源指针。写点纪律承 pk057fix 批台账写点纪律：flock 串行加 O_APPEND 原子整行，禁整文件重写；撤销即追加新行同 token_id 载 status revoked，台账读数取每 token_id 末行，append-only 精神与链同构。台账膨胀明示不防，清理归人节点后裁。

传输形三形取舍判词：取 Authorization Bearer 头形。其一Bearer 头不进 URL 不落标准访问日志与代理日志与 Referer，泄露面最小；其二与 mcpweb 已立单端口统一形态相容，streamable HTTP 客户端原生支持头注入。路径段形拒：令牌进 URL 即落日志与代理与 Referer 三泄露面，且 MCP streamable 端点路径固定不宜携带凭据段。每项目端口形拒：端口管理随项目数线性膨胀、防火墙面扩大、端口号本身成侦察面、破单端口统一形态。三形取舍是传输层裁剪非执法，令牌校验程序与传输形正交。

## 令牌与会话映射 {#token-session-mapping}

判词：令牌会话一对一形。一条经认证的 HTTP 连接绑定恰好一个 lease 会话，同时刻一令牌至多一个活跃 lease 会话，重复 open 即同包活跃闸既有拒定，禁一令牌多会话并行禁会话池。

绑定形：MCP streamable HTTP 连接经 Bearer 头认证后，server 以本进程正身件加令牌派生值调用 lease open 立会话，会话号经工具结果透出给客户端记录；此后该连接上一切写操作携带该会话号，租内五验逐操作核验。断开收约形承 DES-014：零写连接轻收约，有在途写走完整 close 链闸与 closeguard 三检照走，收约失败转挂起候人节点 takeover。孤儿会话处置承既有 PID 探针三态与心跳停滞判据与 takeover 通道，零新增清理机制。

身份锚变体判词：从进程正身形变体为 server 进程正身件加令牌哈希注入复合形。DES-014 stdio 形下每连接一子进程身份天然可分，HTTP 形下 server 是常驻进程，客户端无独立进程身份可采，鉴此身份可分性迁移到令牌粒度：lease open 时 server 以令牌哈希为连接派生值注入正身可选件即 session_id 位，使不同令牌立出的会话在正身串与信封 identity_hash 直接可区分，责任归因粒度从连接细化到项目。五验在 HTTP 下各验什么逐条：在册验即令牌台账行 status 末行 active 且会话在会话台账活跃；会话择定验即操作须落本连接自立的会话；范围验即 scope 与 ns 裁剪面覆盖检查；身份验即 server 进程侧 hostname 与 user 与 boottime 漂移照验加令牌哈希与台账对表；绑定验即请求携带凭据派生哈希与会话在册令牌哈希逐笔对表。

边界如实申明：HTTP 形下令牌即身份，令牌泄露即身份冒用，此为令牌信任模型既有边界，与 DES-014 正身防偶发撞名不防产权级仿冒同界不扩不缩；server 进程自身正身件照签发照核，进程侧五验不因令牌形松懈。

## 授权矩阵 {#authorization}

判词：路由层矩阵加命名空间裁剪形。scope 三档决定工具与路径是否向调用方透传，透传后的判定全归既有程序，矩阵与裁剪俱是静态映射表随批评审，零 LLM 裁决位。

scope 三档语义逐条：readonly 档即只读五工具可调与写工具一律拒透传，承 mcpweb 只读面结构性缺席语义的令牌化推广，缺席从实例级细化到令牌级；write:ns 档即写工具可调但操作面被命名空间裁剪，形如 write:ns=sih-engine/doc/design 即该令牌写面限该前缀，ns 与工作区子树与任务包前缀的映射表随批评审；custom 档即逐工具逐旗标白名单显式登记于台账行，登记面即授权面，零缺省放行。

写操作包命名空间裁剪形：write:ns 令牌的 lease open --allow 与 --repo 参数与 record 写入路径逐条对 ns 前缀检查，出界即路由层拒透传不发起调用；透传后 lease 侧 --allow 登记面出界仍由既有 scope_violation 执法拦截，两层各司其职不重复判定，即路由层裁剪管凭据授权面、执法层 scope_violation 管会话登记面，判据同源即台账 ns 与 open 登记面。

与既有理由码原位衔接逐条：scope_violation 即透传后会话登记面出界的既有执法拒，原样透出；locked_elsewhere 即锁冲突既有拒，原样透出不吞不译；wait_turn 即排队受理既有返位次形，经独立工具透出，零 LLM 轮询零 token 消耗语义承 DES-014 不变。零新理由码零新执法位，矩阵拒透传与执法拒在失败语义节分层映射。

## 写路径复用 {#enforcement-reuse}

判词：零新增执法。HTTP 写面是既有 CLI 的薄投影加令牌裁剪层，参数透传、结果透传、退出码透传，全部既有执法原位生效，令牌只裁剪透传不做第二套判定。

执法复用逐件：scribe 三护栏即工地链副本禁追加与闸二重意图拒与闸三会话在册验对 HTTP 写面逐笔生效，server 禁以任何方式代填或绕过；lease open 六位闸序与 lock 悲观五验与 unlock 加持锁验与 closeguard 收约三检与 close 链闸与 claims 领取账本俱原位；git hooks 直提守卫在 commit 位照拦，HTTP 发起的 commit 须经 lease commit 正典通道，无登记 plain commit 即拒的语义与发起方传输形无关。

record append 无幂等闸的 HTTP 风险如实申报：stdio 形下调用方是进程内 agent 无传输层重试，HTTP 形下客户端超时重试即同 report 重复认证笔，闸二只拒 intent 重放不拒 append 重放，风险敞口为传输重试新造。缓解两件：其一锁纪律强制形即写面调用必须携带在册会话且 trail 路径锁面持有约束承既有锁面语义，跨客户端重试撞锁即 locked_elsewhere 拒；其二重放明示不防即同会话窗口内的重试重放不新增自动拒重，重复笔由事件信封审计与 meter 交叉核对检出，处置归人节点，承 DES-014 append 无幂等闸如实申报边界不扩不缩；客户端重试纪律入工具描述教学面。

禁令三条承 DES-014 照录：server 禁内嵌任何 allow 或 deny 判定逻辑替代执法，禁缓存执法结果跨调用复用，禁绕过 CLI 直写台账链文件或 git 对象。

## 审计与撤销 {#audit-revocation}

判词：承既有链加令牌归因。每笔写已上链是既有事实，本设计零新审计面，只定令牌身份归因与撤销与轮换形。

信封主体加令牌身份形：链事件信封既有位生效即每笔链事件载 session_id 与 identity_hash；令牌哈希经 lease open 注入正身可选件后，同 server 不同令牌的信封 identity_hash 直接可分，令牌归因零回查即闭合；信封 identity_hash 与台账 token_hash 的对应表载签发留痕，链面审计按信封回查台账行即可归项目。

撤销形：撤销即台账追加新行同 token_id 载 status revoked，末行为准；撤销动作走治理通道落链留痕，不在 MCP 工具面对客户端开放。在飞会话拒绝判词：撤销拒定位在路由层，server 每笔写透传前查令牌台账末行 status，非 active 即拒透传不发起调用，与 takeover 与 bypass 拒透传同形，零新理由码零新执法位；已立会话不被 server 强拆，客户端换新令牌重连重立会话，旧会话由既有孤儿清理通道兜底。

令牌轮换形：轮换即新令牌签发行与旧令牌撤销行同批落链，操作紧邻收窄窗口；轮换窗口双活如实申报明示不防，即签发与撤销两笔之间旧令牌仍有效，窗口期滥用事后可审计；轮换不迁移在飞会话，旧令牌会话照撤销形处置。

## 威胁模型 {#threat-model}

判词：六向各给缓解或明示不防，防域与不防域逐条申报不含糊；缺省绑定 127.0.0.1，远程与 HTTPS 暴露明示不防入边界。

令牌泄露：缓解三件，即台账哈希落册明文一次性使台账失窃不等于凭据失窃、撤销通道使泄露令牌可即时作废、缺省绑定 127.0.0.1 使网络暴露面收窄到本机回环；明示不防即本机明文截获后的窗口期滥用，事后凭信封令牌归因可审计。

跨项目越权：缓解三件，即 write:ns 路由层前缀裁剪使出界调用不发起、租约五验绑定验使他会话操作既有拦截、执法层 scope_violation 使会话登记面出界既有拒；明示不防即 server 进程被劫持，承 DES-014 进程劫持同界不防实时阻止只保事后可审计。

重放：缓解一件即链铸时戳 flock 临界区单调自铸使乱序重放不可插入承既有；明示不防两件，即 record append 同会话窗口重试重放与 Bearer 头本机截获重用，前者审计检出处置归人节点，后者在 127.0.0.1 防域内不构成远程威胁。

枚举：缓解两件，即令牌高熵随机使枚举不可行、未认证响应统一 401 同载荷使无效与撤销与缺头零区分不泄露台账行存在性；项目存在性经命名空间裁剪拒与教学裁剪双位不泄露。

台账膨胀：明示不防，append-only 即容量换审计，令牌台账与链台账同界，清理归人节点后裁零自动清理。

单令牌滥调：缓解两件，即锁面粒度持锁使单项目占用面有界、wait-turn 保序队列使跨项目后来者不饿死；写频本身不限流明示不防承 DES-014，归人节点监管位。

边界申明：缺省绑定 127.0.0.1 是本设计防域的前提而非可选优化；远程暴露与 HTTPS 终端部署明示不防入边界，本设计防域是本机多 agent 多项目面不是网络传输安全，远程部署须前置 TLS 终端但那超出本设计防域且本设计不预设不预占。

## 失败语义 {#failure-semantics}

判词：双层映射形。传输层与 MCP 载荷层错误面分离，传输层只管认证与路由拒，执法与参数错误全走载荷层原样透出，HTTP 层不翻译不吞。

传输层映射逐条：401 未认证即无头或头形错或令牌不在册或已撤销，四因统一 401 同载荷零区分，载荷不泄露区分信息；403 越权即认证过但矩阵拒透传，readonly 调写工具或 ns 出界或 custom 白名单外，载荷告拒透传事实与 scope 现值；405 与 400 即传输形错，照 HTTP 标准语义零教学负载；429 限流即映射语义在档而限流器不在本设计，承写频不限流明示不防，若将来人节点立限流位则 429 载荷照教学四字段形，本设计零实装零预设。

载荷层映射：MCP streamable POST 常态 200 包 JSON-RPC error 或 isError 载荷；执法理由码即 scope_violation 与 locked_elsewhere 与 SessionNotActive 与 IntentRecordUsedRejected 与 PackageAlreadyClaimed 原样透出不吞不译；教学四字段承 SPEC-023 即 error 与 what_this_tool_does 与 valid_params 与 canonical_pointers，写工具载荷加 retry_discipline 一字段载重试纪律即撞锁改 wait-turn 与重试前查会话在册。

报错即教学边界承 DES-014 分级裁剪形：教参数名与退出码三值与闸位名称与理由码与修复动作；不泄露绝对路径面即错误转述一律工作区相对形、他会话身份、他会话存在性、他项目存在性即 ns 出界错误只告本操作不可成与 本令牌 ns 边界不列其他项目名。张力如实申报：401 零区分降低合法客户端撤销后排障能力即教学面收窄，权衡依据是基线五不生成不等于不引导与基线二人类注意力只投异常信号，与 DES-014 裁剪张力同构；裁剪映射表随批评审可调，调整走修订不改判定语义。零动态拼接不可信数据进错误文本。

## 边界申明 {#boundary}

注入面通用化与自有对话循环归 pk-079 分相承载，本设计只涉 MCP server 进程边界内的传输认证与路由裁剪层，不涉客户端运行时与注入面通用机制。GOV-002 与 v3 换版不触碰：写面投影以现行各工具版本为界即 lease 1.39.0 与 scribe 引擎件现行与 identity 0.5.0 与 meter 0.2.0，版本升级走各工具既立换版程序，本设计不预设不预占。判定语义正典留确定性程序：本设计零 LLM 裁决位，scope 三档矩阵与 ns 前缀映射与错误裁剪映射俱是静态数据，任何判定语义变更走既立程序即得一裁加执契终签。

SiInfer 彩排写授权即本设计第一实例但不预占：第一实例只是首个适用场景登记，实装批的包命名空间映射表与签发台账初册归实装批按本设计落，本批零预写零预占。alpha 相读数面归 SPEC 023 号契约件已立契约，本设计不重复不修改不冲突；DES-014 stdio 面安全模型不废，HTTP 面是其传输变体加多项目扩展，两面对表同一执法层，stdio 形下本设计令牌层不适用即无传输凭据位，DES-014 形下本设计 ns 裁剪不适用即单机单工作区。本设计属 des-001 域，产出经化格核阅检词认证序。
