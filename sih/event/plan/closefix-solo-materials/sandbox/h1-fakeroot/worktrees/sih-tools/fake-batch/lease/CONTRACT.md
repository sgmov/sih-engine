# 租约契约（租约／lease）

按任务包生命周期治理写入的租约工具，2026-08-26 用户签署立名即双工具并库，工地外壳与锁本体合并为一件。钉实即借用 git 机制，通过两把锁强制性让 LLM 不能够直接修改主分支的文件，两把锁的意义是副本归并主分支时不会出现冲突。立约开工建副本签发会话档，租内双锁，期满审查归还归并拆本。回归义构成性于租约期满归还，完美直译对两侧词典词，词条入检词登记，推导史见 sih-engine PRO-007 簇九。

## 调用 {#usage}

cd sih-tools/lease 后十三子命令。open 即立约开工，参数 --package 任务包、--identity 正身报告、--intent 意图记录双腿验收、--repo 可重复、--allow 可重复、--claims 领取账本路径覆写即闸一联动警示读数位、--at、--root、--ledger。claim 即任务包领取登记，参数 --package 任务包、--ttl 时效分钟数必填正整数、--claimant 领取人标识即会话预备号或委外自报标识缺省 anon、--at、--root、--claims。unclaim 即领取释放，参数 --package、--claimant 给参即验与在领相符、--at、--root、--claims。lock 即租内取锁，参数 --path、--identity、--session、--mode 即 exclusive|append 缺省 exclusive、--at、--root、--locks、--ledger。check 即乐观链验基线，参数 --path、--registry、--doc-root、--trail 可重复、--cascade-dir、--reports-root、--root、--locks。status 即查册，参数 --package、--session、--path、--history、--claims 附领取视图开关、--at 即领取视图过期判定参照、--claims-ledger 领取账本路径覆写、--root、--ledger、--locks。unlock 即放锁，参数同 lock。close 即收约三检，参数 --package、--force、--reason、--at、--root、--ledger、--locks。commit 即提交正身路径，参数 --repo、--session、--stage 即 wip 或 settle、--subject、--seq、--cert、--note、--trail 可重复、--root、--ledger。reconcile 即三方对表，参数 --repo、--trail 可重复、--base、--limit、--bypass-ledger、--root、--ledger。bypass 即绕行留痕，参数 --repo、--sha、--reason、--session、--at、--bypass-ledger、--root。install-hooks 即守卫安装，参数 --repo 可重复缺省双仓、--root。uninstall-hooks 即守卫拆卸，参数同 install-hooks。

## 机器形态 {#machine}

立约链：open 验意图即围堰 ask3 包核形态契约加引擎 ask3gate 核血统四类，无意图无会话；解析任务包请求写入段为范围第一源即 scope_source 字段；起 git 副本即分支 t6d 加包名每包每仓一支并记基线分支为归并目标位；签发会话档即台账行载写入范围与正身双哈希与意图节即记录哈希与锚点数；绑定侧档即工地根下 .bindings 载稳定子集三件 hostname 加 user 加 boottime，不入版控不进台账。

领取账本承 claimgate-solo 批即任务包领取登记声明位。claims 台账即 sih-tools/lease/ledger/claims.ndjson append-only 追加即唯一写点历史笔原文保留零改写，行五字段即 package 与 claimant（会话预备号或委外自报标识）与 claimed_at 与 ttl_minutes 与 status。claim 同包已有未过期在领即拒 PackageAlreadyClaimed 独立异常载领取人与到期时刻详情非空，声明位拒绝 exit 一非执法拒绝，领取不验身份不验绑定即登记可见性门槛低于租内锁五验。unclaim 即在领释放落 released 行，无在领即拦 no_active_claim 载实效状态，领取人给参不符即拦 not_claimant。实效状态三值读时派生即 released 弹在领同包、过参照时刻即 expired、否则 claimed，expired 不落笔零改写，判定时自动标注即僵尸领取不靠人清；--at 参照时刻覆写只影响过期判定不重放事件序。status --claims 附领取视图即每包最新领取实效状态三值标注加四字段读数，缺旗标零 claims 键零噪声向后兼容。闸一联动即 open 签发成功时同包有他人未过期领取即在输出与会话档台账行载 claims_warning 警示行载领取人与领取时刻与到期时刻，claimant 与签发会话号同形即自领不警示，零在领即零键零噪声；只警示不拒，同包唯一硬执法仍归闸一 PackageSessionActive，两拒不同位不互相替代。

租内双锁：lock 走悲观链五验序固定即在册验、会话择定、范围验、身份验、绑定验，理由码入报告即 no_active_session、session_not_active、scope_violation、identity_anomaly、binding_absent、hostname_drift、user_drift、boottime_drift；他会在册持同 path 即 locked_elsewhere 拦，同会话重复记行不拦。unlock 同五验加持锁验即 not_holder 与 not_locked 拦。check 即乐观链子进程调级联 cascade check 即 trail 可重复按参序接续，脏上游拦退出码一，unverified 不拦承有度，不在册过注记承拦多不拦漏，checked 行入锁台账。

锁判定三洞修复承 locksplit-solo 批即路径同一化加追加态锁加路径包含判定。路径同一化：normalize_path 升级为工作区根相对规范形即绝对路径剥根前缀、去 ./ 前缀、尾斜杠统一，锁账本新笔一律落规范形，互斥判定对历史笔双侧规范化后比较即账本 append-only 零改写，异形态同路径互斥不再被绕穿。追加态锁：lock 增 --mode exclusive|append 缺省 exclusive 向后兼容，判定规则即 append 与 append 可共存、exclusive 与任何形态互斥，unlock 按持位放；共享追加面即 trail 文件与 CALL-LOG 与 reports 与 counts 与台账与 core 包声明 append 态即并发批互不憋，引擎 lockgate_guard 对 trail 追加操作认 append 持位即他会话 append 持位不拦。路径包含判定：取锁冲突判定增包含规则即他方所持路径为本路径祖先目录或后代即冲突，堵目录文件双持洞。locked_elsewhere 报告增 held_path 与 held_mode 两键即持锁方与持锁型如实透出。

收约三检 close：锁清零即本会话在锁非零拒收工；前置态整批拒即目标仓停置合并态（git-dir 含 MERGE_HEAD 或 rebase-merge/rebase-apply 或 CHERRY_PICK_HEAD 或 REVERT_HEAD 或 BISECT_LOG 标记）或共享面脏（已跟踪改动非零或未跟踪件覆盖分支 tip 落地路径）即整批拒绝零部分动作错误详情全量透出禁空串，半程不可达即要么全归并要么零动作，未碰撞未跟踪件（如任务包装配件）不构成前置态；归并先行于拆本即副本分支有新提交先归并基线分支，归并成后方移除工地删支，无提交即跳归并；merge 与删支返回码全检即失败计 merge_failed 或 branch_delete_failed 不吊销会话，工地与分支留待清障后复跑自愈即 pk-022 假绿修复。凭证与副本同生共死即先移除后吊销，任一仓失败不吊销留残自愈即目录已不存在计 missing。删支幂等即删前 rev-parse 查 ref 在席，缺席计 already_gone 照常收敛不判败即重复删支不幂等缺陷修除；结果字段拆 worktree_result 与 branch_result 两列如实分报；失败的收约落 close_failed 台账行随败随记，该事件对在册判定与对表分类双惰性即台账只增不改。

写入门四闸承 guardrail2-solo 批即四条写入入门护栏按写入面分承两仓。闸一同包唯一即 open 在验意图前查 sessions 台账同包已有 issued 未 revoked 会话即拒 PackageSessionActive 独立异常载包名与在册会话号详情非空，堵同包并发双跑即单飞批铁律的机械落点。闸四收约预检即在现有前置态探针后、真归并前逐仓增 git merge-tree --write-tree base branch 探测本场归并内容冲突，任一仓非零即整批拒零动作载冲突文件清单堵半程不可达；支已删即 rev-parse 缺席跳过不误拦残局收束。引擎侧承闸二三即闸二重意图拒（scribe intent 链目录全量重放面查同 record 路径已有 intent_refined 即拒 IntentRecordUsedRejected）与闸三会话在册验（scribe intent 与 append 认证验 --session 在会话台账为活跃，无或已吊销即拒 SessionNotActive），各承 --allow-reintent 与 --no-session-reason 两旗标默认关留主会处置位。

提交四验 commit 承 DEC-012 裁决三与四即提交界与认证门同界：会话在册验即 session 活跃；范围验即暂存件全落 allow 即条目精确或目录前缀；认证在链验即 settle 必挂 --cert 且哈希前缀命中 trail 上 certification_completed 事件的 event_hash；信息机械生成即模板单源 build_message 三形态 wip 与 settle 与收约归并，base 由工具自算即主检出取分支名加 HEAD 短号、副本提交取基线分支加 merge-base 短号，调用方不携自由 message。编辑位迁移即本会话副本路径作仓别名，范围验按其正身仓映射，他会话副本仍拦。拦截理由码五件即 session_not_active、repo_not_in_session、nothing_staged、staged_out_of_scope、cert_not_on_chain。wip 即段中检查点不设认证门，settle 即段结算必过认证门。

三方对表 reconcile 承 DEC-012 裁决七即反绕行机制：git log 对会话台账对 trail 对 bypass 台账四方分类，message 含 session 行且会话号在册且 cert 命中即 routed，subject 为 merge 冒头且包名在册即 routed_merge，挂接直改链笔引用（guardcore.DIRECT_PEN 单源认形全半角冒号同形）且哈希前缀对上链上任一 event_hash（任意事件非认证专属即 _load_all_event_hashes 核验面）即 routed_direct（idenlane-guard-solo T-8 路由认账，令源即主会四笔 bypass 实证噪声 c8861e9f 与 5cba19e5 与 fe6af59a 与 CALL-LOG 补笔俱为几行小改动被迫走例外通道即 bypass 信号价值稀释，承用户轻车道兼容裁定），引用不在链的挂接形不入此类落 bypass 对表即已登记归 bypass 未登记出 unbypassed 告警 fail-visible；routed_direct 与 routed_merge 计入 routed 汇总且同形入 unrouted_tail 尾单（可见性非告警即不影响退出码）；session 行不在册即 session_orphan，cert 不在链即 cert_missing，无模板提交（既非 session/cert 形又非 merge 形又非直改引用在链形）逐笔对 bypass 台账即已登记归 bypass 类不告警、未登记出 unbypassed 告警类，unrouted 保留为历史类名即新数据零出只作兼容键。只报不拦即对表是可见性不是闸门，存量与增量经 first_routed 分界，unrouted 或 orphan 或 cert_missing 或 unbypassed 非零即退出码一。封线内置即缺 --base 时按仓名套 SEAL_BASES 界线父为起算，封线号不在该仓即同名异源回落全史显式，套用即报告出 base_source 三键。追认表即 SEAL_EXEMPTS 按仓名钉死界后存量，表内提交归 sealed 类不计违规不入尾单，summary 出 sealed 计数，表变更须升版本。

守卫三件即 guardhook-solo 批承 adisp-guard-1 裁决（链事件 2ada7331）与用户 2026-09-02 批准令。守卫语义即只拦提交信息形态不判内容：guardcore.validate_commit_message 纯函数单源判合规，合规形覆盖 lease 全部 message 形态即 settle 形（正文含 session: 十六位与 cert: 挂接行）、wip 形（首行含 wip 标记加 session: 挂接行即 wip 无认证门故无 cert，此形为 dispatch 字面 session 加 cert 两挂接行之外的实补即不补则守卫误伤 lease 自身 wip 正规路径）、merge 形（首行 merge: <批名> 副本归并）、direct 形（idenlane-solo iden-02 即提交信息携带直改链笔挂接「直改链笔: <事件哈希前八位>」全半角冒号同形即 DIRECT_PEN 认形，首位判定先于三形不排他即返回 ok_direct；真实在链由钩子层对当日 trail grep 核验引用前八位命中 fail-closed 引用不在链即拒并出指引，主树 d5cd596f 实装、idenlane-guard-solo 批补夹具与判定一裁），拒因四值即 no_session、no_cert、no_merge_hanger、batch_prefix_no_session。批名前缀形（subject 首记号连字符批名模式且无 session 挂接行）显式独立立类承 guardrail-solo 护栏三即 aea1768 同形必拦，这是对无 session 兜底的显式命名非新增拦截即无 session 本就拒。轻车道文件类白名单即 guardcore.DIRECT_LANE_FILE_WHITELIST 冻结架构常量十条目（idenlane-guard-solo T-9 承用户 2026-09-06 扩面令，文书类九路即 lease/ledger 台账与 lease 与 scribe 的 CALL-LOG 与 scribe/identity/tally reports 与 parking materials 与 PARKING 投影双档，加处置类一条即 untracked-disposal 未跟踪件处置），起步宁窄勿宽即源代码与引擎件不入选仍走工地全仪式，本批为声明位登记零执法（commit-msg 钩位不见文件面，机械执法归后继裁定面），扩面走本契约修订禁裸奔增删。拦多不拦漏边界如实声明：守卫拦形态模仿者不能拦持真实会话号手写 wip 形即残余通道由 reconcile 对账兜底（cert 缺席与段结算认证门与 unbypassed 告警），merge --squash 与 git 缺省归并信息等合法非常规形会被拦即走 --no-verify 加 bypass 登记或改正规路径。钩子落位注记：形态判定落 hooks/commit-msg 位即信息既定阶段（git pre-commit 阶段 COMMIT_EDITMSG 未写即无信息可校验，2026-09-02 实测在案），拦截语义与 pre-commit 同即提交落成前最后机械闸；hooks/pre-commit 为环境预检薄壳即 python3 可用与 guardcore 可导入，破即 fail-closed 拒提交不让守卫失效静默开通道。钩子禁依赖 venv 即判定纯函数零第三方依赖由薄壳以 sys.path 直入 src 导入。install-hooks 即向仓写 git config core.hooksPath 指仓内 hooks 目录（sih-tools/lease/hooks，双仓同指一目录），config 属环境态不入版控即换机须重装且 --repo 可重复缺省双仓；uninstall-hooks 即 unset 可逆，键缺席计 already_absent 照常收敛。bypass 即绕行留痕子命令落 ledger/bypass.ndjson 逐行 JSON（event/repo/sha/reason/session/at/tool），台账只增不改承工程基线四，sha 全号短号皆收即对表前缀互含。

台账双册即 ledger 下 sessions.ndjson 与 locks.ndjson，追加即唯一写点，历史行原文保留不随改名重写。退出码三值：零即成；一即拦含五验失败与锁态冲突与脏上游与收约三检失败；二即工具异常含文件非法与 git 不在与多在册无参。写面封闭即源码写调用仅台账追加与绑定侧档与 git，零 LLM。

## 租约协议 {#protocol}

正身留痕不签，租约位执行即拦，验证与执行分工承 DEC-010 与 DEC-011。绑定失配即漂移走人节点申诉重立约零惩罚。会话档写入范围以任务包请求写入段为第一源，机械链即意图到会话到锁到写。

## 验收判据 {#criteria}

可证伪八条承任务包 lease-merge-t6d 即 L1 至 L8：词条与血统档落位核阅绿；六子命令全可用测试全绿；lock 与 unlock 语义与原 acquire 与 release 对齐；close 锁未清零拒收工；close 归并删支两态正确；双台账随迁历史原文保留；真会话全链跑通；写面封闭。合计二十测全绿。

可证伪两条承任务包 lease11-t6d 即 L9 与 L10：commit 四验即越界暂存拦与空暂存拦与他仓拦与 cert 不在链拦与在链放行，message 三形态模板单源；reconcile 三方分类即 routed 与 routed_merge 与 unrouted 与 orphan 判类正确，净界退出码零污界退出码一。合计二十六测全绿。

## 融回门 {#merge}

三查对表承孵化环第四步。落点即引擎基础设施层承 GOV-003 第 1 段与 DEC-007 归属判据。融回评估两重门槛即体量与时间，主判据贡献度，达标由用户届时裁量。编辑位迁移与认证门留编辑位迁移批。
