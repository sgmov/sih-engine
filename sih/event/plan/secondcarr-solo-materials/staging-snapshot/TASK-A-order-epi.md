数学核心（必须给出可判定主张，禁止空话）：
- 设定：完全格 (L, ≤)（承 ORD-002），单调算子 f: L → L（承 ORD-004）。前不动点 f(x) ≤ x 与后不动点 f(x) ≥ x 的定义已在 ORD-003，引用即可，不重复定义。ORD-003 已给 lfp(f) = 前不动点之交、gfp(f) = 后不动点之并，本条不重复定理，给两条推论性原理加一条新定理
- 归纳原理（定理一）：R 是 f 的前不动点蕴含 lfp(f) ≤ R。证明：lfp 是全体前不动点之交
- 共归纳原理（定理二）：R 是 f 的后不动点蕴含 R ≤ gfp(f)。证明：gfp 是全体后不动点之并
- 两原理独立性（命题）：前不动点类与后不动点类互不蕴含。例：L 为二元素链 0 < 1，f 为常顶映射 f(x) = 1。则 0 是后不动点而 1 是前不动点，0 不是前不动点（f(0) = 1 不小于等于 0），1 不是后不动点。lfp(f) = 1 且 gfp(f) = 1，两原理在同一算子上管住不同的候选集。逐项核验后写入
- 镜像对偶定理（定理三，本件核心新内容）：设 d: L → M 为完全格间逆序双射，即 x ≥ y 当且仅当 d(x) ≤ d(y)，且 f: L → L 单调。定义 f 的镜像算子 f^d: M → M 为 f^d = d ∘ f ∘ d。断言：f^d 单调；对任意 x，x 是 f 的不动点当且仅当 d(x) 是 f^d 的不动点；且 lfp(f) = d(gfp(f^d)) 且 gfp(f) = d(lfp(f^d))。证明要点：单调性由三次逆序复合得；不动点传递由 d 单射得；lfp 侧：d(gfp(f^d)) 是 f 的不动点（gfp(f^d) 是 f^d 的不动点，d 单射消去），且任取 f 的前不动点 p，则 d(p) 是 f^d 的后不动点（f^d(d(p)) = d(f(p)) 且 f(p) ≤ p 给出 d(f(p)) ≥ d(p)），故 d(p) ≤ gfp(f^d)，由 d 逆序得 p ≥ d(gfp(f^d))，对全体前不动点 p 成立故 d(gfp(f^d)) 是其交即 lfp(f)。证明写完整但紧凑
- 共归纳实例（一段）：双模拟关系作为关系集算子的 gfp。设带标记转移图，F(R) 定义为满足所有转移保持的转移对关系，双模拟即 F 的 gfp，共归纳原理给出验证法则：要证 R 是双模拟，证 R 是 F 的后不动点即可。不展开过程代数细节
- 知止衔接（一段）：可及元概念。x 可及当且仅当不存在自 x 出发的无限严格 f 降链。可及元集是 lfp 的子集，单调算子下可及元集恰为 lfp 的可判定侧。本条只登记关系不展开，工程侧见工程注意事项

数学核心：
- 设定：语言 L 为非逻辑符号集加其公式集。新符号 s 为函子或关系或常元。s 在 L 中可定义当且仅当存在 L 公式 φ 显式给出 s 的定义
- 定义扩张 L[s]：L 加符号 s 加定义公理
- 保守性定理（定理一）：设 s 由 L 公式 φ 定义，A 为 L[s] 句子，A_φ 为 A 中 s 的所有出现代以 φ 所得 L 句子。则 L[s] 可证 A 当且仅当 L 可证 A_φ。证明方向一：推导逐项代入。方向二：定义公理在 L 的每个模型上把 s 唯一钉为 φ 所指称的集合，L[s] 模型与 L 模型一一对应，语义保真
- 跳跃即不可定义（命题二）：s 在 L 中不可定义蕴含 L[s] 增加真实表达力，一般不再保守。反例段：L 为无新符号的一阶纯逻辑语言，s 为一元谓词，取 φ 不存在，L[s] 可断 s 非空而 L 不可断任何具体集合非空，非保守。反例写具体
- 可归约性对可推性（定义段，EPI-14 命名区分的数学化）：可推性即固定语言内的句法后承，p 可从 Γ 推出；可归约性即语言层面归约，新元素 p 可归约到基语言 L 当且仅当 p 在 L 中可定义。EPI-14 每步可归约回前步而无外部跳跃即：步 i 新增符号集在步 i 之前语言加锚集内可定义，跳跃即出现不可定义符号
- 锚集（定义段）：预设锚集 A 为命名传统选择固定的外部符号集，扩张以 L 加 A 为基。锚符号声明为外源，使用不构成跳跃。原文「Daoist 范畴作为外部锚定统一在命名传统选择中」即 A 在链首固定，后续步只用 A 与既有语言的可定义元
- 可判定性边界（命题三，如实标注）：给定基语言与候选定义 φ，判定 φ 是否定义 s：在给定有限模型类上可判，枚举模型比对指称；全语义意义上等价性判定一般不可判，须降级为判定标记，可定义，候选可定义，疑似不可定义三态
