## 三、发现与判读

1. p-06 模态翻转嫌疑为本跑最大发现。提示词与口径已逐字节排除即 topic 除 gid 与 scheme 除题名外同字节、同为 MINIMAX 官方端 MiniMax-M3 思考关温度零；厂跑在 08-26 坐席跑在 08-28，同名模型端点侧版本不可见即自报 version unlisted，漂移嫌疑成立而漂移定责归复测与端点核对不在本批。此现象与代际注记机制同源即同名模型跨日可变，单席位材料判读须带当日性。
2. c2-02 七发 no_answer 逐发核验全是模型答了违例但 JSON 串坏即理由值含未转义引号，按口径如实计 no_answer 不改判，测量集中度被口径拉低已如实呈现。
3. strict 单席位升格零命中即七题熵全超 0.05 bits 阈（无答与二项分布所致），p-12 双口径一致 stable_clear 而熵 0.122 不过严格腿，如实。
4. boundary 旗 74 发中含无答行的边界标记，与八厂口径同构。
