# DES-015 MCP HTTP 面多项目识别与分项目写授权安全模型

## 概览 {#overview}

- 本设计承 mcpline 线 HTTP 写面设计批定位，令源用户 2026-09-09 令「http要分项目的如何做，也要做写入权限」加同日基底改令「每项目一域，工具中央账本随项目」，是 mcpweb HTTP 只读面在役与 DES-014 stdio 安全模型在档之后的多域扩展设计，为 HTTP 写面实装批的硬前置，未过本设计不一裁实装批不开工::[边界申明](#boundary)
- 项目识别判词取一项目一治理域形：链与锁册与台账与泊界全住各项目自己的 sih 目录，目录布局规约本设计定稿，司衡仓即第一域历史布局登记映射不迁移::[项目域识别形](#domain-identity)
- 令牌首要职责判词取域绑定形：token 映射 SIH_ROOT，写只落所绑域，跨项目越权因域隔离结构性消失；签发通道归主窗签发位承人节点令源，台账形即域内令牌册哈希落册明文一次性，传输形三形取舍判词取 Authorization Bearer 头形::[项目域识别形](#domain-identity)
- 识别与会话映射判词取令牌会话一对一形：一令牌同时刻至多一个活跃 lease 会话且会话住所绑域，身份锚从进程正身形变体为 server 进程正身件加令牌哈希注入复合形，五验逐项在 HTTP 下各验什么逐条载::[令牌与会话映射](#token-session-mapping)
- 授权判词取域隔离为主加域内薄层形：scope 三档即 readonly 与域写档与 custom，域绑定承载分项目写授权主防线，域内细粒度裁剪退为薄层，与既有 scope_violation 与 locked_elsewhere 与 wait_turn 理由码原位衔接零新执法位零 LLM 裁决位::[授权矩阵](#authorization)
- 中央工具判词取本体一份全域共用形：scribe 与 lease 与 critsweep 与 gauge 与 mcpline 中央一份全机共用如 git 一装仓库遍地，执法语义全域同源，版本兼容约束与升级程序与域内零工具副本与中央单点可用性边界逐条载::[中央工具版本对全域的约束](#central-tools)
- 写面判词取零新增执法形：令牌只裁剪透传，scribe 三闸与租约五验与 closeguard 与 git hooks 原位生效，record append 无幂等闸的 HTTP 重试风险如实申报缓解两件::[写路径复用](#enforcement-reuse)
- 审计判词承既有哈希链加域内自足形：信封既有位生效令牌身份经正身注入直接归因，撤销与轮换落所绑域台账，链验与判据扫与秤星在每域内自足闭合域间零依赖::[审计与撤销](#audit-revocation)
- 威胁模型各向各给缓解或明示不防：令牌泄露域限爆炸半径、跨项目越权结构性消失、重放与枚举与台账膨胀与中央工具本体篡改逐条申报，缺省绑定 127.0.0.1，远程与 HTTPS 暴露明示不防入边界::[威胁模型](#threat-model)
- 失败语义判词取双层映射形：传输层状态码与 MCP 载荷层教学四字段分离，未认证统一 401 零区分不泄露跨域存在性，执法理由码走载荷层原样透出不吞不译::[失败语义](#failure-semantics)
- 边界申明：司衡仓即第一域历史布局不迁移，SiInfer 彩排即首个新城的第一实例但不预占，自有运行时归 pk-079 与 GOV-002 v3 换版不触碰，DES-014 stdio 面安全模型不废两面对表同一执法层::[边界申明](#boundary)

## 项目域识别形 {#domain-identity}

判词：一项目一治理域形。项目的治理身份承载是该域自己的 sih 目录树，链与台账与泊界全住域内；令牌的首要职责是绑定项目域，HTTP 面多项目识别问题在域隔离下消解为令牌与域的一对一映射问题。

域目录布局规约定稿：新域自举按正典布局落地，即域根下 sih 目录树承载全部治理状态：sih/event/trail/ 住逐日哈希链、sih/ledger/ 住台账册族即 sessions.ndjson 会话册与 locks.ndjson 锁册与 tokens.ndjson 令牌册与 bypass 与 bills 等既有账册同规约、sih/state/ 住治理状态即 plan 任务包区与 parking 泊界与 skills 与校准面、泊界材料住 sih/state/parking/materials/。域内数据一律 ndjson append-only 形，写点纪律承 pk057fix 批台账写点纪律即 flock 串行加 O_APPEND 原子整行禁整文件重写，全域适用。

第一域历史布局映射：司衡工作区本身即第一域，现存引擎仓加工具仓两处历史布局登记映射不迁移，即链与治理状态住引擎仓 sih-engine/sih/ 下、租约台账住工具仓 sih-tools/lease/ledger/ 下、调用留痕住 sih-tools/calllog/ 下、令牌册住 sih-tools/mcpline/ledger/tokens.ndjson 与工具仓工具面自治位规约同形；第一域布局是映射表数据不是代码，中央工具按映射表寻径，后继新城一律正典单根布局，两形并存以登记面为准。

令牌签发通道判词：主窗签发位承人节点令源。签发动作不在 MCP 工具面对任何 HTTP 客户端开放，参照 DES-014 takeover 与 bypass 拒透传先例，server 对签发类调用一律拒透传；签发机械执行归主窗代理，令源归人节点，即人节点裁决面收缩到令源与机械执行归代理，承工程基线五治理延伸是减少人参与。签发程序五步固定：其一高熵随机源出令牌明文，其二算 sha256 得令牌哈希与 token_id 即哈希前十六位，其三确定所绑域即 SIH_ROOT，其四向所绑域令牌册追加台账行，其五明文经签发会话回执一次性交付认领项目，明文不落台账不落链不落任何仓内文件。

令牌台账形判词：域内令牌册哈希落册，台账行字段固定即 token_id 与 token_hash 与 domain_root 即所绑域根与 scope 即三档之一与 status 即 active 或 revoked 与 issued_at 与 issued_by 即令源指针；明文一次性交付不经台账不经链。撤销即追加新行同 token_id 载 status revoked，读数取每 token_id 末行，append-only 精神与链同构；台账膨胀明示不防，清理归人节点后裁。

传输形三形取舍判词：取 Authorization Bearer 头形。其一Bearer 头不进 URL 不落标准访问日志与代理日志与 Referer，泄露面最小；其二与 mcpweb 已立单端口统一形态相容，streamable HTTP 客户端原生支持头注入。路径段形拒：令牌进 URL 即落日志与代理与 Referer 三泄露面，且 MCP streamable 端点路径固定不宜携带凭据段。每项目端口形拒：端口管理随项目数线性膨胀、防火墙面扩大、端口号本身成侦察面、破单端口统一形态。三形取舍是传输层裁剪非执法，令牌校验程序与传输形正交。

域自举程序形：新城立域四步，即按正典布局落地 sih 目录树、经中央 scribe 落首笔域登记链事件、人节点令源签发首令牌入域册、域映射登记入中央工具寻径面；自举的实装细节归实装批，本设计只定形零预写。

## 令牌与会话映射 {#token-session-mapping}

判词：令牌会话一对一形。一条经认证的 HTTP 连接绑定恰好一个 lease 会话，同时刻一令牌至多一个活跃 lease 会话，重复 open 即同包活跃闸既有拒定，禁一令牌多会话并行禁会话池；会话住所绑域，即 lease open 以所绑域为 --root 立会话，会话行落所绑域会话册，零跨域会话。

绑定形：MCP streamable HTTP 连接经 Bearer 头认证后，server 查令牌哈希得所绑域，以本进程正身件加令牌派生值对该域调用 lease open 立会话，会话号经工具结果透出给客户端记录；此后该连接上一切写操作携带该会话号，server 对一切写调用的 root 与 trail 与台账参数一律锚定所绑域，调用方参数中的域指向面不透传即结构上不存在写落他域的通路。断开收约形承 DES-014：零写连接轻收约，有在途写走完整 close 链闸与 closeguard 三检照走，收约失败转挂起候人节点 takeover。孤儿会话处置承既有 PID 探针三态与心跳停滞判据与 takeover 通道，零新增清理机制，全部在所绑域台账与锁册内闭合。

身份锚变体判词：从进程正身形变体为 server 进程正身件加令牌哈希注入复合形。DES-014 stdio 形下每连接一子进程身份天然可分，HTTP 形下 server 是常驻进程，客户端无独立进程身份可采，鉴此身份可分性迁移到令牌粒度：lease open 时 server 以令牌哈希为连接派生值注入正身可选件即 session_id 位，使不同令牌立出的会话在正身串与信封 identity_hash 直接可区分，责任归因粒度从连接细化到域与项目；域绑定本身不经身份件承载而经台账行承载，即正身件答谁在写、令牌册答写到哪域。

五验在 HTTP 下各验什么逐条：在册验即令牌在所绑域令牌册 status 末行 active 且会话在所绑域会话册活跃；会话择定验即操作须落本连接自立的会话；范围验即 scope 薄层裁剪面覆盖检查；身份验即 server 进程侧 hostname 与 user 与 boottime 漂移照验加令牌哈希与所绑域册对表；绑定验即请求携带凭据派生哈希与会话在册令牌哈希逐笔对表加操作目标路径前缀属于所绑域根。

边界如实申明：HTTP 形下令牌即身份，令牌泄露即所绑域内的身份冒用，爆炸半径以域为界，此为令牌信任模型既有边界，与 DES-014 正身防偶发撞名不防产权级仿冒同界不扩不缩；server 进程自身正身件照签发照核，进程侧五验不因令牌形松懈。

## 授权矩阵 {#authorization}

判词：域隔离为主加域内薄层形。分项目写授权的主防线是域绑定即结构性隔离，一令牌只写所绑域，他域对其结构性不可寻址；scope 三档退为域内细粒度薄层，只裁剪所绑域内的工具与路径面。矩阵与裁剪俱是静态映射表随批评审，零 LLM 裁决位。

scope 三档语义逐条：readonly 档即只读五工具可调与写工具一律拒透传，承 mcpweb 只读面结构性缺席语义的令牌化推广，缺席从实例级细化到令牌级；域写档即所绑域内全部写工具可调，分项目授权已由域绑定承载，域内不再设第二层项目面裁剪；custom 档即域内细粒度白名单，逐工具逐旗标显式登记于台账行，可含域内路径前缀收紧，登记面即授权面，零缺省放行。域写档是缺省授出形，custom 是收紧形，readonly 是只读形，三档皆以所绑域为边界前提。

跨项目越权分量申明：旧基底设想的命名空间前缀裁剪防线被域隔离取代，即令牌册行的 domain_root 就是唯一授权边界，越权不再靠逐调用裁剪拦截而靠写通路结构性不存在；域内薄层只服务单域多承包位的细粒度场景，非跨域防线。

与既有理由码原位衔接逐条：scope_violation 即域内薄层出界或会话登记面出界的既有执法拒，原样透出；locked_elsewhere 即所绑域锁冲突既有拒，原样透出不吞不译；wait_turn 即排队受理既有返位次形，经独立工具透出，零 LLM 轮询零 token 消耗语义承 DES-014 不变。零新理由码零新执法位。

## 中央工具版本对全域的约束 {#central-tools}

判词：本体一份全域共用形。工具本体即 scribe 与 lease 与 critsweep 与 gauge 与 mcpline 与核阅与检词与正身与计数的中央安装一份全机共用，如同 git 一份安装仓库遍地，域只住状态与数据不住工具代码。

域内零工具副本判词：每域 sih 目录树只承载链与台账与状态，零工具代码零二进制副本；若工具随域复制，执法语义即随副本分叉，同一操作在不同域得出不同判定的风险结构性出现，故域内工具副本禁入是执法语义全域同源的构造性保障，非部署优化。

中央工具清单与现位登记：引擎件即 sih-engine/target/debug 下的 scribe 与 attractor 与 scrutinator，工具面即 sih-tools 下 lease 与 critsweep 与 gauge 与 mcpline 与 identity 与 meter 与 nomenclator 与 formatter；中央位登记随第一域历史布局映射面承载，新城不另设工具位。

版本兼容约束逐条：其一读兼容硬约束，即工具新版本必须可读全部既有域的链与台账与泊界材料，ndjson append-only 格式加版本字段是读兼容的载体，读兼容破坏的版本不得发布；其二升级程序唯一，即工具版本变更走各工具既立换版程序与引擎重编程序，全域同批切换，禁按域分批升级形成版本混跑窗；其三链格式演进走版本字段加既立程序，旧域链在新版本工具下 verify 语义不变；其四台账写点纪律跨域同形，即 flock 加 O_APPEND 原子整行全域适用不因域而异。

中央单点可用性边界如实申报：中央二进制不可用即全域写面不可用，这是本体一份形的代价；域内数据是朴素 ndjson 文件，中央不可用期各域仍可读可审计可对表，写面恢复随中央恢复，本设计不为可用性引入域级工具副本，那会买回执法分叉风险；此边界承工程基线治理延伸是减少人参与与执法单一来源的权衡，申报归档不隐藏。

## 写路径复用 {#enforcement-reuse}

判词：零新增执法。HTTP 写面是既有 CLI 的薄投影加令牌域锚定层，参数透传、结果透传、退出码透传，全部既有执法原位生效，令牌只裁剪透传与锚定域根不做第二套判定。

执法复用逐件：scribe 三护栏即工地链副本禁追加与闸二重意图拒与闸三会话在册验对 HTTP 写面逐笔生效，链路径按所绑域解析后护栏照验，server 禁以任何方式代填或绕过；lease open 六位闸序与 lock 悲观五验与 unlock 加持锁验与 closeguard 收约三检与 close 链闸与 claims 领取账本俱在所绑域台账与锁册内原位；git hooks 直提守卫在每域各仓 commit 位照拦，HTTP 发起的 commit 须经 lease commit 正典通道，无登记 plain commit 即拒的语义与发起方传输形无关；域级泊界与判据扫与秤星承接 CLI 照旧以域根为参，零新增承接面。

record append 无幂等闸的 HTTP 风险如实申报：stdio 形下调用方是进程内 agent 无传输层重试，HTTP 形下客户端超时重试即同 report 重复认证笔，闸二只拒 intent 重放不拒 append 重放，风险敞口为传输重试新造。缓解两件：其一锁纪律强制形即写面调用必须携带在册会话且所绑域链路径锁面持有约束承既有锁面语义，跨客户端重试撞锁即 locked_elsewhere 拒；其二重放明示不防即同会话窗口内的重试重放不新增自动拒重，重复笔由事件信封审计与 meter 交叉核对检出，处置归人节点，承 DES-014 append 无幂等闸如实申报边界不扩不缩；客户端重试纪律入工具描述教学面。

禁令三条承 DES-014 照录并扩域维：server 禁内嵌任何 allow 或 deny 判定逻辑替代执法，禁缓存执法结果跨调用复用，禁绕过 CLI 直写任何域的台账链文件或 git 对象。

## 审计与撤销 {#audit-revocation}

判词：承既有链加令牌归因加域内自足。每笔写已上链是既有事实，本设计零新审计面，只定令牌身份归因与撤销与轮换形与域内治理自足性。

信封主体加令牌身份形：链事件信封既有位生效即每笔链事件载 session_id 与 identity_hash；令牌哈希经 lease open 注入正身可选件后，同 server 不同令牌的信封 identity_hash 直接可分，令牌归因零回查即闭合；信封 identity_hash 与所绑域令牌册 token_hash 的对应表载签发留痕，链面审计按信封回查域册行即可归项目。

撤销形：撤销即向所绑域令牌册追加新行同 token_id 载 status revoked，末行为准；撤销动作走治理通道落所绑域链留痕，不在 MCP 工具面对客户端开放。在飞会话拒绝判词：撤销拒定位在路由层，server 每笔写透传前查所绑域令牌册末行 status，非 active 即拒透传不发起调用，与 takeover 与 bypass 拒透传同形，零新理由码零新执法位；已立会话不被 server 强拆，客户端换新令牌重连重立会话，旧会话由既有孤儿清理通道兜底。

令牌轮换形：轮换即新令牌签发行与旧令牌撤销行同批落所绑域链，操作紧邻收窄窗口；轮换窗口双活如实申报明示不防，即签发与撤销两笔之间旧令牌仍有效，窗口期滥用事后可审计；轮换不迁移在飞会话，旧令牌会话照撤销形处置。

域内治理自足性判词：每域链 verify 全文验独立可跑可判 valid、critsweep 以域根为参回算域内五判据与泊界与在飞、gauge 域内读数、租约 status 与 reconcile 域内对表，四件俱在域内自足闭合，域间零依赖；一域治理健康度的审计不要求读他域任何数据，这是域形对审计面的构造性收益，即审计爆炸半径与写爆炸半径同域限。

## 威胁模型 {#threat-model}

判词：各向各给缓解或明示不防，防域与不防域逐条申报不含糊；缺省绑定 127.0.0.1，远程与 HTTPS 暴露明示不防入边界。

令牌泄露：缓解三件，即域册哈希落册明文一次性使台账失窃不等于凭据失窃、撤销通道使泄露令牌可即时作废、缺省绑定 127.0.0.1 使网络暴露面收窄到本机回环；爆炸半径以域为界即一令牌一域；明示不防即本机明文截获后的窗口期滥用，事后凭信封令牌归因可审计。

跨项目越权：结构性消失即主防线申报，令牌绑域写通路只锚定所绑域，他域对令牌结构性不可寻址不靠逐调用拦截；残余面如实申报两条，其一 server 进程被劫持可寻址全域即承 DES-014 进程劫持同界在多域形下影响面放大，不防实时阻止只保事后可审计，其二域内横移即所绑域内越权归域内既有锁面与会话执法承载与本设计无关。

重放：缓解一件即链铸时戳 flock 临界区单调自铸使乱序重放不可插入承既有；明示不防两件，即 record append 同会话窗口重试重放与 Bearer 头本机截获重用，前者审计检出处置归人节点，后者在 127.0.0.1 防域内不构成远程威胁。

枚举：缓解两件，即令牌高熵随机使枚举不可行、未认证响应统一 401 同载荷使无效与撤销与缺头与跨域令牌零区分不泄露域册行存在性；跨域存在性即某域是否在册是否立域是否持有令牌俱不经任何错误载荷泄露，域隔离在侦察面同样闭合。

台账膨胀：明示不防，append-only 即容量换审计，域册与域链同界且膨胀域限于所绑域，清理归人节点后裁零自动清理。

中央工具本体篡改：明示不防实时阻止，中央一份形使工具本体被篡改即全域执法面被篡改，影响面较 DES-014 单进程界放大，此为中央形代价如实申报；缓解在事后可审计三件，即工具源码 git 版控使二进制可重建可对表、域链哈希链独立于工具本体可验即被篡改工具落笔的伪链过不了域链 verify 全文验、critsweep 与 watchcheck 域内异常扫俱可检出。

边界申明：缺省绑定 127.0.0.1 是本设计防域的前提而非可选优化；远程暴露与 HTTPS 终端部署明示不防入边界，本设计防域是本机多域多 agent 面不是网络传输安全，远程部署须前置 TLS 终端但那超出本设计防域且本设计不预设不预占。

## 失败语义 {#failure-semantics}

判词：双层映射形。传输层与 MCP 载荷层错误面分离，传输层只管认证与路由拒，执法与参数错误全走载荷层原样透出，HTTP 层不翻译不吞。

传输层映射逐条：401 未认证即无头或头形错或令牌不在所绑域册或已撤销或所绑域册不可读五因统一 401 同载荷零区分，载荷不泄露区分信息，域册不可读走 401 是 fail-closed 申报；403 越权即认证过但薄层拒透传，readonly 调写工具或 custom 白名单外，载荷告拒透传事实与 scope 现值；405 与 400 即传输形错，照 HTTP 标准语义零教学负载；429 限流即映射语义在档而限流器不在本设计，承写频不限流明示不防，若将来人节点立限流位则 429 载荷照教学四字段形，本设计零实装零预设。

载荷层映射：MCP streamable POST 常态 200 包 JSON-RPC error 或 isError 载荷；执法理由码即 scope_violation 与 locked_elsewhere 与 SessionNotActive 与 IntentRecordUsedRejected 与 PackageAlreadyClaimed 原样透出不吞不译；教学四字段承 SPEC 023 号契约件即 error 与 what_this_tool_does 与 valid_params 与 canonical_pointers，写工具载荷加 retry_discipline 一字段载重试纪律即撞锁改 wait-turn 与重试前查会话在册。

报错即教学边界承 DES-014 分级裁剪形并扩域维：教参数名与退出码三值与闸位名称与理由码与修复动作；不泄露绝对路径面即错误转述一律域根相对形、他会话身份、他会话存在性、他域存在性即跨域令牌与未知域与未立域在载荷层零区分零提及。张力如实申报：401 零区分降低合法客户端撤销后排障能力即教学面收窄，权衡依据是基线五不生成不等于不引导与基线二人类注意力只投异常信号，与 DES-014 裁剪张力同构；裁剪映射表随批评审可调，调整走修订不改判定语义。零动态拼接不可信数据进错误文本。

## 边界申明 {#boundary}

注入面通用化与自有对话循环归 pk-079 分相承载，本设计只涉 MCP server 进程边界内的传输认证与域锚定与路由裁剪层，不涉客户端运行时与注入面通用机制。GOV-002 与 v3 换版不触碰：写面投影以现行各工具版本为界即 lease 1.39.0 与 scribe 引擎件现行与 identity 0.5.0 与 meter 0.2.0，版本升级走既立程序与中央工具版本约束节，本设计不预设不预占。判定语义正典留确定性程序：本设计零 LLM 裁决位，scope 三档矩阵与域锚定映射与错误裁剪映射俱是静态数据，任何判定语义变更走既立程序即得一裁加执契终签。

司衡仓即第一域：现存引擎仓加工具仓历史布局登记映射不迁移不重写，第一域的链与台账照旧现位运转，本设计域布局规约只约束新城自举。SiInfer 彩排写授权即首个新城的第一实例但不预占：第一实例只是首个新城适用场景登记，实装批的域自举与签发台账初册归实装批按本设计落，本批零预写零预占。alpha 相读数面归 SPEC 023 号契约件已立契约，本设计不重复不修改不冲突。DES-014 stdio 面安全模型不废：stdio 形下单机单工作区无传输凭据位，本设计令牌层与域锚定层对 stdio 形不适用；HTTP 形下两设计对表同一执法层，DES-014 管连接与会话与身份与执法复用的本形，本设计管多域识别与凭据与传输形，重叠面以先立DES-014 为准从其判词。本设计属 des-001 域，产出经化格核阅检词认证序。
