## 消解处置

叩问处置[号源唯一]：登记处置——检词 register 登记入 core 包工地副本，zh=号源唯一，定义即单一名册续号不重号规约的机械面即 entry_id 一经使用不得复用，本批实装第三道门号源唯一拒。先例 parkreplay-solo 声称登记实未入主树（其提交未含 terms.json 改动），本批如实补登。

叩问处置[重放面]：登记处置——检词 register 登记入 core 包工地副本，zh=重放面，定义即配对门判定所依据的既有事件集合边界，书简泊配对门的重放面为链目录全量。先例 parkreplay-solo 声称登记实未入主树，本批如实补登。

叩问处置[链目录全量]：登记处置——检词 register 登记入 core 包工地副本，zh=链目录全量，定义即 --trail 同目录全部 ndjson 链文件按名序的并集即跨日全史重放材料面。先例 parkreplay-solo 声称登记实未入主树，本批如实补登。

叩问处置[跨天出泊]：登记处置——检词 register 登记入 core 包工地副本，zh=跨天出泊，定义即泊入事件在先日链、出泊事件落记录当日链的停泊出泊形态即全史出泊的普遍形态。先例 parkreplay-solo 声称登记实未入主树，本批如实补登。

叩问处置[已出泊号复用]：登记处置——检词 register 登记入 core 包工地副本，zh=已出泊号复用，定义即 entry_id 已出泊后再次用于 enter 请求的复用形态，本批号源唯一拒即拦此形态。

叩问处置[跨天已用号]：登记处置——检词 register 登记入 core 包工地副本，zh=跨天已用号，定义即 entry_id 在先日链已出现 parking_entered、当日链再次 enter 的跨天复用形态，本批号源唯一拒即拦此形态。
