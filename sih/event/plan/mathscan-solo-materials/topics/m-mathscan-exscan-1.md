# 待裁命题

数学仓全盘扫描的例行化挂点提案以机械三态分流呈报：确定性扫描器（rev3 同参双跑逐字节一致为绿判据，四表一致性核对器零红为配套判据）挂接两案候选位——A 案挂 gauge 例行读数旁（每日三维快照落链后同跑）、B 案挂批尾（每批 close 前跑，红则拦收口并出漂移清单）——机械程序只承载跑批与三态分流与泊界呈报，两案择位与例扫执行节奏归人类裁决，代理不自动择案执行；stable_clear 亦呈泊界不执行，扫描红在 A 案位不拦日常读数、在 B 案位拦收口并出清单。该命题符合确定性程序是治理操作唯一执行者：分流与判据全由扫描器与核对器机械承载；符合人类注意力只投向异常信号：漂移清单即异常信号视图，节奏裁量退人是人类介入点收敛到确定性程序无法自动处理的异常范围；符合治理延伸是减少 LLM 参与：全程零新增 LLM 判定位。
