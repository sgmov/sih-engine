## 哲学桥接 {#philosophy-bridge}

- 借鉴源:圆盘积分是微积分基本定理在三维几何中的直接应用。博纳文图拉·卡瓦列里在 1635 年提出卡瓦列里原理,认为两个立体如果等高处截面积相等则体积相等,这是圆盘积分的思想先驱。17 世纪牛顿与莱布尼茨的微积分把体积计算从几何论证变为代数运算,圆盘法 V = π ∫_a^b [f(x)]^2 dx 与壳法 INT-022 成为旋转体体积计算的两种标准方法。20 世纪后,圆盘积分成为机械设计、容器工程、几何建模的基础工具,把三维体积问题分解为二维截面积的累加,把体积问题转化为积分问题。
- 哲学命题:PRO-05 道四规约与实现必有间隙,锚句「道四:规约与实现必有间隙。」圆盘积分把三维旋转体「规约」为「二维母线围成面积」,这是双重有损链的具体形态。规约侧是三维立体的体积 V,实现侧是 ∫ π f(x)^2 dx 的代数表达。两次有损编码累加出规约与实现之间的间隙:第一次编码从三维降到二维(立体 → 母线围成面积),第二次编码从连续面积降到离散求和(∫ 替换为 Σ)。任何有限步长 dx 都留下规约与实现之间的余项,O(dx) 量级。道四命题断言「间隙不可消除」,圆盘积分以最简洁的方式展示了这一约束:即使函数 f 完美光滑、积分上下限都有限,dx → 0 的极限过程仍需无限步累加,有限步永远有 V - V_n 的余项。间隙的工程化处理是「用足够小的 dx 让余项落入可接受阈值」,这是道四的「治理」:不能消除间隙,只能识别、记录、缩窄。
- 哲学命题:PRO-08 应,锚句「司衡之应:应而不藏,应辨当下,应几未来。」圆盘积分的执行是「应」的典型场景。给定函数 f 与积分区间 [a, b] 立即算出 V = π ∫ [f(x)]^2 dx 是应辨当下,已抵达的、可机械执行的当下程序。继续预测 dx 减半后 V 的变化趋势,或估计 ∑ V_n 序列的收敛速度,是应几未来。司衡之应在圆盘积分中具象为:应而不藏对应公示中每个因子 π、[f(x)]^2、dx 都显式呈现,不藏「为什么是 π 与 [f(x)]^2 的乘积」的几何依据;应辨当下对应已知 f 时的立即可计算性;应几未来对应 O(dx) 收敛阶的预判,dx 减半误差减半,这是规约与实现之间间隙缩窄速度的几何级数形态。

### 形式化 {#formalization}

设 y = f(x) ≥ 0 在 [a, b] 上连续,绕 x 轴旋转,圆盘法求体积 V = π ∫_a^b [f(x)]^2 dx。

- 间隙作为余项:PRO-05 L15「道四:规约与实现必有间隙。」在本条目具象为：把 ∫ 替换为 Σ 后,V_n = π ∑_{i=1}^n [f(x_i)]^2 Δx 是规约侧的离散和,V 是实现侧的连续积分。二者之差 V - V_n 是间隙,O(Δx) 量级。函数 f 在 [a, b] 上若满足 Lipschitz 条件,|V - V_n| ≤ (b-a) sup|f'|·Δx / 2。这是道四间隙的可计算形态:不是「间隙存在」的纯哲学断言,而是 O 量级可被定量表述的工程事实。间隙不消除,只通过减小 Δx 让余项落入阈值。判断「间隙可被忽略」的工程判据是 |V - V_n| / |V| < ε,这是治理在精度阈值下对间隙的记录与判定。卡瓦列里原理是间隙的另一种工程化:两个立体截面积相等则体积相等,这是「通过截面规约体积」的间接策略,绕过了直接计算 f(x) 的负担。
- 应辨当下与应几未来:PRO-08 L108「司衡之应:应而不藏,应辨当下,应几未来。」在本条目具象为：应辨当下指已知 f 与区间时立即套用 V = π ∫ [f(x)]^2 dx 的动作,这是机械的、无歧义的、有限步可完成的「当下」。应几未来指预判 Δx 减半时 V_n 的行为,需要 O(Δx) 收敛阶的渐近分析。dx → 0 时 V_n → V 的极限由 LIM-001 极限承载,但工程上不会等极限完成,只在 Δx 足够小时停止。O 阶语言(大 O 记法 LIM-006)是应几的工具:「dx 减半误差减半」是「几」的典型表达,即还未达到极限但已预告收敛速度。司衡之应在此具体化为:应而不藏在公示中显式呈现 π、[f(x)]^2、dx 三因子的几何依据;应辨当下在 f 已知时立即可算;应几未来在 O(Δx) 阶语言对更大 n 行为的预判。
- 卡瓦列里原理作为间接规约:卡瓦列里原理「等高截面相等则体积相等」是规约策略的另一个选择,不直接计算 f(x) 而是比较截面积 A(x) = π [f(x)]^2。这是道四间隙的「绕路」策略:规约侧从「求原函数」替换为「比较截面积」,实现侧从「直接计算」替换为「间接比较」。绕路策略让某些原本难以计算的体积(如球缺、椭球)通过与已知立体的截面对比得到。绕路不消除间隙,只是让间隙出现在新的位置:从「∫ 与 Σ 的差距」变为「比较对象的代数等价是否成立」。这是道四「间隙不可消除,只能识别」的微缩。
- 圆盘法与垫圈法的对称:垫圈法 V = π ∫ ([R(x)]^2 - [r(x)]^2) dx 处理有空腔的旋转区域,这是圆盘法的内嵌版本。两种方法在「规约」层面相同(垂直于旋转轴切片),在「实现」层面不同(单层 vs 双层)。对称是规约与实现之间可塑性的具体表现:同一规约下的不同实现给出不同结果,实现的选择影响最终数值,但不改变规约的几何结构。
- 与其他概念的关系:上游 INT-001 反导数与 INT-007 微积分基本定理：本条目依赖积分运算与基本定理的连接。下游 INT-022 柱壳积分与 MUL-003 加百列号角：壳法是另一种切片方向,加百列号角是圆盘积分的极端情形(有限体积与无限表面积)。同层 INT-021 旋转体：本条目是 INT-021 圆盘法在 MUL 上下文的具体化,垫圈法是带空腔的扩展。APP-003 二体问题：天体力学中引力势能的球壳积分在概念上与圆盘积分同构,都是把三维问题分解为同构的一维累加。
- 边界:圆盘法只适用于旋转对称体,非旋转体的体积需要三重积分或更一般的多维积分。垫圈法处理有空腔的旋转区域,空腔必须与旋转轴同轴,偏心空腔需要其他方法。圆盘法假设被积函数非负,负值需要分段处理或取绝对值,但 π [f(x)]^2 平方后永远非负,几何对应关系变化需要单独处理。
