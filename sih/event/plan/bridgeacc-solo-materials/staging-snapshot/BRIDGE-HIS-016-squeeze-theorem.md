## 哲学桥接 {#philosophy-bridge}

- 借鉴源：夹逼法，squeeze theorem，是柯西与魏尔斯特拉斯严格化运动中确立的极限判定定理。其思想可追溯到阿基米德穷竭法，即用多边形从内外两侧逼近圆的面积，两侧面积趋于同一值时圆面积被确定。夹逼法的核心是不等式：`f(x) ≤ g(x) ≤ h(x)` 且 `lim f = lim h = L`，则 `lim g = L`。它不依赖被夹逼量 `g` 的显式表达式，只依赖上下边界 `f, h` 的极限行为，因此适用于难以直接求极限的场景。
- 哲学命题：PRO-07 鉴，锚句「映照：只反映事实，不投射判断」夹逼法是「映照」在极限判定中的具体化。它不投射「`g(x)` 应该等于 `L`」的判断，只反映「`f(x) ≤ g(x) ≤ h(x)` 且 `lim f = lim h = L`」的事实。当 `f` 与 `h` 都已通过其他途径被独立映照为 `L` 时，`g` 的极限被自动映照为 `L`，无需对 `g` 自身的形态做任何判断。这正是鉴层「不投射判断」的程序化形态：把 `g` 的极限判定从「分析 `g` 的结构」投射性操作，转为「映照 `f, h` 的已知极限」反射性操作。
- 哲学命题：PRO-05 道四规约与实现必有间隙，锚句「治理不能消除间隙，只能识别、记录、缩小间隙」夹逼法精确演示了「间隙不可消除但可被识别、记录、缩小」的认识论姿态。`g(x)` 与 `L` 之间的「间隙」在多数情况下无法被直接消除：没有显式表达式可代入：但可以通过构造 `f, h` 把间隙夹窄到任意小。`f(x) ≤ g(x) ≤ h(x)` 三个函数之间永远存在「规约与实现的间隙」，但「`lim f = lim h = L`」的判定把这个间隙「识别、记录」下来，再用夹逼定理「缩小」它到 `0`。柯西与魏尔斯特拉斯没有消除间隙：`g` 自身的形态永远有规约未定义的空间：但他们确立了「承认间隙、可记录、可缩小」的程序。

### 形式化 {#formalization}

设函数 `f, g, h: D → ℝ` 在某去心邻域 `U(a) \ {a}` 满足 `f(x) ≤ g(x) ≤ h(x)`，且 `lim(x→a) f(x) = L`，`lim(x→a) h(x) = L`，则 `lim(x→a) g(x) = L`。

- 映照的程序化：PRO-07 L79「映照：只反映事实，不投射判断」在此为：「事实」是 `f(x) ≤ g(x) ≤ h(x)` 的不等式结构与 `lim f = lim h = L` 的极限事实，「判断」是 `lim g = L`。定理本身不投射「`g` 应该等于 `L`」的判断：若没有 `f, h` 的辅助，单看 `g` 本身确实无法判定其极限。映照的操作是：先把 `f, h` 各自独立的极限映照为 `L`，再让 `g` 的极限被这一对映照「反射」出来。鉴层的「不投射」在此即「不绕开 `f, h` 直接给 `g` 的极限下判断」。
- 间隙的不可消除：PRO-05 L101「治理不能消除间隙，只能识别、记录、缩小间隙」在夹逼法中具象为：`g` 与 `L` 之间的「规约与实现间隙」在结构上无法被消除：没有从 `g` 到 `L` 的直接编码通道，没有这个通道时夹逼法才成为必要工具。柯西的程序不是「消除间隙」，是「用 `f, h` 把间隙圈出来」`f ≤ g ≤ h` 圈出 `g` 所在的带状区域，`lim f = lim h = L` 把带状区域压缩到宽度 `0`。间隙始终存在，只是被识别、记录、缩到任意小。
- 上下界作为「双重锚定」：夹逼法要求上下界都已知其极限值，等价于一种「双重锚定」结构：`f` 与 `h` 各自独立锚定到 `L`，`g` 通过不等式被两个锚点夹住。这与哲学原文中「道一锚热力学、道三锚 Shannon、道四锚 Godel」的多重外部锚定同构。`g` 自身不必是收敛的：`g` 的收敛性是 `f, h` 锚定的派生属性。
- 失效的几何条件：夹逼法失效时：`lim f ≠ lim h` 或 `f, h` 中至少一个的极限未知：`g` 的极限不被确定，间隙不被「圈出」。这与 PRO-05 L17「间隙不可消除，只能识别、记录、治理」一致：夹逼法不提供「`g` 的极限存在」的保证，只提供「`g` 的极限在 `lim f` 与 `lim h` 之间」的事实记录。如果 `lim f` 与 `lim h` 没有共同的「事实」，夹逼法就退化为空操作。
- 工程映射：HIS-016 工程映射「facet 审阅质量的夹逼判定」对应 PRO-07 与 PRO-05 的双重闭合：`coverage ≥ x` 是下界，`false_positive ≤ y` 是上界，两个边界各自独立锚定到历史样本统计，审阅质量 `Q` 的判定被夹在中间。审阅质量 `Q` 本身无法被直接度量，但 `Q` 一定满足 `lower ≤ Q ≤ upper`，当 `lower` 与 `upper` 趋于一致时，`Q` 被确定。工程基线第四条「可验证性约束」是夹逼法的工程版本：操作结果的可机械校验不必精确到单一值，只须给出可校验的上下界。
- 可证伪条件：若某夹逼实例中 `f(x) ≤ g(x) ≤ h(x)` 成立且 `lim f = lim h = L`，但 `lim g ≠ L`，则夹逼法被证伪。该证伪条件的哲学根据是 PRO-07 L79「映照只反映事实」不等式结构与极限事实都是可机械校验的「事实」，若事实成立但结论不成立，唯一的可能是「事实未被真实映照」即不等式结构在邻域内有未被记录的违反。可证伪条件不投射「夹逼法一定对」的判断，只要求「事实映照 → 结论映照」的程序可被反向校验。

HIS-016 的工程映射「审阅质量的夹逼判定 / 上下界的双重锚定 / 间隙的识别与缩小」对应 PRO-07 + PRO-05 的双重闭合：夹逼法是「不投射判断只反映事实」的鉴层程序在极限论中的具体化，又是「承认间隙不可消除但可识别记录缩小」的道四约束在判定工具中的具体化。两命题共同为「不要求精确度量，只要求可校验上下界」的工程方法论提供 19 世纪分析学严格化运动的哲学锚定。
