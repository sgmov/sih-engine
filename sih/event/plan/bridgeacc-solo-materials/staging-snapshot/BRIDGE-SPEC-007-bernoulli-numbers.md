## 哲学桥接 {#philosophy-bridge}

- 借鉴源：伯努利数自 1713 年雅各布·伯努利遗著 Ars Conjectandi 引入，用以表达 1^k + 2^k + ... + n^k 的闭式求和，关孝和独立发现，欧拉推广至级数求和与 zeta 函数在偶数点 ζ(2n) 与 B_{2n} 的解析关系。
- 哲学命题：PRO-05 道四，锚句「道四也是道家"大成若缺"在司衡哲学中的具体化：最完美的系统必然有"缺"，缺不是缺陷，是系统的本质。」；PRO-04 道三，锚句「代码不会自行揭示意图」
- 形式化：伯努利数 B_n 在生成函数 t/(e^t - 1) = Σ B_n t^n/n! 中是连接离散求和与连续展开的系数序列；其存在性证明是「幂和公式的闭式」要求某个特殊有理数序列统一表达任意 k 次幂的和，即幂和公式是「规约层的有形化求和公式」，形式闭合，伯努利数是「实现层的实际系数」，具体数值。两者之间存在 PRO-05 L17 描述的「双重自晦累加即间隙」规约层用生成函数写一次编码，幂和公式再用 B_n 系数做二次编码，两次有形化之间累积自晦，间隙不可消除只能识别记录治理。B_n 的偶数递推，奇数项 B_n = 0 对 n ≥ 3，是道四「间隙结构客观存在」的具体化：不是所有 n 都有非零伯努利数，部分 n 的间隙为 0 是结构性事实，可机械判定即 n mod 2 = 1 且 n ≥ 3 则 B_n = 0，不需要逐点验证，是 PRO-05 L57「间隙是规约与实现之间的客观存在，不是规约不够详细，不是实现不够忠实：是"有形"对"有形"的根本局限」在系数层面的体现。与 zeta 函数的关系 ζ(2n) = (-1)^(n+1) B_{2n} (2π)^{2n} / (2(2n)!) 把离散系数 B_{2n} 与连续分析函数 ζ 在偶数点绑定，是道三 L17「代码不会自行揭示意图」的逆操作：ζ(2n) 的值如 π^2/6 等不能从 ζ 函数定义式直接读出，但通过 B_{2n} 即可恢复「为何 ζ(2n) 等于这个值」的意图，伯努利数是 ζ 函数偶数点「意图必复」的离散表达。司衡治理类比：伯努利数之于幂和公式，正如「核心规约的核心系数」之于「治理系统整体输出」系数是离散的、稀疏的，仅偶数项非零，但承载了整体行为的全部信息；治理系统的核心规约亦不应是「每条规则覆盖每条场景」的稠密铺陈，而应是「最少系数覆盖最大场景」的稀疏结构，B_n 的递推定义是「最小完备集」的样本。
