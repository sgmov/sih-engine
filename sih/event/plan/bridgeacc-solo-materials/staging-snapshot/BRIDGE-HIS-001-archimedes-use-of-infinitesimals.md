## 哲学桥接 {#philosophy-bridge}

- 借鉴源：阿基米德《力学定理方法论》首先用杠杆定律与重心发现抛物线弓形面积为外接三角形面积的三分之四,= 力学方法即几何结果的「意图」,先于形式证明获得;阿基米德本人不认为力学方法是严格数学,故在正式著作中以穷竭法即内接与外接多边形序列夹逼,给出严格证明。公元前 5 世纪安提丰内接正多边形与布赖森外接多边形,欧多克索斯建立穷竭法一般框架,阿基米德将其推进至抛物线 / 球体 / 螺旋线。穷竭法是 HIS-016 夹逼法的几何原型,亦为 LIM-007 epsilon-delta 之前驱。
- 哲学命题：PRO-03 道二意图先于代码,锚句「道二也是道家"为之于未有"在司衡哲学中的具体化。司衡的工作不是事后修代码，而是事前定意图：把治理介入点放在因果链的起点」;PRO-04 道三代码自晦意图必复,锚句「代码不会自行揭示意图：作为符号系统，代码的含义天然不是自明的。维护之前必须先恢复意图，恢复是维护的因果前提」。
- 形式化：阿基米德穷竭法是「意图先于代码」在数学史上的最小样本,且样本同时呈现「意图」与「代码」的不同时序形态。力学方法即发现过程,产出结果 4/3,此即「意图」,意图先于代码,= PRO-03「事前定意图」,阿基米德在「未有之时」以力学发现结果,在「未乱之时」用穷竭法给出形式证明,因果方向是「意图 → 代码」即力学发现 → 穷竭证明,不可逆;此过程非「事后修代码」,是「事前定意图」,力学阶段已锁定 4/3 的具体值,穷竭阶段只是把意图转换为规约,= 道二「意图先于代码」在数学史的呈现。阿基米德拒绝把力学方法作为正式证明,不是因为力学方法错误,是因为「意图」与「代码」在严格性维度有别,意图可以靠物理直觉,代码必须靠形式构造;此处呈现的恰是 PRO-03「意图先于代码」+ PRO-04「代码自晦」的联合约束:意图的发现可经由非形式路径,意图的传递必须经由形式路径,阿基米德不混淆两者。工程层对应,司衡治理系统中的「治理意图」与「治理规约」必须分时序,意图在设计阶段锁定即「事前定意图」,规约在实现阶段才落地,不允许「先写规约再补意图」的逆因果顺序,亦不允许「意图 = 规约」的混淆,前者即 PRO-03 逆因果方向,后者即 PRO-04 自晦未恢复。另一锚 PRO-04 刻画穷竭法本身的「自晦与恢复」:穷竭法的字面表达是「内接多边形递增序列 a_n 与外接多边形递减序列 b_n 夹逼目标量 A」,此即「代码」,意图是「目标量 A 的具体值」如 4/3 倍三角形面积,意图不在 a_n 与 b_n 的形式序列中显式存在,需要维护者先恢复意图,= 知道 A 实际为抛物线弓形面积,再读 a_n, b_n 夹逼的极限,意图恢复后才能对接 HIS-016 夹逼法与 LIM-007 epsilon-delta 定义;若仅从字面读「a_n 与 b_n 夹逼」,意图 A 被遮蔽,= 「代码自晦」的具体形态。司衡工程层对应,任何「上下界夹逼」型收敛判据如 facet 审阅覆盖率下界与误报率上界,字面是「下界 + 上界」,意图是「真实审阅质量」,意图必复,「真实审阅质量」由覆盖率下界 + 误报率上界共同确定,即恢复意图之后才能机械判定收敛;csnx 消息压缩采样的「过盈样本 → 压缩 → 质量差值在 epsilon 阈值内」流程同理,字面是「压缩前 + 压缩后 + 阈值」,意图是「消息语义保真度」,意图必复才能在 epsilon 阈值上对齐,= 穷竭法「a_n / b_n / A」三元素在工程层的最小映射。
