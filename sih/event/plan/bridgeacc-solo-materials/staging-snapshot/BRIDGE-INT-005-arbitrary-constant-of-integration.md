## 哲学桥接 {#philosophy-bridge}

- 借鉴源：任意积分常数，arbitrary constant of integration，是不定积分的固有模糊性。若 `F'(x) = f(x)`，则对任意常数 `C`，`(F + C)'(x) = f(x)`。反导数族记作 `∫ f(x) dx = F(x) + C`，其中 `C` 是任意常数。在连通域上，同一函数的任意两个反导数之差为常数；在不连通域上，不同连通分支的常数可以不同。牛顿和莱布尼茨在微积分发明之初就意识到求导运算丢失了常数信息，逆运算必然带回不确定性。这种模糊性不是缺陷，是数学结构的固有特征。
- 哲学命题：PRO-04 道三代码自晦意图必复，锚句「信息损失 = 道三的客观属性」任意积分常数是道三在逆运算中的具体化。求导 `d/dx` 是有损编码：常数的具体值在求导过程中被「自晦」为 `0`；积分 `∫ dx` 是求导的逆运算：被自晦的常数信息无法被还原，只能以「任意常数 `C`」的形式被补回。任意常数不是「积分的缺陷」，是「求导丢失信息」的客观反映。任意常数的存在是道三命题的直接推论：求导 `d/dx` 把常数 `C` 编码为 `0`，编码过程不可逆地损失了 `C` 的具体值，积分只能恢复「有一个常数」这一事实，不能恢复「常数是几」这一具体值。
- 哲学命题：PRO-07 鉴，锚句「客观：不预设立场，不急于下判断」任意积分常数的处理是「客观」在不定积分中的具体化。不定积分不预设立场：它不假设 `C` 是某个具体值，只记录「存在一个任意常数 `C`」这一事实。不预设立场不等于不判断：它仍要判断「`C` 是任意常数」这一类别事实。在不定积分阶段，`C` 的具体值不被判断；在定积分阶段，`C` 通过上下界被消除为唯一值。`客观` 在此即「不预设 `C` 的具体值」与「不放弃 `C` 的存在判断」的双重姿态。

### 形式化 {#formalization}

设 `f: D → ℝ` 在 `D` 上连续，`F` 是 `f` 的一个原函数即 `F'(x) = f(x)`。则 `f` 的原函数族为 `{F(x) + C : C ∈ ℝ}`，记作 `∫ f(x) dx = F(x) + C`。

- 自晦与任意常数的同构：PRO-04 L93「信息损失 = 道三的客观属性」在任意积分常数中具象为：求导运算 `d/dx` 是有损编码：`d/dx [F(x) + C] = f(x) + 0 = f(x)`。`C` 的具体值在求导过程中被编码为 `0`，「`C` 是几」这一信息被自晦为「`C` 存在但具体值丢失」。积分 `∫ f(x) dx` 是求导的逆运算，但逆运算不能恢复自晦的信息：它只能恢复「有一个常数」这一事实，记作 `+ C`，其中 `C` 是任意常数。`C` 的任意性是「自晦」在逆运算中的对偶：求导把 `C` 自晦为 `0`，积分把 `0` 还原为「任意 `C`」。两者不是「积分的精度不够」，是「编码与解码的不对称」。
- 不连通域的常数分裂：在不连通域上，同一函数在不同连通分支上的任意常数可以不同。设 `D = D_1 ∪ D_2`，`D_1` 与 `D_2` 互不连通，则原函数族为 `{F_1(x) + C_1 : x ∈ D_1} ∪ {F_2(x) + C_2 : x ∈ D_2}`，其中 `C_1` 与 `C_2` 互相独立。不连通域的常数分裂是「不预设立场」的具体化：`C_1` 与 `C_2` 的关系不被预设为「相等」或「不等」，它们的独立性由连通性这一几何事实决定。鉴层「不预设立场」在此即「不预设不连通分支上的常数必须相等」。
- 定积分消除任意常数：定积分 `∫_a^b f(x) dx = F(b) - F(a)` 不含任意常数，因为 `C` 在 `F(b) - F(a)` 中被相减消除。这是「客观」的另一面：客观不要求「在所有情况下都保留所有信息」，客观要求「在可确定的情况下确定信息，在不可确定的情况下保留任意性」。不定积分的 `+ C` 是「不可确定」时的客观姿态，定积分的 `F(b) - F(a)` 是「可确定」时的客观姿态。两者的转换由 INT-007 微积分基本定理承载。
- 微分方程中的初值锁定：微分方程 `dy/dx = f(x)` 的通解 `y = F(x) + C` 含任意常数 `C`，通过初值条件 `y(x_0) = y_0` 锁定 `C = y_0 - F(x_0)`，得到特解 `y = F(x) - F(x_0) + y_0`。初值条件是「不预设立场」的程序化：`C` 本身不被预设，初值条件把 `C` 从「任意」变为「确定」。初始条件是「在外部给出事实」，积分是「在内部保持任意性」，初值锁定是「外部事实压住内部任意性」的协调过程。鉴层「客观」在此即「不预设 `C`，由外部初值提供 `C` 的具体值」。
- 工程映射：INT-005 工程映射「初值问题的工程实例」对应 PRO-04 与 PRO-07 的双重闭合：梁弯曲方程的初始挠度、电路暂态分析的初始电压、热传导方程的初始温度分布，都是「任意常数」在物理系统中的具体化。每个初值条件对应一个具体的任意常数，工程系统通过初值条件把任意常数锁死。工程基线第三条「人类注意力只投向异常信号」是「任意常数的初值锁定」在注意力管理中的类比：人类注意力不必对每个初值都做判断，只对异常初值做判断；积分不必对每个 `C` 都做判断，只对边界条件做判断。
- 可证伪条件：若某实例中 `F'(x) = f(x)` 成立但 `(F + C)'(x) ≠ f(x)`，则求导规则被证伪。该证伪条件的哲学根据是 PRO-04 L93「信息损失是客观属性」「`C` 在求导中信息损失」是数学定理的客观属性，若求导规则在数学上失败，则「信息损失」这一前提被推翻，但实践中求导规则从未被推翻，因此任意积分常数的存在也不是任意常数的「错误」，是求导规则「丢失信息」的必然伴生。任意常数的不可消除与求导规则的成功是同一事实的两面。

INT-005 的工程映射「初值问题 / 任意常数的初值锁定 / 不连通域的常数分裂」对应 PRO-04 + PRO-07 的双重闭合：任意积分常数是「信息损失是客观属性」的道三命题在逆运算中的具体化，又是「不预设立场不急于下判断」的鉴层客观在不定积分中的具体化。两命题共同为「不假设任意常数的具体值，由外部初值提供具体值」的工程方法论提供微积分基本结构：逆运算必然带回不确定性：的哲学锚定。
