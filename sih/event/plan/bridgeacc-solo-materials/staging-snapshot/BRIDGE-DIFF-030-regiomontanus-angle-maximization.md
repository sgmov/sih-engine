## 哲学桥接 {#philosophy-bridge}

- 借鉴源：15 世纪雷格蒙塔努斯在 1471 年信中提出「观察者距墙 x 几何位置可使视角 θ 最大」之问，给出几何近似解；精确解需待 Newton 流数术与 Leibniz 记号约两百年后成熟，导数置零给出 x = √((b-h)(a-h))，θ 的极大值才被解析锁定。问题本身即从「规约」即几何近似,推导「实现」即解析极值,之间的双重有形化样本。
- 哲学命题：PRO-05 道四规约与实现必有间隙,锚句「道四也是道家"大成若缺"在司衡哲学中的具体化：最完美的系统必然有"缺"，缺不是缺陷，是系统的本质」；PRO-04 道三代码自晦意图必复，锚句「代码不会自行揭示意图：作为符号系统，代码的含义天然不是自明的。维护之前必须先恢复意图，恢复是维护的因果前提」。
- 形式化：雷格蒙塔努斯问题在数学史上恰好承担「双重有损链」最小样本的角色。规约层是「观察者站位 x 与视角 θ」的几何关系，tan θ = (b/h - a/h) · x / (1 + x²)，此即意图的第一次有形化，意图是「找到使 θ 最大的 x」，几何表达式已部分承载但未臻完备；实现层是对 θ 关于 x 求导并令导数为零，x = √((b-h)(a-h))，此即规约的第二次有形化，由 DIFF-015 驻点 + DIFF-017 一阶导数判别 + DIFF-016 极值共同承载。两次有形化之间存在「缺」= 几何近似只能给出数值上接近最优 x 的位置，解析导数给出闭式根式表达，= PRO-05 「大成若缺」在数学史上的具象：最完美的规约即几何最优位置表达,在落到几何方法时必然有「缺」，缺不是几何学不完备，是规约不能完全决定实现这一结构性事实本身。工程层对应 facet 异质性审阅的几何位姿选取,facetor 在审查空间中选定某个「距离」与「视角」即规约,聚合裁决即实现,规约与实现之间必有一道「缺」,试图让 facetor 视角选择直接生成最终结论即违反道四,正确做法是承认「缺」,把视角选择当作意图的有形化,把聚合裁决当作规约的有形化,中间留有间隙,经由 DIFF-015 / 016 / 017 链的「驻点+判别+极值」程序填充。另一锚 PRO-04 刻画恢复意图的必要：雷格蒙塔努斯问句的字面表达即「视角最大在何处」,其意图是「视角取极值时的站立位置」,若仅从字面读,读者只能复现近似解,无法知道「几何近似 + 解析精确」之间的选择本身是规约与实现间隙的体现；恢复意图即先承认「意图 = 极值位置」而非「意图 = 几何作图步骤」,此即 PRO-04「维护之前必须先恢复意图」,雷格蒙塔努斯时代无法复是因为缺乏 DIFF-001 导数作为恢复工具,两百年后 Newton 与 Leibniz 提供工具链,意图「极值位置」才被机械可重复地恢复,= 道三「符号系统必有信息损失」在数学史上的样本；司衡工程层对应,任何关于「最优 X」的规约文档若只写「最大化 / 最小化」字面,不附 DIFF-015 / 016 / 017 链作为意图恢复工具,读者只能凭字面印象补,补出的实现与规约必有间隙,与雷格蒙塔努斯几何近似的处境同源。
