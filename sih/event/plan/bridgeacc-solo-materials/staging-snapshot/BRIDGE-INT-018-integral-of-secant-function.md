## 哲学桥接 {#philosophy-bridge}

- 借鉴源：「正割函数积分」是微积分早期一个著名的「需要技巧」的不定积分。结果 `∫ sec(x) dx = ln|sec(x) + tan(x)| + C`。被积函数 `sec(x) = 1/cos(x)` 单看没有任何直接换元的路标：既不是 `f'(x)/f(x)` 的形式，也没有显而易见的 `u` 让 `du` 与 `dx` 形成简单关系。十七世纪的标准做法是「乘以共轭」的技巧：把 `sec(x)` 乘以 `1 = (sec(x)+tan(x))/(sec(x)+tan(x))`，得到 `sec(x)·(sec(x)+tan(x))/(sec(x)+tan(x))`，令 `u = sec(x)+tan(x)` 后求导 `du = sec(x)tan(x) + sec^2(x) dx = sec(x)·(sec(x)+tan(x)) dx`，恰好让分子化为 `du`、分母保留 `u`，积分变为 `∫ du/u = ln|u| + C`。莱布尼茨与伯努利家族都研究过此积分，默卡托投影中纬度的积分也是 `sec(x)` 形式，这让正割积分在大航海时代的导航计算中具有实际价值。
- 哲学命题：PRO-04 道三，锚句「道三：代码自晦，意图必复。」单看 `sec(x) dx` 这六个字符的「有形」符号，无法看出任何通向 `ln|sec(x)+tan(x)|+C` 的路径。积分的「意图」即「通过共轭乘积打开 `sec(x)+tan(x)` 的导数结构」并不在符号的字面中存在。`sec(x) dx` 不自明地揭示「应该乘以共轭」这一意图，也不自明地揭示「替换变量应该是 `sec(x)+tan(x)`」。这就是「代码自晦」在积分运算中的具体化：被积函数作为「有形」符号，其含义不充分自明，必须先在维护或求解前恢复出构造者的「意图」即「为什么这一步乘法是有意义的」。意图必复：「维护之前必须先恢复意图」在此即「积分之前必须先识别共轭乘积的意图」，否则积分器将无法构造出 `u = sec(x)+tan(x)` 这一替换。
- 哲学命题：PRO-06 法，锚句「法一：顺因。尊重因果方向，介入点在前端。」共轭乘积是「顺因」在积分运算中的具体化。`sec(x) dx` 单独存在时没有自然的因果方向：没有 `f'(x)/f(x)` 这样的对数微分结构，也没有 `f'(x)·g(x) + f(x)·g'(x)` 这样的乘积导数结构。共轭乘积「顺着 `sec(x)+tan(x)` 的导数结构」介入：`d/dx[sec(x)+tan(x)] = sec(x)tan(x) + sec^2(x) = sec(x)·(sec(x)+tan(x))`，正是分子需要的形式。介入点在前端：乘法作用在被积函数上，即前端，不是作用在最终结果上，即后端。前端介入成本低：一次乘法即可识别替换；后端介入成本高：若先求原函数再想构造路径，已错过时机。共轭乘积是「顺」顺着 `sec(x)+tan(x)` 的导数结构顺势而为，不是「逆」不强行把 `sec(x)` 拆成 `1/cos(x)` 后用部分分式或幂级数对抗。

### 形式化 {#formalization}

设 `sec(x) = 1/cos(x)`，积分 `I = ∫ sec(x) dx`。

- 自晦作为意图隐藏：PRO-04 L15「道三：代码自晦，意图必复。」在正割积分中具象为：「自晦」即 `sec(x) dx` 这六个字符的字面不揭示替换路径。`sec(x)` 的导数是 `sec(x)tan(x)`，但被积函数没有 `tan(x)` 因子；`sec(x)+tan(x)` 的导数是 `sec(x)·(sec(x)+tan(x))`，但被积函数没有 `sec(x)+tan(x)` 项。共轭乘积 `sec(x)·(sec(x)+tan(x))/(sec(x)+tan(x)) = sec(x)` 是构造者「意图」的工程装置：意图是「让 `du = sec(x)·(sec(x)+tan(x)) dx` 与分子匹配」，但这一意图在 `sec(x) dx` 中不可见。意图必复：「维护之前必须先恢复意图」在此即「积分之前必须先恢复共轭乘积的意图」。恢复路径是「注意到 `d/dx[sec(x)+tan(x)] = sec(x)tan(x) + sec^2(x) = sec(x)·(sec(x)+tan(x))`」这一观察是「意图」的入口，积分器需要主动构造它。检验是「反代入求导」`d/dx[ln|sec(x)+tan(x)|] = (sec(x)tan(x)+sec^2(x))/(sec(x)+tan(x)) = sec(x)·(sec(x)+tan(x))/(sec(x)+tan(x)) = sec(x)`，恢复成功。
- 顺因作为前端介入：PRO-06 L49「法一：顺因。尊重因果方向，介入点在前端。」在正割积分中具象为：`sec(x)` 不存在「自然」的因果链：它不是某个函数 `g(x)` 的导数。共轭乘积是「在前端构造因果链」把 `sec(x)` 改写为 `sec(x)·(sec(x)+tan(x))/(sec(x)+tan(x))`，让分子 `sec(x)·(sec(x)+tan(x))` 与 `d[sec(x)+tan(x)] = sec(x)·(sec(x)+tan(x))dx` 形成 `du/u` 的因果对应。介入点在前端：共轭乘积作用在被积函数层面，即前端，不是作用在积分结果层面，即后端。前端介入的成本是「一次恒等乘法与一次替换识别」，后端介入的成本是「在 `1/cos(x)` 上反复试换元」。共轭乘积是「顺」顺着 `sec(x)+tan(x)` 的导数结构顺势构造替换，不是「逆」不与 `sec(x)` 的不可积性硬碰。
- 等价形式的结构：结果 `ln|sec(x)+tan(x)| + C` 也可写为 `ln|tan(x/2 + π/4)| + C`。两个形式在区间上互为等价：「半角正切」与「正割加正切」通过恒等式 `tan(x/2 + π/4) = sec(x) + tan(x)` 连接。这种等价性是「自晦的反面」同一结果有多个「形」，每个「形」对应不同的构造路径，但最终指向同一「意」即「`sec(x)` 的原函数」。维护或迁移时，「形」的转换是机械的：读者可按相同恒等式重写，「意」的恢复需要知道「`sec(x)+tan(x)` 与 `tan(x/2+π/4)` 是同一原函数的两种表达」。
- 边界：`sec^2(x)` 的积分是 `tan(x) + C`，不需要共轭技巧；`sec^3(x)` 的积分需要分部积分，不能直接用共轭乘积：见 INT-019 正割立方积分。`x = π/2` 处 `sec(x)` 有奇点，奇点附近需要广义积分处理，不能直接套用不定积分公式。本技巧只适用于「`sec(x)` 的一次幂」，更高次幂需要分部积分或更复杂的代数处理。这一边界是「共轭技巧的适用域」`sec(x) + tan(x)` 的导数结构恰好是 `sec(x)·(sec(x)+tan(x))`，让一次幂时被积函数与替换变量形成精确对消；二次幂时 `sec^2(x) + sec(x)tan(x)` 不会被同一替换消化。
- 与其他概念的关系：上游 INT-008 分部积分与 INT-010 换元积分：本积分的核心是换元，让被积函数与替换变量的导数形成匹配；分部积分在 `sec^3(x)` 等更高次幂中才被调用。下游 INT-019 正割立方积分：`sec^3(x)` 的积分需要分部积分与本结果的组合。同层 INT-019 正割立方积分：`sec^3(x)` 是 `sec(x)` 一次幂的自然延伸，但需要不同技巧。
