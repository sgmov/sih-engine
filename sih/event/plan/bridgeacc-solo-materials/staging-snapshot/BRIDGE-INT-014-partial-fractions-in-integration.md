## 哲学桥接 {#philosophy-bridge}

- 借鉴源：部分分式积分，partial fractions integration，是有理函数积分的标准方法。核心思路是「分解后逐个积分」：将复杂有理函数 `P(x)/Q(x)` 拆分为简单分式的和，再对每个简单分式分别积分。分解步骤是先对分母 `Q(x)` 做因式分解为线性因子与不可约二次因子的幂次乘积，再把 `P(x)/Q(x)` 表示为各因子对应分式的和。线性因子 `(x - a)^n` 对应 `A1/(x-a) + A2/(x-a)^2 + ... + An/(x-a)^n`，不可约二次因子 `(x^2+bx+c)^n` 对应类似形式。积分结果由多项式、对数函数、反正切函数组成。该方法由莱布尼茨和约翰伯努利系统使用，欧拉发展为系统的代数技巧。任何有理函数都可以用部分分式分解后积分，结果由这三类基本函数叠加而成。
- 哲学命题：PRO-06 法，锚句「法四：损补。定向调节规则，不笼统加码也不笼统删除」部分分式积分是「损补」在积分运算中的具体化。复杂有理函数是有余：它有冗余的代数结构，不能直接积分。简单分式是不足：它形式简单、行为已知。每个简单分式的积分是「补」补充到 `P(x)/Q(x)` 的完整积分中。`P(x)/Q(x) = Σ A_i / (x - a_i)^k_i` 这一分解操作是「损」把复杂的有余结构分解为多个简单的不足结构。损补的精度调节在此即「每个简单分式的系数 `A_i` 必须精确计算」，`A_i` 偏大或偏小都会让分解后的积分偏离原函数的真实值。「定向」在此即「每个分式的系数针对特定因式而非全局估计」。
- 哲学命题：PRO-07 鉴，锚句「去蔽：主动去除验证者的偏见」部分分式分解中的「系数求解」是「去蔽」在代数运算中的具体化。复杂有理函数 `P(x)/Q(x)` 的「蔽」是其代数结构遮蔽了简单分式之和的本质：表达式看起来是一个整体，看不出可以拆解为简单分式。系数求解是「去蔽」操作：通过代入特定 `x` 值或比较系数，把遮蔽在「整体形式」下的「分式之和」结构揭示出来。解出的每个 `A_i` 都是「已被去蔽的事实」它不是工程师的判断，是代数恒等式的机械推演。「主动去除」在此即「主动代入特殊值、主动比较系数、主动建立线性方程组」，不依赖直觉或近似。

### 形式化 {#formalization}

设 `P(x), Q(x)` 为多项式，`deg P < deg Q`，`Q(x) = ∏_{i=1}^k (x - a_i)^{n_i}`，其中 `a_i` 互异。

部分分式分解：
`P(x)/Q(x) = Σ_{i=1}^k Σ_{j=1}^{n_i} A_{ij} / (x - a_i)^j`

系数 `A_{ij}` 的确定方法：
- 代入特殊值 `x = a_i` 得到 `A_{i1} = lim_{x→a_i} (x - a_i)·P(x)/Q(x)`
- 对 `A_{ij}` 的高阶系数使用求导或比较系数法

积分：
`∫ P(x)/Q(x) dx = Σ A_{ij} · ∫ dx / (x - a_i)^j + C`

- 损补作为分解：PRO-06 L73「法四：损补。定向调节规则，不笼统加码也不笼统删除」在部分分式积分中具象为：复杂有理函数 `P(x)/Q(x)` 是有余的：它的代数结构复杂，不能直接积分。简单分式 `A/(x-a)^j` 是不足的：形式简单、行为已知。部分分式分解是「损」把有余结构分解为多个不足结构。积分 `Σ A_{ij}·∫ dx/(x-a_i)^j` 是「补」补充到 `P(x)/Q(x)` 的完整积分中。损补的「定向」在此即「每个简单分式的系数 `A_{ij}` 针对特定因式 `(x-a_i)^j`」不同因式之间的系数互不混淆，全局参数即 `deg Q` 被分解为局部参数即 `A_{ij}`。
- 系数求解的去蔽：PRO-07 L77「去蔽：主动去除验证者的偏见」在部分分式分解中具象为：复杂有理函数 `P(x)/Q(x)` 的「蔽」是其代数结构遮蔽了「分式之和」的本质。整体形式看起来不可拆解，但分式之和的代数结构是确定的。系数求解是「去蔽」通过代入特殊值或比较系数，把遮蔽在「整体形式」下的「分式之和」结构揭示出来。每个 `A_{ij}` 是「已被去蔽的事实」它不是工程师的估计，是代数恒等式的机械推演。`A_{ij}` 的偏大或偏小都会被「反代入」检测到：这是「去蔽」的可验证性。
- 重复因子的处理：当分母有重复因子如 `(x - a)^n` 时，部分分式分解中该因子对应 `A1/(x-a) + A2/(x-a)^2 + ... + An/(x-a)^n`，系数需要逐阶求解。`A_n` 通过最高阶系数匹配得到，`A_{n-1}` 通过次高阶系数匹配得到，依此类推。重复因子的逐阶求解是「知止」在分解中的具体化：「知止」指知道在何处停止每阶系数的求解，从最高阶向最低阶递推。
- 不可约二次因子的处理：当分母有不可约二次因子如 `(x^2+bx+c)^n` 时，部分分式分解中该因子对应 `(B_1 x + C_1)/(x^2+bx+c) + ... + (B_n x + C_n)/(x^2+bx+c)^n`。积分通过配方法化为对数与反正切形式：`∫ (Bx+C)/(x^2+bx+c) dx = (B/2)·ln(x^2+bx+c) + (2C - Bb)/√(4c-b²)·arctan((2x+b)/√(4c-b²))`。这一处理是「顺因」的具体化：不顺「分子分母整体」强行积分，顺「分母为不可约二次多项式」的特殊结构分别处理对数与反正切。
- 边界：部分分式积分只适用于有理函数，三角函数、指数函数、对数函数等超越函数的组合不直接适用。三角有理式需要先用 INT-011 正切半角换元转化为有理函数，再做部分分式分解。这一边界是「法的适用边界」有理函数是规则严格成立的场景，超越函数是规则不适用、需先转化的场景。分母因式分解对高次多项式没有一般公式，需要数值方法近似：这是「自晦在数值方法中的具体化」高次多项式的根不能代数表示，只能数值逼近。
- 工程映射：INT-014 工程映射「拉普拉斯逆变换 / 采样效率极点分解 / 收敛率有理模型积分」对应 PRO-06 与 PRO-07 的双重闭合：控制系统中传递函数 `H(s) = P(s)/Q(s)` 的拉普拉斯逆变换通过部分分式分解实现：把 `H(s)` 分解为 `Σ A_i/(s - p_i)^k_i` 后，每个分式对应一个已知的时间域函数 `t^k e^{p_i t}`，叠加得到完整时域响应。csnx 采样的效率模型如果有理函数，部分分式分解可识别各极点对效率的独立贡献：每个极点 `p_i` 对应一个独立衰减模式，便于针对性优化。convergence 层收敛率的有理模型可通过部分分式分解精确积分：分解后每个分式的积分是已知的对数或反正切函数，叠加得到完整的累积收敛行为。这三类应用的共同结构是「复杂有理对象通过分解为简单分式而被处理」，对应「损补」与「去蔽」的双重程序化。
- 可证伪条件：若某实例中 `P(x)/Q(x)` 是真分式即 `deg P < deg Q`，分母因式分解正确，但部分分式分解后逐项积分之和不等于 `P(x)/Q(x)` 的原函数，差分不为常数时部分分式积分被证伪。该证伪条件的哲学根据是 PRO-06 L73 与 PRO-07 L77 的双重：「损补」要求系数精确，「去蔽」要求代数恒等式成立。若部分分式分解的系数有误差或积分过程有误，「损补」与「去蔽」的程序被违反，结论不可被机械校验。实践中部分分式积分从未被证伪，因为代数恒等式与积分线性性是数学定理的客观属性。

INT-014 的工程映射「拉普拉斯逆变换 / 极点分解 / 有理模型精确积分」对应 PRO-06 + PRO-07 的双重闭合：部分分式积分是「损有余补不足，定向调节规则」的损补法在积分运算中的具体化，又是「主动去除验证者偏见，揭示遮蔽结构」的去蔽法在代数分解中的具体化。两命题共同为「复杂有理函数分解为简单分式、系数精确求解、逐项积分后叠加」的工程方法论提供 17 世纪代数分解技巧的哲学锚定。
