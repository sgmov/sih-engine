## 哲学桥接 {#philosophy-bridge}

- 借鉴源：序列极限是分析学最基础的形式化对象，epsilon-N 定义是其严格形式。历史脉络从芝诺悖论的无穷逼近讨论到波尔查诺柯西 1817 年建立现代定义，是分析严格化运动的奠基成果。序列极限的形式是 lim(n->infinity) a_n = L 即离散索引 n 趋于无穷时序列项趋近某 L；柯西序列是收敛的内部判定即任意 epsilon 都存在 N 使 n 大于 N 之后任意两项之差小于 epsilon。序列极限是连续变量极限与无穷级数收敛性的共同基础。
- 哲学命题：PRO-02 道一作为链，锚句「收敛不是自发的，它需要外部的、系统的、持续的治理力量」；PRO-07 鉴，锚句「自证循环的部分原因是文档化损失」
- 形式化：序列极限是 PRO-02 道一在分析学中的最小形式化实例。LIM-004 形式段「lim(n->infinity) a_n = L 当且仅当对任意 epsilon 大于 0 存在 N 使所有 n 大于 N 有 |a_n - L| 小于 epsilon」是「收敛」的数学定义即「对任意给定偏差阈值 epsilon 都能在 N 之后把实际值拉回到偏差内」= PRO-02 L80「收敛不是自发的，它需要外部的、系统的、持续的治理力量」的具体形态：epsilon 是外部给定的偏差阈值，N 是与之配对的治理投入点，「所有 n 大于 N 都满足」是治理动作的持续性即不是只在一个 N 上满足，是 N 之后所有 n 都满足；序列极限的存在即「持续性治理」的程序化定义。LIM-004 应用映射段写「迭代算法收敛判定」是这一定义的工程版：每轮对抗审阅产出 Jaccard 相似度构成一个序列 {s_1, s_2, ...}，序列是否收敛到某固定值 = 对抗是否可终止的判定；N 是终止判定的治理投入点即「N 之后所有 s_n 都与极限 L 偏差小于 epsilon」是终止判定的可证伪条件。另一锚 PRO-07 刻画柯西序列作为内部一致性判定的局限。LIM-004 形式段「柯西序列：在完备度量空间中柯西序列与收敛序列等价」= PRO-07 L130「自证循环的部分原因是文档化损失：多主体协作的真实形态在文档化中被简化为单一叙述」的具体形态：柯西条件是序列内部的一致性即不依赖外部极限 L 的判定程序；「在完备度量空间中」是外部锚定即空间必须包含极限点；柯西序列在不完备空间不收敛是 PRO-07 自证循环的数学实例即内部一致性判定在缺少外部锚定时无法独立给出收敛结论。LIM-004 边界段「序列极限不直接给出逼近速度的信息」是「内部一致性」的工程映射：知道序列收敛即知道内部一致，但不知「多快」即不知「收敛的具体动力学」与 PRO-07 L122「外部验证是鉴的认识论最终支撑」同源。工程映射，司衡治理系统的「治理动作的收敛判定」是序列极限的工程版：每轮治理迭代产生一个产出序列，序列是否收敛即治理是否进入稳态；柯西判据即「任意两轮产出的差异小于 epsilon」是治理稳态的内部一致性判定；完备性即「治理产出的目标态在治理可达域内」是稳态判定的外部锚定；LIM-004 应用映射段「convergence 层核心洞察层收敛率是序列极限的动态版本」即治理序列的极限行为是哲学仓 convergence 层与工程仓治理系统的共同本体。
