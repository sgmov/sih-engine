## 哲学桥接 {#philosophy-bridge}

- 借鉴源：「弧长」是曲线长度的严格数学定义。核心公式：若平面曲线 `y = f(x)` 在 `[a, b]` 上连续可导，则弧长 `L = ∫_a^b sqrt(1 + (f'(x))^2) dx`；参数曲线 `x(t), y(t)` 的弧长 `L = ∫_a^b sqrt((dx/dt)^2 + (dy/dt)^2) dt`；空间曲线增加 `z(t)` 分量。核心微分形式是「`ds = sqrt(dx^2 + dy^2)`」把勾股定理作用到无穷小切线段上。弧长公式的历史从阿基米德用穷竭法计算圆周长开始，17 世纪莱布尼茨等人独立发现微分形式，使任意光滑曲线的长度都可被严格计算。弧长公式的被积函数 `sqrt(1 + (f')^2)` 通常没有初等原函数，需要数值方法如梯形法则或特殊函数处理，这构成弧长计算的固有困难。
- 哲学命题：PRO-05 道四，锚句「道四：规约与实现必有间隙。」「曲线长度」是规约层概念，几何直观上「曲线有多长」是一个自然问题；弧长积分 `L = ∫ sqrt(1 + (f')^2) dx` 是实现层公式。规约「曲线长度」与实现「该积分」之间必有间隙：弧长积分的被积函数通常没有初等原函数，例如对 `y = x^2` 在 `[0, 1]` 上，`sqrt(1 + (2x)^2) = sqrt(1 + 4x^2)` 的原函数是 `(x/2)·sqrt(1+4x^2) + arcsinh(2x)/4`，已是反双曲正弦形式而非多项式；对更复杂的曲线如椭圆周长、`y = sin(x)` 等，弧长积分往往只能数值逼近或用椭圆积分等特殊函数表达。这就是「规约与实现必有间隙」在积分运算中的具体化：规约层「我要算曲线的长度」与实现层「积分解析式无初等形式」之间存在结构性间隙，不是因为曲线定义不够详细，不是因为积分技巧不够熟练，是「规约对实现」的根本局限。间隙不可消除，只能识别、记录、治理：识别即判断何时用数值方法，记录即把数值结果连同步长一起存下，治理即在数值方法与解析方法之间选边。
- 哲学命题：PRO-07 鉴，锚句「映照：只反映事实，不投射判断」微分弧长 `ds = sqrt(dx^2 + dy^2)` 是「映照」在几何-代数之间的具体化。切线段的水平分量 `dx` 与垂直分量 `dy` 是切线向量的两个分量，是几何事实；`sqrt(dx^2 + dy^2)` 把两个分量按勾股定理合成为切线段长度，是事实的代数映照。映照不投射「切线段应该用其他几何度量」的判断，不投射「曲线弯曲应该让长度变大或变小」的偏好：切线段长度就是水平分量与垂直分量的几何合成，与曲线的弯曲程度无关。积分 `L = ∫ ds` 是「映照」的累积形式：`ds` 是无穷小切线段长度的映照，`∫ ds` 是把无穷多个这样的映照累加起来得到全曲线长度。检验是「对直线段 `y = mx` 在 `[0, 1]` 上，`L = ∫_0^1 sqrt(1+m^2) dx = sqrt(1+m^2)` 与勾股定理一致」映照在简单情况下可由初等几何直接验证。

### 形式化 {#formalization}

设平面曲线 `y = f(x)` 在 `[a, b]` 上连续可导，弧长 `L = ∫_a^b sqrt(1 + (f'(x))^2) dx`。

- 规约与实现间隙的具体化：PRO-05 L15「道四：规约与实现必有间隙。」在弧长积分中具象为：「规约」即「曲线 `y = f(x)` 在 `[a, b]` 上的几何长度」，是几何直观层的不带公式的概念。「实现」即「`L = ∫_a^b sqrt(1 + (f'(x))^2) dx`」，是带积分公式的代数形式。间隙的具体形态是「`sqrt(1 + (f')^2)` 通常无初等原函数」。例如 `f(x) = x^2` 在 `[0, 1]` 上的弧长是 `sqrt(5)/2 + arcsinh(2)/4`，涉及反双曲正弦；`f(x) = sin(x)` 在 `[0, π]` 上的弧长是 `2√2·E(1/√2)`，涉及第二类完全椭圆积分。间隙不可消除：这不是「积分器算不出来」，是「被积函数的结构本身超出了初等函数类」。治理间隙的方式是「用数值方法或特殊函数替代初等原函数」梯形法则给出 `O(h^2)` 精度的数值弧长，椭圆积分给出符号化的特殊函数值。
- 映照作为微分弧长：PRO-07 L79「映照：只反映事实，不投射判断」在弧长微分形式中具象为：「事实」即切线向量的水平分量 `dx` 与垂直分量 `dy`，是切线的几何事实。「映照」即 `ds = sqrt(dx^2 + dy^2)`，把两个分量按勾股定理合成为切线段长度。映照不投射：不投射「切线段应该用曲线长度的某种近似」的判断，不投射「切线段在弯曲处应该更长或更短」的偏好。映照的可验证性是「对直线段 `y = mx`，`ds = sqrt(1+m^2) dx`，`L = (b-a)·sqrt(1+m^2)` 与勾股定理 `L^2 = ((b-a))^2 + (m(b-a))^2 = (1+m^2)(b-a)^2` 一致」。积分形式 `L = ∫ ds` 是「映照的累积」把无穷小切线段长度的映照累积为全曲线长度。累积不引入新的判断，只是把已有映照按区间拼接。
- 参数形式与平面形式的等价：参数曲线 `L = ∫_a^b sqrt((dx/dt)^2 + (dy/dt)^2) dt` 与函数曲线 `L = ∫_a^b sqrt(1 + (dy/dx)^2) dx` 通过链式法则 `dy/dx = (dy/dt)/(dx/dt)` 严格等价。两种形式映照同一事实：曲线的几何长度。等价性是「映照的不变性」同一事实的不同表达形式，不改变映照结果。对空间曲线增加 `dz/dt` 项是自然的扩展。映照在不同表达形式下保持一致，是「映照可验证」的形式化体现：读者可按相同链式法则重写并比对结果。
- 边界：弧长计算的是几何长度，不描述方向或曲率。方向是切线的方向即 `f'(x)`，曲率是 MUL-006 范畴。弧长公式要求曲线光滑，含尖点的曲线需要在尖点处分段积分；不连续曲线的弧长无定义或需要广义弧长概念。这一边界是「规约的适用域」「曲线长度」这一规约对光滑曲线给出初等形式，对不光滑曲线需要分段或广义化。无穷曲线的弧长可能有限如悬链线，可能无限如对数螺线，需要专门的判别准则。
- 与其他概念的关系：上游 DIFF-001 导数与 INT-007 微积分基本定理：弧长公式的导数 `f'(x)` 来自导数定义，弧长作为定积分来自基本定理。下游 MUL-006 曲率与 INT-021 旋转体：曲率是弧长对弧长的导数即 `dθ/ds`，旋转体表面积与体积依赖弧长与位置函数。同层 INT-015 二次积分与 INT-017 梯形法则：当弧长积分化为二次积分形式即 `sqrt(ax^2+bx+c)` 时用 INT-015 的方法，数值逼近时用 INT-017 梯形法则。
