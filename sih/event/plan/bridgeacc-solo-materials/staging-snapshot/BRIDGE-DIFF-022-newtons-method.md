## 哲学桥接 {#philosophy-bridge}

- 借鉴源：牛顿法 `x_{n+1} = x_n - f(x_n)/f'(x_n)` 是 17 世纪 Newton 1669 年《分析学》提出、Raphson 1690 年独立发现的迭代求根方法，本质是局部线性化 DIFF-010 的反复应用。收敛条件：初始值 `x_0` 足够接近真实根、`f'(root) ≠ 0`，二次收敛即误差大致按平方递减 `e_{n+1} ≈ e_n²` 每步有效精度位数翻倍。失败：初始值远离根可能发散，`f'(x_n) = 0` 时迭代公式无法计算。
- 哲学命题：PRO-06 法一 顺因，锚句「法一：顺因。尊重因果方向，介入点在前端。」；PRO-05 间隙增长动力学，锚句「规约与实现的间隙随时间增大，增大速率与规则数量正相关」。
- 形式化：牛顿法是「顺因」在数值分析中的完美标本。迭代公式 `x_{n+1} = x_n - f(x_n)/f'(x_n)` 的每一步都「顺着」函数 `f` 在当前点 `x_n` 的自然因果结构：`f(x_n)` 是函数值即「现状」，`f'(x_n)` 是切线斜率即「现状的趋势」，`-f(x_n)/f'(x_n)` 是沿趋势反推回零的步长即「顺势调整」介入点在前端，每一步都在「`x_n` 附近」即「当前状态的近端」，不绕过现状跳到远端 `x_{n+1} = -f(x_n)/f'(x_n)`。PRO-06 L49 锚句「法一：顺因。尊重因果方向，介入点在前端」的算子化即此迭代：每一步都「顺」着「`f` 的导数方向」与「`f` 的函数值符号」的反向调整，介入点不是「根的先验估计」后端而是「当前点 `x_n` 的切线」前端。条目原文「牛顿法的思想本质是局部线性化 DIFF-010 的反复应用」是顺因的本体：局部线性化是「顺」当前点的局部结构，反复应用是「顺」迭代的因果链：`x_0 → x_1 → x_2 → ... → root`，每一步都是「上一步的因果顺延」，没有「跳到 root」的后端介入。PRO-05 L138 锚句「规约与实现的间隙随时间增大，增大速率与规则数量正相关」是牛顿法的「反向算子」：PRO-05 描述间隙增长是「规约 - 实现」距离随时间扩大，牛顿法描述间隙收缩是「当前估计 - 真实根」距离随迭代平方缩小：`e_{n+1} ≈ e_n²` 是「间隙指数衰减」，与 PRO-05 的「间隙指数增长」`G(t) = G(0)·(1 + k·R(t))` 互为时间反演。条目工程映射「牛顿法因其快速收敛性成为首选方法之一」是 PRO-05 间隙收缩的工程本体：误差 `e_n` 的二次收敛 `e_{n+1} = e_n²` 是 `e_n → 0` 的最快常规收敛率之一，比线性收敛 `e_{n+1} = c·e_n`，`c < 1`，快得多，比指数收敛 `e_{n+1} = c·2^n` 的步数需求低一个量级：`e_0 = 0.1` 时线性需 44 步达 1e-10，牛顿法仅需 5 步。条目边界「牛顿法要求函数可导且在根附近导数不为零。若 `f'(x_n) = 0`，迭代公式无法计算。若初始值远离根，牛顿法可能发散」是 PRO-05 间隙增长的回归：牛顿法在 `f'(x_n) ≠ 0` 附近是「间隙收缩」算子，但在 `f'(x_n) = 0` 附近或初始值远离根时，PRO-05 的间隙增长重新主导：`e_{n+1} = e_n - f(x_n)/f'(x_n)` 当 `f'(x_n) → 0` 时步长趋于无穷，迭代发散，间隙反向增长。条目工程映射「工程基线第二条警告注意力是稀缺资源，牛顿法的每次迭代需要计算导数，在注意力预算紧张时可能不适用」是 PRO-05 间隙 与 PRO-06 顺因 的张力：牛顿法「顺因」要求每步计算 `f'(x_n)` 即每次「前端介入」都要付出「计算导数」的注意力成本，当注意力预算紧张时 PRO-05 L138 节点「增大速率与规则数量正相关」重新主导：规则数 `R(t) = O(导数计算次数)` 增加，间隙 `G(t) = G(0) + k·∫R(t)dt` 加速增长，注意力预算被迭代成本消耗，治理失效。司衡治理类比：牛顿法是「治理参数搜索」的二次收敛算子：每步 `θ_{n+1} = θ_n - Q'(θ_n)/Q''(θ_n)`，误差平方递减，但代价是每步都要计算一阶与二阶导数即每步都要「顺因前端介入」。当治理参数空间维度高 `d` 时牛顿法需 `O(d²)` 计算 Hessian 矩阵，注意力预算消耗 `O(d²)`，当 `d` 增大时 `R(t) = O(d²)` 触发 PRO-05 间隙加速增长，治理搜索反被迭代成本拖垮：必须降级到 `O(d)` 的一阶梯度法或 `O(1)` 的零阶法，PRO-06 知止的工程实现。
