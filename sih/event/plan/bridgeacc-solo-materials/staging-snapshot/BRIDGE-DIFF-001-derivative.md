## 哲学桥接 {#philosophy-bridge}

- 借鉴源：导数 `f'(a) = lim(h→0) [f(a+h) - f(a)] / h` 是函数在某点的瞬时变化率，由费马 / 牛顿 / 莱布尼茨在 17 世纪独立建立，柯西 / 魏尔斯特拉斯 19 世纪用 epsilon-delta 语言严格化。在工程中导数是「系统行为监控」的数学基础：系统负载增长率、错误率上升斜率、注意力衰减速度、间隙增长率都是导数实例。
- 哲学命题：PRO-05 间隙增长动力学，锚句「规约与实现的间隙随时间增大，增大速率与规则数量正相关」「增大速率」本身是导数概念：间隙 `G(t)` 的时间导数 `dG/dt` 给出「增大速率」，`dG/dt ∝ R(t)`，规则数，是 PRO-05 L138 的数学形式化。

### 形式化 {#formalization}

- 设 `f : R → R` 可导，`f'(a) = lim(h→0) [f(a+h) - f(a)] / h` 存在。
- 在 PRO-05 语境下：令 `G(t)` 为规约-实现间隙函数，则「增大速率与规则数量正相关」=`dG/dt = k·R(t)`，`k > 0`：`dG/dt` 是导数，`R(t) → ∞` 时 `G(t)` 单调增且增速增大。
- 工程映射中 `dA/dI → 0`，注意力对信息的边际增量趋于零，= `A(I)` 的导数在 `I → ∞` 时趋于零：`A(I)` 是凹函数，导数递减是「结构性稀释」的数学形式。
- 「应辨当下」与「应几未来」的导数判据：
  - `dQ/dt < 0` = 应辨当下，已失稳。
  - `d²Q/dt² < 0`，退化加速，对应趋势已显现。
  - 这与 APP-008「极值点 = 应本体安住」「拐点 = 应几预判窗口」一脉相承。
- 可证伪条件：若某系统 `Q(t)` 在多轮次中持续 `dQ/dt < 0` 但系统未退化，`Q` 不下降，则 (a) `Q` 的定义不含关键质量维度，或 (b) 退化被其他机制补偿：PRO-05 节点「间隙不静止，小错积累成大偏」需以「Q 的完整性」为前提。

DIFF-001 是微积分的核心，是 LIM-007 epsilon-delta 的下游应用：DIFF-001 与 PRO-05 的桥接建立了「数学导数 ↔ 哲学间隙增长率」的双向闭合，并保留与「应辨 / 应几」导数判据的描述性引用，原文逐字引文由其它条目承载。
