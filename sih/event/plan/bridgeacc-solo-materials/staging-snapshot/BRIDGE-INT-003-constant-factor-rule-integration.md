## 哲学桥接 {#philosophy-bridge}

- 借鉴源：常数因子法则，constant factor rule for integration，是积分线性性的基本组成。对于常数 `c`，`∫ c·f(x) dx = c·∫ f(x) dx`，定积分版本同样成立。法则源自积分作为极限的本质：黎曼和中常数因子可直接提取到求和号外，取极限后仍在积分号外。法则的边界由 `c` 是否为常数决定：若 `c` 依赖积分变量即 `c = c(x)`，则不能提取为 `c·∫ f(x) dx`，因为 `c(x)` 与 `dx` 之间存在动态耦合。该法则与和法则 INT-002 一起构成积分线性性的两个支柱。
- 哲学命题：PRO-06 法，锚句「每条规则都应能回答「这条规则何时停止生效」」常数因子法则精确演示了「规则停止生效」的边界条件。该规则仅在 `c` 为常数的条件下生效，一旦 `c` 依赖积分变量 `x`，规则立即停止生效，转而需要分部积分 INT-008 或其他工具。「规则停止生效」不是规则的失败，是规则「知止」的具体化：每条规则都有它的适用域，越出适用域时规则自动让位给其他规则。常数因子法则与和法则的并集 `INT-002 + INT-003` 构成积分线性性 INT-004，但两者的适用域都是「线性算子内的项」若运算对象是 `c(x)·f(x)`，两规则都不适用。
- 哲学命题：PRO-05 道四规约与实现必有间隙，锚句「道四也是道家"大成若缺"在司衡哲学中的具体化：最完美的系统必然有"缺"，缺不是缺陷，是系统的本质」常数因子法则的「缺」是 `c` 必须为常数的约束。看似完美的线性规则有「缺」：不能处理 `c(x)·f(x)` 的情形。这「缺」不是规则的缺陷，是规则的本质。规则的本质是「在 `c` 不依赖 `x` 的前提下可提取」，这一前提就是规约与实现之间的间隙：规约层「`c` 是常数」是命名承诺，实现层「`c` 不依赖 `x`」是数学条件，两者之间存在识别层。命名承诺与数学条件之间的间隙，正是「大成若缺」在微积分基本规则中的具体化。

### 形式化 {#formalization}

设 `f: D → ℝ` 在 `D` 上可积，`c ∈ ℝ` 是常数，则不定积分 `∫ c·f(x) dx = c·∫ f(x) dx + C`，定积分 `∫_a^b c·f(x) dx = c·∫_a^b f(x) dx`。

- 知止作为规则的适用域：PRO-06 L149「每条规则都应能回答「这条规则何时停止生效」」在常数因子法则中具象为：规则「停止生效」的条件是 `c` 不再是常数。黎曼和 `S_n = Σ c·f(x_i)·Δx` 中常数 `c` 与 `f(x_i)` 的乘积是合法的，因为 `c` 不依赖 `i`。若 `c = c(x)`，则黎曼和变为 `Σ c(x_i)·f(x_i)·Δx`，`c(x_i)` 与 `Δx` 不可分离，因为 `c(x)` 随 `x` 变化，其在小区间 `[x_i, x_{i+1}]` 上的取值影响乘积的极限行为。知止的判定不是「规则在某处不成立」「不成立」是数学失败：而是「规则在某处停止生效，让位给其他规则」。`c(x)·f(x)` 的积分不归常数因子法则管，归分部积分 INT-008 管。
- 大成若缺：PRO-05 L19「道四也是道家"大成若缺"在司衡哲学中的具体化：最完美的系统必然有"缺"，缺不是缺陷，是系统的本质」在常数因子法则中具象为：最完美的线性规则必然有「缺」：它不能处理 `c(x)·f(x)`。这「缺」是系统的本质。线性算子 `L(c·f) = c·L(f)` 只在「`c` 不在算子的输入域内」时成立，「`c` 必须在算子外」就是规约的承诺；「`c` 不能依赖被积变量」就是实现层的数学条件。规约层与实现层之间的间隙是 `c` 的命名身份：「常数」这个名字的内涵是「与 `x` 无关」，外延是「所有可被提取的标量」。识别这个间隙是规则生效的前提：若 `c` 的命名身份不是「与 `x` 无关」，规约层与实现层之间没有间隙被识别，规则不应被调用。
- 黎曼和层面的因子提取：黎曼和 `S_n = Σ c·f(x_i)·Δx = c·Σ f(x_i)·Δx` 中常数 `c` 的提取不依赖任何连续性或极限条件：纯算术恒等式。从黎曼和到积分的极限过程中，`Σ f(x_i)·Δx → ∫ f(x) dx`，常数 `c` 保持不变。提取操作是「在黎曼和层就完成」，极限只是把和传递到积分。这与知止的结构同构：「提取」在进入积分运算之前就完成，积分运算内部不再做提取判断。
- 失效的边界：`c(x)·f(x)` 的积分不归常数因子法则管，但也不归「提取失败」管：它归「规则不适用」管。知止的精确含义是「在该点停止」而非「在该点失败」。`∫ x·f(x) dx ≠ x·∫ f(x) dx` 不是「常数因子法则错了」，是「常数因子法则在该点不适用」。区分「错」与「不适用」是 PRO-06 L149 知止判定的关键：「错」要求修正规则，「不适用」要求切换规则。常数因子法则的「错」需要被排除，「不适用」需要被切换到 INT-008 分部积分或 INT-009 反向链式法。
- 工程映射：INT-003 工程映射「单位换算 / 固定成本提取」对应 PRO-06 与 PRO-05 的双重闭合：单位换算中常数因子对应单位换算系数，固定成本提取中常数因子对应单位成本。这两类工程操作的共同结构是「存在一个不依赖被处理对象的标量，可被预先提取到操作外」。单位换算系数的「不依赖被处理对象」即「单位换算前后数值意义不变」，固定成本的「不依赖被处理对象」即「单位成本不随样本量变化」。工程基线第二条「信息洪流的结构性不对称」是常数因子法则的工程反例：LLM 生成速度不构成「不依赖被审查对象的标量」，因为生成量与审查量之间存在动态耦合，不能提取为单一因子。
- 可证伪条件：若某实例中 `c` 被声明为常数，但 `c` 实际依赖 `x` 即 `c = c(x)`，则常数因子法则被错误调用。该证伪条件的哲学根据是 PRO-05 L19「缺不是缺陷，是系统的本质」规则的「缺」是「`c` 必须为常数」的前置条件，前置条件不成立时规则的结论不成立，规则被「错误调用」而非「证伪」。「错误调用」与「证伪」的区分是知止与道四的分工：知止负责识别「该点停止生效」，道四负责记录「该点存在缺」。

INT-003 的工程映射「单位换算 / 固定成本提取 / 规则适用域识别」对应 PRO-06 + PRO-05 的双重闭合：常数因子法则是「每条规则都应能回答何时停止生效」的知止在积分运算中的具体化，又是「最完美的规则必然有缺，缺不是缺陷是大成的本质」的道四约束在基本线性规则中的具体化。两命题共同为「识别规则适用域、在适用域外切换规则、不混淆错与不适用」的工程方法论提供微积分基本法则的哲学锚定。
