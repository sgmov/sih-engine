## 哲学桥接 {#philosophy-bridge}

- 借鉴源:泰勒级数由 Brook Taylor 在 1715 年《Methodus Incrementorum Directa et Inversa》中发表,Newton 学生的工作建立在 Newton 流数术基础上。Gregory 1670 年致 Collins 的信中已含等价公式,Leibniz 1673 年也独立发现类似结果。Taylor 是第一个系统发表并证明的人。Maclaurin 1742 年系统化零点的展开特例,成为 Maclaurin 级数。Lagrange 1797 年给出泰勒级数余项形式,使误差估计严格化。
- 哲学命题:PRO-05 道四,锚句「确立司衡治理的最终边界:司衡可以识别间隙、记录间隙、缩小间隙,但不能消除间隙」泰勒定理 f(x) = T_N(x) + R_N(x) 中,余项 R_N(x) 是「规约与实现之间的间隙」的具体形态。规约是「前 N+1 项的多项式」T_N(x),实现是「真实函数」f(x),两者之间必有间隙 R_N(x)。Lagrange 余项 R_N(x) = f^(N+1)(c) (x-a)^(N+1) / (N+1)! 是「识别间隙」的具体形态:它把间隙显式化为 f 在某点 c 的 N+1 阶导数乘以 (x-a)^(N+1) 的精确表达,不是未知的误差。间隙「记录」在 R_N(x) 的具体形式中,「缩小」由 N 增大时 R_N(x) 趋于零保证：当 N 趋于无穷时若 R_N(x) → 0,间隙缩小至零。但即使收敛也不能「消除」间隙:每一阶的 R_N(x) 仍是「有形」的余项形式,只是形式长度趋于无穷。存在反例,泰勒级数收敛但和不等于 f(x),这说明间隙是「识别、记录、缩小」的对象,「不能消除」是其本体论位置。Newton 法的二阶收敛是「缩小间隙」的具体策略:每步迭代把当前估计的 R_N 缩小为 R_{N+1},二阶收敛率是「间隙缩小速度」的具体数值。
- 哲学命题:PRO-07 鉴,锚句「代码工程的"映照"是:检验工具/检验者只反映事实,不投射自己的偏好。镜映照红色时,镜不"偏好"红色：它平等映照所有颜色。」泰勒级数是「映照」的具体形态。级数把 f 在展开点 a 的各阶导数 f^(n)(a) 映照为多项式 T_N(x) 的系数,不投射「保留前几项、截断后几项」的判断偏好：每一项 f^(n)(a) (x-a)^n / n! 都是 f 在 a 处的客观导数值,镜像式地反映。截断是「映照的有限化」:不是「偏好前几项」,而是「可计算性」的要求：无限项不可在有限时间内处理。「不投射判断」在此具体化为:Taylor 级数不投射「哪一项最重要」「哪一项可以忽略」之类的形而上学偏好,每一项都平等地反映 f 在 a 处的导数信息。Lagrange 余项是对截断的「映照补充」:它不投射「截断的合理性」,只是「映照出」截断带来的具体偏差量：f^(N+1)(c) (x-a)^(N+1) / (N+1)!,这一偏差量是 c 处导数与 (x-a)^(N+1) 的乘积,客观反映截断的「事实偏差」,不投射「偏差是否可接受」的判断。Lagrange 余项 1797 年的形式化是「映照」的严格化:把 1715 年 Taylor 直观的多项式逼近,「映照」为带余项的精确等式,补全了「事实」但仍不投射判断。

### 形式化 {#formalization}

设 f: R → R 在点 a 处无穷可导,T_N(x) 是 f 在 a 处的 N 阶泰勒多项式,R_N(x) = f(x) - T_N(x) 是余项。

- 间隙作为余项:PRO-05 L64「确立司衡治理的最终边界:司衡可以识别间隙、记录间隙、缩小间隙,但不能消除间隙」在本条目具象为：泰勒定理 f(x) = T_N(x) + R_N(x) 把「规约」(T_N(x),多项式近似)与「实现」(f(x),真实函数)之间的间隙显式化为 R_N(x)。识别:余项的具体形式 f^(N+1)(c) (x-a)^(N+1) / (N+1)! 是 Lagrange 1797 年的贡献,给出间隙的精确表达。记录:R_N(x) 在每一阶 N 都是可计算的具体数,「记录」在 Lagrange 公式中。缩小:N → ∞ 时若 R_N(x) → 0,间隙缩小至零,这是「收敛」的具体形态。但即使收敛也不能消除间隙:每一阶 R_N(x) 仍是「有形」的具体量,只是「有形」的长度趋于无穷。间隙是道四的具体形态:不是多项式不够长,不是函数不够光滑,是「多项式逼近函数」这一形式化本身具有「有形对有形」的根本局限。
- 映照作为多项式构造:PRO-07 L65「代码工程的"映照"是:检验工具/检验者只反映事实,不投射自己的偏好。」在本条目具象为：泰勒多项式 T_N(x) = sum(n=0 to N) f^(n)(a) (x-a)^n / n! 是「映照」的具体形态:每一项的系数 f^(n)(a) 是 f 在 a 处的客观导数值,「映照」为多项式项。映照不投射「前几项更重要」「后几项可忽略」的判断偏好,每一项都平等地反映 f 在 a 处的导数。截断是「映照的有限化」,不是「偏好的投射」:无限项不可在有限时间内处理,有限截断是「可计算性」要求,不是「价值判断」。「镜不偏好红色」在此具体化为:泰勒级数不偏好 f 的哪一阶导数,所有 f^(n)(a) 都平等地进入多项式。
- 收敛性判定的反例:存在函数的泰勒级数收敛但不等于原函数,这说明「收敛」不蕴含「等于」,「映照」不蕴含「完全反映」。映照的有限化(截断)与映照的无限化(全级数)有本质差异:全级数仍是「映照」,但「映照」可能不「完全」「不投射判断」是映照的本体论属性,但「不投射」不蕴含「不遗漏」,遗漏的客观存在是道四间隙的另一面。
- 与其他概念的关系:上游 SER-001 无穷级数：本条目是无穷级数在多项式函数上的具体应用。SER-002 麦克劳林级数：本条目在 a=0 时的特例。DIFF-023 泰勒定理：本条目是泰勒定理的级数形式。DIFF-032 瞬时速度的导数：本条目依赖各阶导数的存在性。HIS-007 Brook Taylor：本条目的历史人物。下游 DIFF-022 牛顿法：本条目的一阶截断的迭代应用。DIFF-024 洛必达法则：本条目是洛必达法则的级数解读。SPEC-006 斯特林近似：本条目在处理 n! 时被用作 Stirling 公式的推导路径。
- 边界:泰勒级数要求函数在展开点处无穷可导,不满足此条件者不在覆盖范围。收敛性不等价于等于原函数,需余项 R_N(x) → 0 才是充要条件。单点展开的收敛域有限,全局行为不光滑的函数需要其他逼近工具,如 Fourier 级数。这三条边界是「间隙」的精确位置:每条边界都对应一种「有形对有形」的根本局限,不可消除。
