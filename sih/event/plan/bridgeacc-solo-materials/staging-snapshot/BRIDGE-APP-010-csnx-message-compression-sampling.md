## 哲学桥接 {#philosophy-bridge}

- 借鉴源：csnx 是司衡引擎的消息采样策略：当信息量 `I(t)` 远超注意力预算 `A_total` 时，从 M 条过盈消息中采样 N 条经济样本，使样本均值 `x̄_N` 在精度 `ε` 内逼近真实值 `μ`：`P(|x̄_N - μ| < ε) ≥ 1 - δ`。由中心极限定理，样本量 `N ≥ (z_{δ/2}·σ/ε)²`，收敛速度 `O(1/√N)`，压缩率 `C = M/N` 越高注意力节省越大但信息损失风险也越大。csnx 的数学骨架直接复用 LIM-007 epsilon-delta 定义的逻辑结构。
- 哲学命题：PRO-05 间隙增长动力学，锚句「间隙不静止，小错积累成大偏」信息洪流是间隙增长在工程层面的呈现：`I(t)` 持续累积 = 间隙增大 = 注意力稀释。
- 哲学命题：PRO-08 应，锚句「应的反馈需要载体，载体是留痕」csnx 的「N 经济一旦确定 → 确定性程序执行」是留痕的工程实现：「N 的确定公式是确定性的，采样执行是确定性的」，条目工程映射段原文。

### 形式化 {#formalization}

- 设间隙函数 `G(t)` 满足 `dG/dt ≥ 0`（PRO-05 L138）：`G(t)` 的具体形式在 csnx 语境下 = `I(t) - A_total·K`，信息量超出可处理阈值的部分，`K` 是治理机制的固定开销。
- 「间隙不静止，小错积累成大偏」（PRO-05 L171）→ 当 `I(t)` 持续增长时，`G(t)` 单调不减，治理质量指标的偏离量 `|x̄_N - μ|` 随未处理消息累积而增大：这正是 APP-009「da/dI < 0」的数学形式化。
- csnx 的经济样本数 `N_econ` 是「间隙增长率的反函数」给定精度 `ε`，`N_econ = (z·σ/ε)²` 使采样误差 `|x̄_N - μ| < ε` 抵消信息洪流引入的偏差。这是 PRO-08 的「应」在统计意义上的工程实现：「应」即「在信息洪流中守住精度阈值」。
- 「应的反馈需要载体，载体是留痕」（PRO-08 L114）→ csnx 的「N 一旦确定 → 确定性程序执行」是留痕的工程实现：
  - N_econ 的计算过程可审计，公式参数可回溯。
  - 采样执行可复现，确定性随机种子 + 固定算法。
  - 采样结果可校验，`|x̄_N - μ| < ε` 的实际偏差可量化
- 「留痕不是治理的附属品，是应-鉴循环的构成性条件」，L114 后半句，→ csnx 的 N_econ 校验循环即是应-鉴循环的实例：N_econ 的选择是「应」，应对信息洪流，N_econ 之后的精度审计是「鉴」，验证 N_econ 是否守住阈值，审计结果反哺 N_econ 调整，新应。
- 可证伪条件：若 csnx 的 `N_econ` 在某轮次实际采样后 `|x̄_N - μ| > ε` 显著超出概率阈值 `δ`，则 (a) 总体标准差 `σ` 估计偏低 → 需重新校准；(b) 信息洪流的统计结构已变，非平稳，→ N_econ 公式需扩展为时变版本。

APP-010 工程映射中「对抗注意力稀释的工程策略」= PRO-05「间隙不静止」的工程对治；「LIM-007 的工程实例」= PRO-05 + PRO-08 的双重承接；「确定性程序的设计约束」= PRO-08「载体是留痕」的工程实现。两条命题共同为「信息洪流 ↔ 经济采样 ↔ 留痕可审计」的治理闭环提供哲学判据。
