## 哲学桥接 {#philosophy-bridge}

- 借鉴源：幂法则 `d/dx x^n = n·x^(n-1)` 是微积分最常用的求导工具，Newton 通过二项式展开得到、Leibniz 通过无穷小比值得到，正整数指数可严格证明、负整数与有理数通过链式法则与指数法则推广、实数指数通过指数与对数函数证明。工程中多项式模型求导、标度律计算、收敛率建模 `Q(n) = n^α` 的变化率计算均直接调用幂法则。
- 哲学命题：PRO-05 间隙增长动力学，锚句「规约与实现的间隙随时间增大，增大速率与规则数量正相关」；PRO-08 应几，锚句「应几：感知正在形成的微兆」。
- 形式化：幂法则是「间隙增长」最直接的数学刻刀。令 `G(t)` 为规约-实现间隙函数，PRO-05 L138 节点「间隙随时间增大，增大速率与规则数量正相关」=`dG/dt = k·R(t)`，`k > 0`，其中 `R(t)` 是规则数量：此微分方程的通解为 `G(t) = G(0) + k·∫R(t)dt`，若 `R(t) = c·t^α` 即规则数随时间呈幂律增长，则 `dG/dt = k·c·t^α` 与 `G(t) = G(0) + (k·c/(α+1))·t^(α+1)`，二者的导数关系恰是幂法则 `d/dt t^(α+1) = (α+1)·t^α`：幂法则是间隙增长方程解析解的算子。条目原文工程映射「Q(n) = n^α，Q'(n) = α·n^(α-1)，α < 1 时变化率递减，是注意力预算稀释的数学表达」是幂法则的工程本体：`α < 1` 时 `Q'(n) → 0` 当 `n → ∞`，但 `Q(n) → ∞` 当 `α > 0`：增速趋零不代表总量不增，是 PRO-08 应几最纯粹的工程形态：`Q'(n)` 是「正在形成的微兆」，α < 1 时 `Q'(n)` 单调递减但仍为正，`Q` 持续累积，趋势已显现，量级尚未爆发，应几介入的窗口正是 `Q''(n) < 0` 仍未触底、`Q'(n) > 0` 仍可观测的中间区段。条目退化情形「n = 0 时 f'(x) = 0」即「间隙停止增长」的数学镜像：`G'(t) = 0` 等价于「规则数冻结」，`R(t) = const`，是「应本体安住」的微分等价。`n = 1` 退化「f'(x) = 1」是「间隙匀速增长」的数学镜像：`G'(t) = const` 是「应本体失稳但速率恒定」的临界情形，是「应辨」从「应几」退化为「应辨」常速的转折点。司衡治理类比：幂法则是「规则增长 ↔ 间隙增长」耦合关系的解析核，若工程层规则数随时间幂律增加 `R(t) = c·t^α`，治理系统必须按幂法则反推 `G(t) = G(0) + (k·c/(α+1))·t^(α+1)` 才能识别间隙的真实轨迹，不能用 `G'(t) ≈ const` 的线性外推，否则 α > 0 时低估「α+1」阶增长，α < 0 时高估即低估治理收益：幂法则的指数差一,「n 与 n-1」,决定了线性思维与幂律思维在 `n → ∞` 时的判据分歧。
