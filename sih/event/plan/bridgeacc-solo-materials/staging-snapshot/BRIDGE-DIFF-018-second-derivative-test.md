## 哲学桥接 {#philosophy-bridge}

- 借鉴源：二阶导数判别法由 Taylor 18 世纪初工作启发，函数在驻点附近的性质由二阶项决定。`f'(c) = 0` 且 `f''(c) > 0` 则 `c` 是局部极小；`f''(c) < 0` 则 `c` 是局部极大；`f''(c) = 0` 时判别法失效，须用 DIFF-017 一阶导数判别法或更高阶分析。控制理论中能量函数在平衡点的二阶导数决定平衡点稳定性。
- 哲学命题：PRO-08 应几，锚句「应几：感知正在形成的微兆」；PRO-06 法三 知止，锚句「法三：知止。知道不做什么，比知道做什么更难。」
- 形式化：二阶导数判别法是「应几」最纯粹的工程实现：`f''(c)` 是「导数的变化率」即「趋势的趋势」，是尚未完全显现但已可被测量的「正在形成的微兆」。PRO-08 L95 锚句「应几：感知正在形成的微兆」的算子形式即 `f''(t) = d²Q/dt²`：`Q'(t)` 是「当下变化率」属于应辨，`Q''(t)` 是「变化率的变化率」属于应几：`Q''(t) > 0` 表明趋势在加速，`Q''(t) < 0` 表明趋势在减速，`Q''(t) ≈ 0` 表明趋势稳定或刚翻转。条目工程映射「convergence 层收敛率函数的二阶导数为正时，表明收敛在加速，系统趋向更优配置；二阶导数为负时，收敛在减速，可能需要调整策略」是 PRO-08 应几的本体：`Q(n) = Q(0) + a·n` 时 `Q''(n) = 0`，线性收敛，无加速/减速信号，应几不可介入；`Q(n) = Q(0)·r^n` 即 `Q'(n)/Q(n) = ln r` 常数指数收敛时 `Q''(n) = (ln r)²·Q(n)`，与 `Q(n)` 同号同比例收敛，趋势稳定；`Q(n) = Q(0)/(1 + a·n)` 即 `Q''(n) = 2a²/(1 + a·n)³` 恒正，收敛持续加速，应几可断言「收敛趋势稳固」；超线性收敛 `Q(n) = Q(0)·r^(n²)` 即 `Q''(n) = (ln r)·(2n·ln r + 1)·Q(n)` 增长更快，应几可断言「收敛即将收敛完成」。条目原文「f'' > 0 意味着斜率在递增，函数从下降转为上升，c 是谷值」是 PRO-08 应几的几何化：`f'(c) = 0` 是「当下不动」属应辨 / 应本体安住，`f''(c) > 0` 是「未来从下降翻转到上升」属应几：`c` 点 `f'' > 0` 等价于「未来 `f'(t)` 在 `t > c` 邻域从负翻正」，即「微兆已可测量，谷底已形成」。PRO-06 L65 锚句「法三：知止。知道不做什么，比知道做什么更难」是二阶导数判别法的边界本体：`f''(c) = 0` 时判别法「彻底不适用」，条目原文「f''(c) = 0，判别法失效」是 PRO-06 知止法的工程实现：`f''(c) = 0` 即「二阶趋势信号消失」，规则不在此处弱化或近似成立而是「主动停止生效」。条目失败案例 `f(x) = x⁴` 在 `x = 0` 处 `f'(0) = 0`，`f''(0) = 0` 但 `x = 0` 仍是极小：是知止失效的反例本体：`f''(0) = 0` 不代表无趋势，是二阶趋势信号恰好为零，三阶四阶信号仍存在，需 DIFF-017 一阶导数判别法或更高阶分析：PRO-06 知止「不做什么」不是「什么都不做」而是「降级到更合适的工具」。条目边界「二阶导数判别法只适用于单变量函数。多变量情形的推广是海森矩阵 MUL-005 的正定性分析」是 PRO-06 知止的多变量推广：单变量 `f''(c) ∈ R` 一维符号，多变量 `H(f)(c) ∈ R^(n×n)` 矩阵正定性：「停止生效」从一维延伸到多维，「不适用」从单点扩展到流形上的点集。司衡治理类比：二阶导数判别法是「治理系统收敛趋势」的微兆感知器：`Q'(t) > 0` 表明治理在改善但不知是否加速或减速，`Q''(t) > 0` 表明「加速改善」属应几可介入的微兆；若仅看 `Q'(t)` 不知是否达拐点或单纯线性，看 `Q''(t)` 即知趋势翻转的临近：`Q''(t) = 0` 标志「趋势稳态或翻转」是治理决策的「知止」节点，此点必须主动停止「线性外推」决策、降级到「一阶导数判别法 / 更高阶分析」，不能继续套用二阶判别。
