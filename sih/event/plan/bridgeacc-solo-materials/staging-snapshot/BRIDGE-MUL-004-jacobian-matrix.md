## 哲学桥接 {#philosophy-bridge}

- 借鉴源:雅可比矩阵以德国数学家卡尔·古斯塔夫·雅各布·雅可比命名,雅可比在 19 世纪研究坐标变换和重积分的变量替换时发现了雅可比行列式的关键作用。雅可比矩阵是多元微积分的自然推广,概念由多位数学家在 18-19 世纪逐步形成。雅可比的主要贡献是阐明了雅可比行列式在变量替换中的系统性作用,使多变量积分的换元法有了统一的数学框架。链式法则 Dg(f(x)) · Df(x) 是 DIFF-009 链式法则在多变量情况下的推广,雅可比行列式 |det(J)| 给出变量替换积分中局部体积元的缩放因子 dV = |det(J)| dx_1...dx_n。
- 哲学命题:PRO-05 道四规约与实现必有间隙,锚句「道四:规约与实现必有间隙。」雅可比矩阵把非线性映射「规约」为局部线性近似,这是双重有损链的微缩。规约侧是非线性函数 f 的完整定义,实现侧是 J = [∂f/∂x_1 | ∂f/∂x_2 | ... | ∂f/∂x_n] 的线性矩阵。两个环节都涉及有损编码:第一次编码从 f 本身降到一阶偏导数矩阵,信息只保留一阶,二阶及以上的非线性被丢弃;第二次编码从连续偏导数降到矩阵元素 J_ij,信息又被进一步结构化为有限表格。道四命题断言「间隙不可消除」,雅可比矩阵以最简洁的方式展示这一约束:即使 f 完美光滑、所有偏导数连续,矩阵形式只保留 f 在某一点的局部线性行为,远离该点时线性近似与真实 f 的差距由二阶及高阶项决定。雅可比矩阵 det(J) = 0 标记规约侧的非平凡退化,这是间隙「识别」的具体表现：det(J) = 0 不是「映射无定义」,而是「规约在这一点不再有可逆的实现」。
- 哲学命题:PRO-08 应,锚句「司衡之应:应而不藏,应辨当下,应几未来。」雅可比矩阵的执行是「应」的两种时态。已知点 x 与映射 f,立即算出 J(x) = [∂f_i/∂x_j] 是应辨当下,已抵达的、可机械执行的当下程序。继续预测 det(J) = 0 附近的退化方向,或估计非线性映射 f 的高阶项贡献,是应几未来。司衡之应在雅可比矩阵中具象为:应而不藏对应矩阵元素的显式陈列,每个 J_ij 是 ∂f_i/∂x_j 的具体偏导数,不藏「为什么是这些偏导数」的链式法则依据;应辨当下对应已知 f 时的立即可计算性;应几未来对应 det(J) 的零值检测与策略空间有效维度的预判。

### 形式化 {#formalization}

设 f: R^n → R^m 是向量值函数,f = (f_1, f_2, ..., f_m),每个 f_i 是 n 个变量的标量函数。雅可比矩阵 J 是 m × n 矩阵,J_ij = ∂f_i/∂x_j。

- 间隙作为线性化残差:PRO-05 L15「道四:规约与实现必有间隙。」在本条目具象为：f 的泰勒展开 f(x + h) = f(x) + J(x)h + O(|h|^2) 中,规约侧是 J(x)h 的一阶线性项,实现侧是 f(x + h) 的真实值。两者之差是高阶项 O(|h|^2),这是道四间隙在局部线性化中的具体形态。间隙不消除,只通过减小 |h| 让高阶项落入可接受阈值。det(J) = 0 是间隙的另一种识别:在这一点,线性化不再是可逆映射,规约与实现之间的对应关系在局部退化,需要更高阶信息恢复。间隙的工程化处理是「用足够小的 |h| 让 O(|h|^2) 落入阈值,或在 det(J) = 0 附近切换到二阶海森矩阵 MUL-005」,这是道四的「治理」。
- 应辨当下与应几未来:PRO-08 L108「司衡之应:应而不藏,应辨当下,应几未来。」在本条目具象为：应辨当下指已知 f 与 x 时立即算出 J(x) 的动作,这是机械的、无歧义的、有限步可完成的「当下」。每个偏导数 ∂f_i/∂x_j 是已抵达的、具体的计算动作,可以用自动微分或符号微分直接得出。应几未来指预判 det(J) 在 x 空间中的零值集合,或估计 f 的非线性度由高阶项决定。det(J) = 0 处的退化是「几」:还没到达退化点,但已通过 det(J) 的符号变化预告策略空间有效维度的下降。司衡之应在此具体化为:应而不藏在 J 矩阵元素显式呈现,每个 J_ij 是 ∂f_i/∂x_j;应辨当下在 f 已知时立即可算;应几未来在 det(J) 零值检测与策略空间有效维度的预判。
- 链式法则作为多变量应-鉴循环:复合函数 g(f(x)) 的链式法则 Dg(f(x)) · Df(x) 是 DIFF-009 单变量链式法则在多变量情况下的推广,也是「应-鉴」循环的微缩：「应」(Dg) 触发新认识(对 g 的偏导数),新认识(对 f 的偏导数)产生新「应」。链式法则的矩阵乘法是规约与实现之间的桥:每个矩阵是规约侧的局部线性化,矩阵乘积是实现侧的复合映射。桥的承载是矩阵乘法的不交换性(在非方阵情况下)与 det(Jg · Jf) = det(Jg) det(Jf) 的可乘性,后者让复合映射的体积缩放因子等于各因子体积缩放因子的乘积。
- 雅可比行列式与策略空间:det(J) = 0 在工程上意味着策略空间的局部降维。例如对抗工具的状态空间变换中,det(J) = 0 标识策略空间在该点退化,有效维度从 n 降到 n-1 或更低。这是应几的具体场景:还没到达退化点,但已通过 det(J) 的零值预告策略空间的临界状态。降维是间隙的另一种形态：规约侧的有效信息量减少,实现侧需要重新组织以适应新维度。
- 与其他概念的关系:上游 MUL-001 偏导数与 DIFF-009 链式法则：本条目是偏导数的矩阵组织与链式法则的多变量推广。下游 MUL-005 海森矩阵与 MUL-007 格林定理：海森矩阵是二阶推广,格林定理是积分层面的应用。同层 DIFF-010 局部线性化：本条目把单变量局部线性化推广到多变量情形。MUL-010 向量微积分：雅可比矩阵是向量微积分中梯度、散度、旋度等概念的统一载体。
- 边界:雅可比矩阵只包含一阶偏导数信息,二阶及以上的非线性需要海森矩阵 MUL-005。雅可比矩阵描述的是局部线性近似,大范围非线性变换中需逐点重新计算。不可微函数不存在雅可比矩阵,不连续或不可微的变换需要其他数学工具(如广义函数论、测度论)。
