## 哲学桥接 {#philosophy-bridge}

- 借鉴源：反导数的思想史源流是求导运算的逆问题。牛顿流数术中从流数求流量即是反导数过程，莱布尼茨从求和面积问题自然引出反导数；反导数与定积分的关系直到 INT-007 微积分基本定理被严格建立。数学定义是若 F' 等于 f 则 F 是 f 的反导数，反导数不唯一即 F 加任意常数 C 仍是反导数，= 反导数是函数族而非单点；记号 F 等于 integral f dx 把「F 是 f 的原函数」与「F 加上 C 还是 f 的原函数」压成同一个符号。
- 哲学命题：PRO-04 道三代码自晦意图必复，锚句「代码不会自行揭示意图」；PRO-05 道四规约与实现必有间隙，锚句「治理不能消除间隙，只能识别、记录、缩小间隙」。
- 形式化：反导数 F 等于 integral f dx 的记号是 PRO-04 自晦的具体形态，记号 F 字面读法是「一个函数」，意图是「一族函数即 F 加任意常数」，字面与意图之间存在自晦，= PRO-04 L17「代码不会自行揭示意图」的具体呈现；维护者面对 F 等于 x 平方加 x 这类记号必须先恢复意图即追问「F 是否包含任意常数 C」「C 的值由什么决定」「F 在某区间上是否需要定值」才可对接下游 INT-005 任意积分常数与 INT-007 微积分基本定理，若仅从字面读 F 等于某函数直接代入下游，等价于把一族函数压成单点，丢失「C 是任意常数不可被指定」这一关键信息。另一锚 PRO-05 刻画间隙的必然性，反导数定义的字面是「若 F' 等于 f 则 F 是反导数」，实现是「F 加任意 C 也满足 F' 等于 f」，= 规约与实现之间的固有间隙：规约层只说「F' 等于 f」，实现层必须补出「加 C」，间隙不可消除因为「+C」是「F' 等于 f」这一微分条件无法决定的部分，等价于 PRO-05 L101「治理不能消除间隙，只能识别、记录、缩小间隙」工程层「+C」的标注是间隙的识别与记录，不能消除因微分条件本质不决定 C 值，下游 INT-007 微积分基本定理把间隙从「反导数层面」缩到「定积分数值层面」即用上下限消解 C，是「缩小间隙」而非「消除间隙」的具体形态。工程映射，司衡治理系统中「治理规则」与「规则的具体执行」之间存在 +C 类间隙即「规则的字面定义」与「规则在具体场景的实例」之间的自由度，规则不能完全决定场景实例，间隙不可消除但可被「记录 +C」「标注 +C 取值由场景决定」与「用判据缩小 +C 范围」三步治理，这与 INT-001 的反导数 +C 是同构：规约层给微分条件 F' 等于 f，实现层加 C 构成一族函数，C 是间隙，C 由初值条件缩小与 INT-007 定积分用上下限消 C 是同源。
