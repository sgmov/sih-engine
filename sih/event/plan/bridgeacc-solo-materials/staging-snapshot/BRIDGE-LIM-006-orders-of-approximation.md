## 哲学桥接 {#philosophy-bridge}

- 借鉴源：近似阶是逼近精度的度量工具，源自泰勒展开的截断。大 O 记法由巴赫曼 1894 年引入、兰道推广，成为描述渐近行为的标准语言。零阶近似即常数近似，一阶近似即线性近似，n 阶近似即截断到第 n 次项，误差与 (x - a)^(n+1) 同阶。当 |x - a| << 1 时高阶项迅速变小，低阶近似就足够精确。物理学家用「高阶小量」描述可忽略的效应是这一定义的日常化。
- 哲学命题：PRO-06 法，锚句「高了压低，低了抬高；有余的减损，不足的补足。」；PRO-05 道四规约与实现必有间隙，锚句「道四否定治理的绝对正确性而非有效性：」。
- 形式化：近似阶是 PRO-06 损补在逼近论中的最小样本。LIM-006 形式段「保留到 n 次项误差是 n+1 阶小量」= PRO-06 L75「天之道像张弓：高了压低，低了抬高；有余的减损，不足的补足」的具体形态：泰勒展开的截断是「损」即把高阶项丢掉，「保留低阶项」是「补」即把对当前精度贡献最大的项保留；「n+1 阶小量是误差」是「损」的程序化即误差被削减到第 n+1 阶，余项可量化即「不足」被识别。LIM-006 应用映射段「物理学家会说某效应是高阶小量意味着在当前精度下可以忽略」是这一定义的物理版：高阶项 = 损的对象，低阶项 = 补的对象，「高阶小量可忽略」是损补的判定规则。LIM-006 形式段「当 |x - a| << 1 时高阶项迅速变小低阶近似就足够精确」= 损补的适用条件：当 x 距 a 足够近时高阶项的有余被削减到不影响精度的程度即损的对象够小，可以放心地丢；损补的精度由截断点 n 决定，n 越高精度越高但计算量越大 = 「刚好够」的精度调节。另一锚 PRO-05 刻画近似阶放弃绝对正确的本体论。LIM-006 边界段「近似阶度量的是误差的量级不给出误差的具体值」= PRO-05 L99「道四否定治理的绝对正确性而非有效性」的具体形态：近似阶不追求「误差等于零」的绝对正确即不给出误差具体值，只追求「误差是某阶小量」的有效性即误差量级可控；这与 PRO-05 L101「道四承认间隙」同源：间隙即误差，近似阶是「记录间隙的量级」的程序化即「不消除间隙但把间隙量化」。LIM-006 应用映射段「数值积分的梯形法是二阶精度辛普森法是四阶精度，精度阶直接决定了达到目标误差所需的计算量」= PRO-05 L99 否定绝对正确的工程版：选择二阶而非四阶是承认「不追求更高精度只追求当前够用」即否定绝对正确；选择四阶而非二阶是「追求更高精度的有效性」。LIM-006 形式段「大 O 记法存在常数 C 和 delta 使 |f(x)| 小于等于 C|g(x)|」是「有余的减损」的程序化：C 是缩放因子即「多余的部分」被 C 削减到符合 |f(x)| 小于等于 C|g(x)| 的边界。工程映射，司衡治理系统的「治理精度的分阶适配」是近似阶的工程版：convergence 层核心洞察层收敛率是近似阶问题即收敛率度量多轮审阅产出与目标分布的误差随轮次缩小的一阶或二阶是 LIM-006 应用映射段的核心案例；多轮对抗审阅的效率评估是对抗新攻击点数量衰减速度的近似阶诊断；csnx 采样精度是质量关于样本数近似阶决定的边际收益：共同结构是「治理精度按阶适配」与 PRO-06 L75 损补同构。
