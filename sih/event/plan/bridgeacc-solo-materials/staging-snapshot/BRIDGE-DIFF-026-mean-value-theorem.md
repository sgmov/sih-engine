## 哲学桥接 {#philosophy-bridge}

- 借鉴源：中值定理又称拉格朗日中值定理，18 世纪 Lagrange 雏形、19 世纪初 Cauchy 严格证明：若 `f` 在 `[a, b]` 连续，在 `(a, b)` 内可导，则存在 `c ∈ (a, b)` 使 `f'(c) = [f(b) - f(a)] / (b - a)`。几何意义：`f` 在 `c` 点的切线平行于连接 `(a, f(a))` 与 `(b, f(b))` 的割线。等价形式 `f(b) - f(a) = f'(c)·(b - a)`。是微分学基本定理，连接函数局部性质与全局性质。
- 哲学命题：PRO-08 应辨，锚句「应辨：应对已抵达的挑战」；PRO-07 鉴·映照，锚句「映照：只反映事实，不投射判断。」
- 形式化：中值定理是「连接局部与全局」的最简洁数学桥梁，也是「应辨」在微分几何中的最小表达。`f(b) - f(a) = f'(c)·(b - a)` 把全局差分 `f(b) - f(a)` 归约到局部导数 `f'(c)`：`[f(b) - f(a)] / (b - a)` 是「平均变化率」属全局，`f'(c)` 是「瞬时变化率」属局部，定理担保二者相等的 `c` 存在。PRO-08 L94 锚句「应辨：应对已抵达的挑战」的算子化即此 `c` 点的存在：全局异常 `f(b) - f(a) ≠ 0` 是「已抵达的挑战」，定理担保存在「`c` 点」的瞬时异常 `f'(c) ≠ 0` 应对之：`c` 是「应辨点」即「局部异常已被识别的点」。条目工程映射「中值定理保证了：如果整个会话的 trail 记录中平均变化率异常，则至少存在一个时间点的瞬时变化率同样异常。反查时不必检查每一个时间点」是 PRO-08 应辨 的工程本体：平均变化率异常是「已抵达的挑战」属应辨当下，定理担保存在「`c` 点」即「`trail` 中某个时间点」其瞬时变化率也异常：治理系统的「反查」只需验证平均值即可定位异常存在，不必逐点检查全部 trail。条目工程映射「但工程基线第三条要求只通过视图介入，不逐点检查」是 PRO-08 应辨 与 工程基线第三条的合流：MVT 把「逐点检查」压缩为「平均值检查 + 异常点存在性」二步，第三条「只通过视图介入」即此压缩的工程表达：视图呈现平均值，异常点存在性由 MVT 担保，治理动作不需要逐点扫描。条目边界「中值定理保证存在性，不给出 `c` 的具体位置。`c` 是抽象存在的点，一般情况下无法精确计算」是 PRO-07 L79 锚句「映照：只反映事实，不投射判断」的最纯粹数学标本：定理只「反映」`c` 存在这一「事实」，不「投射」`c` 在哪一具体位置这一「判断」存在性是事实，定位是判断，定理刻意停留在事实层。条目原文「中值定理要求函数在开区间内可导。若函数在某点不可导，中值定理不一定成立」是 PRO-07 映照 的边界：定理只反映「连续 + 可导」下的事实即「存在 `c` 使 `f'(c) = ...`」，不反映不可导点的「`c` 在哪」的事实：`f` 在某点不可导时 `c` 可能不在该点，但定理仍可能成立，只是不再由标准中值定理担保。这是映照的「条件依赖」：反映事实依赖前提条件，前提不满足时事实不成立或需其他定理替换。司衡治理类比：中值定理是「治理系统反查」的存在性担保：若治理输出在会话周期 `[t_0, t_1]` 上的平均变化率异常，则 trail 中至少存在一个时间点 `c` 其瞬时变化率也异常。反查机制只需验证平均 + 定位 `c` 存在即「已找到应辨点」，不必逐点检查全部 trail：这是 PRO-07 映照「只反映事实」与 PRO-08 应辨「应对已抵达挑战」的合并。`c` 的具体位置不需要 L79 锚句「不投射判断」即不要求定位精确坐标，只要求存在性被映照：这种「存在性担保 + 不投射位置」的反查范式是工程基线第三条「人类注意力只投向异常信号」的形式化基础：平均值异常 = 信号存在 = 治理介入点。
