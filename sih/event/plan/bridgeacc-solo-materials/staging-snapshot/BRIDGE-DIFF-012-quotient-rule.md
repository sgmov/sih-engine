## 哲学桥接 {#philosophy-bridge}

- 借鉴源：商法则 `d/dx [g(x)/h(x)] = [g'(x)·h(x) - g(x)·h'(x)] / [h(x)]²` 是乘积法则与链式法则的直接推论，可由 `g/h = g·h⁻¹` 的两步复合导出。莱布尼茨记号 `d(u/v) = (v·du - u·dv) / v²` 使其形式可记忆。前提条件：`h(x) ≠ 0`，分母趋于零时商法则不适用或导数趋于无穷。
- 哲学命题：PRO-05 间隙增长动力学，锚句「规约与实现的间隙随时间增大，增大速率与规则数量正相关」；PRO-06 法三 知止，锚句「法三：知止。知道不做什么，比知道做什么更难。」
- 形式化：商法则是「间隙」与「比率」的最精确数学仪器。令规约为分子 `g(t)`，实现为分母 `h(t)`，则 `R(t) = g(t)/h(t)` 是「规约覆盖率」或「对齐率」，`R'(t) = [g'(t)·h(t) - g(t)·h'(t)] / h(t)²` 是「对齐率的变化率」商法则将 `R'(t)` 分解为「分子增长贡献」`g'(t)/h(t)` 与「分母增长贡献」`-g(t)·h'(t)/h(t)²` 的竞争效应，二者方向相反，分母增长 `h'(t) > 0` 压低比率，分子增长 `g'(t) > 0` 抬高比率。PRO-05 L138 节点「间隙随时间增大，增大速率与规则数量正相关」即此商法则的工程实例：令 `g(t)` 为已规约规则数、`h(t)` 为总规则数，`R(t) = g(t)/h(t)` 是「规约覆盖率」，`R'(t) < 0` 当新增规则数超出规约速率，治理的「对齐率」持续下降：商法则的竞争效应分解清晰指出「规则数 `h'(t) > 0` 增长」是覆盖率下降的元凶，而非「规约速率 `g'(t) < 0` 不足」。条目工程映射「facet 审阅的异质性比率 = 分歧数 / facetor 总数」是商法则的另一极纯净工程形态：`H(t) = d(t)/n(t)`，`H'(t) = [d'(t)·n(t) - d(t)·n'(t)] / n(t)²` 分解「分歧增长」与「facetor 增长」对异质性比率的相反贡献：`n'(t) > 0` 即 facetor 数量增加压低异质性比率，分歧被摊薄；`d'(t) > 0` 即分歧本身增长抬高异质性比率；二者代数求和决定 `H(t)` 的单调性。商法则的「分母不为零」前提是数学层面最纯粹的「知止」PRO-06 L65「法三：知止。知道不做什么，比知道做什么更难」是商法则的本体论承诺：`h(x) = 0` 即规则的适用边界，规则在此点「停止生效」，不是「弱化」也不是「近似成立」而是「彻底不适用」。条目原文「分母趋于零时商法则不适用」与「在分母趋于零的点，导数可能趋于无穷大或不存在」是知止的工程本体：`h(x) → 0` 时 `R'(x) → ±∞`，规则失效的形式是「输出无界」而非「输出错误值」，是知止法「知道不做什么」最彻底的形式：连「错误答案」都不给，只给「此规则不适用」的退出信号。司衡治理类比：商法则是「规则增加 ↔ 规约覆盖率下降」耦合关系的解析核，若规则数随时间增长 `h'(t) > 0`，规约必须以更快速度增长 `g'(t) > h'(t)·g(t)/h(t)` 才能维持 `R'(t) ≥ 0`：这一条件等价于「新增规则的规约速率必须超过其规模占比的增长率」，是治理投入下界；不满足此条件即「知止失效」，系统注定退化。
