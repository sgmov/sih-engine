## 哲学桥接 {#philosophy-bridge}

- 借鉴源:麦克劳林级数是泰勒级数在展开点 a=0 时的特例,由科林·麦克劳林在 1742 年的《Treatise of Fluxions》中系统化。核心思想:用无穷多项多项式逼近函数,把光滑函数在零点附近表示为幂级数 sum(n=0 to infinity) f^(n)(0) x^n / n!。每项系数由 f 在零点的 n 阶导数决定,这是「局部导数值决定全局级数」的反直觉结构。麦克劳林级数不是单一公式,是一族以零点为中心的局部展开,通过收敛半径 R 划定「多远还能逼近」的边界。
- 哲学命题:PRO-06 法,锚句「法三:知止。知道不做什么,比知道做什么更难。」麦克劳林级数在工程中的实际使用,不是把无穷多项都算出来,而是截断到 N 项,丢弃高阶项,接受截断误差。这是「知止」在数学中的最纯粹形态:收敛半径 R 内的级数是无限的,工程层必须决定 N 截断,这一步不是「算不出来所以停」,而是「已经够用所以停」。始制有名,名亦既有,夫亦将知止,知止可以不殆：麦克劳林级数一旦被命名,就有「何时停止展开」的元问题。截断 N 的选择就是知止的判断:不追求与原函数绝对相等(那是无限项),也不放任截断误差过大(那是 N 太小),在「机器精度内可接受」处停。芝诺悖论 HIS-015 的现代解:无穷多项不能在有限步完成,但截断到 N 项可在有限步完成,「有限步完成逼近无穷」靠的就是「知止」在 N 处停止,误差由收敛性保证可被估出。
- 哲学命题:PRO-07 鉴,锚句「代码工程的"客观"是:在检验时不预设"应该是什么",只看"实际是什么"」麦克劳林级数的收敛判定是「鉴」的具体形态。收敛半径 R 由函数的解析性质决定,不预设「这个函数应该收敛到 R」,只看「级数 sum f^(n)(0) x^n / n! 的部分和在 |x| < R 时是否真的逼近 f(x)」。这是「在检验时不预设"应该是什么"」收敛判据只问「实际是否收敛」,不投射「因为这是 e^x 所以应该全局收敛」之类的形而上学偏好。e^x、sin(x)、cos(x) 的全局收敛是「实际计算结果」,不是「预设承诺」;ln(1+x) 在 x=-1 处的行为、1/(1-x) 在 |x|=1 上的行为,都需「实际计算部分和」后才能判定。收敛性判定的客观性:任何读者按相同的 N、x、f^(n)(0) 计算部分和必得同一截断误差,验证过程不投射「哪一项贡献最大」「哪个 x 最难逼近」之类的先入为主。

### 形式化 {#formalization}

- 知止作为截断:PRO-06 L65「法三:知止。知道不做什么,比知道做什么更难。」在本条目具象为：麦克劳林级数 f(x) = sum(n=0 to infinity) f^(n)(0) x^n / n! 在工程中永远被截断为 f_N(x) = sum(n=0 to N) f^(n)(0) x^n / n!。截断 N 的选择是「知止」的具体形态:不追求 N = infinity(那是无限步),也不放任 N 太小(那是误差过大),在「机器精度 epsilon 满足 |f(x) - f_N(x)| < epsilon」处停。始制有名的工程解读:级数 f(x) 一旦被命名,就有「该函数在 |x| < R 内可被泰勒级数表达」的元承诺,这一承诺本身是「始制有名」;N 的选择是「名亦既有,夫亦将知止」名字已经确立,现在要知道停止的边界。芝诺悖论的现代解:无穷多项不能在有限步完成,但「有限步逼近无穷」的合法性由收敛性保证：「有限 N 的部分和与极限的距离趋于零」,这是「知止」不损失严谨性的根据。工程映射:多轮对抗审阅的轮次选择是同构问题,前几轮已经逼近,后续轮次的边际贡献递减,可在「边际贡献低于阈值」处停：这正是麦克劳林级数收敛速度的工程类比。
- 客观作为收敛性判定:PRO-07 L53「代码工程的"客观"是:在检验时不预设"应该是什么",只看"实际是什么"」在本条目具象为：麦克劳林级数的收敛半径 R 由「级数 sum f^(n)(0) x^n / n! 的部分和是否真的逼近 f(x)」决定,不预设「这个函数应该收敛到 R」之类的承诺。e^x 的麦克劳林级数在所有 x 收敛是「实际计算结果」,不是「e^x 是好的所以应该全局收敛」的偏好。ln(1+x) 在 x=-1 处收敛、在 x=-1 之外发散也是「实际计算」,不是「ln 是好的所以应该全局收敛」的偏好。收敛性判定的客观性:任何读者按相同的 N、x 计算部分和,必得相同的截断误差,验证过程不投射「哪个 x 难逼近」「哪个函数有漂亮性质」之类的偏好。映照的工程形态:截断误差 |f(x) - f_N(x)| 是「实际偏离多少」的度量,不是「应该偏离多少」的判断：鉴用截断误差反映级数逼近的事实,不投射「误差应该小于 epsilon」的规约偏好。csnx 消息压缩采样的同构:取前 N 项、丢弃高阶项、估计截断误差,这是「客观」的具体工程实现,「取几项」由「实际偏离」决定,不由「应该偏离」预设。
- 收敛半径作为规约边界:麦克劳林级数 f(x) = sum f^(n)(0) x^n / n! 的收敛半径 R 是函数的内在属性,不由规约预设：同一函数在不同 x 上的行为是「实际计算」的结果,不是「应该是什么」的承诺。|x| < R 内级数收敛于 f(x) 是映照,|x| > R 内级数发散是映照,|x| = R 上需单独判断是映照：三种情况都是「实际是什么」,不投射「应该收敛」或「应该发散」的偏好。规约的边界由收敛半径划定,工程中截断 N 的选择与收敛半径 R 共同决定「在哪个 x、用多少项、误差多少」的完整策略,这是「规约与实现」的中介：规约层(收敛半径)R 与实现层(截断)N 的关系,正是道四「规约与实现必有间隙」的具体形态。
- 经典例子的客观性:e^x = 1 + x + x^2/2! + ... 在所有 x 收敛,这是「实际计算后才知道」的事实,不是「e^x 应该全局收敛」的承诺。sin(x) = x - x^3/3! + x^5/5! - ... 在所有 x 收敛也是计算结果。1/(1-x) = 1 + x + x^2 + ... 只在 |x| < 1 收敛更是「实际计算」的强约束：几何级数在 |x| >= 1 时发散,不是「几何级数应该只在小 x 收敛」的偏好,而是「部分和真的不逼近 1/(1-x)」的事实。ln(1+x) = x - x^2/2 + x^3/3 - ... 在 -1 < x <= 1 收敛,这是「实际计算」后的事实,每个例子都是「客观」的体现。
- 与其他概念的关系:上游 SER-001 无穷级数：麦克劳林级数是无穷级数在幂函数系下的特例。DIFF-023 泰勒定理：本条目是泰勒定理在 a=0 时的展开。DIFF-032 瞬时速度的导数：麦克劳林级数系数的计算依赖各阶导数在零点的值。下游 SER-003 泰勒级数：本条目是泰勒级数的零点特例。同层 SPEC-003 指数函数：e^x 的麦克劳林级数是指数函数与级数展开的桥梁。SPEC-001 自然对数：ln(1+x) 的麦克劳林级数是对数函数与级数展开的桥梁。SPEC-006 斯特林近似：斯特林公式用麦克劳林级数思想推导 n! 的渐近行为。
- 边界:麦克劳林级数只在收敛域内有效,收敛域外的展开不等于原函数,甚至发散,收敛域的判定是 LIM-001 极限的职责。麦克劳林级数要求函数在展开点处无穷可导,不可导或不光滑的函数不在其覆盖范围内,傅里叶级数 SER-004 可以处理不光滑函数。麦克劳林级数是泰勒级数的特例,展开点不为零时必须用泰勒级数的一般形式。
