## 哲学桥接 {#philosophy-bridge}

- 借鉴源：偏导数是多元微积分的基础运算，将单变量导数推广到多变量函数。欧拉在流体力学与变分法中大量使用多元微分运算，玛丽盖尔蒙在曲面论中系统使用偏导数描述曲面几何性质，高斯在微分几何中深化其应用。形式上 partial f/partial x_i = lim(h->0) [f(x_1, ..., x_i+h, ..., x_n) - f(x_1, ..., x_i, ..., x_n)] / h，几何意义是沿 x 方向切线斜率此时 y 固定。Clairaut 定理说明混合偏导与求导顺序无关。
- 哲学命题：PRO-07 鉴，锚句「客观：不预设立场，不急于下判断」；PRO-05 道四规约与实现必有间隙，锚句「「绝对正确」被否定」。
- 形式化：偏导数是 PRO-07 客观在多元分析中的最小程序化实例。LIM-007 形式段「partial f/partial x_i = lim(h->0) [f(x_1, ..., x_i+h, ..., x_n) - f(x_1, ..., x_i, ..., x_n)] / h」即 h 只动第 i 个变量其他变量保持固定 = PRO-07 L78「客观：不预设立场，不急于下判断」的具体形态：「保持其他变量固定」是「不预设立场」的程序化即其他维度上不主动投射变化只让目标维度 h 自变；极限 lim h->0 是「不急于下判断」的程序化即在 h 趋近 0 的过程中才下结论不提前断言。LIM-001 应用映射段「partial Q/partial accuracy 描述仅当准确性变化时质量如何变化保持其他维度不变」是这一定义的工程版：准确性维度的偏导数是质量函数对该维度的客观反映即保持其他维度不变不投射其他维度的变化。LIM-001 形式段「Clairaut 定理混合偏导与求导顺序无关」= 「客观」的进一步实例：先 partial x 再 partial y 与先 partial y 再 partial x 给出相同结果是「不预设立场」在求导顺序维度的体现即不预设求导顺序应该先 y 后 x 还是先 x 后 y，结果独立于顺序。另一锚 PRO-05 刻画偏导数不蕴含整体可微的间隙。LIM-001 边界段「偏导数存在不保证函数连续或可微，多变量函数可能对每个变量都可偏导但作为整体不连续」= PRO-05 L102「「绝对正确」被否定」的具体形态：「每个变量都可偏导」是规约即对每个维度的局部行为都有规定，「整体不连续」是实现即整体行为不符合规约的预期；偏导数存在即「规约」对每个维度有定义但「实现」的连续性不被规约完全决定。LIM-001 形式段「梯度是所有一阶偏导数排成的向量指向函数值增长最快的方向」= PRO-05 L102 的逆向运用：梯度是「规约」对函数局部行为的完整描述 = 把所有维度的偏导数整合为一个向量，指向增长最快方向是「实现」即梯度方向上函数值的实际增长；规约对每个维度的偏导数 + 实现的方向整合 = 偏导数作为「规约的最小单元」与梯度作为「实现的整合形态」的对应。LIM-001 边界段「全微分的条件比偏导数存在更强」= PRO-05 L102 的工程版：「全微分」是更强的规约即要求偏导数存在且连续，对应「实现」即可微函数；「偏导数存在」是更弱的规约，对应的「实现」是可能不连续的函数，与 PRO-05 L102「规约不可能完全决定实现」同源。工程映射，司衡治理系统的「多维度可验证性的独立分析」是偏导数的工程版：工程基线第四条可验证性约束的多维指标中偏导数量化改变某一验证维度对整体可验证性的影响保持其他维度不变 = PRO-07 L78 客观在多维治理中的实例化；机器学习梯度下降直接使用偏导数是治理优化问题的最常见形式：与 LIM-001 应用映射段「梯度下降法直接使用偏导数」是同一结构。
