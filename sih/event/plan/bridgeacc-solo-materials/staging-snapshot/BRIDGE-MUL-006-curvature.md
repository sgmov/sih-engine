## 哲学桥接 {#philosophy-bridge}

- 借鉴源：「曲率」是曲线或曲面在某点偏离直线的程度，是微分几何的基础概念。平面曲线的曲率 `κ = |f''(x)| / (1 + [f'(x)]^2)^(3/2)`，曲率越大弯曲越剧烈。弧长参数化下曲率 `κ = |r''(s)|`，即位置向量对弧长的二阶导数的模，「`r'(s)` 是单位切向量，`r''(s)` 是法向量，其大小就是曲率」。曲率半径 `R = 1/κ` 是曲线在该点最接近的圆的半径。曲面在一点有两个主曲率 `κ_1, κ_2`，高斯曲率 `K = κ_1·κ_2`，平均曲率 `H = (κ_1+κ_2)/2`。高斯绝妙定理：高斯曲率仅依赖曲面上的度量，不依赖曲面在三维空间中的嵌入方式，是内蕴几何性质。曲率的历史从牛顿莱布尼茨时代到欧拉系统研究再到高斯发现内蕴性质，最终导向黎曼几何与广义相对论。
- 哲学命题：PRO-05 道四，锚句「道四：规约与实现必有间隙。」「弯曲程度」是规约层的几何直觉，是经验性的认知；曲率公式 `κ = |f''|/(1+f'^2)^(3/2)` 是实现层的代数形式。规约「弯曲是一个定性的直觉」与实现「曲率是 `|f''|/(1+f'^2)^(3/2)` 这个特定公式」之间必有间隙。间隙的具体形态是「规约对『弯曲』的描述不充分」几何直觉只能定性区分「很弯」、「略弯」、「不弯」三档，无法区分 `κ = 0.5` 与 `κ = 0.6` 的差异。实现层的公式给出了精确的实数，把定性直觉细化为可比较的数值。这就是「规约与实现必有间隙」在几何度量中的具体化：规约「弯曲的强弱」与实现「`κ` 的具体数值」之间存在信息密度的差距，规约不能完全决定实现，实现必然有规约未定义的精度。间隙在「高斯绝妙定理」中显式暴露：规约层的「弯曲」可以理解为「曲面在三维空间中的弯曲」即外在弯曲，实现层的高斯曲率是「内蕴弯曲」即仅依赖曲面度量不依赖嵌入。规约「外在弯曲」与实现「内蕴弯曲」之间有间隙，高斯的洞察恰好是「内蕴弯曲等于高斯曲率」，让规约与实现重新对齐。但对齐不等于消除间隙：「外在直觉」与「内蕴公式」之间的对应仍然是规约对实现的工程化映射，不是等同。
- 哲学命题：PRO-07 鉴，锚句「映照：只反映事实，不投射判断」弧长参数化下曲率 `κ = |r''(s)|` 是「映照」在微分几何中的具体化。`r(s)` 是位置向量对弧长的参数化，`r'(s)` 是单位切向量即 `|r'(s)| = 1` 是事实。`r''(s)` 是切向量的变化率即弯曲的方向，`|r''(s)|` 是变化率的大小即曲率，是「映照」`r''(s)` 把切向量的变化事实直接映照为弯曲程度的数值。映照不投射「切向量变化应该多大才算弯曲」的判断，不投射「曲率应该用其他几何度量」的偏好。映照的可验证性是「对直线 `r(s) = (s, 0)`，`r'(s) = (1, 0)`，`r''(s) = 0`，`κ = 0`」与几何直觉「直线不弯曲」一致；对圆 `r(s) = (R·cos(s/R), R·sin(s/R))`，`r'(s) = (-sin(s/R), cos(s/R))`，`r''(s) = (-cos(s/R)/R, -sin(s/R))/R`，`κ = 1/R` 与「半径为 `R` 的圆曲率为 `1/R`」一致。映照在简单情况下可由初等几何直接验证。

### 形式化 {#formalization}

设平面曲线 `y = f(x)`，曲率 `κ = |f''(x)| / (1 + [f'(x)]^2)^(3/2)`。弧长参数化下 `κ = |r''(s)|`。

- 规约与实现间隙的具体化：PRO-05 L15「道四：规约与实现必有间隙。」在曲率公式中具象为：「规约」即「弯曲的几何直觉」，是经验层的认知。「实现」即「`κ = |f''|/(1+f'^2)^(3/2)`」，是代数层的公式。间隙的具体形态是「规约对弯曲的描述是定性的」「很弯」、「略弯」、「不弯」三档是粗粒度。「实现」对弯曲的描述是定量的：`κ` 是实数，可精细到任意小数位。规约的「很弯」对应 `κ > 0.5` 还是 `κ > 1`？不同场景阈值不同，规约层不固定阈值。实现层的公式给出 `κ` 的精确值，但「多大算弯曲」需要工程化约定。间隙在高斯绝妙定理中显式：「规约层把弯曲理解为外在的即『曲面在三维空间中的形状』，实现层的高斯曲率是内蕴的即『仅依赖曲面度量』，两者不必等同」。高斯的发现是「内外两种弯曲在外在曲面上相等」即高斯曲率等于外在曲率乘积，但这一相等不是规约与实现的同一性，是「外在事实与内蕴事实的数值巧合」。间隙不可消除：规约的「外在直觉」与实现的「内蕴公式」始终有「为什么相等」的认知差距，治理这一差距需要「高斯绝妙定理」作为专门的桥。
- 映照作为弧长参数化：PRO-07 L79「映照：只反映事实，不投射判断」在曲率弧长形式中具象为：「事实」即「`r(s)` 是弧长参数化」即 `|r'(s)| = 1`，是参数化的代数事实。「映照」即 `r''(s)` 直接给出曲率向量，其大小 `|r''(s)|` 给出曲率。映照不投射「切向量变化应该用什么基」的判断：`r''(s)` 在切向量正交方向上的分量即法向分量就是曲率，不掺杂「切向分量应该贡献曲率」的投射。映照的可验证性是「直线 `r(s) = (s, 0)` 与圆 `r(s) = (R·cos(s/R), R·sin(s/R))`」的初等验证。`r(s)` 是弧长参数而非一般参数，这是「映照的输入约束」只有弧长参数化下 `r'(s)` 才是单位切向量，曲率公式 `|r''(s)|` 才直接成立；一般参数化下需要先做 `s = s(t)` 变换。
- 主曲率与高斯曲率：曲面上一点有两个主曲率 `κ_1, κ_2`，是法曲率在所有方向中的最大值与最小值：欧拉发现。`κ_1, κ_2` 是曲面的两个内蕴量，是「曲率在两个独立方向上的分解」。高斯曲率 `K = κ_1·κ_2` 是两个主曲率的乘积，刻画「曲面的整体弯曲」即正曲率如球面、负曲率如鞍面、零曲率如平面。平均曲率 `H = (κ_1+κ_2)/2` 刻画「曲面的平均弯曲」。`K` 与 `H` 一起描述曲面的局部形状，是「曲率从一维曲线到二维曲面的扩展」把单值 `κ` 升级为二元组 `(K, H)` 或 `({κ_1, κ_2})`。这一扩展是「法的复用」同一曲率概念在更高维度上的自然推广，不引入新判断。
- 高斯绝妙定理的认识论地位：高斯曲率「仅依赖曲面上的度量，不依赖曲面在三维空间中的嵌入方式」这一发现在认识论上是重大事件。规约层「弯曲」通常理解为「外在弯曲」即「曲面在三维空间中的形状」，实现层的高斯曲率是「内蕴弯曲」即「曲面本身的度量结构」。高斯绝妙定理让两者在数值上相等：「外在形状的事实」等于「内蕴度量的事实」。这一相等让高斯曲率成为「不依赖观察者视角的几何量」曲面内的二维生物不需要抬头看三维空间就能测量自己所在曲面的弯曲。这是「映照的客观性」在微分几何中的极致体现：曲率是曲面的内在事实，不依赖外部观察。
- 边界：曲率描述的是几何弯曲程度，不描述曲线或曲面的拓扑性质，拓扑性质是代数拓扑的范畴。曲率是局部性质，每一点的曲率可能不同，全局性质需要曲率的积分，属于整体微分几何的范畴。平面曲线的曲率与空间曲线或曲面曲率的定义不同，不能混用。空间曲线需要挠率来完全描述，曲面需要主曲率或高斯曲率。这一边界是「曲率概念的适用域」平面曲线用单值 `κ`，空间曲线需要 `κ` 与挠率 `τ`，曲面需要主曲率或高斯曲率，每一层有各自的形式化。
- 与其他概念的关系：上游 DIFF-001 导数与 MUL-001 偏导数：曲率公式的 `f'(x)`、`f''(x)` 来自导数定义，曲面主曲率来自偏导数。海森矩阵 MUL-005：主曲率是海森矩阵的特征值的几何解释。INT-020 弧长：弧长参数化是 `κ = |r''(s)|` 的前提。下游 MUL-007 格林定理与 MUL-009 斯托克斯定理：曲率是这些定理的局部输入。同层 DIFF-032 瞬时速度的导数：瞬时速度的导数即瞬时加速度，与曲线参数化的二阶导数同源，曲率是弧长参数化下二阶导数的模。
