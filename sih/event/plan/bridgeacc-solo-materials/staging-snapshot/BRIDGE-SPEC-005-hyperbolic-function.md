## 哲学桥接 {#philosophy-bridge}

- 借鉴源:双曲函数由约翰·海因里希·兰伯特 18 世纪在研究双曲线几何时系统引入,核心定义通过指数函数给出:sinh(x) = (e^x - e^(-x))/2,cosh(x) = (e^x + e^(-x))/2,tanh(x) = sinh(x)/cosh(x)。双曲函数与三角函数形式对称但代数性质不同:cosh^2(x) - sinh^2(x) = 1 取代了 sin^2 + cos^2 = 1,符号的系统差异反映了 x^2 - y^2 = 1 与 x^2 + y^2 = 1 的本质区别。导数 d/dx sinh(x) = cosh(x),d/dx cosh(x) = sinh(x)：与三角函数不同,cosh 没有周期性,因为双曲函数不会回到自身。19 世纪悬链线问题的解决使双曲函数进入工程应用:悬链线 y = a cosh(x/a) 恰好是 cosh 的图像。
- 哲学命题:PRO-01 立名本体论,锚句「引导:名字引导后续推导的方向,从名字派生的概念决定哪些展开被允许、哪些被禁止」双曲函数的名字「hyperbolic」引导了整族函数的推导方向。名字「hyperbolic」框定了函数的几何来源:与双曲线 x^2 - y^2 = 1 关系密切,正如三角函数「trigonometric」框定与单位圆 x^2 + y^2 = 1 的关系。从这一名字派生的概念包括:cosh^2 - sinh^2 = 1 的恒等式(取代了 sin^2 + cos^2 = 1)、cosh 没有周期性(取代了 sin、cos 的周期性)、参数方程 (cosh t, sinh t) 在双曲线上的运动(取代了 (cos t, sin t) 在圆上的运动)。名字「hyperbolic」被禁止的推导:不能从双曲函数推导出周期性(被名字承诺排除)、不能推导出 sin^2 + cos^2 = 1 形式(被名字承诺排除)。立名本体论的关键判据:名字不是标签,名字是「哪些展开被允许、哪些被禁止」的本体论承诺。双曲函数的具体化:18 世纪兰伯特在引入这一族函数时,名字的选择决定了后续所有推导的形式：若命名为「exp-based functions」,推导方向会偏向指数函数性质;命名为「hyperbolic」,推导方向偏向几何性质。两种命名都「正确」,但引导的推导不同。
- 哲学命题:PRO-04 道三,锚句「代码不会自行揭示意图：作为符号系统,代码的含义天然不是自明的。维护之前必须先恢复意图,恢复是维护的因果前提。」双曲函数的代码层(定义)与意图层(名字承诺)之间存在自晦。代码:sinh(x) = (e^x - e^(-x))/2,cosh(x) = (e^x + e^(-x))/2：这是符号化的、显式的、可用 exp 展开的代码。意图:sinh、cosh 是「hyperbolic functions」这一意图不在代码中显式存在,代码没有「hyperbolic」字样,也不直接显示与双曲线 x^2 - y^2 = 1 的关系。代码自晦:sinh(x) = (e^x - e^(-x))/2 不会自行揭示「这是与双曲线相关的函数」,只显示「这是两个指数函数的差的一半」。意图必复:从代码恢复意图,必须先理解「(cosh t, sinh t) 是双曲线的参数方程」这一理解是「意图必复」的具体形态,不能在符号中直接读取,必须经过「参数化双曲线」的恢复动作。cos^2 + sin^2 = 1 替成 cosh^2 - sinh^2 = 1 不是「符号差」,是「意图差」:圆是闭合的、双曲线是开放的,意图决定了「恒等式是求和还是求差」,代码只显示「求差」,意图显示「为什么求差」。

### 形式化 {#formalization}

- 名字引导推导:PRO-01 L17「引导:名字引导后续推导的方向,从名字派生的概念决定哪些展开被允许、哪些被禁止」在本条目具象为：双曲函数的名字「hyperbolic」框定了函数的性质来源:与双曲线 x^2 - y^2 = 1 关系密切。名字派生的概念:(1)cosh^2(x) - sinh^2(x) = 1 的恒等式：这是「hyperbolic」的核心承诺,与三角函数 sin^2 + cos^2 = 1 形成对照;(2)cosh 没有周期性：双曲线开放,不像圆闭合,所以 cosh 不会回到自身;(3)参数方程 (cosh t, sinh t) 满足 x^2 - y^2 = cosh^2 t - sinh^2 t = 1,在双曲线上运动：这是「hyperbolic」名字的几何承诺。名字禁止的推导:不能从双曲函数推导周期性(被名字承诺排除);不能从双曲函数推导 sin^2 + cos^2 = 1 形式(被名字承诺排除);不能从双曲函数推导有界性(被名字承诺排除,cosh 趋于无穷)。立名本体论的关键判据:18 世纪兰伯特命名时,「hyperbolic」的选择决定了后续所有推导的形式：若命名为「exp-based functions」,推导方向偏向指数性质;命名为「hyperbolic」,推导方向偏向几何性质。两种命名都「正确」,但引导的推导不同,这是「名字引导后续推导」的工程化体现。
- 代码自晦与意图必复:PRO-04 L17「代码不会自行揭示意图：作为符号系统,代码的含义天然不是自明的。维护之前必须先恢复意图,恢复是维护的因果前提。」在本条目具象为：sinh(x) = (e^x - e^(-x))/2 是「代码」层,显式、可计算、可用 exp 展开为 sum x^(2n+1)/(2n+1)!,这是符号系统的固有属性。意图:sinh、cosh 是「hyperbolic functions」,与双曲线 x^2 - y^2 = 1 关系密切：这一意图不在代码中显式存在,代码只有「(e^x ± e^(-x))/2」,没有「hyperbolic」字样。代码自晦:sinh(x) = (e^x - e^(-x))/2 不会自行揭示「这是与双曲线相关的函数」,只显示「这是两个指数函数的差的一半」。从代码恢复意图,必须先理解「(cosh t, sinh t) 是双曲线的参数方程」,这一理解不能从代码直接读出,必须经过「参数化双曲线」的恢复动作。cosh^2 - sinh^2 = 1 替成 sin^2 + cos^2 = 1 是「意图差」:圆是闭合的、双曲线是开放的,意图决定了「恒等式是求和还是求差」,代码只显示「求差」,意图显示「为什么求差」。sinh 的反函数 arsinh(x) = ln(x + sqrt(x^2 + 1)) 在 x → ∞ 时趋于 ln(2x),在 x → -∞ 时趋于 -ln(-2x)：这一渐近行为不在反函数定义中显式存在,必须从「arsinh 是对数尺度」这一意图恢复。
- 导数对称性:sinh 与 cosh 的导数构成互导对：d/dx sinh = cosh, d/dx cosh = sinh。这与 sin、cos 的导数关系同构(差一个符号),但本质不同:sin 与 cos 是周期函数,sinh 与 cosh 是单调函数。导数同构反映代码层同构,导数结果的性质差异反映意图层差异：这是「代码同构、意图不同」的典型案例。cosh^2 - sinh^2 = 1 对 x 求导得 2 cosh sinh' - 2 sinh cosh' = 2 cosh^2 - 2 sinh^2 = 2,这是「恒等式稳定」的体现,也是「代码自洽」的体现：但「为什么求和替成求差」不在代码中显式存在,必须从「双曲线是 x^2 - y^2 = 1」的意图恢复。
- 饱和函数 tanh:tanh(x) = sinh(x)/cosh(x) = (e^x - e^(-x))/(e^x + e^(-x)) 是 (-1, 1) 区间的饱和函数,导数 sech^2(x) = 1 - tanh^2(x) 处处可微。这一性质是「名字引导推导」的另一例证:若不命名「hyperbolic」,tanh 可能被命名为「sigmoid」或「saturation function」,推导方向会偏向神经网络或优化;命名为「hyperbolic」,推导方向保留与 sinh、cosh 的关系。tanh 的工程映射:对抗强度建模、信号压缩、神经网络激活：这些应用都利用 tanh 的「饱和」性质,即「初始线性、最终饱和」的结构。这一结构在「hyperbolic」名字下是「cosh/sinh 之比的极限行为」,在「sigmoid」名字下是「sigmoid 曲线的标准形态」名字引导了从哪个角度理解同一函数。
- 悬链线的工程意义:y = a cosh(x/a) 是均匀重力场下柔性绳索的自然形状,这一应用体现了「hyperbolic」名字的工程价值：不是所有「exp-based functions」都能描述悬链线,只有 cosh(因为它在 x=0 处的二阶导数等于自身)才能描述悬链线。从 cosh 的定义 (e^x + e^(-x))/2 恢复「为什么 cosh 描述悬链线」的意图,必须经过「微分方程 y'' = y 的解」的恢复动作：这又是「意图必复」的具体化。
- 与其他概念的关系:上游 SPEC-003 指数函数：双曲函数通过 exp 定义。SPEC-002 e：双曲函数的底数。SPEC-004 双曲角：双曲角的几何定义与双曲函数紧密相关。下游 SER-003 泰勒级数：sinh、cosh 的泰勒级数展开只含奇次或偶次项,这是「hyperbolic」名字承诺的代数性质。同层 SPEC-001 自然对数：反双曲函数用对数表达,arsinh、arcosh、artanh 的定义都用 ln。SPEC-006 斯特林近似：双曲函数在渐近分析中与斯特林公式相关。
- 边界:双曲函数虽然形式上与三角函数对称,但不具备周期性,cosh(x) 在 x 趋于无穷时趋于无穷,sinh(x) 同理,周期振荡问题是三角函数的范畴不是双曲函数的范畴。双曲函数是实值函数到实值的映射,不处理复数域的解析性质,复数域上的推广是复分析的内容。双曲函数不解决双曲空间的度量问题,双曲空间的距离和曲率是微分几何的范畴,双曲函数只是其中的计算工具之一。
