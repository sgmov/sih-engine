## 哲学桥接 {#philosophy-bridge}

- 借鉴源：「22/7 超过圆周率的证明」是经典的积分不等式证明。核心构造是函数 `f(x) = x^4(1-x)^4/(1+x^2)`，在 `[0,1]` 上恒非负。证明者先对分子做多项式长除法得到 `f(x) = x^6 - 4x^5 + 5x^4 - 4x^2 + 4 - 4/(1+x^2)`，再逐项积分得 `∫_0^1 f(x) dx = 1/7 - 4/6 + 5/5 - 4/3 + 4 - 4·arctan(1) = 22/7 - π`。因为被积函数 `f(x)` 在 `[0,1]` 上恒非负，且仅在端点 `x=0` 与 `x=1` 处为零，所以积分严格大于零，故 `22/7 - π > 0`，即 `π < 22/7`。整条证明链由「构造可见的非负被积函数」与「机械积分计算」两步组成，前者保证符号方向，后者给出数值结果。`22/7` 是自古巴比伦就使用的圆周率近似，证明者并未主张它是最佳近似，只是用积分工具给出「近似值大于真实值」这一严格方向。
- 哲学命题：PRO-07 鉴，锚句「映照：只反映事实，不投射判断」构造出的被积函数 `f(x) = x^4(1-x)^4/(1+x^2)` 是「事实」，其恒非负性质是代数事实而非判断。`x^4(1-x)^4` 在 `[0,1]` 上是四次方乘四次方，必然非负；除以 `1+x^2` 始终为正的分母，结果仍非负。这是「映照」在证明构造中的具体化：证明者不投射「这一函数可能为负」的判断，也不投射「这一积分可能等于零」的侥幸。映照是「只看被积函数在 `[0,1]` 上的非负性是代数事实」`x ≥ 0` 与 `1-x ≥ 0` 在 `[0,1]` 上同时成立，四次方后仍非负，分母 `1+x^2 > 0` 让整体保持非负。映照不投射：不投射「可能分子分母同时为零」的怀疑，因为分子的零点 `x=0` 与 `x=1` 都是孤立的端点，区间内部的 `0 < x < 1` 严格让被积函数为正。积分映照积分对象的非负性，输出「严格大于零」是事实的直接投射。
- 哲学命题：PRO-08 应，锚句「应而不藏：如实应对，不藏不掖」`π` 与 `22/7` 谁大谁小是一个已存在但未严格确认的挑战，证明是「应辨当下」在数学中的具体化。证明者「应而不藏」把多项式长除法、逐项积分、`arctan(1) = π/4` 的代入、最终 `22/7 - π` 的相减：所有中间步骤全部显式写出，不藏不掖。证明不在「`22/7` 与 `π` 接近」上含糊其辞，不在「两者差距很小」上模糊处理，直接给出「`22/7 - π > 0`」的严格方向。应而不藏在此即「把 22/7 与 π 的差距符号不掩盖地写出来」。应辨当下的「辨」对应「符号判断」`∫_0^1 f(x) dx > 0` 是对 `22/7` 与 `π` 大小关系的最终辨归，结果可被任何读者按相同步骤重算复核。

### 形式化 {#formalization}

设 `f(x) = x^4(1-x)^4/(1+x^2)`，区间 `[0,1]`。

- 映照作为构造：PRO-07 L79「映照：只反映事实，不投射判断」在本证明中具象为：「事实」是 `f(x)` 在 `[0,1]` 上的非负性，是代数结构自明的。「映照」即证明者不引入任何额外假设，直接把 `f(x) ≥ 0` 这一代数事实映射到积分严格正的结果。映照的载体是「积分保序性」非负函数的积分非负，连续非负且不恒为零的函数的积分严格正。映照不投射「`f(x)` 在 `[0,1]` 之外的行为」，不投射「被积函数可能是周期函数之类的猜测」，不投射「积分可能受高阶项影响」之类的复杂化判断。检验是「被积函数在端点 `x=0` 与 `x=1` 处为零，区间内严格正」这一检验用初等代数即可完成，映照的可验证性由代数恒等式承载。
- 应而不藏作为显式步骤：PRO-08 L52「应而不藏：如实应对，不藏不掖」在本证明中具象为：`f(x)` 的多项式长除法被显式列出：`x^4(1-x)^4/(1+x^2) = x^6 - 4x^5 + 5x^4 - 4x^2 + 4 - 4/(1+x^2)`。每一步都是机械的代数变形，不藏「为什么分子分母是这种特定组合」的构造意图，但每一步变形都写出供复核。逐项积分 `1/7 - 4/6 + 5/5 - 4/3 + 4` 与 `4·arctan(1) = π` 的代入都不藏不掖。证明者不写「这一步显然」「这一步容易验证」之类的省略，把所有数值带入显式化。最终 `22/7 - π > 0` 是对 `π` 与 `22/7` 大小关系的如实输出，应对的成功：证实 `22/7 > π`：不夸大，应对的限制：`22/7` 不是最佳近似：不掩盖。
- `arctan(1) = π/4` 的事实链：证明链中 `arctan(1)` 的值是 `π/4`，这一事实来自三角学基本定义，不来自本证明的构造。`arctan(1) = π/4` 是「事实输入」它由 `tan(π/4) = 1` 这一单位圆上的事实承载，不依赖本证明的构造意图。本证明把 `arctan(1)` 的事实带入积分链，是「事实链的连接」`arctan(1) = π/4` 让 `4·arctan(1) = π` 进入最终表达式，从而 `22/7 - π` 作为积分值出现。事实链的可验证性是「任意读者按相同步骤重算得到同一结果」。
- 边界：本证明回答的是 `π` 与 `22/7` 的大小关系，不回答 `π` 的精确计算或更高精度近似。`22/7` 不是 `π` 的最佳有理近似，`355/113` 给出更高精度。本证明的意义在于方法论的示范，不在于近似精度本身。`x^4(1-x)^4/(1+x^2)` 的构造不是「自然涌现」它是证明者的工程选择。同一思路可推广到构造 `∫_0^1 g(x) dx = a/b - π` 的其他有理近似上界或下界，例如 `g(x) = x^4(1-x)^4/(1+x^2)^2` 给出 `π > 3.14` 类的不等式。这一边界是「构造的工程性」被积函数不是数学对象的固有结构，是证明者针对结论构造的工程性装置。
- 与其他概念的关系：上游 INT-006 卡瓦列里求积公式与 INT-001 反导数或不定积分：本证明依赖多项式逐项积分的能力与 `arctan` 反导数公式。下游无。SPEC-001 自然对数与 SER-001 无穷级数：`22/7` 与 `π` 的高精度比较有 `arctan` 级数展开的方法，即马青公式，但本证明是构造法而非级数法。同层 INT-017 梯形法则：梯形法则是数值积分的近似法，本证明是精确积分给出严格不等式，方法论上互补。
