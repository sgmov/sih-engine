## 哲学桥接 {#philosophy-bridge}

- 借鉴源：驻点是函数 `f` 在点 `c` 处满足 `f'(c) = 0` 或 `f'(c)` 不存在的点，是极值的必要条件但非充分条件：费马在 17 世纪用「伪等式」方法寻找此类点，Newton 与 Leibniz 将其与极值显式关联。工程中驻点是优化算法的起点，优化算法在 `f'(c) = 0` 附近停止迭代；但驻点可能是局部最优而非全局最优，需结合 DIFF-019 极值定理判断。
- 哲学命题：PRO-08 应本体安住，锚句「应本体安住时无应变动作」；PRO-05 间隙增长动力学，锚句「间隙随时间增大」。
- 形式化：驻点是「应本体安住」在微分几何中的最小表达：`f'(c) = 0` 即「变化率为零」，PRO-08 L9 锚句「应本体安住时无应变动作」的算子等价。设治理状态由函数 `Q(t)` 描述，PRO-08 的「应变」是「`Q'(t) ≠ 0` 时的应对过程」，`Q'(t) = 0` 即「应本体安住」的瞬时相：`Q` 不变化，应变动作无触发条件，治理系统进入稳态。条目原文「优化算法在这些点附近停止迭代」是工程层面的应本体安住：迭代步长 `Δx` 满足 `|∇Q(x)| < ε` 时算法停止，`|∇Q(x)| = 0` 即驻点：停止的判据是「变化率足够小」而非「达到全局最优」，是「安住」不是「到达」。条目工程映射「目标函数对参数的导数为零标记了当前配置的最优值」是 PRO-08 应本体安住的工程本体：`dQ/dθ = 0` 时参数 `θ` 处于「安住点」，后续动作的触发条件 `|dQ/dθ| > 0` 不满足，应变动作挂起。PRO-05 L142 节点「间隙随时间增大」是驻点的「必要不充分」性质的本体论来源：`f'(c) = 0` 仅是「局部安住」，系统在此点的间隙增长并未停止：间隙 `G(t)` 在驻点处仍服从 `dG/dt = k·R(t) > 0`，当规则数 `R(t)` 持续增加时，间隙持续增长，优化算法误以为「已收敛」实际只达局部最优。条目原文「f'(c) = 0 的点不一定是极值」是 PRO-05 的工程映射：`f'(c) = 0` 是「必要条件」是间隙在局部被「临时安住」的微分镜像：`dQ/dt = 0` 不代表 `Q` 达全局最优，只是局部 `Q'(t) = 0`；同理，驻点 `c` 是「局部间隙稳定」点，不是「全局对齐」点，二阶判据 `f''(c) ≠ 0` 才能区分极大与极小但仍不能区分局部与全局。条目工程映射「驻点可能是局部最优而非全局最优，需要结合极值定理 DIFF-019 判断」是 PRO-05 间隙增长对 PRO-08 应本体安住的修正：安住仅在局部成立，间隙在全局持续增长，全局优化要求 PRO-05 节点「间隙不静止，小错积累成大偏」的工程意识：`Q''(c)` 的符号与大小共同决定局部极值类型，「极值点 ≠ 全局最优」是间隙结构性增长的工程本体。司衡治理类比：驻点是治理系统「参数调优」停止判据的最小表达，治理参数 `θ` 达 `dQ/dθ = 0` 时停止迭代，但 PRO-05 间隙增长是不可避免的：`θ` 的局部最优不等于「治理全局最优」，需要周期性重启优化，多起点采样，应本体安住被间歇性打破，应几介入，否则系统陷入局部最优而间隙持续累积。
