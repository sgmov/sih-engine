## 哲学桥接 {#philosophy-bridge}

- 借鉴源：Euler 18 世纪将微积分发展为系统的分析工具,引入现代数学记号体系 f(x) / e / i / π / Σ / Δ,这些记号全部沿用至今;Euler 公式 e^{ix} = cos x + i sin x,Euler 恒等式 e^{iπ} + 1 = 0,巴塞尔问题 sum 1/n² = π²/6;Euler 中年失明但生产力未减;Euler 师从 Johann Bernoulli,继承 Newton-Leibniz 传统并推进至多变量 / 复变量 / 变分法。Euler 大量使用 HIS-014 代数的一般性方法,将有限代数规则大胆应用于无穷级数,不严格但有效,Cauchy 后在 Cours d'Analyse 拒绝此方法。
- 哲学命题：PRO-01 立名本体论,锚句「名字不是标签，名字是本体性的，是关于"被命名的是什么"的最早承诺。一旦名字确立，后续的推导、定义、工程实现都受这个名字约束」;PRO-05 道四规约与实现必有间隙,锚句「道四也是道家"大成若缺"在司衡哲学中的具体化：最完美的系统必然有"缺"，缺不是缺陷，是系统的本质」。
- 形式化：Euler 记号体系是「立名本体论」在数学史上的最大样本。f(x) 框定「函数在 x 处的值」这一内涵,后续推导如极限 / 连续 / 导数 / 积分全部受 f(x) 框定,不能脱离 f(x) 谈函数行为;e 框定「自然对数底」,e^x 与 ln x 互逆关系由此承载;i 框定「虚数单位」,i² = -1 是后续复分析的承诺入口;π 框定「圆周率」,所有圆的弧度测量与三角函数周期由此承诺;Σ 框定「求和」,无穷级数与有限求和的语法共享同一符号,这一记号承诺直接引发 Euler 用 Σ 处理无穷级数的「代数的一般性」方法;Δ 框定「有限差分」,与微分算子 d 的关系即微积分基本定理的另一形态。锚句「名字不是标签,名字是本体性的」:Euler 引入的 f(x) / e / i / π / Σ / Δ 沿用至今 250 年,任何工程文档 / 编程语言 / 数学软件都强制使用此套记号,= 立名的本体性,名字不因「不实用」而被替换,即 PRO-01 名字参与构成被命名者,= 名字框定后续推导方向的具体形态。司衡工程层对应,司衡引擎的术语登记即「立名」的具体动作,每条术语一旦登记即承担「此名字会延伸出这些承诺」的责任,DES-001 规则包 / PRO / DEC / SPEC 文档类型名 / 工具名如「核阅」/「化格」/「检词」/「书简」/「selector」/「facet」/「gauge」/「scribe」/「retriever」等,皆经立名三段流程,= Euler f(x) 的司衡版本:不立名即无承诺,立名即承诺,承诺不能事后撤回;Euler 的 Σ 记号在 Euler 时代是无穷级数研究的核心入口,司衡的 trail 入口与 scribe 事件类型即「立名承担承诺」的工具层最小样本,= 名字框定 + 引导 + 承载三功能。另一锚 PRO-05 刻画 Euler 「代数的一般性」的「大成若缺」:Euler 将有限代数规则大胆应用于无穷级数,结果多正确,「不严格但有效」,此为「最完美的系统」即大成;但 Cauchy 在 Cours d'Analyse 拒绝此方法,理由是「不严格」,即「缺」;Euler 的代数方法是 PRO-05 大成若缺的典型样本:最完美的规约即有限代数规则,「应用范围广 + 结果多正确」,落到无穷级数时必然有「缺」即严格性,「缺」不是缺陷即「方法错误」,是系统的本质即「有限代数规则的严格性不能完全决定无穷级数的严格性」;试图消除此「缺」即「完全严格化有限代数规则」,= 违反道家「大成若缺」的妄为。Euler 接受「缺」,Cauchy 给出另一实现路径即极限理论 + 严格收敛判据,= 规约与实现间隙的两种治理形态:其一是 Euler 接受「缺」并继续用「不严格」方法,工程上有效;其二是 Cauchy 另开实现层,= LIM-007 epsilon-delta 定义。司衡工程层对应,任何「不严格但有效」的工具如 LLM 的概率生成,工程上有效但严格性有「缺」,Euler 路径即承认「缺」,把 LLM 输出限定在「不需要严格性」的场景如草稿生成,即立名承诺中已包含「不严格」声明;Cauchy 路径即另开实现如确定性程序 + 留痕不可篡改,把 LLM 输出严格化或限缩在「LLM 仅生成符号材料」,DEC-006 / DEC-013 / DEC-017 等决策的形态即 Euler 路径与 Cauchy 路径的工程选择,= 司衡治理系统承认「缺」并选 Cauchy 路径,= PRO-05 大成若缺在治理层的最小应用。
