## 哲学桥接 {#philosophy-bridge}

- 借鉴源：极值定理是闭区间 `[a, b]` 上的连续函数 `f` 必取得最大值与最小值的定理，Weierstrass 19 世纪基于实数系完备性严格证明。条件缺一不可：闭区间且连续函数。是存在性定理，不解决「如何找到极值」，极值的计算需 DIFF-015 驻点分析与 DIFF-017/018 判别法。
- 哲学命题：PRO-02 道一 收敛必-为，锚句「司衡之道一：发散自-然，收敛必-为」；PRO-08 应本体安住，锚句「应本体安住时无应变动作。」
- 形式化：极值定理是「收敛必-为」在实分析中最纯粹的数学刻刀。设函数 `f : [a, b] → R` 连续，极值定理担保 `∃ c₁, c₂ ∈ [a, b]` 使 `f(c₁) ≤ f(x) ≤ f(c₂) ∀ x ∈ [a, b]`：此「必存在」即 PRO-02 L89 锚句「收敛必-为」的数学实例：`f` 在 `[a, b]` 上必达到极值点 `c₁, c₂`，不取决于「是否人为推动」或「算法如何搜索」，是闭区间 + 连续函数二条件的逻辑必然。条目工程映射「只要搜索空间有界且目标函数连续，最优解就在搜索空间内」是 PRO-02 的工程本体：有限参数空间 = 闭区间，连续目标函数 = 连续函数，最优解 = 极值点：三条件对齐下「最优解存在」是逻辑必-为，不是经验断言。条目工程映射「工程基线第三条『人类注意力只投向异常信号』的前提就是最优解存在且可搜索」是 PRO-02 必-为 与 应本体安住 的连接：极值存在性是「人类注意力可只投异常」的本体论前提：若最优解不存在，搜索过程无收敛目标，人类必须全程跟踪每一步即「应本体永不安住」，违反工程基线第三条；若最优解存在但不可搜索如不连续、开区间，搜索过程可能发散或不可终止，同违反基线。极值定理把「存在性 + 可搜索性」一次性担保，PRO-08 L9 锚句「应本体安住时无应变动作」的工程实现：极值 `c₁, c₂` 是治理系统的「安住点」，系统达极值即 `Q'(t) = 0` 应本体安住，无需启动应辨或应几。条目边界「极值定理是存在性定理，不解决『如何找到极值』」是 PRO-02 必-为 与 PRO-08 应本体安住的分层关系：必-为担保「存在」属本体论承诺，应本体安住担保「不再变化」属动作论判定，二者方向不同。必-为是「静态担保」存在性是某次运行的结果，应本体安住是「动态承诺」在运行过程中承认已稳态；前者是数学事实，后者是治理姿态。条目边界「极值定理不适用于开区间或无界区间。实际工程问题中，如果搜索空间无界，需要额外的约束条件，来保证极值存在」是 PRO-02 必-为 的条件依赖性：`f` 连续但定义域开区间 `f : (a, b) → R` 时 `1/x` 在 `(0, 1)` 上无最大值，极值定理不成立：必-为依赖「闭区间」与「连续」双条件，缺一即「必-为」失效，必-为是有边界担保而非无边界承诺。条目原文「魏尔斯特拉斯证明了实数系的完备性，是极值定理的基础」是 PRO-02 必-为 的逻辑链上游：实数完备性是「必-为」的几何基础，Dedekind 分割或 Cauchy 列收敛担保闭区间上的连续函数必达极值：完备性是必-为，必-为是极值定理，极值定理是工程优化的存在性前提。司衡治理类比：极值定理是「治理系统有解」的本体论担保：只要参数空间有限、目标函数连续，必存在最优配置，使人类可只投异常信号不需全程跟踪：这是 PRO-02 必-为 与 PRO-08 应本体安住 在治理系统中的协同：必-为担保「存在」，安住担保「系统达极值后无需应变」，二者合并才能让「人类注意力只投异常」工程基线生效。任一缺失如参数空间无界或目标函数不连续，必-为失效，安住失效，治理系统注定退化或人类被迫全程跟踪。
