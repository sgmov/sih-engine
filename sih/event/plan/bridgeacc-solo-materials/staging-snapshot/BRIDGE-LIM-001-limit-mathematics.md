## 哲学桥接 {#philosophy-bridge}

- 借鉴源：极限思想史源流是欧几里得《几何原本》第 X 卷命题 1 与阿基米德穷竭法的直觉化；17 世纪圣文森特格雷瓜尔给出几何级数极限的显式定义；牛顿在《原理》附注中给出「终极比是极限」的清晰定义；19 世纪波尔查诺 1817 年发展 epsilon-delta 技术，柯西 1821 年与魏尔斯特拉斯将其形式化为今天的 epsilon-delta 定义。数学表述即序列极限与函数极限的 epsilon-delta 形式化，核心特征是极限的唯一性。极限不回答「无穷是否真实存在」的本体论问题，极限是数学工具将无穷从本体论实体降级为语言表达。
- 哲学命题：PRO-02 道一发散自-然收敛必-为，锚句「司衡之道一：发散自-然，收敛必-为。」；PRO-07 鉴，锚句「镜的特点是纯粹映照」。
- 形式化：极限的「自变量趋近」过程是 PRO-02「发散自-然」的具体形态：序列 a_0, a_1, ... 在 n 增大时各项分散展开，函数 f(x) 在 x 趋近 c 时值不断变化无单一锚定点，两者皆「发散」即无瞬时收敛点；极限值 L 的存在是「收敛必-为」的具体形态：n 趋于无穷时序列必收敛于某 L，x 趋于 c 时函数必收敛于某 L，= PRO-02 L89「收敛必-为」在数学分析层的奠基实例。极限的唯一性定理保证 L 唯一即「收敛」目标唯一 = PRO-02 L121「收敛是规范性」的判据保障：若两个不同 L 都满足 epsilon-delta 条件则数学矛盾，唯一性把「收敛」从「可能多值」压缩到「必须单值」，这与道一「收敛必-为」中「必-为」的强制性同源。另一锚 PRO-07 刻画极限的「去蔽映照」本质。epsilon-delta 定义即「对任意 epsilon 存在 delta 使所有近点 x 满足 f(x) 与 L 的距离小于 epsilon」是 PRO-07 鉴「映照」三要素的具体形态：epsilon 是「可被允许的偏差」的主动预设即「去蔽」剥离主观偏差只留偏差阈值；delta 是「与偏差阈值对应的逼近距离」的客观存在即「客观」不预判 delta 应该多小只看 epsilon 给定后 delta 存在；|f(x) - L| < epsilon 是「实际值与极限值的距离反映」即「映照」不投射 L 应该是什么只反映 f(x) 实际值。epsilon-delta 三件套即 PRO-07 鉴三要素去蔽、客观、映照在数学层的程序化实例。工程映射，司衡治理系统中「治理动作的可验证性」是 epsilon-delta 的工程版：epsilon 对应「可被允许的偏差阈值」如「治理报告与实际状态的偏差上限」，delta 对应「审查覆盖范围」即「在多大范围内核查」，|报告 - 实际| < epsilon 对应「报告值与实际值的偏差反映」；这与 LIM-001 epsilon-delta 在收敛率审计的「Jaccard 相似度在 epsilon 内」是同构：极限不是「无穷的真实存在」而是「逼近行为的可验证判据」与 PRO-07 鉴「镜不主动投射」同源：极限不投射 L 应该是什么只映照 f(x) 在逼近过程中的实际行为。
