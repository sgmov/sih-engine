## 哲学桥接 {#philosophy-bridge}

- 借鉴源：克拉德尼图形是 Ernst Chladni 1787 年发表的声学可视化实验：小提琴形金属板振动时，沙子向节线，位移为零的曲线，聚集，形成对称几何图案。其数学骨架是二维双调和方程 `D∇⁴w + ρh d²w/dt² = 0` 的本征值问题，本征模式 W(x,y) 在节线上为零。Sophie Germain 1816 年给出第一个近似解。
- 哲学命题：PRO-04 道三代码自晦意图必复，锚句「"自晦"：代码不会自行揭示意图」本征模式 W(x,y) 不在板面字面存在，「节线」是意图，本征模式，的有形化外化。
- 哲学命题：PRO-07 鉴，锚句「镜的特点是纯粹映照」沙子在节线聚集是数学结构的客观映照，沙子不「主动选择」节线，是节线区域为唯一稳定位置。

### 形式化 {#formalization}

- 设板振动方程的解空间为 H = {W(x,y) : ∇⁴W = λ²W, 边界条件}，本征模式 Wₙ 是 H 的正交基：Wₙ 不在板面字面存在，是抽象数学对象。
- 板的物理振动 y(t) = Σ aₙ Wₙ cos(ωₙt + φₙ) 是 Wₙ 在「实现」层的有形化：但 Wₙ 在板面任意点的瞬时位移是被多模叠加掩盖的「自晦」信息。
- 节线集合 Nₙ = {(x,y) : Wₙ(x,y) = 0} 是 Wₙ 的「不藏外化」PRO-04 L17「维护之前必须先恢复意图」的实例：识别 Nₙ 即恢复 Wₙ 的几何结构。
- 沙子的物理行为满足「纯粹映照」：PRO-07 L62「镜不区分"好"与"坏"：它平等映照所有」沙子在节线停留是「镜」对所有节点位移的平等反映，不预判哪条节线更重要。
- 「映照同时完成验证与度量」（PRO-07 L69）：Chladni 图形一次穿透同时完成：
  - 验证：节线是否符合 `∇⁴W = λ²W` 在给定边界条件下的解，识别 λ 是否对应本征值。
  - 度量：节线的曲率 / 分叉数 / 对称性偏离 Wₙ 的解析预测多少，度量 λ 的偏差
- 可证伪条件：若某次 Chladni 实验的节线图案与 `∇⁴W = λ²W` 的解析解显著偏离且无法用边界不规则性解释，则板振动方程，意图，需修正，PRO-04 的「必复」在「意图错误」时触发。

APP-006 的工程映射中「不可见结构的可视化」对应 PRO-07 的「映照」；「模式与形状的耦合」对应 PRO-04 的「自晦 → 必复」；「结构性必然不是偶然失误」对应 PRO-07 的「客观」。两条命题共同为「抽象 PDE 本征模式 ↔ 物理振动节线图形」的双向通路提供哲学判据。
