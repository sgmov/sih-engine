## 哲学桥接 {#philosophy-bridge}

- 借鉴源：牛顿 1670s 在《流数术》中以运动为基本对象，定义流量为变化的量、流数为变化率，`x` 的流数记作 `x-dot`，即位置对时间的导数。牛顿的核心洞察是「瞬时速度不是'一瞬间走的距离除以一瞬间的时间'」，而是「平均速度在时间间隔趋于零时的极限」。19 世纪 Cauchy 与 Weierstrass 用 epsilon-delta 语言为该极限提供了不依赖无穷小的严格定义。
- 哲学命题：PRO-04 道三代码自晦意图必复，锚句「有形系统的固有属性是"可读性有限"，无论代码多么清晰，其含义都不能从符号本身完全还原」平均速度 `[x(t+h) - x(t)] / h` 是「有形」的有限量，是位置变化可测可算的形式化；瞬时速度 `v(t) = lim(h→0) [x(t+h) - x(t)] / h` 是「含义」，是意图，不在有限平均速度的字面中。有限平均速度「可读性有限」，其极限含义不能从该有限表达式直接还原：必须经过极限操作。
- 哲学命题：PRO-05 道四规约与实现必有间隙，锚句「间隙是规约与实现之间的客观存在」有限步长 `h` 下的平均速度是「规约」：可在任意步长下计算，但只是近似；瞬时速度是「实现」：运动的真实变化率，仅作为极限存在。两者之间的差 `|[x(t+h) - x(t)] / h| - |v(t)|` 是「客观存在」的间隙，`h → 0` 时收缩但不可归零。

### 形式化 {#formalization}

设位置 `x : R → R` 在 `t` 处可导，定义平均速度 `v_h = [x(t+h) - x(t)] / h` 与瞬时速度 `v(t) = lim(h→0) v_h`。

- 规约 vs 实现的形态判定：`v_h` 是 `h` 的函数，依赖步长；`v(t)` 是 `t` 的函数，无步长依赖。「规约是意图的有形化」映射为 `v_h` 是 `v(t)` 的有形化：`v_h` 可在任意 `h ≠ 0` 下计算，是「可见」的可计算对象；`v(t)` 仅作为极限存在，是「意图」层的真实速度。
- 自晦与必复的极限操作：`v(t)` 不能从任一固定 `h` 下的 `v_h` 直接读出，「含义不能从符号本身完全还原」在此即 `v(t) ≠ v_h` 对任意 `h ≠ 0`；「必复」表现为必须经过 `h → 0` 的极限操作才能从「有限平均」恢复「瞬时意图」这与 PRO-04 L17「维护之前必须先恢复意图，恢复是维护的因果前提」同构。
- 间隙的客观性与粒度依赖：`v_h - v(t) = O(h)`，即「间隙是规约与实现之间的客观存在」在瞬时速度语境下量化为残差的 `O(h)` 阶；`h` 缩小 10 倍残差缩小 10 倍，但任意非零 `h` 下残差非零。柯西极限严格化所保证的恰是 `lim(h→0) v_h = v(t)`，即残差可被外推为零但任意步长下不可归零。
- 牛顿流数的工程映射：仪表的「瞬时读数」本质是极小步长下的平均速度，`v_h` 在测量周期 `h` 下被当作「瞬时」；该简化的有效性由 `v_h - v(t) = O(h)` 的量级判定，与工程基线第二条「信息洪流是结构性约束」在测量步长选择上同源：更细的步长要求更多测量资源，资源约束决定实际步长下限。
- 可证伪条件：若某位置函数 `x(t)` 在某 `t` 不可导，则 `v(t)` 的「意图」在该点不存在：任何有限步长下的 `v_h` 都无法通过极限操作收敛到单一值，对应「必复失败」：恢复瞬时意图的程序在该点不可执行，必须改用差分或分布导数。

DIFF-032 的工程映射「变化率分析 / 注意力预算的结构性稀释 / 退化的检测」对应同一哲学骨架：「有限差分 = 规约 / 导数 = 实现意图 / 残差 = 客观间隙」的三元闭合在所有「变化率」类工程问题中可复用，PRO-04 与 PRO-05 共同为「平均 → 瞬时」的极限操作提供本体论与认识论双层判据。
