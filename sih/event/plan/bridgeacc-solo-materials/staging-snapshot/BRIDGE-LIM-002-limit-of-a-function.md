## 哲学桥接 {#philosophy-bridge}

- 借鉴源：函数极限的思想史源流是 19 世纪分析严格化运动，柯西 1821 年《分析教程》给出函数极限的雏形定义，魏尔斯特拉斯用 epsilon-delta 语言形式化。严格化的动机是牛顿莱布尼茨微积分依赖无穷小被贝克莱批评为「已消失量的幽灵」。函数极限的 epsilon-delta 定义即对任意 epsilon 存在 delta 使 0 小于 |x - c| 小于 delta 时 |f(x) - L| 小于 epsilon；关键特征是极限定义不要求 f 在 c 点有定义，sin(x)/x 在 x 等于 0 处无定义但极限等于 1。函数极限描述逼近行为不描述该点的实际取值。
- 哲学命题：PRO-07 鉴，锚句「涤除玄鉴：心本是镜，但被尘垢蒙蔽；涤除尘垢，是认识的前提。」；PRO-04 道三代码自晦意图必复，锚句「代码不会自行揭示意图」。
- 形式化：函数极限的 epsilon-delta 定义是 PRO-07 鉴在数学严格化中的最小样本。19 世纪微积分的「已消失量的幽灵」是认识论的「尘垢」= 贝克莱批评揭示的「尘垢」即无穷小本体论承诺对认识论清晰性的蒙蔽；epsilon-delta 把无穷小从本体论实体降级为语言表达即「涤除尘垢」= PRO-07 鉴「涤除玄鉴」在微积分基础层的实例。epsilon 是任意给定的偏差阈值即「去蔽」的主动承认即承认认识存在偏差而非「极限精确等于 L」；delta 是与 epsilon 对应的逼近距离即「客观」存在即不预判 delta 应该多小；|f(x) - L| 小于 epsilon 是实际值与极限值的偏差反映即「映照」不投射 L 应该是什么，与 PRO-07 L79「映照：只反映事实，不投射判断」同源。= 鉴三要素在极限定义中的程序化对应。另一锚 PRO-04 刻画「f(c) 可不存在」的本体论间断。函数极限的 epsilon-delta 定义形式是 lim(x->c) f(x) 等于 L 即字面只写 L 不写 f(c) 形式上的函数求值，「意图」是「L 是 f 在 c 附近的逼近目标」，「字面」是「lim 形式下 c 点可不存在」= PRO-04 L17 自晦的具体形态。维护者面对 sin(x)/x 在 x 等于 0 处无定义但极限等于 1 的事实必须先恢复意图即追问「为何 f 在 c 点无定义但极限存在」「f 在 c 点的间断与极限的连续是何关系」才可对接下游 LIM-008 连续函数与 DIFF-032 作为瞬时速度的导数；若仅从字面 lim(x->0) sin(x)/x 等于 1 直接应用会丢失「c 点无定义」与「极限存在」并存的关键信息。工程映射，司衡治理系统中「治理规则在边缘场景的可执行性」是函数极限的工程版：epsilon 对应「治理规则在边缘案例的允许偏差」即规则在边界附近的容错；delta 对应「边缘案例的覆盖范围」即多大范围内规则仍生效；f(c) 可不存在即「某些边缘案例无现成规则可应用」但「规则在边缘附近的极限值仍可被验证」这与 LIM-002 sin(x)/x 在 x 等于 0 无定义但极限等于 1 的形态同构，治理规则不必覆盖所有 c 点但须给出 c 点附近的极限行为即 epsilon-delta 验证。
