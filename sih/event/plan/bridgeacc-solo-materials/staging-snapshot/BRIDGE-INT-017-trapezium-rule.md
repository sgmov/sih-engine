## 哲学桥接 {#philosophy-bridge}

- 借鉴源：梯形法则的思想根源是阿基米德穷竭法。阿基米德用内接与外切多边形逼近圆面积,本质上是把曲线段替换为直线段、再累加所有梯形面积近似圆面积。17 世纪莱布尼茨与牛顿的微积分把这一过程从几何论证转化为代数运算,梯形法则成为把积分真值替换为离散加权和的标准方法。19 世纪欧拉-麦克劳林公式给出梯形法则与精确积分之间的精确差,O(h^2) 收敛阶与余项 -(b-a)^3/(12n^2) f''(xi) 都被严格化。20 世纪数值分析把它从几何直觉推进为工程标准,任何无解析解的积分都用此法做首次近似。
- 哲学命题:PRO-05 道四规约与实现必有间隙,锚句「道四:规约与实现必有间隙。」梯形法则是用有限个梯形的离散求和替代连续积分,这是规约与实现之间间隙的具体形态。规约侧是无限细分的连续积分,实现侧是有限个梯形面积的加权和,两侧之间的差就是间隙。O(h^2) 误差阶表明步长 h 缩到零时误差趋于零但永不为零,任何有限 n 都留下未消除的间隙。这正是道四命题的数学实例:双重有损链意图 → 规约 → 实现中,把规约从无限细步换为有限步是规约环节的有损编码,实现环节通过加权和进一步压缩信息,两次有损编码累加出梯形法则的余项。间隙随 n 增大而缩窄但不可消除,只能识别、记录、治理,这是规约与实现之间结构性约束的数学等价。
- 哲学命题:PRO-08 应,锚句「司衡之应:应而不藏,应辨当下,应几未来。」梯形法则的执行分为两个时态。当工程给出确定步长 h 或分段数 n 时,机械算出当前近似值,这是应辨当下:已抵达的具体精度要求立即处理。当需要预估 n 继续增大时近似值如何变化,或比较 O(h^2) 收敛与辛普森 O(h^4) 收敛的速度差异,这是应几未来:在微兆阶段预判继续加密是否带来边际收益。司衡之应在此具体化为:应而不藏对应机械可重算的加权和公示,应辨当下对应已知 n 下的固定输出,应几未来对应 O 阶语言对更大 n 行为的预判。应辨与应几共同构成梯形法则的使用维度:既给出当前近似,又提示精度随步长缩小的趋势。

### 形式化 {#formalization}

设 f 在 [a, b] 上二次可微,等分 n 段,步长 h = (b-a)/n。

- 间隙作为余项:PRO-05 L15「道四:规约与实现必有间隙。」在本条目具象为：精确积分 I = ∫_a^b f(x) dx 与梯形近似 T_n = h/2 [f(x_0) + 2f(x_1) + ... + 2f(x_{n-1}) + f(x_n)] 之差 I - T_n 称为间隙,O(h^2) 量级。当 f''(x) 在 [a, b] 上有界 M_2,间隙 |I - T_n| ≤ M_2 (b-a)^3 / (12 n^2)。这个上界是道四间隙在数值积分上的可计算形式:不是「间隙不可消除」的纯哲学断言,而是 O 量级可被定量表述的工程事实。间隙随 n 增大而缩窄,符合「双重有损链」中规约环节的有损压缩可被无限缩小但不可归零。判断「间隙可被忽略」的工程判据是 |I - T_n| / |I| < epsilon,这是治理在特定精度阈值下对间隙的记录与判定。
- 应辨当下与应几未来:PRO-08 L108「司衡之应:应而不藏,应辨当下,应几未来。」在本条目具象为：应辨当下指给定 n 后立即算 T_n 的动作,这是机械的、无歧义的、有限步可完成的「当下」。应几未来指预判 n 增大时 T_n 的行为,需要 O(h^2) 收敛阶的渐近分析,即 R_n ≈ -(b-a)/12 h^2 f''(xi),由此估计 T_{2n} - T_n 的符号与量级,这是「几」即微兆阶段的预判。O(h^2) 阶与 O(h^4) 阶的比较是应几的典型场景:在 h 较小时辛普森法则的边际收益比梯形法则更大,这是间隙缩窄速度的预判,属于未来形态的「几」而非已抵达的「辨」。应而不藏在梯形法则中具象为公示本身可被任何执行者按相同步骤重算,无隐藏的常数、无省略的高阶项,所有精度信息以余项公式显式承载。
- 复化与递推关系:从 T_n 到 T_{2n} 的递推公式 T_{2n} = T_n/2 + h/2 sum_{k odd} f(x_k),把已知的 T_n 作为输入,加上新插入节点处的函数值。这是应辨当下(已知 T_n)与应几未来(预估 T_{2n})的协同:递推公式让两个时态通过同一机械程序桥接,「加一倍节点」的边际操作可被预先估计。递推的收敛速度由 O(h^2) 决定,h 减半误差减为四分之一,这是间隙缩窄的几何级数形态。
- 与其他概念的关系:上游 INT-007 微积分基本定理与 LIM-001 极限：梯形法则是把积分精确值替换为有限和的工程化,LIM-001 提供 n → ∞ 时 T_n → I 的极限语义。下游 SER-005 欧拉-麦克劳林公式：梯形法则是欧拉-麦克劳林公式的零阶截断,加上端点修正 f(a)/2 + f(b)/2 后误差阶提升。同层 SER-001 无穷级数：梯形法则的余项用 O 记法描述,O 记法的严格化需要级数收敛概念。INT-016 22/7 超过圆周率的证明：本条目给出近似,INT-016 给出近似与精确值差距的严格符号方向,两者方法论互补:梯形法则的工程近似与恒正被积函数的精确判断分别处理不同精度需求。
- 边界:梯形法则给出一维积分的数值近似,不适用于多维区域。多维积分需要蒙特卡洛或张量积求积,超出梯形法则的直接职责。梯形法则要求被积函数至少二次连续可导,间断点处误差阶退化,这是光滑性对间隙缩窄速度的硬约束。O(h^2) 收敛阶是固定常数,不随用户配置改变;更高精度需要换辛普森 O(h^4) 或高斯求积,这是阶的跃迁而非渐进改进。
