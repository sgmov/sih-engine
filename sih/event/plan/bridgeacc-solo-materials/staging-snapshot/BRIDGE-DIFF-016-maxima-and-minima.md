## 哲学桥接 {#philosophy-bridge}

- 借鉴源：极值，函数 `f : D → R` 在 c 点取得局部极大值若存在邻域使 `f(c) ≥ f(x)`，极小值对称，定义域内全局极值与极值定理 DIFF-019 配套。Fermat 在 17 世纪研究光的折射时提出求极值的一般方法，是微积分诞生的驱动力之一；Newton 与 Leibniz 将极值问题纳入微积分体系；Weierstrass 在 19 世纪严格化，给出极值存在充分条件。极值是优化问题的核心，工程中「最大化效率、最小化成本、最小化误差、最大化吞吐量」等表述都是极值问题的实例。
- 哲学命题：PRO-08 应本体，锚句「应本体安住时无应变动作」；PRO-06 法三 知止，锚句「法三：知止。知道不做什么，比知道做什么更难。」
- 形式化：极值是 PRO-08 应本体「安住」在数学上的几何实例：若 c 是局部极值点且 f 在 c 可微，则 `f'(c) = 0`，函数在 c 点的「瞬时变化率为零」，= 「应本体安住」= 「无应变动作」：在 c 邻域内 `f` 不向任一方向倾斜，安住于局部最高或最低；全局极值是「安住」在更大范围上的版本：`f(c) ≥ f(x)` 对所有 `x ∈ D` 成立，= 应本体在 D 全域的安住，无任何方向上的应变。极值点邻域的「f 在 c 之上 / 之下」结构，使 `f'(c) = 0` 不仅是局部必要条件，也是安住的几何必然：「应变」要求 `f'(c) ≠ 0`，应变被定义为「向某方向变化」，极值点是「向某方向变化」不存在的状态。DIFF-016 与 DIFF-004 在此同构：DIFF-004 中常数 `c` 满足 `dc/dt = 0`，= 应本体安住；DIFF-016 中极值点 `c` 满足 `f'(c) = 0`，= 应本体安住；区别在于 DIFF-004 中 `c` 是常量「永远安住」，DIFF-016 中 `c` 是「瞬时安住」`f'(c) = 0` 仅是局部条件，离开 c 点后 `f` 仍可变化，进入应变。司衡治理类比：审查产出的局部峰值，`f(Q)` 在某轮次 `c` 处取得局部极大值，意味 `df/dc = 0` 在该轮次 = 审查产出「安住」于局部最优，可能陷入「过拟合某轮次」而全局未最优；治理应本体在 c 安住，治理动作失稳的提示是「应几」感知下一轮次 `df/dc < 0` 的微兆，及时介入避免局部最优吞噬全局。另一锚 PRO-06 法三 知止刻画极值问题的元方法学结构：极值的存在不是通过「做更多事」更多轮次、更多采样、更多评估：实现的，而是通过「知道在哪里停止」在哪一邻域内 f 不再需要变化，即「止」于 c：实现的。法三「知道不做什么，比知道做什么更难」与极值定理 DIFF-019 的存在性判据同源：DIFF-019 不构造极值点，只保证极值在闭区间连续函数上存在：这是「知道极值会在某处停止」的程序化表达，比「显式给出极值点」更基本；同样，工程优化在约束条件下寻找极值，目标函数未必光滑、定义域未必连通，DIFF-016 的极值定义仍是「在某处停止」即某 `c ∈ D` 使 `f(c)` 不再需要被改进。可证伪条件：若某系统声称找到极值但其输出在邻域内仍 `f'(c) ≠ 0` 或「应变动作仍触发」，则 PRO-08 安住失守：`f(c)` 不是极值点而是被误标，对治是回到 DIFF-015 驻点判据与 DIFF-018 二阶导数判据分别检验临界点条件，不通过「f 在 c 看起来很高」反推 c 是极大值点。
