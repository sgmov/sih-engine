## 哲学桥接 {#philosophy-bridge}

- 借鉴源:Stirling 1730 年《Methodus Differentialis》中提出阶乘的渐近近似公式,基于 de Moivre 早期工作。de Moivre 在 1730 年前发现 n! 渐近展开的主要项,Stirling 给出更精确形式并补充常数项 ln(sqrt(2*pi))。Laplace 后来将 Stirling 近似与中心极限定理联系起来,使其成为概率论的基础工具。基本形式 n! 约等于 sqrt(2*pi*n) * (n/e)^n,对数形式 ln(n!) 约等于 n*ln(n) - n + (1/2)ln(2*pi*n) + 1/(12n) - 1/(360n^3) + ...,误差 1/(12n) 在 n>=10 时已小于 1%。
- 哲学命题:PRO-07 鉴,锚句「代码工程的"客观"是:在检验时不预设"应该是什么",只看"实际是什么"。」Stirling 近似是「客观」在渐近分析中的具体形态。n! 是离散整数阶乘,s sqrt(2*pi*n) * (n/e)^n 是连续函数表达式,前者作用于整数,后者作用于实数。Stirling 近似「不预设 n! 应该是什么」,不投射「阶乘必须严格等于其定义」之类的形而上学判断,只「客观」地映照 n! 在 n 很大时的「实际是什么」极限 lim(n->inf) n! / (sqrt(2*pi*n) * (n/e)^n) = 1 是「客观」的极限陈述,反映 n! 与 Stirling 公式的「实际比值」,不投射「两者应该完全相等」的判断偏好。「不投射判断」在此具体化为:Stirling 近似不投射「n 必须足够大」「误差必须可忽略」「应用场景必须避免小 n」之类的偏好,只是给出 n! 在 n 趋于无穷时的「实际行为」。检验者可独立对同一 n 计算 n! 与 Stirling 公式的比值,验证过程只反映计算事实,不含检验者关于「n 应该多大」「近似是否有效」的判断。对数形式 ln(n!) 约等于 n*ln(n) - n + (1/2)ln(2*pi*n) + 1/(12n) - 1/(360n^3) + ... 是「客观」在计算可行性中的延伸:不投射「n! 必须直接计算」的判断,只「客观」反映 n! 的对数在大 n 时的「实际值」,避免 n! 直接计算溢出。
- 哲学命题:PRO-05 道四,锚句「道四也是道家"大成若缺"在司衡哲学中的具体化:最完美的系统必然有"缺",缺不是缺陷,是系统的本质。」Stirling 近似是「大成若缺」在渐近分析中的具体形态。Stirling 公式 sqrt(2*pi*n) * (n/e)^n 是「最完美的系统」:它用一个简洁的连续函数精确逼近 n!,在 n 很大时相对误差仅 1/(12n),这是「最完美」的近似。但这一「完美系统」必然有「缺」:相对误差 1/(12n) 是「缺」的具体表达,n 越接近 1 时「缺」越大。Stirling 级数 ln(n!) = (n+1/2)ln(n) - n + (1/2)ln(2*pi) + sum(k=1 to m) B_{2k}/(2k(2k-1)*n^(2k-1)) + R_m(n) 的「缺」更微妙:这一渐近级数是「发散级数」,截断到第 m 项时误差 R_m(n) 最小,但 m 继续增大时误差反而增大：这是「最完美系统必然有缺」的极致形态:即使不断精化「规约」(增加项数),「缺」(余项 R_m) 不仅不缩小,反而可能扩大。「缺不是缺陷」在此具体化为:渐近级数的发散性不是 Stirling 公式的「缺陷」,是其「本质」为大幅角参数优化的工具在小幅角参数下必然失效,这是工具的本体论属性而非偶然瑕疵。Laplace 把 Stirling 近似与中心极限定理联系是「缺」的物理学意义:大 n 阶乘的统计涨落由 Stirling 公式精确描述,但小 n 时涨落不可忽略,「缺」是中心极限定理应用范围的精确边界。

### 形式化 {#formalization}

设 n! = 1·2·3·...·n,Gamma 函数 Gamma(n+1) = n!,Stirling 近似为 n! ≈ sqrt(2*pi*n) * (n/e)^n。

- 客观作为极限映照:PRO-07 L53「代码工程的"客观"是:在检验时不预设"应该是什么",只看"实际是什么"。」在本条目具象为：Stirling 公式 lim(n->inf) n! / (sqrt(2*pi*n) * (n/e)^n) = 1 是「客观」的极限陈述。这一极限不投射「n! 应该如何定义」「n! 应该等于什么表达式」的形而上学判断,只反映 n! 在 n 趋于无穷时的「实际行为」:与 sqrt(2*pi*n) * (n/e)^n 的比值趋于 1。对数形式 ln(n!) = n*ln(n) - n + (1/2)ln(2*pi*n) + 1/(12n) - 1/(360n^3) + ... 是「客观」在更精细尺度的延伸,不投射「n! 的对数应该如何表示」的判断,只反映 n! 的对数在大 n 时的实际值。「客观」还体现在误差估计:相对误差 1/(12n) 不投射「误差应该可以忽略」的判断,只反映「n! 与 Stirling 公式的相对偏差是多少」的事实。
- 大成若缺与渐近级数的发散性:PRO-05 L19「道四也是道家"大成若缺"在司衡哲学中的具体化:最完美的系统必然有"缺",缺不是缺陷,是系统的本质。」在本条目具象为：Stirling 公式 sqrt(2*pi*n) * (n/e)^n 是「最完美的系统」:简洁、精确、在大 n 时近似 n! 极为准确。相对误差 1/(12n) 是「缺」的具体表达,这一「缺」在大 n 时趋近于零,但永远不能消除。Stirling 级数的「缺」更极端:作为渐近级数,每一项都更精确地反映 n! 在大 n 时的行为,但级数本身发散,截断到第 m 项时误差最小,m 继续增大时误差反而增大。这是「最完美系统必然有缺」的极致形态:「规约」(有限项级数)的「精化」(增加项数)不必然「缩小」「缺」(余项)。「缺不是缺陷」在此具体化为:渐近级数的发散性是 Stirling 公式的「本质」,不是其「缺陷」Stirling 公式是为大 n 设计的工具,小 n 时其「缺」自动显现,这是工具的本体论边界。
- 误差缩小的条件性:Stirling 近似的基本形式相对误差 1/(12n),n>=10 时已小于 1%。这一「缩小间隙」是有条件的:n 越大误差越小,但 n 越接近 1 误差越大。「条件性」是「道四」的本体论属性:间隙可缩小,但缩小的速率与参数 n 强相关,n 是「收敛」的控制参数。Laplace 把 Stirling 近似与中心极限定理联系是「条件性」的概率论延伸:大 n 时 n! 的统计涨落由 Stirling 公式精确描述,小 n 时涨落的相对幅度不可忽略。
- 与其他概念的关系:上游 SPEC-002 e：Stirling 公式中 (n/e)^n 项引入常数 e。SPEC-001 自然对数：对数形式 ln(n!) 是 Stirling 公式的常用形式。SPEC-007 伯努利数：Stirling 级数的系数由伯努利数给出。SER-005 欧拉-麦克劳林公式：Stirling 公式可由欧拉-麦克劳林公式推导。下游 SER-001 无穷级数：Stirling 级数是无穷级数(但发散)。INT-022 柱壳积分：某些柱壳积分的渐近分析依赖 Stirling 公式。同层 DIFF-023 泰勒定理：Stirling 级数与泰勒级数形式相似但收敛性不同(发散 vs 收敛)。APP-001 常微分方程：某些 ODE 的渐近分析依赖 Stirling 公式。
- 边界:Stirling 近似是渐近近似,不是精确等式,小 n 时近似精度有限。Stirling 近似不解决 Gamma 函数的一般性质,只是 Gamma 函数在大幅角参数下的渐近行为。Stirling 近似是实分析工具,不涉及概率分布的形状或统计推断的具体方法。这三条边界是「缺」的不同形态:每条边界都对应一种「规约与实现之间间隙」的本体论存在,不可消除。
