## 哲学桥接 {#philosophy-bridge}

- 借鉴源：「柱壳积分」是计算旋转体体积的第二种基本方法，与圆盘法 INT-021 互补。核心公式：曲线 `y = f(x)` 在 `[a, b]` 上绕 `y` 轴旋转，体积 `V = 2π ∫_a^b x·f(x) dx`。推导：在位置 `x` 处取宽度 `dx` 的竖条，绕 `y` 轴旋转形成柱壳，柱壳半径为 `x`、高度为 `f(x)`、厚度为 `dx`，展开近似为「长 `2π·x`、高 `f(x)`、厚 `dx`」的矩形，体积微元 `dV = 2π·x·f(x)·dx`，积分得总体积。圆盘法垂直于旋转轴切片，柱壳法平行于旋转轴切片，两种方法覆盖了「绕水平轴」与「绕垂直轴」两类典型场景。柱壳法的优势在「绕垂直轴」时显现：不必反解 `x = g(y)`，直接用原函数 `f(x)` 即可；圆盘法在「绕水平轴」时优势对调。方法选择取决于哪个方向让积分更简单，是工程中典型的「场景决定方法」。
- 哲学命题：PRO-06 法，锚句「法三：知止。知道不做什么，比知道做什么更难。」柱壳法与圆盘法的「选择准则」是「知止」在积分方法论中的具体化。柱壳法不是「普适」的体积计算方法，它有适用域：「绕垂直轴且函数以 `y = f(x)` 给出时」；圆盘法同样有适用域：「绕水平轴时」。柱壳法「知道不做什么」不试图覆盖圆盘法的场景，不在「绕水平轴」时强行套用竖条分解。圆盘法也「知道不做什么」不试图覆盖柱壳法的场景，不在「绕垂直轴」时强行反解函数。两种方法各自有「停止生效」的边界：司衡的每一条规则都应能回答「这条规则何时停止生效」。柱壳法的「停止边界」即「旋转轴与函数自变量方向不同时」，超出此边界应换圆盘法。圆盘法的「停止边界」即「旋转轴与函数自变量方向相同时」，超出此边界应换柱壳法。知道在何处停止：「什么不该规约、什么不该审查、什么不该流程化」在积分中具体为「什么情形不该用此方法」。
- 哲学命题：PRO-07 鉴，锚句「客观：不预设立场，不急于下判断」柱壳微元 `dV = 2π·x·f(x)·dx` 是「客观」在体积分解中的具体化。柱壳的几何结构是事实：半径为 `x`、高度为 `f(x)`、周长为 `2π·x`、厚度为 `dx`、展开后近似为矩形：这些几何事实不投射「柱壳应该是更复杂的形状」的判断，也不投射「应该用其他几何分解」的偏好。`2π·x·f(x)·dx` 是几何事实的直接代数表达，不掺杂「近似应该有多精确」的判断。客观即「只看柱壳的几何是矩形展开」，不投射「展开后是否真的是矩形」的怀疑：当 `dx → 0` 时，柱壳的侧面积与矩形面积的差距是高阶无穷小，忽略是数学上的合法简化。检验是「对 `f(x) = h` 常数函数在 `[a, b]` 上绕 `y` 轴旋转，`V = 2π·h·∫_a^b x dx = π·h·(b^2 - a^2)` 与圆柱壳体积公式一致」客观在简单情况下可由初等几何直接验证。

### 形式化 {#formalization}

设 `f(x) ≥ 0` 在 `[a, b]` 上连续，绕 `y` 轴旋转，柱壳法体积 `V = 2π ∫_a^b x·f(x) dx`。

- 知止作为方法选择：PRO-06 L65「法三：知止。知道不做什么，比知道做什么更难。」在柱壳法中具象为：「知止」即柱壳法的适用边界是「绕垂直轴即 `y` 轴，且函数以 `y = f(x)` 形式给出」。超出此边界，「知止」要求停止使用柱壳法，转用其他方法。「停止生效」的判据是「旋转轴的方向」与「函数的表达形式」两个事实：旋转轴为 `y` 轴，函数为 `y = f(x)`，柱壳法生效；旋转轴为 `x` 轴，函数为 `y = f(x)`，柱壳法停止，圆盘法生效。「不做什么」即「不在 `y` 轴以外的旋转轴上强行套用柱壳公式」。「更难」的部分即「识别停止边界」很多教科书在「绕 `y` 轴用柱壳法，绕 `x` 轴用圆盘法」上反复切换，初学者常在两种方法间犹豫。知止的方法论是「先把旋转轴与函数表达形式对齐，再选方法」，对齐本身就是「停止判据」的具体化。
- 客观作为几何分解：PRO-07 L78「客观：不预设立场，不急于下判断」在柱壳法体积微元中具象为：「事实」即「竖条绕 `y` 轴旋转形成柱壳」，是几何事实。「客观」即 `dV = 2π·x·f(x)·dx` 直接来自「柱壳展开近似为矩形」的几何事实：周长 `2π·x` 是圆柱侧周长，高度 `f(x)` 是柱壳母线长，厚度 `dx` 是切片宽度，三者相乘是矩形体积的代数表达。客观不投射：不投射「应该用其他几何度量代替周长」的判断，不投射「应该用梯形法或辛普森法提高精度」的简化偏好。客观的可验证性是「对 `f(x) = h` 常数函数，柱壳法退化为圆柱壳体积公式 `π·h·(b^2-a^2)`，与初等几何一致」。
- 选择准则的方向性：柱壳法与圆盘法的「选择准则」是「绕垂直轴时优先柱壳，绕水平轴时优先圆盘」。准则的客观依据是「反解函数的成本」绕 `y` 轴用圆盘法需要把 `y = f(x)` 反解为 `x = g(y)`，反解成本可能极高甚至无显式形式；柱壳法直接用 `f(x)` 避免反解。绕 `x` 轴用圆盘法直接用 `f(x)`，柱壳法需要把 `f(x)` 分解为多个 `x = g(y)` 区间，反而复杂。选择不是「看哪个方法更常用」或「看哪个方法更直观」，是「看哪个方法让积分更简单」客观的成本结构决定选择，不预设立场。
- 边界：柱壳法计算旋转体体积，不计算表面积。表面积使用 INT-020 弧长的旋转积分公式，柱壳侧面积是表面积微元的近似但严格推导需要 INT-021 旋转体的表面积公式。柱壳法沿平行于旋转轴方向分解，旋转轴与切片方向一致时应使用圆盘法。这一边界是「柱壳法的适用域」「绕垂直轴」是其唯一适用域，超出此域应停止使用。柱壳法对「绕非坐标轴」即斜轴的旋转不直接适用，需要先做坐标变换把斜轴化为坐标轴，再应用柱壳法或圆盘法。
- 与其他概念的关系：上游 INT-007 微积分基本定理与 INT-004 线性性：柱壳法依赖基本定理把体积微元累积为总体积，依赖线性性把 `2π·x·f(x)·dx` 分解为常数 `2π`、变量 `x`、函数 `f(x)`、微分 `dx` 的乘积。下游 MUL-002 圆盘积分与 MUL-003 加百列号角：圆盘积分是柱壳法的对偶，加百列号角是柱壳法的著名反例即「表面积有限但体积无限的旋转体」。同层 INT-021 旋转体：柱壳法与圆盘法是计算旋转体体积的两种互补方法，分别覆盖不同旋转轴方向。
