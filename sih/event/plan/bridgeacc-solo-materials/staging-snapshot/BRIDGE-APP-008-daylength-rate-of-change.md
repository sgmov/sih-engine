## 哲学桥接 {#philosophy-bridge}

- 借鉴源：昼长 `D(N) = (2/ω) arccos(-tan(φ) tan(δ))` 关于日序号 `N` 的导数 `dD/dN` 给出变化率，其结构由太阳赤纬 `δ = ε sin(2π(N-N₀)/365)` 决定：在二至点，`cos(2π(N-N₀)/365)=0`，变化率为零，极值，在二分点，`cos(...)` 取极值，变化率绝对值最大，拐点。日常经验，"夏至前后白天几乎不变长，春分前后白天变长特别快"，与数学描述一致。
- 哲学命题：PRO-04 道三代码自晦意图必复，锚句「"自晦"：代码不会自行揭示意图」日常经验作为「意图」，昼长公式作为「代码」直觉感受的「不均匀」需恢复为「公式 + 导数」才显形。
- 哲学命题：PRO-08 应，锚句「趋势已显现、风险在酝酿、机会在浮现」二分点是昼长变化率的「拐点 = 趋势加速点」，对应应几预判窗口；二至点是「极值点 = 状态最优」，对应应本体安住，无需应变。

### 形式化 {#formalization}

- 设昼长函数 `D : {1,...,365} → R⁺`，日序号 N 为自变量。日常感知给「D 的定性形状」，意图 I，昼长公式给「D 的解析表达」，代码 K：`K = f(I)` 是有损编码：K 含精确数值但 I 含「为何这样」的物理直觉。
- `dD/dN` 是 K 的导数运算结果，但 `dD/dN` 的物理意义，变化率，不在 K 字面中：PRO-04 L17「代码不会自行揭示意图」：必须先恢复 I，春分 / 夏至的物理含义，才能理解「为何变化率在二分点最大」的直觉。
- 二至点，`cos(2π(N-N₀)/365)=0`，：`dD/dN = 0` ： 极值点，状态最优，对应 PRO-08 的「应本体安住」治理在此处无应变动作，与 L9「应本体安住时无应变动作」一致。
- 二分点，`cos(2π(N-N₀)/365)=±1`，：`|dD/dN|` 最大 ： 拐点，变化率峰值，对应 PRO-08 L13「趋势已显现、风险在酝酿、机会在浮现」治理在此处为「应几预判窗口」，预判介入而非立即应变。
- 工程映射中「极值点与拐点的区分」=「应本体安住」vs「应几预判窗口」的区分；「系统性能的峰值不等于性能增长率的峰值」，APP-008 工程映射段，=「应辨当下」≠「应几未来」。
- 可证伪条件：若某观测数据 `D_obs(N)` 在二分点附近显著偏离 `dD/dN` 预测值，变化率被低估，则「应几预判窗口」的判定阈值需上调，PRO-04 的「必复」在「意图 / 模型错误」时触发。

APP-008 的工程映射中「变化率的非均匀性」对应 PRO-08 的「应几 vs 应本体」二分；「从日常经验到数学严格化」对应 PRO-04 的「自晦 → 必复」；「极值点与拐点的区分」对应 PRO-08 的「已形 vs 未形」两相。两条命题共同为「直觉经验 ↔ 导数 / 变化率」的双向量化提供哲学判据。
