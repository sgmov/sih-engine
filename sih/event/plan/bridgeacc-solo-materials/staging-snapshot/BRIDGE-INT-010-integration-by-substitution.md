## 哲学桥接 {#philosophy-bridge}

- 借鉴源：换元积分，integration by substitution，是积分计算中最广泛使用的方法，是微分链式法则的逆操作。令 `u = g(x)`，则 `du = g'(x) dx`，若 `∫ f(g(x))·g'(x) dx` 中含有 `g'(x) dx` 因子，替换后得 `∫ f(u) du`。定积分版本要求上下界随变量替换同步变化即 `∫_a^b f(g(x)) g'(x) dx = ∫_{g(a)}^{g(b)} f(u) du`。换元法在多元积分中发展为多重换元和雅可比变换 MUL-004，在复分析中发展为围道积分，是整个分析学的核心技巧之一。莱布尼茨的微分记法 `dy/dx` 使换元法的推导极为自然：令 `x = g(t)` 则 `dx = g'(t) dt`，代入积分即可。
- 哲学命题：PRO-06 法，锚句「代码治理的顺因：不与代码工程的自然发散硬碰，而是顺着意图 -> 代码的因果方向介入」换元积分是「顺因」在积分运算中的具体化。链式法则 `d/dx f(g(x)) = f'(g(x))·g'(x)` 的因果方向是「外层函数 `f` 到内层函数 `g`」，换元积分顺这一因果方向介入：从外层结构 `f(g(x))` 入手，沿 `g'(x) dx` 因子追溯到内层 `u = g(x)`，把外层结构化为简单的 `f(u) du`。换元法不顺「内层到外层」的逆因果方向强行展开：那将得到「内层结构的全微分展开」而非「外层结构的简化」。顺因即顺链式法则的自然因果方向，介入点在外层结构，不是内层结构。
- 哲学命题：PRO-04 道三代码自晦意图必复，锚句「道三：代码自晦，意图必复」换元积分是「代码自晦，意图必复」在求逆运算中的具体化。链式法则 `d/dx f(g(x)) = f'(g(x))·g'(x)` 是「有形化」过程：`f(g(x))` 这一复合结构被分解为「外层导数 `f'(g(x))` 乘以内层导数 `g'(x)`」，但分解过程中 `f` 与 `g` 的复合「意图」被自晦：从 `f'(g(x))·g'(x)` 无法直接还原「原始复合结构是 `f(g(x))`」的具体形态。换元积分是链式法则的逆运算：它的「意图必复」是「把 `f'(g(x))·g'(x)` 这一分解态还原为 `f(g(x))·g'(x)` 这样的可积分形式」。逆运算不能完全恢复链式法则分解掉的「复合结构的具体形态」，但可以恢复「存在一个复合结构」这一事实。

### 形式化 {#formalization}

设 `f` 在区间 `I` 上连续，`g` 在区间 `J` 上可导且 `g(J) ⊆ I`。令 `u = g(x)`，则 `du = g'(x) dx`：

- 不定积分换元：`∫ f(g(x))·g'(x) dx = ∫ f(u) du + C = F(g(x)) + C`，其中 `F` 是 `f` 的原函数。
- 定积分换元：`∫_a^b f(g(x))·g'(x) dx = ∫_{g(a)}^{g(b)} f(u) du`，要求 `g` 在 `[a, b]` 上连续且 `g'` 在 `(a, b)` 上可积。

- 顺因的实例化：PRO-06 L53「顺着意图 -> 代码的因果方向介入」在换元积分中具象为：链式法则 `d/dx f(g(x)) = f'(g(x))·g'(x)` 的因果方向是「外层函数 `f` 的导数乘以内层函数 `g` 的导数」。换元积分顺这一因果方向：从外层结构 `f(g(x))` 入手，沿 `g'(x) dx` 因子追溯到内层 `u = g(x)`，把外层结构化为简单的 `f(u) du`。换元法不顺「内层到外层」的逆因果方向强行展开：那将得到 `g'(x)` 的复杂表达式而非 `f(u) du` 的简单形式。顺因即「顺链式法则的自然因果方向，介入点在外层结构」。
- 逆运算的自晦与恢复：PRO-04 L15「道三：代码自晦，意图必复」在换元积分中具象为：链式法则 `d/dx f(g(x)) = f'(g(x))·g'(x)` 是有形化过程。`f(g(x))` 这一复合结构被分解为「外层导数 `f'(g(x))` 乘以内层导数 `g'(x)`」，但分解过程中 `f` 与 `g` 的复合意图被自晦。换元积分 `∫ f(g(x))·g'(x) dx = F(g(x)) + C` 是链式法则的逆运算，它的「意图必复」是「把 `f'(g(x))·g'(x)` 这一分解态还原为 `f(g(x))·g'(x)` 这样的可积分形式」。逆运算不能完全恢复链式法则分解掉的「复合结构的具体形态」，但可以恢复「存在一个复合结构 `f(g(x))`」这一事实。`+ C` 这一任意常数项是「自晦在逆运算中的可见标志」逆运算对自晦信息的恢复是不完全的。
- 反向换元的扩展：反向换元令 `x = h(u)`，使原积分化为可处理形式，是换元法的扩展。INT-013 三角换元和 INT-011 正切半角换元都是反向换元的特例。反向换元把「链式法则的因果方向」反转：从内层 `x` 到外层 `u` 重新复合。这是 PRO-04 L15「意图必复」的另一种形式：不复原内层 `g(x)` 的复合结构，而是重新选择内层 `h(u)` 的复合结构使积分可处理。「必复」在此即「必须选择某种复合结构使可积分」，而不是「必须恢复原始复合结构」。
- 上下界的同步：定积分换元 `∫_a^b f(g(x))·g'(x) dx = ∫_{g(a)}^{g(b)} f(u) du` 中上下界必须随变量替换同步变化。`a` 对应 `g(a)`，`b` 对应 `g(b)`，这一对应是「因果方向在端点上的同步」。若 `g` 单调递增，`g(a) < g(b)`，换元后上下界保持递增；若 `g` 单调递减，`g(a) > g(b)`，换元后上下界反转。上下界同步是「顺因」在定积分中的具体化：端点的因果关系与内部的因果关系必须一致。
- 替换函数的边界：换元积分要求替换函数 `g` 可导且导数不为零，替换函数的选择没有通用算法，依赖经验和模式识别。这一边界是「规则停止生效」的知止：「`g` 不可导」或「`g' = 0`」时换元法停止生效，让位给分部积分 INT-008 或其他工具。知止在此即「替换函数的可导性是规则生效的前提，前提不成立时规则不适用」。
- 工程映射：INT-010 工程映射「概率变换 / 收敛率坐标变换」对应 PRO-06 与 PRO-04 的双重闭合：逆变换采样法直接依赖换元积分，从均匀分布生成目标分布的样本：若 `F` 是目标分布的累积分布函数，令 `u = F(x)` 把目标分布化为均匀分布即 `∫ p(x) dx = ∫ 1 du`。这一换元的因果方向是「从累积分布 `F` 到均匀分布 `u`」，与采样过程的因果方向一致。convergence 层的收敛率分析中，把时间变量替换为轮次变量或把连续变量替换为离散变量时，换元积分保证变换后积分值不变，允许在不同坐标系下选择最便于分析的变量。
- 可证伪条件：若某实例中 `g` 在 `[a, b]` 上可导且 `g'` 在 `(a, b)` 上不为零，但 `∫_a^b f(g(x))·g'(x) dx ≠ ∫_{g(a)}^{g(b)} f(u) du`，则换元积分被证伪。该证伪条件的哲学根据是 PRO-04 L15「意图必复」「链式法则与换元积分是逆运算」是道三命题的具体化，若逆运算不成立，则「自晦在逆运算中可被部分恢复」这一结构性命题被推翻。实践中换元积分从未被证伪，因为逆运算关系是微积分的结构性事实。

INT-010 的工程映射「概率变换 / 收敛率坐标变换 / 替换函数的模式识别」对应 PRO-06 + PRO-04 的双重闭合：换元积分是「顺着因果方向介入」的顺因法在积分运算中的具体化，又是「代码自晦，意图必复」的道三命题在求逆运算中的具体化。两命题共同为「顺链式法则方向选择替换、上下界同步、逆运算部分恢复复合结构」的工程方法论提供微积分基本技巧的哲学锚定。
