## 哲学桥接 {#philosophy-bridge}

- 借鉴源：微分是莱布尼茨 1670s 年在微积分中的核心发明，把 `dy` 与 `dx` 视为「无穷小量」并以 `dy/dx` 表示导数；19 世纪 Cauchy 与 Weierstrass 用极限严格化后，`df = f'(a) dx` 被重新定义为「自变量增量的线性映射」。在工程中微分是误差传播与灵敏度分析的标准工具：给定测量误差 `dx`，输出误差 `dy ≈ f'(x) dx`。
- 哲学命题：PRO-05 道四规约与实现必有间隙，锚句「任何有限规约都无法完美表达全部语义意图，语义间隙随确认粒度缩小但不可归零」`df` 正是「有限规约」：线性映射，有限参数；`Δf = f(a+dx) - f(a)` 才是「全部语义意图」：原函数在该点的真实增量。两者的差 `Δf - df = o(dx)` 是「语义间隙」，且 `dx → 0` 时 `Δf - df → 0` 但任意小 `dx` 下残差仍非零，「不可归零」。
- 哲学命题：PRO-05 间隙增长动力学，锚句「任何代码工程在演化过程中，规约与实现的间隙都呈增长趋势」对固定函数 `f`，`Δf - df` 随 `dx` 单调增；当 `dx` 跨越高阶项阈值，`df` 的线性近似迅速失效，对应「规则积累则间隙增速」在微分语境下的具体化。

### 形式化 {#formalization}

设 `f : R → R` 在 `a` 点可导，定义微分 `df(a) : dx ↦ f'(a)·dx` 与实际增量 `Δf = f(a+dx) - f(a)`。

- 规约 vs 实现的形态判定：`Δf = df + o(dx)`，其中 `df = f'(a) dx` 是「规约」即一阶线性部分，`o(dx)` 是「实现」中线性规约未捕获的高阶残差。残差非零当且仅当 `f` 在 `a` 非线性，PRO-05 L125 的「间隙不可归零」在此即为 `o(dx) ≠ 0`。
- 确认粒度与间隙的量化关系：`Δf - df = f''(a) dx² / 2 + O(dx³)`，故残差量级为 `O(dx²)`：`dx` 缩小 10 倍残差缩小 100 倍，对应「随确认粒度缩小」；但任意非零 `dx` 下残差非零，对应「不可归零」。
- 间隙增长的动力学：固定步长 `dx` 不变，演化过程是函数本身在变：若 `f` 在 `a` 附近的二阶信息变化，例如 `f''` 增大，则 `|Δf - df|` 单调增，对应「间隙随时间增大」；当 `dx` 也被作为「规则数」时，规则越多即步长覆盖范围越大，二阶与高阶项累加越快，对应「增大速率与规则数量正相关」。
- 工程映射的可判定判据：误差传播公式 `dy ≈ f'(x) dx` 给出误差上界 `|dy| ≤ |f'(x)| |dx| + O(dx²)`，在 `dx` 满足「确认粒度阈值」时高阶项可忽略；阈值失效时必须用 DIFF-023 Taylor 展开补全高阶项，构成本条「间隙可识别、可记录、不可消除」的可计算闭合。

DIFF-028 微分与 PRO-05 的桥接建立了「线性近似 = 规约 / 实际增量 = 实现 / 高阶残差 = 间隙」的三元闭合，与 DIFF-010 局部线性化同源，但 DIFF-028 强调「规约与实现必有间隙」的本体论结构而非局部逼近的几何意义。
