## 哲学桥接 {#philosophy-bridge}

- 借鉴源:正割立方积分是分部积分法 INT-008 的标准案例。17 世纪莱布尼茨与伯努利家族在建立积分运算系统时,处理了多种 sec^n 形式的积分。sec^3 的结果 (1/2)(sec(x)tan(x) + ln|sec(x)+tan(x)|) + C 通过分部积分的递推机制得到,展示「分」与「合」两步:先把 sec^3 拆为 sec 与 sec^2,分部积分产生含 sec^3 的等式,移项后把 I 用已知量表示。这不是直接积分,而是自指构造:分部积分产生 I = ... - I + 已知项,等式两端都含 I,移项才能解出 I。这种「自己提到自己」的结构是分部积分递推的共性,I_n = sec^{n-2}(x)tan(x)/(n-1) + (n-2)/(n-1) I_{n-2} 是其一般形式。
- 哲学命题:PRO-05 道四规约与实现必有间隙,锚句「道四:规约与实现必有间隙。」分部积分把 sec^3 拆为 sec 与 sec^2 是规约环节:把不可直接积的目标分解为可处理的子问题。移位操作「2I = sec(x)tan(x) + ∫ sec(x) dx」是实现环节:通过代数变形把 I 从「不可见」变为「可见」。两个环节之间是规约与实现的关系：规约侧给出分解方案,实现侧给出最终表达式。规约环节中「用 sec 与 sec^2 凑微分」是有损编码,不是所有高次 sec^n 都能用同样思路拆解;实现环节中「移项 2I = ...」也是有损编码,要求 sec^n 满足 n ≥ 2 的整数次幂,否则公式不成立。两次有损编码累加出 sec^3 积分的公式只在 n=3 这一具体情形下有效,n=4、5 等需要重新进入规约环节。道四的间隙在这里具象为:递推公式 I_n 与 I_{n-2} 之间的连接系数 (n-2)/(n-1) 永远不是 1,每一阶递推都留下不可消除的损耗,最终结果的精确性依赖无穷多阶的全展开,但 n 步的截断永远有 1/(n-1) 量级的余项。
- 哲学命题:PRO-08 应,锚句「司衡之应:应而不藏,应辨当下,应几未来。」分部积分的「分」是应辨当下的具体形态:已知 n 时立即把 I_n 写成 sec^{n-2}·tan + (n-2)/(n-1) I_{n-2},这是当下可执行的动作。移项解出 I 的「合」是应几未来:从递推公式预判 I_3、I_4、I_5 的具体形式,虽然 I_3 需要 INT-018 的辅助,但递推的「几」已经给出明确方向。司衡之应在 sec^3 推导中具象为:应而不藏对应分部积分的中间步骤全部显式写出：u = sec(x)、dv = sec^2(x) dx、du = sec(x)tan(x) dx、v = tan(x) 都不藏不掖;应辨当下对应「2I = sec(x)tan(x) + ∫ sec(x) dx」中立即识别 I;应几未来对应从 I_3 推 I_5 的递推方向。分部积分的「分」是「应」的当下相,「合」是「应」的未来相,两者协同完成 sec^3 公式的构造。

### 形式化 {#formalization}

设 I_n = ∫ sec^n(x) dx,基例 I_0 = x + C、I_1 = ln|sec(x) + tan(x)| + C。

- 间隙作为递推系数:PRO-05 L15「道四:规约与实现必有间隙。」在本条目具象为：递推公式 I_n = sec^{n-2}(x)tan(x)/(n-1) + (n-2)/(n-1) I_{n-2} 中,系数 (n-2)/(n-1) 永远小于 1,这是 n 阶递推到 n-2 阶时的损耗因子。间隙的具体形态:从 n 阶降到 n-2 阶,信息被部分压缩,不是无损转换。当 n = 3 时,系数 (3-2)/(3-1) = 1/2,与 sec^3 推导中「2I = sec(x)tan(x) + ∫ sec(x) dx」的移位结果一致。n 越大,系数越接近 1,损耗越小,但永远不能等于 1。这是道四「双重有损链」的微缩:规约侧的分解(sec·sec^2)不能完美保留原结构,实现侧的移位(2I)也只能解出一半的 I,剩下的部分需要 INT-018 的辅助。间隙不消除,只通过 INT-018 的已知积分被「识别、记录、治理」,即合入最终公式。
- 应辨当下与应几未来:PRO-08 L108「司衡之应:应而不藏,应辨当下,应几未来。」在本条目具象为：应辨当下指分部积分的「分」动作,「分」是已抵达的、可机械执行的当下程序:取 u = sec(x)、dv = sec^2(x) dx,这一步对任何 n ≥ 3 都成立,是当下统一的处理模式。应几未来指递推公式给出的「合」方向,即从 I_n 到 I_{n-2} 的方向,虽然具体表达 I_3、I_5、I_7 需逐次构造,但递推已经把「接下来怎么走」预告清楚。司衡之应在此具体化为:应而不藏在分部积分公示中显式呈现 u、dv、du、v 的选择,以及 tan^2(x) = sec^2(x) - 1 的代入;应辨当下在「I = sec(x)tan(x) - I + ∫ sec(x) dx」中立即辨出含 I 的等式;应几未来在「2I = sec(x)tan(x) + ∫ sec(x) dx」中预判解 I 的具体形式。
- 自指移位的拓扑:分部积分产生的等式 I = u·v - ∫ v·du,当 v·du 中含 I 时成为自指结构,即「I = ... - I + 已知项」。这是分部积分递推的本质,也是 sec^3 推导「2I = sec(x)tan(x) + ∫ sec(x) dx」的结构。自指结构在工程上常见于递归定义、递推求解,在数学上是规约与实现之间的桥：规约侧给出含 I 的表达式,实现侧通过移位解 I。桥的承载是 INT-018 已知的 ∫ sec(x) dx,没有这个辅助项,自指结构无法闭合。这是应-鉴协同的微缩:应侧的「分」需要鉴侧的「已知」,才能形成闭合的自指解。
- 与其他概念的关系:上游 INT-008 分部积分与 INT-018 正割函数积分：本条目依赖分部积分的「分」与 INT-018 的 ∫ sec(x) dx 已知结果。下游 INT-020 弧长：弧长公式中的 sqrt(1 + (f'(x))^2) 在曲线方程涉及 sec(x) 时积分中出现 sec^3。同层 INT-019 与 INT-018 同属 sec^n 积分族,本条目是 n=3 的特例,递推公式是其一般化。
- 边界:本条目只处理 sec^3(x) 的不定积分,sec^4、sec^5 等高次幂需要递推公式的迭代应用,每次迭代都依赖上一阶的已知结果。sec^3 积分在 x = π/2 处有奇点,奇点附近需用广义积分或极限处理,本条目的结果在奇点邻域不直接适用。递推公式的适用域是 n ≥ 2 的整数次幂,n 不是整数时递推框架不成立,这是 sec^n 积分的边界条件。
