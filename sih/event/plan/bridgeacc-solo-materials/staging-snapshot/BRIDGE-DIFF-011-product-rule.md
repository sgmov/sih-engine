## 哲学桥接 {#philosophy-bridge}

- 借鉴源：乘积法则 `(u·v)' = u'v + uv'`，由 Leibniz 17 世纪发现，他最初错误地猜测 `(uv)' = u'v'`，从代码外观自相似于乘积结构「自然延伸」而来，随即发现这是错的，正确形式是「前导后不导加上不导前导」。证明思路：分子加减 `u(x₀)v(x)` 拆分两项极限，数学上是 DIFF-001 导数定义与 DIFF-005 和法则与 DIFF-006 常数因子法则的组合使用；语义上否定了「乘积结构的导数等于导数的乘积」这一朴素类推。
- 哲学命题：PRO-04 道三代码自晦意图必复，锚句「道三：代码自晦，意图必复。」；PRO-05 道四规约与实现必有间隙，锚句「道四：规约与实现必有间隙。」
- 形式化：Leibniz 的初次错误 `(uv)' = u'v'` 是道三自晦的最小实例：代码形态上与「u 提出来求导，v 不动」再「u 不动，v 提出来求导」的朴素类推同构，但「意图」，即「导数是线性算子，作用在乘积结构上需尊重各因子的微分结构」，被「代码外观」，乘积与导数算子的形式相似，吞没；`(uv)' = u'v'` 是「代码」，`u'v + uv'` 是「意图」；Leibniz 立刻识别到错误并恢复正确形式，「意图必复」这一动作发生在他写下错误公式之后而不是之前：错误公式的写下是「自晦」的产出，复原动作必须独立于错误公式的产出，不能用「修正错误公式」的形式实现，只能用「重新推导一次」的形式实现。司衡工程映射：审查产出的「规约」与「实现」之间常出现 `(uv)' = u'v'` 式的错误，= 规约的字面结构掩盖了意图，如「双 facetor 产出乘积的得分应等于各 facetor 得分之积」，= 实现必须用乘积法则，= `u'v + uv'`，而非简单类推；乘积法则的工程意义即「复归意图」回到导数的因果链 `u·v → u'v + uv'`，不顺从「乘积与导数可交换」的字面规约。另一锚 PRO-05 道四规约与实现必有间隙刻画同一条法则的另一个面相：朴素规约「`(uv)' = u'v'`」与真实实现「`u'v + uv'`」之间的间隙 = 一项之差，「`u'v + uv' - u'v' = u'v + uv' - u'v' = u'(v-v') + uv'`」这一非零修正项；道四「必有间隙」= 朴素规约必然漏项，规约系统的「方」与导数算子实际作用的「隅」之间必有不被规约覆盖的空间，乘积法则即「识别、记录、治理」这一间隙的程序化产物：不是消除间隙，是使间隙的形态「`u'v + uv' - u'v'`」被命名、被记录、可被验证。可证伪条件：若某系统声称实现乘积法则但其工程输出与 `u'v + uv'` 不符而与 `u'v'` 相符，则系统处于 PRO-04 失守与 PRO-05 间隙未治理的双重态；治理对治是回到 LIM-007 epsilon-delta 检验各因子的可导性，再回到 DIFF-005 + DIFF-006 + DIFF-001 重新推导，不通过「整体行为近似线性」反推法则正确。
