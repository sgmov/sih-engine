## 哲学桥接 {#philosophy-bridge}

- 借鉴源:海森矩阵以德国数学家路德维希·奥托·海森命名。海森在 19 世纪中叶系统研究了多元函数的二阶微分形式,将二阶偏导数组织为矩阵形式。海森矩阵的出现源于对多元函数极值问题的精确分析需求:单变量函数的极值判别用二阶导数,多元函数的对应工具就是海森矩阵。20 世纪后,海森矩阵在优化理论、微分几何、机器学习、计量经济学中得到广泛应用,二阶优化方法(牛顿法、拟牛顿法)直接依赖海森矩阵或其近似。
- 哲学命题:PRO-05 道四规约与实现必有间隙,锚句「道四:规约与实现必有间隙。」海森矩阵把多元函数 f 的二阶行为「规约」为 H = [∂²f/∂x_i∂x_j] 的对称矩阵,这是双重有损链的具体形态。规约侧是 f 的完整二阶泰勒展开 f(x + h) = f(x) + ∇f^T h + (1/2) h^T H h + O(|h|^3),实现侧是 H 矩阵本身。两次有损编码累加出规约与实现之间的间隙:第一次编码从 f 本身降到二阶偏导数矩阵,信息只保留到二阶,三阶及以上的非线性被丢弃;第二次编码从连续偏导数降到矩阵元素 H_ij,信息又被进一步结构化为有限表格。海森矩阵的对称性 H_ij = H_ji 是「规约侧简化的副产物」Clairaut 定理(Schwarz 定理)让对称性成立,但在 f 不满足二阶偏导连续时对称性破坏,规约与实现之间的间隙显现。道四命题断言「间隙不可消除」,海森矩阵展示了「即使二阶信息完美保留,高阶项仍存在」这一约束。海森矩阵 det(H) = 0 标识规约侧的退化,这是间隙的另一种识别。
- 哲学命题:PRO-08 应,锚句「司衡之应:应而不藏,应辨当下,应几未来。」海森矩阵的执行是「应」的两种时态。已知 x 与 f 立即算出 H(x) = [∂²f/∂x_i∂x_j] 是应辨当下,已抵达的、可机械执行的当下程序。继续预测 H 在整个参数空间的特征值分布(凸性判断),或估计 H 不定时驻点的鞍点/极小值/极大值属性,是应几未来。司衡之应在海森矩阵中具象为:应而不藏对应矩阵元素的显式陈列,每个 H_ij 是二阶偏导数 ∂²f/∂x_i∂x_j 的具体值,不藏「为什么是对称矩阵」的 Clairaut 定理依据;应辨当下对应已知 f 时的立即可计算性;应几未来对应驻点判别(全部正定 → 极小、全部负定 → 极大、混合正负 → 鞍点)的预判。

### 形式化 {#formalization}

设 f(x_1, ..., x_n) 是标量函数,二阶偏导连续。海森矩阵 H 是 n × n 对称矩阵,H_ij = ∂²f / (∂x_i ∂x_j)。

- 间隙作为二阶截断残差:PRO-05 L15「道四:规约与实现必有间隙。」在本条目具象为：f 的泰勒展开 f(x + h) = f(x) + ∇f^T h + (1/2) h^T H h + O(|h|^3) 中,规约侧是二次型 (1/2) h^T H h,实现侧是 f(x + h) 的真实值。两者之差是三阶及高阶项 O(|h|^3),这是道四间隙在二阶局部近似中的具体形态。间隙不消除,只通过减小 |h| 让高阶项落入阈值。det(H) = 0 是间隙的另一种识别：在这一点二次型退化,二阶局部近似不再提供方向信息。间隙的工程化处理是「在 |h| 足够小时用二阶近似,在 H 退化时切换到三阶或全局优化方法」,这是道四的「治理」。
- 应辨当下与应几未来:PRO-08 L108「司衡之应:应而不藏,应辨当下,应几未来。」在本条目具象为：应辨当下指已知 f 与 x 时立即算出 H(x) 的动作,这是机械的、有限步可完成的「当下」。每个二阶偏导数 ∂²f/∂x_i∂x_j 是已抵达的、具体的计算。应几未来指预判 H 的特征值符号,或估计 f 在参数空间中的凸性。如果 H 在整个参数空间正定,则 f 是凸函数,任何局部极小值都是全局极小值;如果 H 不定,则 f 非凸,需要多起点策略或全局优化方法。凸性判断是「几」:还没走遍整个参数空间,但已通过 H 的特征值预告 f 的全局行为。
- 驻点判别作为应-鉴协同:驻点处 ∇f = 0,海森矩阵的特征值决定驻点性质：全部正定 → 局部极小值,全部负定 → 局部极大值,混合正负 → 鞍点。这是「应」与「鉴」协同的微缩:「应」在 ∇f = 0 处处理已抵达的驻点(应辨当下),「鉴」通过 H 的特征值识别驻点的极值类型(鉴的映照)。驻点判别不依赖 H 的具体值,只依赖 H 的定性(正定/负定/不定),这是「映照」的体现：只反映驻点的类型,不投射对驻点值大小的判断。
- 退化检测作为应几:det(H) = 0 标识参数空间的有效维度降低。这是「几」的典型场景:还没到达退化点,但已通过 det(H) 的零值预告 f 在某些方向上的曲率为零。退化是间隙的具体形态：规约侧的信息量减少,实现侧需要重新组织。工程上的拟牛顿法(L-BFGS)用一阶梯度信息近似 H 而绕过直接计算,这是「治理」的另一种策略:不直接消除间隙,而是用低成本近似换取高计算效率。
- 与其他概念的关系:上游 MUL-001 偏导数与 MUL-004 雅可比矩阵：本条目是 MUL-004 一阶雅可比矩阵的二阶推广,海森矩阵 = J(∇f)。下游 MUL-006 曲率与 APP-001 常微分方程：曲率是海森矩阵在曲线/曲面上的几何表现,常微分方程的雅可比方法用海森矩阵的迹与行列式判别临界点类型。同层 DIFF-022 牛顿法：牛顿法 DIFF-022 直接用海森矩阵的逆做二阶收敛迭代。DIFF-018 二阶导数判别法：本条目是单变量二阶导数判别法的多变量推广。
- 边界:海森矩阵只包含二阶信息,三阶及以上的非线性需要更高阶的张量(共变导数、张量场)。海森矩阵的计算成本随 n² 增长,高维问题中直接计算与存储不现实,需要拟牛顿法等近似方法。海森矩阵不处理约束优化,带约束的极值问题需要拉格朗日乘子法或 KKT 条件。
