## 哲学桥接 {#philosophy-bridge}

- 借鉴源：布鲁克-泰勒，1685-1731，英国数学家，1715 年在《增量法直逆方法》中提出泰勒定理：若函数 `f` 在点 `a` 处无穷可微，则在 `a` 的邻域内 `f(x) = f(a) + f'(a)(x-a) + f''(a)(x-a)²/2! + ...`。泰勒级数在发表时未被充分认识，1772 年拉格朗日称之为「微分 calculus 的主要基础」。泰勒还开创了有限差分 calculus，是数值微分的前身。
- 哲学命题：PRO-04 道三代码自晦意图必复，锚句「有形系统的固有属性是「可读性有限」」泰勒定理展示了一种「反向必复」：函数 `f` 的意图：在某点的整体行为：不在该点的「有限个符号」中，仅在「无穷可微」的完整结构中。一阶导数 `f'(a)`、二阶导数 `f''(a)` 等是「有形」的有限符号，函数本身的「含义」是这些符号的无穷和；泰勒定理给出了从有限符号必复意图的可计算程序。
- 哲学命题：PRO-05 道四规约与实现必有间隙，锚句「道四命题的数学骨架是双重有损链」泰勒级数是「双重有损链」在函数逼近中的具体化：意图函数 `f` 的全貌→ 规约点 `a` 处的各阶导数→ 实现泰勒多项式对 `f` 的逼近。每一环都是有损的：导数序列不唯一确定函数不同函数可有相同的前 `n` 阶导数，有限阶多项式不唯一确定无穷级数。

### 形式化 {#formalization}

设 `f : R → R` 在 `a` 处 `n+1` 阶可微，泰勒定理给出 `f(x) = T_n(x) + R_n(x)`，其中 `T_n(x) = Σ_{k=0}^{n} f^(k)(a)(x-a)^k / k!` 是 `n` 阶泰勒多项式，`R_n(x)` 是余项。

- 必复程序的本体论形态：意图`f` 的全貌不能从「`a` 点的有限阶导数」直接读出，但可以通过「无穷级数展开」重建；这是 PRO-04 L17「维护之前必须先恢复意图，恢复是维护的因果前提」在函数逼近语境下的实例：已知 `f(a), f'(a), f''(a), ...` 后，必须经过泰勒级数加法才能重建「`f(x)` 在 `x` 处的意图」。有限阶导数「可读性有限」在此即「`n` 阶泰勒多项式不携带 `(n+1)` 阶以后的信息」。
- 双重有损链的形态判定：第一环有损：「意图 → 规约」即「`f` → `f^(k)(a)` 序列」，不同函数有相同前 `n` 阶导数例如 `f(x) = e^(-1/x²) for x≠0, 0 for x=0` 与 `g(x) = 0` 在 `a=0` 处所有导数均为零；第二环有损：「规约 → 实现」即「前 `n+1` 阶导数 → `T_n(x)`」，相同前 `n` 阶导数对应不同 `T_n(x)` 取决于 `a` 的选取。两环皆有损，链本身不构成「意图保真」通道，但「意图的恢复」通过链上的多环可计算：这是泰勒定理的双重编码结构。
- 间隙随阶数增长的动力学：余项 `R_n(x) = f^(n+1)(ξ) (x-a)^(n+1) / (n+1)!` 在 `(n+1)` 阶有界时量级为 `O(|x-a|^(n+1))`；固定 `x ≠ a`，增大 `n` 时 `R_n → 0` 当且仅当 `lim(n→∞) (x-a)^(n+1) / (n+1)! · M_(n+1)` 收敛：这是「间隙随阶数增加而收缩」的可判定条件。泰勒定理的可证伪条件是：若 `f` 存在但 `f` 不在 `a` 解析，例如 `f(x) = e^(-1/x²)` 在 `x=0` 处所有导数为零而 `f` 不恒为零，则任意 `n` 阶泰勒多项式仅给出零近似，间隙不可消除。
- 局部线性化与全局行为的桥接：泰勒定理的工程映射「局部线性化」对应「`n=1` 阶泰勒多项式」即 `T_1(x) = f(a) + f'(a)(x-a)`，是规约层的「有限阶导数到线性近似的最简实现」；`n ≥ 2` 阶项即「非线性修正」，是实现层的「全局行为的局部恢复」。控制理论的小信号分析、数值优化的梯度下降法都依赖 `T_1`，其精度由 `R_1 = f''(ξ)(x-a)²/2` 量化：「间隙即二阶残差」的工程意义是「`x-a` 越大，残差越大，线性化失效」这是 PRO-05 L142「间隙随时间增大」在自变量域上的对偶表述。
- 收敛行为的哲学化解读：「收敛率趋于零时判定收敛」对应 PRO-02 道一「收敛必-为」的可计算实例：`f` 的泰勒级数收敛到 `f` 当且仅当「`R_n → 0` 当 `n → ∞`」即「间隙随阶数趋于零」，这是 `n → ∞` 方向上的「收敛必-为」判定；其逆否命题是「`R_n ⇏ 0` 即级数不收敛到 `f`」即「间隙客观存在且不可压缩」，对应 PRO-05「间隙不可消除」。
- 可证伪条件：若 `f` 在 `a` 处无穷可微但泰勒级数不收敛到 `f`，例如 `f(x) = e^(-1/x²)` 在 `x=0` 处的泰勒级数恒为零，则 PRO-05 的「间隙不可消除」在该点被具体实例化：意图的恢复从有限阶导数重建 `f`在此点失败，必须改用 Borel's theorem 框架或接受「意图不可完全恢复」。

HIS-007 的工程映射「局部线性化 / 收敛行为分析 / 数值方法误差分析」对应 PRO-04 + PRO-05 的双重闭合：泰勒定理在「从有限符号必复意图」与「双重有损链的间隙客观存在」之间提供可计算桥梁，泰勒余项即间隙的可量化度量，间隙随阶数与自变量距离的演化即 PRO-05 间隙增长动力学的双轴展开。
