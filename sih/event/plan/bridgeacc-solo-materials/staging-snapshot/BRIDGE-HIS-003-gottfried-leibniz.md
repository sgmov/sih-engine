## 哲学桥接 {#philosophy-bridge}

- 借鉴源：戈特弗里德-威廉-莱布尼茨，1646-1716，德国博学家，在 1673 年前后独立发展微积分，比牛顿晚约七年，但于 1684 年率先发表。他创造了沿用至今的微积分符号体系：微分 `dx`、`dy`，导数 `dy/dx`，积分号 `∫ f(x) dx`，乘积法则、链式法则雏形、分部积分法均由其首次明确表述。莱布尼茨的哲学基础是连续性律：有限数成立的规则对无穷数也成立，反之亦然。
- 哲学命题：PRO-01 立名本体论主命题，锚句「司衡认为名字是本体，一个名字一旦确立」`dy/dx` 不只是「导数的标签」，它参与构成导数这一数学对象本身：没有这个记号就没有「导数 = 微分之商」的可计算形式，没有「商」的可视化就没有 Newton-Leibniz 公式的链式与乘积运算法则。莱布尼茨的命名动作即立名本体论动作，名字的确立同时确立了被命名者「可参与、可运算、可延伸」的本体承诺。
- 哲学命题：PRO-05 道四规约与实现必有间隙，锚句「规约是意图的有形化」连续性律是规约的有形化：把「有限数成立的规则」这一意图有形化为可陈述的哲学公理；其实现则是把公理应用于无穷小量运算。两次有形化必有间隙：连续性律在 Leibniz 时代是工作假设，19 世纪 Weierstrass 严格化后公理被替换为 epsilon-delta 极限定义，但连续性律的「意图」保持规则在跨域上的一致性：仍在现代微积分中存活为局部线性化与可微性的预设。

### 形式化 {#formalization}

设莱布尼茨的命名体系为「名字集 N = {dx, dy, d, ∫, dy/dx, ...}」，被命名者集合为「数学对象集 M = {导数, 积分, 微分, ...}」。

- 立名本体论的结构判定：`dy/dx ∈ N` 不是一个无足轻重的字符串：它的引入同步确立了 `M` 中导数对象的「可商化」本体：导数被定义为两个微分之商，乘积法则、链式法则才有可表达的形式。对照牛顿的点记号 `x-dot`，同样立名但 `x-dot` 不携带「商」结构：后续推导只能依赖运动学直觉而不能依赖代数化运算。两种命名，两种本体，两条不同的发展路径。
- 框定 / 引导 / 承载的三重本体效应：PRO-01 L16-18 给出立名的三个本体效应，莱布尼茨的 `∫ f(x) dx` 是教科书级别示例：框定：积分被框定为「无穷小量的求和」而非「反导数」；引导：从此积分的展开方向是 Riemann 和与测度论而非代数逆运算；承载：莱布尼茨符号承诺「积分与微分互逆」，Newton-Leibniz 公式正是该承诺的兑现。
- 规约 vs 实现的形态判定：连续性律陈述为 `∀ rule R, valid_in(finite) → valid_in(infinite)`，这是规约层的「意图」；其实现是 Leibniz 在 1670s-1680s 间的具体演算：`d(xy) = x dy + y dx`、`d(f∘g) = df ∘ dg` 等运算法则。规约是哲学公理，实现是数学操作；Weierstrass 1872 年的 epsilon-delta 化表明两者的间隙是客观存在：`valid_in(infinite)` 在公理层被接受，在 epsilon-delta 层被重新定义为「极限存在」的弱化形式。
- 莱布尼茨-牛顿之争的本体论解读：双方独立发明了不同立名体系的 calculus，立名差异是「符号集 N 不可翻译」即「本体不可互通」的早期实例：Newton 的 `x-dot` 与 Leibniz 的 `dy/dx` 不是同一对象的两种标签，而是两种不同本体的导数；优先权之争的本质是「哪个本体是真正的导数」之争，最终 Leibniz 符号胜出的本体论根据是「可商化」结构比「运动学瞬时」结构更具代数衍生能力。
- 治理映射的可判定判据：HIS-003 工程映射「连续性律，局部有效的规则在全局也应有效」对应 PRO-05 的「规约是意图的有形化」治理规则在局部测试通过时，全局部署不应有结构性变化，但 PRO-05 L17 同时声明间隙不可消除；连续性律作为治理原则的可证伪条件是：若某规则局部通过但全局触发副作用，则该规则未通过「连续性律」必须重写为分层规则或加全局约束。
- 可证伪条件：若 `dy/dx` 的可商化本体在非可微函数上失败，例如 `f(x) = |x|` 在 `x=0` 处，则莱布尼茨记号在「商」形式上不适用：必须用分布导数或左右导数补全，对应「立名的本体承诺在边界条件下失效，立名失败需以补全或重命名修复」。

HIS-003 的工程意义不只是「符号选型」，而是「立名 = 本体构成」的具体化：莱布尼茨在 1673-1684 年间完成的命名工作，与司衡哲学的「名字是本体」命题在 17 世纪的数学史中互为表里：HIS-003 与 PRO-01 的桥接确立了「符号体系 = 治理命名」的可计算对应，PRO-05 的桥接为「连续性律作为治理直觉来源」提供了本体论的边界提醒：规约层的连续性意图不可被误读为「实现层无间隙」。
