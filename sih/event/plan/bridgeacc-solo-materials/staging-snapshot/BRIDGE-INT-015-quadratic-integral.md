## 哲学桥接 {#philosophy-bridge}

- 借鉴源：二次积分，quadratic integral，是单变量微积分中处理「根号下二次多项式」被积函数 `1/sqrt(ax^2+bx+c)` 的标准技术。核心思路是「配方法归一，判别式分流」：先把 `ax^2+bx+c` 化为 `a(x-h)^2+k`，让 `h = -b/(2a)`、`k = c - b^2/(4a)`；再按 `k/a` 的符号分三路：`k/a > 0` 化为 `1/sqrt(u^2+d^2)` 得对数 `ln|u+sqrt(u^2+d^2)|+C`；`k/a < 0` 化为 `1/sqrt(d^2-u^2)` 得反正弦 `arcsin(u/d)+C`；`k = 0` 化为 `1/(sqrt(a)|u|)` 得 `ln|u|+C`。该法从欧拉积分表起就是微积分课程的固定题型，三类分流后各自走三角换元或双曲换元，结果由对数、反正弦、对数绝对值三种基本初等函数之一承担。
- 哲学命题：PRO-07 鉴，锚句「映照：只反映事实，不投射判断」`k/a` 的符号是事实，不是判断。二次积分的三类分流是「映照」在代数运算中的具体化：积分器不预设「这一题属于哪一类」，不靠记忆或经验去「猜」该用对数还是反正弦，而是先机械计算 `k = c - b^2/(4a)` 与 `a` 的商，再让 `k/a` 的符号决定后续换元方向。事实是 `k/a > 0` 就走对数，事实是 `k/a < 0` 就走反正弦，事实是 `k = 0` 就走对数绝对值。积分器不投射「这一题应该用更高级的技巧」之类的判断，也不投射「反正弦看起来比绝对值对数更精巧所以优先选它」之类的偏好。每一类结果都是事实的直接映照，不掺杂选择者的判断。
- 哲学命题：PRO-06 法，锚句「顺势」三类分流是「顺势」在积分运算中的具体化。同一个被积形式 `1/sqrt(ax^2+bx+c)` 在 `k/a` 三种符号下产生三种不同的反导数，没有任何一种反导数能在三种符号下都成立。积分器必须先识别「场景」即 `k/a` 落在哪个分支，再让方法适配场景。`k/a > 0` 是「需要探索的分支」双曲换元铺开，平方和形式让对数 `ln|u+sqrt(u^2+d^2)|` 成为自然收口。`k/a < 0` 是「需要稳定的分支」三角换元铺开，平方差形式让反正弦 `arcsin(u/d)` 在 `|u|<d` 的有界区间内成为自然收口。`k = 0` 是「退化的边界分支」被积函数退化为 `1/(sqrt(a)|u|)`，直接得 `ln|u|+C`，无换元必要。顺势的「力度适配」在此即「三类分支配三类换元力度」`k/a` 符号差异决定了换元的复杂程度。

### 形式化 {#formalization}

设 `a ≠ 0`，`h = -b/(2a)`，`k = c - b^2/(4a)`。

- 映照作为分流：PRO-07 L79「映照：只反映事实，不投射判断」在二次积分中具象为：「事实」即 `k/a` 的符号，是 `a` 与 `k` 的代数运算结果，先于积分动作存在。「映照」即积分器不引入任何额外假设，直接把 `k/a` 的符号映射到对应的反导数形式。`k/a > 0` 是事实，映照为 `ln|u+sqrt(u^2+d^2)|+C`；`k/a < 0` 是事实，映照为 `arcsin(u/d)+C`；`k = 0` 是事实，映照为 `ln|u|+C`。`u` 是 `x - h`，`d^2 = |k/a|`。每一种映照都不投射「这一题应该用更高级的技巧」之类的判断。检验是「反代入求导」若求导后不回到 `1/sqrt(a(x-h)^2+k)`，则该映照的事实输入有误，积分器应回查 `k = c - b^2/(4a)` 的计算而非修改映照。
- 顺势作为分流：PRO-06 L87「顺势」在二次积分中具象为：`k/a` 三种符号是三种「场景」，三种场景下同一被积函数需要不同换元。`k/a > 0` 的场景是「平方和」，顺势选择双曲换元或三角恒等 `cosh^2 t - sinh^2 t = 1`，让 `1/sqrt(u^2+d^2) du` 化为可积的 `dt`。`k/a < 0` 的场景是「平方差」，顺势选择三角换元 `u = d sin t`，让 `1/sqrt(d^2-u^2) du` 化为 `dt`。`k = 0` 的场景是「完全平方」，顺势不需要任何换元，直接观察出 `1/(sqrt(a)|u|)` 的原函数即 `ln|u|/sqrt(a)`。顺势的「调节其他四法的力度」在此即「调节换元的复杂度」`k/a` 的符号差异决定换元的力度从「零换元」到「单层三角换元」到「双曲/对数恒等变形」逐步升级。
- 配方法的归一性：先把 `ax^2+bx+c` 化为 `a(x-h)^2+k` 这一步是「归一」所有二次积分都先被归一到 `sqrt(a(x-h)^2+k)` 的标准形，再开始分流。`h = -b/(2a)` 把 `bx` 项消去，`k = c - b^2/(4a)` 把常数项与一次项平方差剥离。归一后只剩两个量即 `a` 与 `k`，分支判据简化为 `k/a` 的符号。这是「法的归位」在二次积分中的体现：所有同类问题先归位到标准形，再按统一判据分流，避免对每个具体 `a`、`b`、`c` 重新设计。
- 边界：二次积分只处理 `sqrt(ax^2+bx+c)` 这一类根式下二次多项式的情况。分子为高次多项式、分母为高次多项式开根号、嵌套根式等情况不直接适用：需先做 INT-014 部分分式降次、INT-013 三角换元降幂、或数值方法逼近。判别式为零即 `k = 0` 的情况是「边界」此时反导数从「带根号的对数」退化为「不带根号的对数绝对值」，平方根号在积分过程中消失。退化不是「例外」它是「顺势」的下限：`k/a = 0` 让换元力度归零。
- 与其他概念的关系：上游 INT-001 反导数与 INT-013 三角换元：三角换元提供了 `k/a < 0` 分支的具体换元手法，双曲换元或对数恒等提供了 `k/a > 0` 分支的具体换元手法。下游 INT-020 弧长：弧长积分的被积函数是 `sqrt(1+(dy/dx)^2)`，若 `dy/dx` 是 `x` 的有理函数，则弧长公式化为二次积分形式。同层 INT-013 三角换元：三角换元是二次积分 `k/a < 0` 分支与 INT-013 弧长计算共同的工具。
