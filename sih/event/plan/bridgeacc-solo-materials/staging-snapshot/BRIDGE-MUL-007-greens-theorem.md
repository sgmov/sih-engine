## 哲学桥接 {#philosophy-bridge}

- 借鉴源:格林定理以英国数学家乔治·格林命名。格林在 1828 年的自费出版物中提出这一定理,用于解决电磁学中的问题。格林当时是自学成才的磨坊主,工作直到被威廉·汤姆森发现后才获得广泛认可。核心思想:将区域上的积分转化为边界上的积分,可追溯到高斯、柯西、拉格朗日的工作,但格林给出了最清晰的一般表述。格林定理是斯托克斯定理在二维平面的特例,把二维面积积分转化为一维边界积分,是微积分基本定理在二维的推广。
- 哲学命题:PRO-07 鉴,锚句「映照:只反映事实,不投射判断。」格林定理的核心等式 ∮_C (P dx + Q dy) = ∬_D (∂Q/∂x - ∂P/∂y) dA 是「映照」在数学中的具体形态。左侧是边界 C 上 P、Q 的一维线积分,右侧是区域 D 上偏导数差的二维面积积分。两侧之间是事实到事实的对应,没有「判断」或「偏好」的投射。定理不投射「这个线积分比面积分更本质」「边界比区域更基础」之类的形而上学判断,只是把两个等价的事实陈列出来。映照的载体是「等式两边的相等」任何满足连续偏导数条件的 P、Q,等式都机械成立,不需要额外假设或解释。检验的客观性:读者可独立计算等式两边并对比,验证过程只反映计算事实,不投射对格林「如何想到这一定理」的历史叙事。映照也体现在几何直观上:线积分 = 环量,面积分 = 旋度累积,二者是同一物理量(向量场在某区域的旋转总量)的两种「映照」,不互相替代也不互相偏好。
- 哲学命题:PRO-08 应,锚句「司衡之应:应而不藏,应辨当下,应几未来。」格林定理的执行是「应」的两种时态。已知 P、Q 与区域 D 立即算出 ∬_D (∂Q/∂x - ∂P/∂y) dA 是应辨当下,已抵达的、可机械执行的当下程序。继续预测边界 C 的形状变化如何影响线积分,或用线积分直接计算面积,这是应几未来。司衡之应在格林定理中具象为:应而不藏对应等式两边的显式陈列,左侧线积分的每一项 P dx、Q dy 与右侧面积分的偏导数差都显式呈现,不藏「为什么是 P dx + Q dy 的组合」的形式来源;应辨当下对应已知 P、Q 与 D 时的立即可计算性;应几未来对应通过线积分计算面积(取 P = -y、Q = x 时面积 = (1/2)∮(x dy - y dx))的预判,「几」是面积分的几何意义在边界上的预先揭示。

### 形式化 {#formalization}

设 D 是 R^2 中有界闭区域,边界 C 是分段光滑的简单闭曲线,P(x, y)、Q(x, y) 在 D 上有连续偏导数。

- 映照作为线-面对应:PRO-07 L79「映照:只反映事实,不投射判断。」在本条目具象为：等式 ∮_C (P dx + Q dy) = ∬_D (∂Q/∂x - ∂P/∂y) dA 是「事实的映照」,两侧各自独立可计算:左侧只需知道 C 上的 P、Q,右侧只需知道 D 内的偏导数。等式本身是事实,不是判断;它不投射「线积分在数值上比面积分更小」之类的预测,也不投射「P、Q 必须满足某条件才能用格林定理」之类的额外假设(P、Q 在 D 上有连续偏导数是定理的前提,不是定理的判断)。检验的可重现性:任意读者按相同步骤计算等式两边得到同一结果,这一过程只反映计算事实,不含检验者的偏好。映照也意味着「线积分与面积分是同一对象的两种映照,不互相替代」:在物理上,线积分是向量场沿边界的环量,面积分是向量场旋度在区域的累积,二者由 Stokes 定理统一,但在数学上各有独立的计算路径。
- 应辨当下与应几未来:PRO-08 L108「司衡之应:应而不藏,应辨当下,应几未来。」在本条目具象为：应辨当下指已知 P、Q 与 D 立即套用格林定理计算的动作,这是机械的、有限步可完成的「当下」。面积分 ∬_D (∂Q/∂x - ∂P/∂y) dA 可直接化为累次积分,线积分 ∮_C (P dx + Q dy) 可参数化为单变量定积分,二者都是已抵达的、可计算的具体操作。应几未来指通过线积分直接计算面积 A = (1/2)∮_C (x dy - y dx) 的「绕过面积分」策略,这是「几」:还没算出面积,但已预告「边界参数化足以给出面积」。司衡之应在此具体化为:应而不藏在等式两边显式呈现,各项 P、Q、∂Q/∂x、∂P/∂y 都可机械核对;应辨当下在已知 P、Q、D 时立即可算;应几未来在线积分求面积的预判中绕过二维累加。
- 旋度与散度的双重解读:格林定理的两种形式：旋度形式 ∮_C F · dr = ∬_D (∇ × F) · k dA 与散度形式 ∮_C F · n ds = ∬_D ∇ · F dA：是「映照」在向量分析中的具体表现。同一个边界 C 上的积分,通过不同的向量场构造(切向 vs 法向),映照出不同的内部性质(旋度 vs 散度)。这种双重性说明:映照不是「唯一对应」,而是「多对一」,同一个对象可以有多个不同的映照路径。司衡之应在此具体化为:应而不藏在两种形式并置陈列,不藏「为什么旋度与散度形式都成立」的 Stokes 定理统一依据;应辨当下在选定形式后的立即可计算性;应几未来在选择更易计算的形式时的预判。
- 面积计算的边界策略:取 P = -y、Q = x,格林定理退化为面积公式 A = (1/2)∮_C (x dy - y dx)。这是应几的具体场景:在某些情况下,边界 C 的参数化比区域 D 的累次积分更易处理,例如圆、椭圆等简单闭曲线的参数化已知,直接用线积分绕过面积分。这是「治理」的微缩：不直接处理困难(二维累加),而是通过等价变换(线积分)走更简单的路径。等价变换不消除二维累加的复杂度,只是把复杂度转移到线积分上,这是道四间隙的另一种形态。
- 与其他概念的关系:上游 MUL-001 偏导数与 INT-001 反导数：本条目依赖偏导数计算与基本积分运算。下游 MUL-008 散度定理与 MUL-009 斯托克斯定理：本条目是三维 MUL-008 与 MUL-009 在二维的特例。同层 INT-007 微积分基本定理：本条目是一维微积分基本定理的二维推广。MUL-004 雅可比矩阵：格林定理在曲线积分与面积分之间转换时,雅可比行列式给出变量替换的缩放因子。
- 边界:格林定理只适用于平面区域,三维或更高维的类似定理是散度定理 MUL-008 与斯托克斯定理 MUL-009。格林定理要求边界 C 是简单闭曲线,有孔区域需要将内边界以相反方向纳入积分,这是多连通区域的推广。被积函数 P、Q 必须有连续偏导数,在偏导数不连续或有奇点的区域,定理不直接适用,需要更细致的分析。
