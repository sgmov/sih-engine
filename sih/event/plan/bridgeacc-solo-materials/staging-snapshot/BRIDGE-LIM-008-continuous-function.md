## 哲学桥接 {#philosophy-bridge}

- 借鉴源：连续函数是 19 世纪分析严格化运动的核心成果。波尔查诺 1817 年首次用 epsilon-delta 技术定义连续函数，柯西 1821 年《分析教程》独立发展，魏尔斯特拉斯建立最终形式并构造处处连续但处处不可导的函数。形式上 f 在 a 连续当且仅当 lim(x->a) f(x) = f(a)，等价于对任意 epsilon 存在 delta 使 |x - a| 小于 delta 时 |f(x) - f(a)| 小于 epsilon。介值定理、极值定理、有界性定理是三类核心定理。一致连续是更强的全局性质即 delta 不依赖于 a。
- 哲学命题：PRO-07 鉴，锚句「镜的特点是纯粹映照」；PRO-05 道四规约与实现必有间隙，锚句「双重自晦累加 = 规约与实现之间的「间隙」」。
- 形式化：连续函数是 PRO-07 映照在分析学中的最小程序化实例。LIM-008 形式段「对任意 epsilon 存在 delta 使 |x - a| 小于 delta 时 |f(x) - f(a)| 小于 epsilon」= PRO-07 L61「镜的特点是纯粹映照」的具体形态：自变量 x 距 a 小于 delta 即输入的微小变化，函数值 f(x) 距 f(a) 小于 epsilon 即输出的微小变化；epsilon-delta 是「镜」的连续性即 x 在 a 附近时 f(x) 映照 a 附近的函数值 = 「纯粹映照」的程序化；连续函数是「镜」即不主动投射「f(x) 应该等于什么」只反映 f(x) 的实际值与 f(a) 的偏差是否小于 epsilon。LIM-008 应用映射段「系统行为的无跳变保证输入的微小变化不会导致输出的突变」是这一定义的工程版：状态转移函数连续 = 状态转移像「镜」即输入的小变化被映照为输出的小变化。LIM-008 形式段「可导必连续连续不一定可导」= 「映照」与「投射」的分级：可导是更强的映照即不仅连续还保留切线斜率信息，连续是更弱的映照即只保留函数值信息。另一锚 PRO-05 刻画连续性作为间隙在特定点的不存在。LIM-008 形式段「介值定理如果 f 在闭区间 [a, b] 上连续且 f(a) 与 f(b) 符号相反则存在 c 属于 (a, b) 使 f(c) = 0」= PRO-05 L93「双重自晦累加 = 规约与实现之间的「间隙」」的对照形态：连续函数的介值定理是「无间隙」的数学表达即 f 在闭区间上没有跳过任何中间值 = 实现即函数图像紧贴规约即区间上的取值；间断函数则有「间隙」即 f 在某点跳过某些值 = 实现与规约之间出现间隙。LIM-008 历史脉络段「构造处处连续但处处不可导的函数打破了连续即可导的直觉」是「间隙」概念的深化：连续函数在每点都无间隙但「可导性」要求函数在每点有切线即无「方向间隙」；处处连续但处处不可导说明连续性不足以担保方向无间隙 = PRO-05 L93「双重自晦累加」的具体形态：连续是「值间隙」无自晦，可导是「方向间隙」无自晦，两者是不同维度的间隙。LIM-008 形式段「f 在 a 连续当且仅当 lim(x->a) f(x) = f(a)」即极限值等于函数值 = 「间隙」被识别为零即规约 f(a) 与实现 lim(x->a) f(x) 一致。工程映射，司衡治理系统的「系统行为的可预测性」是连续函数的工程版：状态转移函数连续是治理系统行为可预测的数学基础，与 LIM-008 应用映射段「多轮对抗审阅中对抗策略参数空间上的评估函数连续则策略的微小调整不会导致评估结果的跳变」是同一结构：治理系统的输出连续是治理动作可预测的判据，与 PRO-07 L61「纯粹映照：不主动投射」同构。
