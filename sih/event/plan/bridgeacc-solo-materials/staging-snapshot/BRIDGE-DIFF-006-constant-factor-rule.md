## 哲学桥接 {#philosophy-bridge}

- 借鉴源：常数因子法则 `(c·f(x))' = c·f'(x)`，与 DIFF-004 常数导数法则同期被 Newton 流数术与 Leibniz 记号隐含使用，Leibniz 记号 `d(c·f)/dx = c·df/dx` 使这条「提取」操作直观可见；证明依赖极限的线性性，`lim(h→0) c·[g(x+h)-g(x)]/h = c·lim Δg/h`，常数因子 c 与极限运算可交换。本法则是 DIFF-007 线性性定理 `c₁f₁ + c₂f₂` 退化为单加权和的最小特例。
- 哲学命题：PRO-09-infuse 治益核心规约不可变动，锚句「治益：核心规约不可变动：无形之益弥散，约束固化为系统自限」；PRO-07 鉴·客观，锚句「客观：不预设立场，不急于下判断。」
- 形式化：常数因子 c 在 DIFF-006 中扮演「核心规约」「不可变动」不是「c 不动」，DIFF-004 之意，是「c 通过运算后仍是 c」，微分算子 `d/dx` 不改变 c 的值，c 在 `f → f'` 的因果链中保持原样，「约束固化为系统自限」的具体形态。`d(c·f)/dx = c·df/dx` 之中 c 不出现在 `df/dx` 内部但仍以乘法形式外置于结果，「无形之益弥散」= c 在导数表达式中以「乘以 1」的形式弥散，而非作为加性项或函数项被微分算子「吞入」。工程对应：传感器校准系数、安全系数、facet 多 facetor 加权聚合中的权重，常数 c 通过 c·f 这一「乘性外置」结构保证权重不会污染各 facetor 的导数结构，= 权重不进入各 facetor 的局部因果链，仅在聚合出口处相乘，这是司衡治理「治益」结构在数学上的最小表达；权重若改为非常数，即权重随自变量变化，常数因子法则失效，须降级为乘积法则 DIFF-011，对应治理中规约的「不可变动」= 权重 c 是常量 c，「变动」= 权重 c 退化为 c(x)，治理层对应「核心规约」失守，转入「应变」动作论。另一锚 PRO-07 客观刻画本法则的检验形态：`(c·f)' = c·f'` 的成立不预设 f 的具体形态，f 可微 / f 不可微 / f 含跳跃，法则本身「不预设立场」，仅在 f 可微条件下成立；c 是否为常数仅由 c 与自变量 x 的关系判定，= 客观事实，不被 f 的具体选择污染：若某因子被误标为「常数」实则依赖 x，则「不客观」，常数因子法则给出错误结果，对治路径是回到 LIM-007 epsilon-delta 检验 c 的可微性或 c 随 x 的依赖，不通过「整体行为像线性」反推 c 是常数。
