## 1. 立场的机械形态 {#measure-poly-rev1-立场}

总不变量 M-1 至 M-4。

"替换 facet 九发抽样聚合为三层判别模型"若停留在信念，工程上无约束力。本程序把它落成四条可脚本核查的不变量，后续所有批的验收都对照这四条。

M-1 层次唯一归因：三层判别路径可解:解、可测:校准估计加区间、欠定:诚实三态输出必须各有一键复算脚本，且判定性常数阈值、映射规则、判据必须携带数学载体引用加推导档。"工程经验"不作为独立归因层存在：它要么已被数学推导取代，要么被 M-3 冻结登记，不存在第三种"默许的经验"。

M-2 失败三态定位：治理路径上任何失败必须被机械定位为三者之一：数学模型错模型加参数重算不符预期、载体转写错代码实现与载体条目不符，金向量败、实现偏离代码行为与推导档不符。三者各有一键复算脚本，复算不符即该批失败。人不出现在定位链上：人只出现在第 5 节声明的边界条件处。

M-3 不可译不豁免：无可指认载体的机制，不允许停留在"经验运行"态。二选一：清账走资产盘点:得一裁:数学载体管线立新载体，Agent 不代建；涉及哲学:数学新桥的，作为哲学仓演化候选输入上报，不由工程侧立，或冻结加登记行为冻结、入泊界跟踪、带清账路径。冻结是可见状态，不是隐藏回退。

M-4 模型可自证：每个实例化载体必须携可证伪条件与金向量，承 mathfix4 批机械四查的既成纪律：引用命题在册、调用位实存、可证伪节在场、双答结构在场。不可证伪的模型不进管线：这是"替换聚合模型"的自我保护：被相信的对象本身必须可被推翻，否则信任的是权威不是数学。

范畴排除显式声明三项，各有依据，非逃避：

1. 上下文注入装配位不入本程序：意图锚+温故书单+常设约束+断言清单的确定性装配与生成腿读路径是相邻程序，不并入本程序，程序文档中列为指针即可。依据：程序范围清晰边界，避免 scope creep。
2. 数学不裁哲学命题成立性：承 AGENTS.md 数学仓地位节，数学仓只约束数学推理的正确性，哲学仓仍是唯一权威源。本程序的"可解/可测/欠定"判别边界不替代哲学命题，只作机制边界。
3. Agent 不创造哲学命题：M-3 清账路径中新载体若需哲学新桥，停批上报，不由 Agent 代立。

## 3. 分批计划每批单主题，承 SPEC-016；批序在批一账本产出后定稿 {#measure-poly-rev1-分批计划}

批一 · 全量载体覆盖审计纯脚本，零行为变更，可直接立包：

- 输入 facet 全部源码、数学仓 mapping.md 与五子仓 INDEX。
- 产出 覆盖账本，每个机制逐件标三态：已实例化代码引用载体且推导在案、有可指认载体未实例化、无可指认载体；每个判定性常数逐件标注：载体推导 or 裸奔 or 冻结；环境参数登记面初版。全部由脚本生成，零人工填项，脚本可复算。
- 验收 复算逐字节一致；账本与源码 diff 对表零漏项。
- 批一同时回答本程序当前无法回答的问题：不可译机制的规模。在账本出来前，任何"全量大概多少工作"的估计都是虚构，本程序不做该估计。

批二 · 三层判别模型设计核心，优先：

- 层一·可解性判别：命题约束定义算子 T_C，若为压缩映射 TOP-001 Banach 或完备格上单调算子 ORD-002/003 Knaster-Tarski，则真解存在且唯一 KT 极值不动点，由迭代逼出收敛 LIM-007、终止 ORD-011/016。解是算出来的不是测出来的，测量意见在此层无位置；金向量只验转写，解的正确性由推导档承保。
- 层二·校准测量：仅当不可解才测量：y_i = theta + b + epsilon_i。重复测量只压抽样噪声 epsilon PROB-001/003，同族仪器共享偏差 b 不可由重复消九发的数学死因；偏差用已知真解锚集金向量题库测出扣除；先验取自载体，Bayesian 更新 PROB-005 出后验区间 PROB-011；Fano 界 PROB-009 收底：低于信息界输出「不可分辨」，不输出伪共识。
- 层三·异质性分解：总散度 = 抽样噪声可平均消 + 仪器偏差可校准消 + 欠定项信息不在测量里。三成分各有出口：聚合 / 校准 / 申报不可判走人节点或新载体。欠定项非零时加采重跑只增散度不增信息 pk-049 实测即此定理的实证。
- 判别三出口总括：可解:解；可测:校准估计加区间；欠定:诚实三态输出。与 mathpipe M-2 失败三态定位同构，机械定位、人不在定位链上。
- 产出：模型规格文档载体引用 + 推导档 + formula version + 金向量。
- 验收：九发 channel decompose 测量，stable_clear 齐，判据机械复算一致。

批三指针：期票清偿由 mathpipe-a3-solo 完成，见 sih-tools/gauge/CONTRACT.md 0.4.0 版行载明 mathpipe-a3-solo 已于 2026-09-03 落地 ga-2 两张期票。本程序后续批次编号顺延。

批四起 · 逐件实例化批序按批一账本，治理核心优先、已有可指认载者优先：facet 聚合路径接线、探针退役 A/B 门、校准锚集消费面。每批固定四件：载体引用、推导档、代码接线、金向量。需新载体的批停批走清账路径 M-3。

## 4. 失败定位协议"错了只可能是数学模型错"的操作化 {#measure-poly-rev1-失败定位}

批失败时按序执行，每层一键复算：

1. 模型层：输入加模型参数重算预期输出，与实得对表。不符即数学模型错，修模型走载体修订程序。
2. 转写层：金向量跑代码实现，与载体条目对表。不符即载体转写错，修实现。
3. 实现层：代码行为与推导档对表。不符即实现偏离，修代码。

边界条件如实声明：三层全符而批仍失败时，协议出口是申报"模型域缺口"上人节点：这不是三态之外的第四层归因，而是三态定位的失败检测器：它证明当前模型族覆盖不到该现象，处理方式是扩模型族新载体而非归因给经验。人节点裁的是模型alpha 取值、归一化规则、纪元语义这类模型参数选择，不是绕过模型用经验判案；裁定的正确性仍由数学检验，两者不冲突。

## 9. 命题层 {#measure-poly-rev1-命题}

立题立场：本程序的立题是"数学唯一归因：三层判别：工程消费"：司衡判定性常数与判据只能归因于可指认的数学载体，这是审计合法性的来源，触及本体命题的载体归因，不把"只相信数学"当口号，而当作可脚本核查的不变量。

应用命题映射：PRO-07 鉴要求检验由可重复程序承载，M-1 至 M-4 四条可脚本核查的不变量即其应用。A-A3.1 鉴层破自证循环：M-2 失败三态以金向量独立复算证伪实现，不以实现自述替代机械定位；A-A4.1 候选建议生成器：M-3 只产清账或冻结候选，不代立载体；A-A4.2 裁决权归确定性引擎：归因判定由机械复算承载，裁决权不下放给 LLM，唯一的例外是人节点边界条件即人不出现在定位链上。

治理贡献：本程序把"替换聚合模型"落成对人注意力预算的降维：每批验收只对四条不变量，人类只在边界条件介入、不看原始日志，治理贡献即信息洪流降维与权责归一。判据可信度跟可复算载体走，不跟匿名经验走。
