## 五、schema 修订与改道 {#revision}

实现发现冻结 schema 表达不了对表语义即 json 的路径合成与标量裸文本与行位置空、markdown 的多行段落连接与块引用前缀剥离，走 SPEC-009 修订一显式留痕即 tokens 解码形与 name_from 两对象形与 text_form 四对象形与 lines 枚举与字符区间，全部数据驱动零语言特判。因会话允许面为开工时快照，SPEC-009 入域走收约重开一次，期间撞闭包非幂等旧病灶即已删分支使 close 报败，双分支重建后正规收开，台账如实含改道轨迹。

## 六、残余与披露 {#residual}

rust 条目与寻址 code 载体的字节级对表不可得即寻址 code 载体为崩溃源无基准，当前对齐为名与行位级人工核验。impl 名语义有距即泛型参数可先于类型名被取中，语料四件无此形，登记待深阶。词法界即块注释不嵌套与无原始标识符与标识符限 ASCII，语料内零影响。X2 报告的 commonmark 语料外不齐面登记在案即 tab 展开与四空格嵌套表与未闭合短栏等，语料零实证。对表基准依赖寻址现役面即 memory 包 glob 生长，后续批语料数自然变动属常态非缺陷。
