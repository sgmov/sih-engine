## 大白话节

- **本批做了什么（说人话）**：给 MCP 的第一批五个只读工具写了一份「合同书」。查链、验链、扫判据、心跳、看锁，这五样工具以后叫什么名、收什么参数、吐什么结果、出错时怎么把话说清楚，全部一次写死归档。往后写 MCP 代码的批和验收的批，都拿这份合同对表，不许各说各话。
- **为什么只有合同没有代码（说人话）**：alpha 相的原则是只读不写。合同书本身就是本批唯一的产出物，一行 MCP 代码都不写，代码归并行在飞的实装批。
- **怎么算验收过关（说人话）**：找一个完全零背景的陌生 agent，只给它 MCP 接口和一句话任务，它不靠任何人帮忙就能查链验链，且链校验通过，全程记录入档，才算过关。合同里连「怎么算作弊」都写好了：凡是需要人提示才能完成的、链校验不过的、动过仓库文件的，都算红。
- **红线（说人话）**：MCP 面只准看不准写；扫判据的结果只从屏幕读，不许落任何文件；beta 相的写操作必须先过安全模型设计批；引擎自有运行时归 pk-079 那张卡管，本合同不碰。
